# 浏览器自动化：G1–G11 门禁 → 证据对账

**怎么读**：每行给出①设计文档里该门禁的通过标准（摘要）、②**进程内实现**、③**本轮清点出的自动化证据**
（括号内为该测试类的用例数，来自 `[TestMethod]`/`[Fact]` 计数）、④**只能真机/外部判定**的部分、⑤对应 smoke 清单项。
第五列是**唯一的验收入口**：进程内证据不等于通过，外部观察才作数（两段式验收）。

## 本轮对账的发现

1. **G2 的清单覆盖不足（已修）**：设计给了四项标准（同 context 非目标页拒绝 / 撤销·切目标·**跨 frame 身份**拒绝 /
   **子代理不得扩大父授权** / **建关页无残留**），而 smoke 清单 S-02 只登记了两项。
   现已补齐为四项，并加上自动化覆盖声明（`BrowserPageGrant* / ReadOnlyDelegationTests`，覆盖门禁验证类真实存在）。
2. **其余十条都同时具备**：进程内实现 + 至少一个自动化证据类 + 真机缺口**已登记在清单项**里。
3. **"驱动调用数=0"这类计数型标准**在进程内只能断言**被调用方的调用次数**（如 `BrowserControlAuthorityTests`），
   真机上的"CDP 实际发出次数"仍需外部复核 —— 已在 G1/G2 行注明。

## G1–G4 逐条证据（用例名，P0 四条）

"P0 通过之前不默认开启新通道"，所以这四条最值得把**每条标准**钉到**具体用例**。以下用例名都真实存在于仓库。

### G1 控制权

| 标准 | 用例 |
|---|---|
| 接管后新输入步骤数=0 | `Takeover_Blocks_New_Write_Steps` |
| 排队写调用全部拒绝 | `Takeover_Confirm_Makes_Queued_Revalidate_Fail`、`Admit_Before_Handshake_Is_NotConnected` |
| **已派发动作保留事实** | `DispatchedThenDeadline_KeepsTheDispatchFact_AndIsNeverRetried`、`Takeover_And_Pause_Are_Idempotent` |
| 恢复不复活旧租约 | `Resume_Does_Not_Resurrect_The_Pre_Takeover_Lease`、`Resume_Is_Idempotent_When_Nothing_Was_Interrupted` |
| 授权范围内读取可用 | `Takeover_Does_Not_Revoke_Read_Authorization`、`Pause_Blocks_Writes_But_Keeps_Reads` |
| 关闭推进纪元、连接换代失效 | `Close_Advances_Both_Epochs_And_Drops_Every_Permit`、`Connection_Generation_Change_Invalidates_Epochs_Grants_And_Lease` |

### G2 页面授权

| 标准 | 用例 |
|---|---|
| 同 context 非目标页写拒绝 | `Non_Target_Page_In_The_Same_Context_Is_Refused`、`Page_Without_Any_Grant_Is_Refused_For_Read_And_Write` |
| 读授权 ≠ 写授权 | `Read_Grant_Does_Not_Authorize_Writes` |
| 撤销后拒绝（并推进 epoch） | `Revoked_Grant_Is_Refused_And_Advances_The_Grant_Epoch`、`RevokeExecutionScope_Keeps_Read_But_Drops_Write`、`RevokeAllGrants_Drops_Read_And_Write` |
| **跨 frame / 跨身份拒绝** | `Grant_Bound_To_A_Frame_Does_Not_Authorize_The_Top_Document`、`Grant_Bound_To_Another_Desktop_Or_Process_Is_Refused`、`Ref_Is_Rejected_Across_Frames`、`Untrusted_Caller_Is_Refused_Even_With_A_Grant`、`Grant_Bound_To_A_Stale_Generation_Is_Refused` |
| **子代理不得扩大父授权** | `SubAgent_Cannot_Borrow_Its_Parents_Grant`、`SubAgent_Grant_Must_Be_A_Subset_Of_The_Parents_Scope`、`ASubAgentGrantCannotExceedItsParentScope`、`ASubAgentGrantCannotBeIssuedUnderAnExpiredParentGrant`、`RevokingTheParentGrantCascadesThroughGrandchildren` |
| **建关页无残留** | 进程内只证"账本无残留"：`Page_Close_And_Process_Failure_Invalidate_The_Whole_Page`、`Clear_Drops_Everything_Including_Tombstones`、`ExpiredGrantsAreReclaimedSoTheDictionaryDoesNotGrowForever`；**UI/运行时/注册表残留只能真机** |

### G3 回执

| 标准 | 用例 |
|---|---|
| 同文档 fill/select/check verified | `Fill_With_ExpectValue_Matching_Is_Verified`、`Select_Is_Verified_When_The_Observed_Selection_Matches_The_Request`、`Check_Is_Verified_And_The_Boolean_May_Be_Shown`、`Check_Already_Satisfied_Is_Still_Verified` |

### G4 ref

| 标准 | 用例 |
|---|---|
| 同节点只读/fill/滚动后无需重复定位 | `ReadOnly_Calls_Advance_Nothing`、`Ordinary_Dom_Change_And_Viewport_Change_Invalidate_Nothing`、`Host_Liveness_Check_Rejects_A_Detached_Node` |
| 读操作 PageVersion 增长=0 | `ReadOnly_Calls_Advance_Nothing`、`Dom_Mutation_Advances_Only_The_Dom_Revision` |
| 替换节点/跨页/导航后旧 ref 拒绝 | `Ref_Is_Rejected_On_Another_Page_Even_At_The_Same_Document_Generation`、`Document_Commit_Invalidates_Every_Ref_Of_That_Page_Only`、`Frame_Navigation_Invalidates_Only_That_Frame`、`Unknown_And_Revoked_Refs_Are_Reported_Separately` |
| **不点同名替代节点** | `Issue_Requires_A_Host_Bound_Node_Key`、`Ref_Values_Are_Opaque_And_Not_Derivable_From_Role_Or_Name`（身份绑定，而非"按名字找") |
| 三代事实各自推进/组合 | `Document_Commit_Advances_All_Three_Facts`、`Viewport_Change_Advances_Only_The_Viewport_Revision`、`Revision_Transitions_Compose`、`Viewport_Change_Keeps_Identity_But_Stales_Coordinates` |

**结论**：G1–G4 的**每条标准**都能指到至少一个具名用例；唯一例外是 G2 的"UI/运行时/注册表残留"，
进程内不可证、已登记为真机项（S-02）。⇒ "P0 具备进程内证据"这句话现在**可逐条核对**，不再靠印象。

## 诚实边界（诚实登记）

- **用例数是清点值，不是覆盖率**：它只说明"有这些用例存在"，**不证明**标准已被覆盖到；语义覆盖仍需人读用例。
- **本表不构成验收**：G1–G11 的通过与否由**外部观察**判定（进程内证据只用于"内部一侧可交付"）。
- **逐条映射只做到 G1–G4**（P0 四条，见上节）；G5–G11 仍是**类一级**（登记为可继续细化）。
- **真机从未运行**：所有"只能真机"栏的内容都是**未验证**。
- **本表会过期**：代码/清单变化后需重跑对账（无自动门禁把本表与代码绑定，登记为可改进项）。
