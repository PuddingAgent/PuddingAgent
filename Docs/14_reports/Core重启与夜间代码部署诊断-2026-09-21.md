## 实际故障与修复

### 1. 重复 JSON 工具参数击穿整轮执行（已修复并加载）

历史日志 `pudding-error-20260921_001.log` 07:54:25：run `a62286e9daf746b3942123799614372f` 在 `HarnessToolCompatibilityAdapter.TryFind` 抛 `ArgumentException`，重复字段 `pattern`，异常传播到 ExecutionRunCoordinator，整轮失败。

根因：`JsonNode.Parse` 延迟构建 JsonObject 字典，解析成功不代表属性可枚举；仅捕获 Parse 的 JsonException 漏掉首次枚举的重复键异常。重复字段还存在首值/末值解释差异，不能以“删除一个值继续执行”修复。

修复：按每个 JSON 对象检查解码后的属性名，递归覆盖对象和数组；规范化阶段对歧义参数保留原文，不进入 JsonNode 改写。ToolInvocation 与统一 PuddingToolExecution 两个入口在执行/授权消费前返回 `tool_arguments_duplicate_key` 和纠正提示。工具不执行，回合可接收正常的下一次调用，不因单次参数错误熔断会话。

验证：先加5种反例，在旧代码上全部失败（顶层、嵌套、数组、别名、Unicode转义）；修复后该测试类15项通过，包含独立对象同名合法、拒绝后正常调用以及直接统一执行入口。连同分类器接线、Reviewer、健康和Jev单元测试共 **60/60 通过、0 skipped**。独立 DesktopChild 宿主组合根检查 **1/1 通过**。未执行全仓测试，不称“全套全绿”。
