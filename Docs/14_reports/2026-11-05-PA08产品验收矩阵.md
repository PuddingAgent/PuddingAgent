# PA-08 产品验收矩阵（Pass/Fail/NotRun）

结论前缀说明：**Pass** 仅指该行所列离线证据成立；**NotRun** 表示缺少授权、测试环境或真实 provider 配置，未执行；**Fail** 表示执行后失败。本报告不把离线通过当作产品验收通过。

## 1 08A 离线闭环矩阵（任务书 §4）

| 用例 | 状态 | 证据/原因 |
|---|---|---|
| A+B 目标只先交 A：自动评审、续跑补 B、满足后完成，零“继续”消息 | **NotRun** | 需 Goal 状态机接入 PA-03 完成事实（架构决策第 2/3 项）与真实执行链；已有组件级测试（`ReviewJobCoordinator`/`GoalContinuationPolicy`）不等于该闭环 |
| 同内容普通 Chat：一个 Turn，零自动验收/续跑模型请求 | **NotRun** | 需产品执行链与真实模型；组件策略有 Chat 单轮测试 |
| 缺证据却宣称完成：不能通过，展示未满足标准与证据来源 | **NotRun**（组件级 Pass；评审→面板链路离线冒烟通过） | `ReviewResultValidator` 证据不完整测试通过；`ReviewPipelineIntegrationTests` 串通 Job→Worker→outbox→canonical→projection→查询快照；Goal 状态机与真实模型未接 |
| 两 Worker/重复投递/ACK 丢失：幂等 Job/续跑/结算，无重复计费 | **Pass（离线）** | `ReviewJobStoreTests` 租约/revision 围栏、`ReviewBudgetSequencerTests` 一次结算、`EventDeliveryStoreTests` 去重；产品双 Worker 进程未实测 |
| 取消与派发竞争、provider 忽略取消 | **Pass（组件级）** | `DurableBudgetTests` 取消线性化、`ReviewBudgetSequencerTests` 派发后不退款；真实 provider 未测 |
| 预留/派发/结算各断点重启：根预算不清零、Unknown 不自动退款、旧 owner 不能提交 | **Pass（离线）** | `ExecutionBudgetStoreTests` 跨 DbContext、`ExecutionBudgetReconcilerTests` 未知保留；真实进程重启未测 |
| 插件卸载/重载/撤权：无旧 generation 副作用；未排空如实 StopFailed | **NotRun** | 07B 真实 PluginManager 生命周期未接 |
| 前端断线/乱序/过期 cursor：快照恢复一致、无丢终态/伪造成功 | **NotRun** | 08A 面板为只读投影；SSE 恢复/投影端到端未执行 |

## 2 08B 进程外部署与加载证明

> 离线预检脚本 `TestScripts/test-agent-goal-deploy-preflight.ps1` 已可用（记录 revision/工作树摘要/程序集指纹/目标 DataRoot 路径，不部署）；仍不构成部署证明，08B 各项保持 NotRun。

| 项 | 状态 | 原因 |
|---|---|---|
| 源码 revision/WIP hash/构建 manifest/DataRoot 记录 | **NotRun** | 未获部署授权；且工作树含多人 WIP，不可冒充可复现正式包 |
| 隔离 DesktopHome/DataRoot/端口/包目录生命周期验证 | **NotRun** | 同上 |
| Guardian 部署和新包 `healthy`/Core readiness | **NotRun** | 未授权重启产品进程；未使用 Guardian |
| Core/Desktop PID、启动时间、程序路径、构建身份 | **NotRun** | 同上 |
| 前端产物部署进 `wwwroot/admin` 并核对版本徽标 | **NotRun** | 只完成 `pnpm run build`（exit 0），未部署 |

## 3 08C 真实模型与插件 smoke

| 项 | 状态 | 原因 |
|---|---|---|
| 用户选定测试 Agent/Workspace/provider/profile + 有上限根预算 | **NotRun** | 四项输入未提供；不猜配置、不从 `D:\data` 复制 secret |
| 确定性半交付 fixture → 真实模型完成同类任务 | **NotRun** | 依赖上述配置与运行宿主 |
| SDK 触发 + 插件触发各一次；分类 Valid/Abstain/Degraded 如实展示 | **NotRun** | 插件真实加载未接 |
| 暂停/取消/未授权/卸载真实边界 smoke | **NotRun** | 同上 |

## 4 08D 交付报告

| 项 | 状态 | 说明 |
|---|---|---|
| 每条结论附 Work/Goal/Review/Attempt ID、事件序号、配置/模型版本、退出码、provider 用量、产物 hash、构建身份 | **NotRun** | 08B/08C 未执行，无法给出产品态证据 |
| 逐项 Pass/Fail/NotRun 与原因 | **Pass（本文件）** | 本矩阵即 08D 的逐项清单初版 |
| 状态推进 `ready-for-external-deploy` → `in-product-functional-complete` | **NotRun** | 未部署、未加载新构建 |

## 5 本轮可负责的离线事实

- 08A 面板组件/投影/端点/挂载/前端构建全部离线通过（相关 Jest 47/47、tsc、build exit 0；全 chat 套件 186/187 通过，2 项失败为未改动 InputArea 语音用例的既有 WIP/环境问题）。
- PA-01/PA-03/PA-06/PA-07 持久化、协议与适配离线测试通过（详见 S5 核验报告：组件 276 条 + Platform S5 切片 180 条；2026-11-06 已按裁定修正过滤 ACK/扫描/保留/死信、Waiting 与 Review 原子完成，并补投递 lease CAS + Outbox UoW）。\n- 自动化：`TestScripts/test-agent-goal-components.ps1` 实跑 exit 0（隔离 artifacts、逐工程 build+run、失败即停；RunId 20261106-r39 含前端 Jest 47 + tsc）；`TestScripts/test-agent-goal-product.ps1` 未配置时 NotRun(exit 2)，不部署/不读凭据。
- 以上均**不**证明当前产品进程已加载新构建，也不替代 08B/08C。

## 6 解除 NotRun 所需输入

1. 08B：部署授权 + 隔离 DesktopHome/DataRoot/端口/包目录；Guardian 运行方式确认。
2. 08C：测试 Agent、Workspace、provider/profile、根预算上限；允许的真实模型/插件测试范围。
3. 07A/PA-03/PA-01 语义决策（见《剩余 S5 决策请求》）后，才能把组件级 Pass 提升为闭环 Pass。
