# Goal 状态格式与聊天页崩溃修复（2026-09-16）

## 现场与根因

打开聊天页时 `GoalBanner.tsx:357` 抛出 `Cannot read properties of undefined (reading 'color')`。会话 `206a9b48ec904ebb93e7541131fbb835` 的 Goal `658b4fe8f973438d8bd70b659ee9114a` 已耗尽 3/3 轮额度，实际 GET `/api/v1/conversations/{conversationId}/goal` 返回 `phase: budgetexhausted`。

`GoalCommandsController.ToDto` 对枚举执行 `ToLowerInvariant`，把 `BudgetExhausted` 转成了错误的 wire 值。前端契约及颜色表只接受 `budget_exhausted`，所以 `tone` 为 undefined。此问题发生在 React 渲染阶段。

## 修复

- 查询和命令共用的 `GoalCommandsController.ToDto` 用 `JsonNamingPolicy.SnakeCaseLower` 输出状态，统一七种枚举的 API 契约。
- `GoalBanner` 检查状态是否是映射表自有属性；未知状态显示原始值与中性色，仍可查看目标详情，不提供未经识别的状态切换按钮。
- 额度耗尽显示终态、新建与清除入口。没有添加旧拼写兼容分支，也没有修改运行数据。
