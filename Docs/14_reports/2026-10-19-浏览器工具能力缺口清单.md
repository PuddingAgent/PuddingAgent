# 浏览器工具能力缺口清单（`browser_*` 实测）

**测试日期**：2026-10-19（本机）
**证据量级**：约 **120 次** `browser_*` 调用（含 8 页订单遍历、5 类关键词订单检索、3 组截图矩阵、2 轮定位/交互压测）
**标注规则**：**【已证实】**＝有原始回执、可复现；**【未验证】**＝本次未测，不下结论。

---

## 0. 对既有报告的一处更正

此前 `2026-10-19-浏览器工具验收测试报告.md` 记录「截图可见性门**无工具入口可切换标签**」。**该结论错误。**

```
browser_tabs(action=activate, page_id=<搜索页>)   → ok:true
browser_screenshot(同页, low/png)                → 不再报 "requires a visible browser surface"
                                                   而是进入预算检查（228,088 B > 40 KiB）
```

⇒ **`tabs.activate` 存在且有效**，可见性门**有正当绕过路径**。缺口退化为「**错误文案未提示先 activate**」（见 G18）。

---

## 一、定位层

| 编号 | 缺口 | 证据 | 影响 |
|---|---|---|---|
| **G1·P0【已证实】** | `ref` 定位器不可用于交互 | `browser_locate` 返回 `ref=…-v2-n13`；传给 `browser_interact` 必报 `A reference locator must carry the page version the reference came from. (Parameter 'expectedPageVersion')`；locator 内写 `pageVersion` / `expectedPageVersion` / `page_version` 三种均无效，**6/6 失败** | locate 与 interact 契约断裂＝「能看见、点不着」；被迫手写 XPath |
| **G2·P1【已证实】** | 无 `nth` / `index` 参数 | `locate` 命中 5 个「加入购物车」按钮时无法指定第 1 个；翻页拿 ref 又因 G1 不可用 | 必须改用 XPath `(…)[1]` |
| **G3·P1【已证实】** | 不返回 `href` / 属性 / 坐标 | `fields:["boundingBox"]` 恒为 `null`；`a[href*='item.jd.com']` 返回 0 | 拿不到 SKU；无法为 region 截图提供坐标 |
| **G4·P2【已证实】** | `kind=text` 返回 `name` 为 `null` | `locate(text="购物车")` → `{"tag":"a","name":null}`；`locate(role=link, name=…)` 才有 name | 文本定位拿到元素却拿不到可读名，需二次 locate |

## 二、交互层

| 编号 | 缺口 | 证据 | 影响 |
|---|---|---|---|
| **G5·P0【已证实】** | 点击「假成功」：回执 `ok:true, execution:completed` 但页面无变化 | 点导航「我的订单」→ URL 与 `pageVersion` **均未变**，`verification:"not_requested"` | 无法区分「点了没生效」与「点到装饰元素」 |
| **G6·P1【已证实】** | CSS 多匹配报错不可诊断 | `[class*='addCart']` 命中 5 个 → `ui surface failed (BrowserOperationException)`；对照 `css(#key)` 能清晰报 `no element matches` | 误导为「页面坏了」，浪费调用 |
| **G7·P1【已证实】** | 坐标点击被禁止 | `interact(click, x=233, y=691, observation_id=…)` → `locator is required for this action` | 「截图看到的按钮」点不到；视觉打点流程不可用 |
| **G8·P1【未验证】** | `hover` 无实测通路（`select`/`check`/`upload`/`drag` 亦未测） | 本次未测 | 依赖悬浮展开的菜单（JD 卡片加购）可能点不到 |
| **G9·P2【已证实】** | `press` 仅验证单键（Enter） | 组合键/方向键未测 | 键盘导航类操作不确定 |

## 三、读取层

| 编号 | 缺口 | 证据 | 影响 |
|---|---|---|---|
| **G10·P0【已证实】** | `cursor` 不前进（分页坏死） | R3 `nextCursor=lines:29@…` → R4 传同一 cursor 返回**同一 29 行、同一 cursor**；加大 `max_bytes` 只从第 1 行多给（50 行）。**在搜索结果页与订单列表页各复现一次** | 4095 节点页面永远读不到后半段（商品标题正在后半段） |
| **G11·P0【已证实】** | 输出硬顶约 50 行 / 6 KB | 8 页订单页每页只能读首屏 3–5 单；`max_bytes=24000` 仍只回 50 行 | 读全页只能逐屏截图（~140 KB/次） |
| **G12·P1【已证实】** | 商品卡片无 accessible name | AX 树中连续 20+ 个 `link ref=…` 无 `name` | 结构可读、内容不可读，被迫走截图 |
| **G13·P1【已证实】** | `domText` 扫描不完整 | 两次均 `truncationReason: incomplete_scan`，卡在顶部导航 | 文本通道基本失效 |
| **G14·P2【已证实】** | 无 DOM→Markdown / 结构化抽取 | 只有 AX 文本与原始 `domText`；`http_fetch` 对 JD 搜索页返回 **200 + 空 body**（JS 渲染） | 长表格无法低成本结构化 |
| **G15·P2【未验证】** | iframe / shadow DOM 覆盖 | `snapshot` 有 `include_iframes` / `include_shadow_dom` 形参，本次未测 | 若关键模块在 iframe 内会完全读不到 |

## 四、截图层

| 编号 | 缺口 | 证据 | 影响 |
|---|---|---|---|
| **G16·P1【已证实】** | `detail=low` 硬预算 40 KiB，无自动降级 | 搜索页 `228,088 B`、购物车 `93,120 B` 均超 → `LowDetailBudgetExceeded`（**3/3 全败**） | 真实电商页 `low` 不可用 |
| **G17·P1【已证实】** | region 裁剪与坐标互相锁死 | 唯一低成本出路 `scope=region`（实测 `19,443 B` 通过），但 region 需坐标；坐标只能来自 `boundingBox`（恒 `null`）或一张昂贵全图 | **闭环死锁**：要便宜得裁剪→要裁剪得坐标→要坐标得先看贵图 |
| **G18·P2【已证实】** | 必须显式 `activate` 才能截图，错误文案不提示 | 非可见标签 → `Screenshot requires a visible browser surface; open the tool panel and select this browser tab.`（**从未提「可调用 tabs.activate」**） | 每场景多花 1 次试错 |
| **G19·P2【已证实】** | 大图成本高且无分块语义 | `245,231 B / 4 chunks`、`152,040 B / 3 chunks`、`139,009 B / 3 chunks` | 单张截图 ≈ 一次小文档 token 成本 |
| **G20·P2【未验证】** | `full_page` / 长页拼接 | 未测 | 长页面（订单 8 页）无法一次取证 |

## 八、错误语义与可观测性

| 编号 | 缺口 | 证据 | 影响 |
|---|---|---|---|
| **G29·P1【已证实】** | 同一错误码两种语义 | `browser_page_not_found` 既表示「没传页面目标」（`browser.tabs requires an explicit page target`），也表示「目标不存在」（`page target 'ctx/page' was not found in the bridge runtime`） | 排查方向被误导 |
| **G30·P1【已证实】** | `execution_stalled` 误伤只读并行 | 两个并行相同调用 → 第二个被拒：`the same canonical tool call failed twice with an unchanged result` | 压测 / 重试受阻 |
| **G31·P2【已证实】** | 瞬时错误与真实断连不可区分 | 首次截图 `Desktop disconnected`，紧接 `context.list` 正常 | 误判为故障 |

## 九、成本结构（非缺陷，但决定可用性）

| 指标 | 实测 |
|---|---|
| 单轮往返 | **3.35 s**（含模型） |
| 廉价通道 | `context` / `tabs` / `locate` / `wait_for` **< 2.5 KB** |
| 昂贵通道 | 截图 **93–256 KB / 张** |
| 常驻税 | 工具定义 **73,833 tokens**（104 个工具） |
| 同任务冗余 | 购物任务 **34 次调用 / 138 s**，最小充分路径 **9 次 / 40–50 s** ⇒ **3.8×** |

## 十、修复优先级（按可量化收益）

| 优先 | 缺口 | 修法 | 预期收益 |
|---|---|---|---|
| 1 | G1 `ref` 契约 | `interact` 暴露 `expected_page_version`，或让 `ref` 自带版本由工具校验 | 交互成功率 11% → ≥90%；单次点击 8 次 → 1 次 |
| 2 | G10 `cursor` | 让 `cursor` 真正断点续读 | snapshot 有效率 0/5 → 可读全页；省掉 245 KB/次大图 |
| 3 | G5 点击假成功 | 点击后自动做可观测性断言（URL / pageVersion / DOM 变化），否则返回 `unverified` 而非 `ok` | 消除「以为点了」的隐性失败 |
| 4 | G16 / G17 预算与坐标 | 超预算时自动降级为「裁区域 + 回传元素坐标」；同时让 `locate` 返回 `boundingBox` | 截图成功率 36% → ~100%，解开死锁 |
| 5 | G6 / G29 / G30 诊断质量 | 多匹配报 `matched N, use index`；拆分错误码；只读幂等豁免停滞守卫 | 少 2–3 类误导性重试 |
| 6 | G23 / G24 等待能力 | 支持 `text=` 与 `networkidle` | SPA 页面稳定性 |
| 7 | G18 文案 | 错误里直接写「调用 `tabs.activate` 后重试」 | 每场景省 1 次试错 |

## 十一、已验证可用（避免误伤）

`context.list` · `tabs.list/new/activate` · `navigate.goto` · `snapshot(outline)`（受硬顶） · `locate(text/css/role)` · `interact(fill/press/scroll/xpath-click)` · `screenshot(original / region)` · `wait_for(css, url)`

**本次未验证、不下结论**：`hover` `select` `check` `upload` `drag` `tabs.close` `context.close` `full_page` `iframes` `shadow_dom` `cookies` `downloads`。

## 十二、方法说明与边界

- 全部结论来自工具原始回执，未做推测性补全；无回执支撑的项一律标【未验证】。
- 本次压在 **JD 真实电商页 + 本地测试页** 两类目标上，页面复杂度差异极大：本地页截图/定位全绿，JD 页大面积失败 —— **说明缺口主要暴露在「大 DOM + 重脚本」场景**。
- 未修改任何产品代码、未重启、未卸载/安装任何软件；硬件信息仅通过只读 WMI 获取。
- 隐私：涉及的账号页面仅记录到区级地名与商品类目，未记录姓名、详细地址、订单号。
