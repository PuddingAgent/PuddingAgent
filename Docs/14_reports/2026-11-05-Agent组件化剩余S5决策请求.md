## 2 必须由架构师决定的分叉

1. **07A outbox/分发语义**：`IEventOutboxWriter` 的事务边界未定义业务事实如何加入同一事务；`EventReadRequest.StreamId` 与 `SubscriptionGrant`（仅 workspace+kinds）不匹配 —— 事件流以 Workspace 为流，还是以 Conversation 为流？由谁负责把业务事实与 outbox 在同一 DbContext 事务内提交？
2. **PA-03 runtime binder**：评审执行选哪条模型路由（复用 Agent 的冻结路由/专用 review model/purpose policy？）、Job 预算用哪个账本身份（Goal root/Work/独立 review 账户）与 agent/session 绑定从何而来；谁创建 Job 预留（提交方 vs Worker）？
3. **PA-01 消费者迁移范围**：是否允许把 `ExecutionRunCoordinator`/`ExecutionUsageBudgetTracker` 改为异步持久账本（涉及 Runtime 大改与既有测试迁移），或先保留进程内预算、仅用持久账本做跨轮/重启账目？
4. **08B/08C 授权与配置**：是否授权使用隔离 DesktopHome/DataRoot/端口/包目录执行部署与加载证明；真实模型 smoke 需要的测试 Agent、Workspace、provider/profile 与实际有上限根预算由谁提供。
