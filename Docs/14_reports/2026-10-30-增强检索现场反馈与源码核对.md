# 2026-10-30 增强检索现场反馈与源码核对

结论：**支持“部分可用”的现状判定；本次只核对源码并修订设计，没有再次执行产品内检索、部署或模型评测。** 源码核对起点为 `20f45b9`。用户现场结果作为需求输入保留，不能改写成本次独立复测证据。

## 1. 用户提供的现场观察

| 观察 | 证据范围 |
|---|---|
| `workspace_search(auto)` 查 SymbolRefIssuer 返回 4 项，首屏 3 项、带 continuation/overflow | 用户本轮已实测的词面和分页能力，不证明语义召回 |
| `SymbolRefIssuer.Issue` callers 与 open relations 各 8 项 | 用户现场静态关系结果；数量和行号受冻结源码版本约束 |
| 容器零边说明成员未展开；outline 声明跨度恢复；symbol_ref Fresh/Stale/重定位可用 | 已有行为必须作为回归保护，不能为新方案一并重写或删除 |
| `签发符号引用的令牌` 在 auto 下零命中并输出 GenuinelyAbsent/“确实没有匹配项” | 中文概念查询未召回且否定超出已查范围；应转为回归用例 |
| 根注册状态长期 Registering，命中缺 project_id | 需要状态真源与身份补齐；本次未读取运行中数据库验证具体注册记录 |

## 3. 评测时点更正

本地 `Source/PuddingRetrievalEval/eval/reports/` 有 **75 个文件**（包含 README 和不同格式/元数据，不能称为 75 次独立评测）。本次从 JSON 读取 `StartedAtUtc`，共找到 30 份带该字段的运行报告，最新为 `u4-6-root-scope-2026-09-24.json` 的 `2026-09-24T11:41:20.0691730+00:00`，即北京时间 2026-09-24 19:41:20。

该目录最近一次 Git 提交日期为 2026-10-02。用户观察的“10-02 10:20”不能据此当作模型执行时间；文件落盘/检出时间、提交时间与报告运行时间是三个口径。本次未发现能证明 10-30 当前合同/索引语义已复测的报告，故重跑要求成立。后续以报告内运行时间及构建/模型/语料 hash 为准。
