# DS-W01 单轮执行 SDK 示例主代理复核

结论：**主代理复核通过，已完成源码集成，无阻断缺陷，无需返工。** 状态为 `reviewed-and-integrated`，仅覆盖离线 SDK 消费示例，不等同于真实 HTTP、Agent 执行或 Goal/插件功能验收。

## 1 源码与范围

实际读取了任务书及七个交付文件，目录中没有额外文件或构建产物。示例工程只引用 SDK；测试工程只引用示例；没有 Host/Runtime 依赖、凭据读取、在线连接或隐式宿主创建。

`WorkDemo.RunAsync` 的签名、命令数量、严格参数数量、原样透传、错误映射、一次调用约束与任务书一致：

- submit 不自动查询状态、不重试、不生成替代操作 ID；get 不触发提交。
- 空白字段/数量错误/未知命令先返回固定用法，API 零调用。
- 正常回执/快照原样序列化；Failed/Cancelled 仍是成功查询；空 reply 不重写 Completed。
- `AgentWorkException` 仅输出 code、effectOutcome、operationId；unknown 返回 4；调用方取消返回 130；非调用方取消继续抛出。
- Program 始终写固定离线提示并返回 2，不把参数转发到真实 API。

**证据限制更正：**交付报告中的 `git status` 前后对比只能证明路径状态列表变化，不能证明原本已经脏的文件内容从未变化；未跟踪目录合并显示也不能枚举其中所有新增文件。本次确认七个交付文件在白名单内，并独立核对两套核心指纹共 34 个文件；不据此作出“历史上全仓库其他文件绝未写入/读取”的断言。后续需要这种证明时，应在开工时额外保存受保护文件的内容哈希，而不只保存状态列表。
