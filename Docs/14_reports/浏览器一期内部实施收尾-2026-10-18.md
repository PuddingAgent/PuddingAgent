## 3. 已知缺口（登记未掩盖）

1. `DesktopContextInfo` 无 UserDataDirectory ⇒ Bridge 上下文描述符目录为空串；Core 若依赖目录需补来源。
2. `DesktopElementRef` 无 bbox ⇒ locate 结果 bbox 为 null；线缆元素本来也不带 value/selectedValues。
3. tabs 结果经 `FromPageState` 投影，`IsActive/IsAgentTarget` 标志丢失（旧 controller 会带）；需确认 Core 侧不依赖。
4. `page.waitFor` 多条件（旧 runtime 支持）在新能力契约不可表达 ⇒ 显式拒绝；需契约扩展或工具限制。
5. 路由错误码映射是近似表，已用测试锁定；新增能力错误码必须同步。
6. `SessionPermitMarker` 跳过执行器旧授权后，发现类命令依赖页面存在/信任/自动化/版本检查——需真机与组合根集成验证。
7. 生产路径首次真正切换（发现/页面/tabs/context 命令），无真机回归。
