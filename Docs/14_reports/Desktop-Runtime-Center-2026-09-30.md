# WinUI 运行中心诊断与自适应日志

运行中心导航从左下角移到工作台、浏览器之后，启动设置继续位于底部。

状态以图标、中文文字和颜色共同表达：绿色运行中，黄色启动/停止/等待恢复，红色失败或恢复暂停，灰色未启动/已停止。配置和启动失败也保留错误详情，不被定时刷新清除。

诊断包括 Core PID、地址、数据目录、启动耗时、启动时间、运行时长、CPU 和内存工作集。CPU 用单调时钟采样进程累计 CPU 增量，按逻辑处理器数归一化为整机 0–100%；不包含 WebView 或 Core 的其他工具子进程。首次采样、退出或读取失败显示“—”；新 PID 或同 PID 的不同启动时间重置基线。

运行中心采用 Auto / 星号 Grid 行分配空间，移除日志的固定 350 高度和 860 宽度限制。日志显示最近 300 行，按窗口宽度换行，剩余高度用于滚动视口；支持开关跟随最新日志。只在页面和窗口可见时每秒读取指标，日志不变时不重新赋值。

验证采用独立测试与隔离 DesktopHome / DataRoot 生命周期测试，不操作运行中的生产 Core。

- Desktop 回归 **253 / 253 通过**；新增采样测试覆盖整机 CPU 归一化、PID 复用/新进程重置、非法时间间隔、实际进程内存及不可用指标。
- WinUI 普通构建 0 错误；保留既有依赖/编译警告。指标组件先独立回归，再接入界面。
- 实际窗口在 1440×920 与 1000×740 间缩放，自动断言日志宽度、高度同步变化且保有正高度；放大后仍跟随日志底部。真实 Core 的 CPU 与工作集均有读数。
- 最终 smoke：Shell PID `34336`，Core PID `20956 → 43976 → 30772`；独立 Core、工作台、托盘、浏览器、重启、崩溃恢复、退出回收、端口及租约释放全部通过。检查了运行中心内容截图；截图不含系统合成的 Mica，不声称覆盖所有 DPI/系统主题。
- 日志位于 `temp/runtime-center-tests.log`、`temp/runtime-center-build.log`、`temp/runtime-center-smoke.log`，测试产物位于隔离的 `temp/` 输出。未更改用户的运行中实例或 `D:\data`。
