# 浏览器自动化外部 smoke 清单（真机观察项，G1–G11）

## 这是什么

本会话里「真机未验证」的结论散落在二十多条 changelog 中，交接时**无法执行**。本清单把它们收拢成
逐条可做、可勾的观察项，覆盖设计方案的门禁 G1–G11。

**清单内容与代码同源**：`Source/Pudding.DesktopService/BrowserSmokePlan.cs` 是唯一真源，
本页是其渲染结果；有测试（`BrowserSmokePlanTests`）保证两者不漂移、且**每条都必须写着"怎么触发"与"看到什么才算过"**。

**给外部控制器**：进程内的 Agent 只能证明"已加载的成品"，本清单里的每一条都**必须在真机上由外部一方观察**
（这也是为什么每条都标了 `RequiresRealDevice`）。执行完请按 B7 的交付清单流程产出
`external-lifecycle-verified` 结论（`DesktopAcceptance` 会拒绝内部主体作出该结论）。

## 清单

| 项 | 门禁 | 区域 | 怎么触发 | 看到什么才算过 |
|---|---|---|---|---|
| S-01 | G1 | 控制权 | 在测试页上让用户接管，然后尝试一次写入（click/fill） | 驱动调用数 = 0；只读观察仍可用；恢复后旧写租约不复活 |
| S-02 | G2 | 页面授权 | 对同 context 的非目标页发起写入；跨 frame/跨身份再试一次；撤销 grant 后重试；再由父代理签发的子代理尝试扩大授权；最后建页并关闭 | 全部拒绝（帧/身份不匹配也拒绝）；撤销后驱动调用数 = 0；子代理不得扩大父授权；建关页后无残留（标签项/订阅/注册项） |
| S-03 | G3 | 回执 | click 一个纯 SPA 菜单项（不导航、不推进版本） | 不被判失败；回执的 execution/side-effects 与事实一致 |
| S-04 | G4 | 元素引用 | 同一节点连续 20 次只读 + 一次 fill + 普通滚动 | 无需重复定位；读操作不推进 PageVersion；文档导航后旧 ref 被拒且不会点到同名替代节点 |
| S-05 | G5 | 阅读预算 | 中文与英文 SERP fixture 各一次 extract | 一次调用返回前 10 条标题；UTF-8 序列化 ≤ 1536 字节；无额外 locate；**另记录进入模型后的文本 token 与调用次数**（文本与视觉分别记，压缩字节 ≠ token 节省） |
| S-06 | G6 | 正文与分页 | 含标题/列表/表格/代码/链接的结构化 fixture；再跨 TTL 取 cursor | 聚合内容覆盖 100%、不重不漏；超预算仍是合法输出；过期 cursor 明确 cursor_expired；**全文模式必须显式选择**（默认不是全文） |
| S-07 | G7 | 定位与输入 | 十种 locator 矩阵（含 exact/重复/隐藏）；受控输入重渲染；密码字段 | 受控值一致、密码不回显；0×0/禁用/遮挡被拒；一次 fill 回执即可确认非敏感值（**无二次 snapshot**） |
| S-08 | G8 | 滚动 | window 与嵌套容器的非边界滚动 + 滚到边界 + 无限滚动页 | 非边界有真实位移；边界是 no-op（不假称成功）；to_top/to_bottom/to_ref 能停且回报停止原因；无限滚动等新条目后 contentChanged=true |
| S-09 | G9 | 视觉与坐标 | 整页/视口截图；导航过程中再次截图；缩放后使用旧坐标 | 截图与目标一致、导航中不返回旧页；**detail=low 基准 ≤512px/40 KiB（超预算明确 budget_exceeded 或要求局部截图，不无限压缩后仍称可读）；单张输入 ≤8 MiB，超限明确说明原因**（不静默截断/降级）；元数据含源/输出尺寸、设备缩放、CSS viewport、scroll offset、裁剪变换与三代修订号；缩放后旧坐标被拒；**实际模型收到类型化图片**（不是 base64 长串；文本模型得到明确限制）；**窗口隐藏（托盘）后再截一次**：必须给出可判定结果（可用，或明确报不可用），**不得**返回黑图/旧帧冒充成功 |
| S-10 | G10 | 委派 | 父代理持有页面写租约时委派子代理写同一页；再取消/接管/超时 | 父子写租约不并存；子代理**真正**发现并调用 browser_*；父结果 ≤2 KiB 且不含整页；取消/接管/超时都回收许可 |
| S-11 | G11 | 生命周期 | 启停新通道；迟到 CoreReady；断连；桌面隐藏/恢复；跨标签；重启/崩溃/退出 | 订阅不增长；旧会话不复活；断连不双执行；重启/崩溃/退出有外部证据 |
| S-12 | G7 | 输入路径·文件选择器 | 在含 `input[type=file]` 的页面上：① 用工具上传一个真实文件；② 让页面脚本自行触发文件选择框 | ① 上传按 DOM.setFileInputFiles 真实完成（元素收到文件）；② **记录为不支持**——WebView2 SDK 无文件选择器 API，我们不接管页面自弹的选择框，也不假装接管（见驱动里的缺口说明） |
| S-13 | G3 | 页面事件接管与上报 | 同一会话内依次触发：脚本对话框（alert/confirm/prompt）、权限请求、新窗口、下载 | 流程**不被卡住**（对话框被应答、权限被拒、新窗口被抑制、下载被取消）；快照的 `pageEvents` 如实列出这些事实——**有界**（最多保留最近 8 条，按条数截断而非截断文本）、连续重复**合并为 (xN)**、总次数另计；且**不用于继续交互**（它是事实说明，不是新的定位依据） |

## 诚实边界

- **清单不是证据**：它只说明"要观察什么"。本页**不含**任何真机观察结果；所有真机结论仍是**未验证**状态。
- **fixture 依赖**：S-05/S-06 需要 TestSite 的标准 fixture（中文/英文 SERP、结构化长文），
  这些 fixture 的固定尺寸/标题长度属于验收前提，需与 TestSite 一起准备。
- **G11 完全落在外部控制器**：单实例转发与退出回收在进程内不可自证（见 `Agents.md`「验证边界」）。
- **清单会随能力变化更新**：新增能力必须同时更新 `BrowserSmokePlan`（测试会拦住"门禁未覆盖"与"字段缺失"）。
- **未包含性能与并发压测**：设计未提出，故不臆造。
