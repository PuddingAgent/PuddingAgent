# 修改日志（Changelog）使用规则

> 本文件是 `Docs/00Changelog/` 的规则入口。**修改日志类内容只放这里**，不放 `code_map.md`，不放 `Docs/` 根目录，不放 ADR 正文。
> 代码索引规则见根 [`code_map.md`](../../code_map.md) 与 [`Agents.md`](../../Agents.md) 的「code_map.md 使用规则」。

## 1. 什么算「修改日志」

**日志 = 按时间记录「这轮做了什么改动、为什么、验证到哪一步」。** 属于日志的内容：

- 任务执行记录、轮次记录（「第 N 轮」）、阶段进展；
- 提交号/分支清单，测试与门禁数字、性能实测数字；
- 验收结论与留白（做完了什么、什么还没验证）；
- 缺陷排查时间线、根因分析过程；
- 部署、回滚、配置变更记录（含运行时 `D:\data` 配置改动）。

**不属于日志的内容，按性质去别处**：

| 内容 | 去处 |
|------|------|
| 关键概念 / 组件 / 关键文件（相对路径）/ 用途 | 根 `code_map.md`、子项目 `code_map.md` |
| 长期有效、编号的架构决策 | `Docs/07架构/NN ADR-xxx.md` |
| 面向未来施工的设计方案与规格 | `Docs/Features/` |
| 一次性诊断 / 验收 / 评测报告（完整证据） | `Docs/Reports/`、`Docs/QA/` |
| 规程、约定、门禁 | `Docs/Conventions/` |
| 测试与探针脚本 | `Tests/`、`Source/*Tests/`、`TestScripts/` |

> 判据：**「现在是什么」→ 索引/ADR/规格；「什么时候改了什么」→ 日志。**

## 2. 目录结构与命名

```
Docs/00Changelog/
  2026Year/
    09/
      2026-09-12-索引组件拆分落地.md
    10/
      2026-10-02-根code_map迁出历史记录.md
```

- 按 **年 / 月** 两层：`<YYYY>Year/<MM>/`（例如 `2026Year/10/`）。
- 文件名：`YYYY-MM-DD-<主题>.md`，主题用中文短句；**同一天多个主题就写多个文件**，不要把多个主题堆成一个巨型文件。
- 文件名日期 = **写入（记录）日期**，不是被记录事件的日期。
- 批量归档历史材料时，允许 `YYYY-MM-DD-<归档主题>.md` 一个文件装跨日期内容，但必须在文件头写明覆盖范围与来源。

## 3. 文件格式（推荐骨架）

```markdown
# 2026-10-02 <主题>

## 目标 / 背景
为什么做这件事，触发它的问题或裁定。

## 改动
文件级：`相对路径` — 做了什么。新增/迁移/删除分别标注。

## 验证
实际跑了什么（命令、套件、用例数）、结果数字；**没验证就写「未验证」并说明原因**。

## 影响与回滚
配置/数据/部署影响；如何回滚（备份路径、还原命令、需要重启什么）。

## 关联
ADR / 设计 / 报告 / 任务 id / 提交号。
```

硬性要求：**日期主题 + 改了什么（含文件路径）+ 验证状态 + 未完成部分**。其余可简写。

## 4. 强制规则

1. **禁止**把日志写进索引与决策文档：`code_map.md`（根与子项目）、`Docs/README.md`、ADR 正文、`Docs/架构.md`。
2. **禁止**把日志文件放在 `Docs/` 根目录；新日志一律进 `Docs/00Changelog/<YYYY>Year/<MM>/`。
3. 每个原子任务完成后写一条日志，并与该任务的代码改动放在**同一个 commit**（见 `Docs/Conventions/Agents-Hygiene.md`）。
4. **追加式、可更正、不抹除**：已写入的日志不删改历史结论；更正写成「更正（YYYY-MM-DD）：…」。
5. 日志是**摘要**，不是证据仓库：完整证据留在 `Docs/Reports/`、`Docs/QA/`，日志里链接过去，不要复制整份报告或大段代码。
6. 敏感信息（apiKey、ControlToken、用户隐私数据、密钥路径）**不得**写入日志。
7. 引用他人未提交的 WIP 时写明「他方 WIP / 未提交」，不要把未验证内容写成已完成。

## 5. 与其他目录的速查

| 目录 | 放什么 | 时间维度 |
|------|--------|----------|
| `code_map.md`（根/子项目） | 关键概念、组件、关键文件、用途 | 无时间（只描述当前） |
| `Docs/07架构/NN ADR-*.md` | 冻结的架构决策 | 决策生效日 |
| `Docs/Features/` | 设计方案、规格、施工计划 | 面向未来 |
| `Docs/Reports/`、`Docs/QA/` | 诊断/验收/评测报告（证据） | 按事件日期 |
| **`Docs/00Changelog/`** | **修改日志：这轮改了什么、验证到哪** | **按记录日期** |
| `Docs/superpowers/`、`Docs/Tasks/` | 历史设计/任务演进（只读） | 归档 |
