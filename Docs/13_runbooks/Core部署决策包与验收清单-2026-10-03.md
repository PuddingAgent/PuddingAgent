# 5. 一条可执行命令

```
bootstrap_reboot(
  deployment_mode = "desktop-build",
  frontend_mode   = "skip",
  reason          = "把 Core 从 2026-10-01 11:14 产物升级到 HEAD 908edfa（190 提交），接入索引状态面板数据面 /api/admin/index/status 并生效 code_symbol_search 的 index_freshness"
)
```

参数说明（全部有依据，非默认猜测）：

- `deployment_mode=desktop-build`：由 Desktop 停止 Core → 编译 → 事务部署到实际启动目录 →
  校验 `PuddingAgent.dll` SHA-256 → 重启（fail-closed）。
- `frontend_mode=skip`：前端 dist **已构建且已部署并逐位验证**（§1），无需重建，
  避免把前端变量引入这次"后端上电"。默认值就是 `skip`，此处显式写出以便审计。
- 不带 `keep_yolo`：默认**保留**当前模式（不改变运行模式）。
- 不带 `artifact_directory` / `artifact_assembly_sha256`：`desktop-build` 模式由 Desktop 自行编译，
  这两项只在 `prebuilt-artifact` 模式下需要。

**触发后果（须知情）**：本进程会终止并在新 Core 中恢复；所有运行中的子代理会被终止
（P-5 已确认当前没有）；期间服务不可用数分钟。
