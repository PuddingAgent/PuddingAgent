# 每日只读巡检

在目标实例的 `<DataRoot>/config/system.json` 合并以下设置，然后按实例的运行方式重启 Core。将 `WorkspaceId` 指向已启用且未冻结的工作区。

```json
{
  "AutomationSchedules": {
    "HouseInspection": {
      "Enabled": true,
      "WorkspaceId": "default",
      "Cron": "0 8 * * *",
      "TimeZoneId": "Asia/Shanghai"
    }
  }
}
```

- 默认关闭。启用后，从下一次匹配的调度分钟开始生成「每日只读巡检」看板任务，停机错过的分钟会跳过。
- 上面的配置生成待执行任务。需要自动派发时，设置该工作区实际的 `PreferredAgentId`，并确保现有自动派发已覆盖该工作区。巡检读的是实例级运行统计，工作区和执行 Agent 应有相应权限。
- 卡片引用随 Core 分发的 `maintenance/inspect-house.ps1`。脚本检查本实例的数据库、队列、用量聚合和重复错误数量。卡片使用 `-SummaryOnly` 报告错误聚类计数。
- 若到点没生成任务，先检查工作区、时区和 Core 日志中的巡检 Worker 告警。同一配置的重启保留游标。调整工作区、Agent 或时间规则后从新规则的未来时刻开始。
