## 12. 修改后的最低验收

```powershell
dotnet build .\Source\PuddingAgent\PuddingAgent.csproj --no-restore
git diff --check
python .\dev-up.py --restart
```

然后确认：

- 健康检查为 200；
- 针对性测试通过；
- 浏览器唯一消息端到端成功；
- 延迟历史同步后消息仍存在；
- 刷新后消息仍存在；
- 当前启动周期 Error 数为 0；
- `Source/code_map.md` 和相关 ADR 已同步；
- 未覆盖用户已有的无关工作区修改。
