# 工作流与任务图

> **2026-08-09 更新**：任务规划、子代理运行归档和 MOA 计划编译核心已经进入当前架构，
> 不再统一归类为 V3 远期特性。执行状态机、持久化和 Admin UI 仍按阶段落地。

## V1 范围

- 单轮对话：用户消息 → Agent 回复
- 多轮对话：带上下文历史的连续对话
- 工具调用：Agent 在对话中调用工具（进程内执行）
- 动态任务规划：持久化 plan/node、委派深度与子代理任务上下文
- 子代理运行：独立身份、workspace、run archive 与父会话投影
- MOA Phase 1：将设计请求和专家组编译为显式激活、带门禁的只读 DAG

## 当前分层

- 通用任务树负责目标拆分、分配、进度和结果。
- 子代理执行层负责单个成员运行、权限、超时、归档和终态。
- MOA 编排层负责多模型独立提案、交叉批判、法定人数和综合决策。
- Skill 负责识别何时进入工作流，不承担模型路由和运行一致性。

MOA 核心见 [ADR-069](80ADR-069MOA子代理设计委员会编排核心ADR.md)。当前只完成计划编译，
后续执行器必须复用现有 `ISubAgentInvocationService`，不得新建平行的子代理执行引擎。
