## 当前范围

- 单轮对话：用户消息 → Agent 回复
- 多轮对话：带上下文历史的连续对话
- 工具调用：Agent 在对话中调用工具（进程内执行）
- 动态任务规划：持久化 plan/node、委派深度与子代理任务上下文
- 子代理运行：独立身份、workspace、run archive 与父会话投影
- MOA Phase 1–3：编译显式激活的只读 DAG，用纯状态机执行门禁，并通过既有子代理链路按精确模型路由派发
- Agent Orchestration Phase 1：版本化 JSON 图、typed node/control-data edge、纯 DAG 编译器、事件信封和 MOA 模板适配
- Agent Orchestration Phase 1B：版本化组件/触发器注册表、强类型多模态端口、ArtifactRef、contract hash 与独立 GraphLayout
- Agent Orchestration Phase 2A：不可变修订 CAS、持久化 run/node/event、显式激活、原子 claim/fence、过期恢复和游标回放

## 当前分层

- 通用任务树负责目标拆分、分配、进度和结果。
- 通用编排图负责多前驱 DAG、执行门禁、输出可见性、不可变修订和后续持久化调度。
- 子代理执行层负责单个成员运行、权限、超时、归档和终态。
- MOA 模板层负责多模型独立提案、交叉批判、法定人数和综合决策，并编译为通用编排图。
- Skill 负责识别何时进入工作流，不承担模型路由和运行一致性。
