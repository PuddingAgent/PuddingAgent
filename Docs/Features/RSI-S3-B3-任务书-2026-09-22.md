## 3. 已冻结契约（逐字实现，不得另发明）

### 3.1 入口（§2.11 + §2.12）

```csharp
public sealed record RsiScope(
    string WorkspaceId, string AgentInstanceId, string SessionId, string ConversationId);

public interface IRsiTrajectorySource
{
    Task<IReadOnlyList<RsiTrajectory>> GetRecentAnnotatedAsync(
        RsiScope scope, int limit, CancellationToken ct);
}
```

- 查询维度**只用 `ConversationId`**；`WorkspaceId` / `AgentInstanceId` / `SessionId` **只用于盖章**，**不得**参与取数、**不得**被推导（§2.11 三条禁令）。
- ⛔ 不得 join `chat_messages`；⛔ 不得「取第一条」；⛔ 不得用 turn 行的 `workspace_id` 覆盖入参。

### 3.2 新数据访问方法（§2.12.2）

```csharp
Task<IReadOnlyList<string>> GetRecentTurnIdsAsync(string conversationId, int limit, CancellationToken ct);
```

- SQL 形状：`WHERE conversation_id = @c ORDER BY created_at DESC, turn_id DESC LIMIT @limit`（`created_at` 是 **`long` 毫秒**）；
- 返回前在**内存中反转为时间升序**（`turn_id` 是并列时的 tiebreaker）；⛔ 不得只按 `created_at` 排（并列时不确定）。

### 3.3 边界行为（§2.12.4）

| 入参 | 行为 |
|---|---|
| `scope` 为 null | `ArgumentNullException.ThrowIfNull(scope)` |
| `limit <= 0` | 返回 `[]`，**不访问数据库** |
| `scope.ConversationId` 空/空白 | 返回 `[]`，**不访问数据库** |
| 无 turn / 无工具事件 | 返回 `[]` |

### 3.4 组装链（复用，不重写）

`GetRecentTurnIdsAsync` → `GetEventsByTurnIdsAsync(turnIds, eventTypes, ct)` → 按 `TurnId` 分组 → 映射为 B1 的 `RsiTurnSlice`/`RsiEventRow`（**盖章 scope 的三个身份字段**）→ `RsiTrajectoryAssembler.Assemble(...)`。

- `eventTypes` 数组 = `ConversationEventTypes.ToolCallRequested` / `ToolCallCompleted` / `ToolCallFailed`（§2.4；`failed` 照收但不得依赖其出现）；
- slice 顺序 = `turnIds` 的顺序（时间升序）；组内事件按 `Sequence` 升序（装配器内部已保证，但分组时不得打乱）；
- ⛔ 不得在 B3 里重新实现结局判定或用例逻辑（一律复用 B1）。

## 5. 验收标准（机械可验，缺一不算完成）

### 5.2 Runtime 主用例（`RsiTrajectorySourceTests`，用 fake `IRsiTrajectoryDataAccess` 记录调用）
1. **S15（§2.11，必须能红）**：入参 `SessionId` / `AgentInstanceId` 取**故意与任何行都不同的值**，断言输出轨迹这两个字段**逐字等于入参**；
2. 多 turn 分组与顺序：两个 turn 的事件交错返回 ⇒ 断言按 `turnIds` 顺序、组内按 `Sequence` 升序；
3. `limit <= 0` 与空 `ConversationId` ⇒ 返回 `[]` **且 fake 记录到 0 次调用**；
4. 无工具事件（只有 `MessageContentAppended`）⇒ `[]`；
5. 事件类型参数断言 = 三类（`requested` / `completed` / `failed`）；
6. `scope` 为 null ⇒ `ArgumentNullException`。

### 5.3 Platform 执行级证据（`RsiRecentTurnIdsQueryTests`，照抄 `RsiTrajectoryDataAccessTests.cs` 的既有模式）
