## 2. 依赖方向（本项目宪法：每层只管自己的职责）

**允许**：
- 上层业务 → **算子契约**（`PuddingCode.Operators`）
- 算子实现 → 算子契约 + 基类
- 模型适配器 → 模型抽象（`IClassifierModel`）
- 场景算子 → 基类

**禁止**：
- 上层业务 → 具体算子实现
- 算子实现 → 供应商 / HTTP / Jev 协议
- 契约层 → 任何具体供应商
- 契约层 → `Rsi` / `Goal` / `ToolApproval` 任何领域类型
- 场景算子 → 另一个场景算子

**反转点（端口 / 适配器）**：
| 端口（契约层） | 适配器（实现层，S1a 不实现） |

## 3. 契约层（`PuddingCode.Operators`）

### 3.1 枚举与基础记录

```csharp
/// <summary>置信度种类：区分「模型自报」与「已校准」，避免下游把自报值当概率用。</summary>
public enum ConfidenceKind { Unknown = 0, ModelSelfReported = 1, Calibrated = 2 }

/// <summary>分档：把「不确定就升级」变成类型可见，而不是散落的 if。</summary>
public enum JudgementTier { Unknown = 0, Auto = 1, Confirm = 2, Human = 3 }

/// <summary>判断器三值。Abstain 是一等结果，禁止折叠为 Yes/No。</summary>
public enum JudgeOutcome { Unknown = 0, Yes = 1, No = 2, Abstain = 3 }

/// <summary>所有算子的公共输入面。场景上下文实现本接口。</summary>
public interface IOperatorContext
{
    string SceneKey { get; }
    /// <summary>输入身份指纹（用于缓存、审计去重与复现）。</summary>
    string InputDigest { get; }
}

/// <summary>溯源身份四元组（自 ToolCallClassificationContext 提升；不改变其既有定义）。</summary>
public sealed record OperatorIdentity
{
    public required string WorkspaceId { get; init; }
    public required string SessionId { get; init; }
    public required string AgentInstanceId { get; init; }
    public required string UserId { get; init; }
}

/// <summary>一条证据（必须可回溯）。</summary>
public sealed record JudgementEvidence
{
    public required string Kind { get; init; }      // 例 "canonical_event" / "rule" / "source_file"
    public required string Reference { get; init; }  // 例 event_id / ruleId / path:line
    public string? Note { get; init; }
}
```

### 3.2 阈值策略（一等对象）

```csharp
/// <summary>
/// 判断阈值策略。**阈值必须外置**：打分器不得自行决定通过与否，
/// 否则事后无法回答「为什么放行」，且自我改进候选可悄悄移动判据。
/// </summary>
public sealed record ThresholdPolicy
{
    public required string PolicyId { get; init; }
    public required int Version { get; init; }
    /// <summary>score &gt;= 本值 ⇒ Yes（含等于）。</summary>
    public required double YesAtOrAbove { get; init; }
    /// <summary>score &lt;= 本值 ⇒ No（含等于）。</summary>
    public required double NoAtOrBelow { get; init; }
    /// <summary>风险类别（例 high_risk）；影响分档与门槛选择。</summary>
    public string? RiskClass { get; init; }
    public string? SceneKey { get; init; }

    /// <summary>确定性判定：三区间。落在两阈值之间的开区间 ⇒ Abstain。</summary>
    public JudgeOutcome Apply(double score);
}
```

**硬性语义（必须有单测）**：
- `score >= YesAtOrAbove` ⇒ `Yes`（**边界含等**）
- `score <= NoAtOrBelow` ⇒ `No`（**边界含等**）
- 其余 ⇒ `Abstain`
- `YesAtOrAbove <= NoAtOrBelow` 属非法配置 ⇒ 构造/校验期拒绝（**不得**静默产生全 Abstain 或全 Yes）

### 3.3 统一信封 `JudgementEnvelope`（收敛既有 5 个 verdict 的公共核）

```csharp
/// <summary>已应用的阈值（连同结果落库，供事后解释「为什么通过」）。</summary>
public sealed record AppliedThreshold
{
    public required string PolicyId { get; init; }
    public required int Version { get; init; }
    public required double YesAtOrAbove { get; init; }
    public required double NoAtOrBelow { get; init; }
}

public sealed record JudgementEnvelope
{
    // —— 身份与可复现性（缺一不可）——
    public required string JudgementId { get; init; }
    public required string SceneKey { get; init; }
    public required string InputDigest { get; init; }
    public required string OperatorId { get; init; }
    public string? OperatorVersion { get; init; }
    public string? ModelId { get; init; }
    public int? InstructionVersion { get; init; }
    public AppliedThreshold? Threshold { get; init; }
    public required int SchemaVersion { get; init; }

    // —— 结果（按投影填充；同一信封可被三种投影共享）——
    public double? Score { get; init; }
    public string? ScoreScale { get; init; }
    public JudgeOutcome? Outcome { get; init; }
    public string? PrimaryLabel { get; init; }
    public IReadOnlyDictionary<string, double>? LabelDistribution { get; init; }

    // —— 置信（必须带种类）——
    public double? Confidence { get; init; }
    public required ConfidenceKind ConfidenceKind { get; init; }

    // —— 证据与成本 ——
    public required string Reason { get; init; }
    public string? ReasonCode { get; init; }
    public IReadOnlyList<JudgementEvidence> Evidence { get; init; } = [];
    public double? LatencyMs { get; init; }
    public bool Cached { get; init; }

    // —— 溯源 ——
    public OperatorIdentity? Identity { get; init; }
    public IReadOnlyList<string>? SourceEventIds { get; init; }
    public string? SourceSha { get; init; }
    public required DateTimeOffset CreatedAtUtc { get; init; }
}
```

## 4. 实现侧基类

### 4.1 分层（基础设施内 ≤2 层；场景层恰好 1 层）

```
OperatorBase<TCtx, TResult>          ← 基础设施-1：横切（非虚）
   ├── ScorerBase<TCtx>              ← 基础设施-2：固定投影（非虚）
   ├── JudgeBase<TCtx>               ← 基础设施-2：固定投影（非虚）
   └── ClassifierBase<TCtx>          ← 基础设施-2：固定投影（非虚）
          └── <场景算子>              ← 场景层：唯一 1 层
```

### 4.2 `OperatorBase<TCtx, TResult>` 的职责（**全部非虚**，子类不得覆盖）

1. **输入指纹与缓存**：以 `(OperatorId, OperatorVersion, InstructionVersion, InputDigest)` 为键；命中则置 `Cached=true` 并短路；
2. **独立超时与取消**：独立 `CancellationTokenSource`；**取消/超时不得冒泡异常**，转降级结论 + 稳定 `ReasonCode`；
3. **异常兜底**：`ClassifyCoreAsync` 抛出的任何异常 ⇒ 降级结论（对齐既有不变式：**禁止向调用方冒泡异常**）；
4. **模型调用封装**：经 `IClassifierModel`，含重试/预算/采样（S1a 只需接缝与最小实现，**不接真实供应商**）；
5. **健康上报**：成功 / 失败 / 弃权计数（端口由既有 `IClassifierHealthReporter` 体系复用或另立；S1a 只定义接缝）；
6. **审计旁挂（可选）**：**旁挂、失败不影响裁决、失败必留 Warning**。

> ⚠️ **不可回退的既有契约**：审计**不得**成为同步必经环节。现有语义是「**裁决先于留痕**」：审计写入失败不改变已定裁决，只记 Warning（基类若把它提为必经步骤即回退该契约）。
> ⚠️ `OperatorBase` 也**不得**产生既有 `ClassificationVerdict` 形状的耦合——两者并存，不互相引用。

### 4.3 场景算子的 **6 项抽象声明**（编译期强制，缺一不编译）

```csharp
protected abstract string SceneKey { get; }                       // 1
protected abstract OperatorInstruction Instruction { get; }        // 2  (Text + Version)
protected abstract OperatorOutputShape OutputShape { get; }        // 3  (Labels? / ScoreScale?)
protected abstract ThresholdPolicy? Threshold { get; }             // 4  来自 provider，不得硬编码常量
protected abstract string ProjectInput(TCtx context);              // 5  canonical → 结构化片段（确定性）
protected abstract TResult Project(ModelJudgement judgement, TCtx context, OperatorScope scope);  // 6
```

（`OperatorInstruction`、`OperatorOutputShape`、`OperatorScope` 为 S1a 需新增的小记录类型；`OperatorScope` 承载 `OperatorIdentity` + `AppliedThreshold` + 计时 + 取消令牌等运行时上下文。）

**反面约束**：`OperatorBase` **不得**为这 6 项提供默认值（内置默认标签集/默认阈值）——那会让基类变成上帝类、把场景差异压成开关。必须**抽象**。

### 4.4 唯一可变点

```csharp
protected abstract Task<TResult> ClassifyCoreAsync(TCtx context, OperatorScope scope, CancellationToken ct);
```

其余成员一律 `sealed` 或 `非虚`。

## 5. 守卫（把边界变成测试）

### 5.1 单测（xUnit，随项目既有测试工程）
1. `ThresholdPolicy.Apply`：三区间 + **两侧边界含等** + 非法配置被拒；
2. `JudgementEnvelope`：必填字段缺失不可编译（用 `required` 保证，测一个构造样例）；
3. **三投影读同一信封**：同一信封分别投影为 `ScoreResult` / `JudgeResult` / `ClassificationResult`，字段一致；
4. **`Abstain` 不被折叠**：`Apply` 在两阈值之间返回 `Abstain`，且没有任何投影把它变成 `Yes` / `No`；
5. **反脆弱守卫（反射）**：枚举基础设施程序集中所有 `OperatorBase` 派生类型，断言**被覆盖成员 ⊆ 白名单**（6 项声明 + `ClassifyCoreAsync`）；出现额外覆盖即失败；
6. 降级契约：`ClassifyCoreAsync` 抛异常 ⇒ 返回降级结论且**不冒泡**；取消 ⇒ 同上。
