1. **PreCompactionFlush**: 借鉴 Claude Code 的 pre-compaction flush 模式，压缩前用 Flash LLM 快速提取关键事实防止信息丢失 — 设计思路好 ✅

3. **`SanitizeForLlmContext`**: 运行时控制消息过滤 + LLM 序列归一化，在注入 LLM 前的最后一道防线 ✅
4. **`IsRuntimeControlMessage`**: 精确匹配 fuse/recovery/runtime-mode 控制消息，防止运行时指令污染 LLM 上下文 ✅
5. **Health check 先行**: AutoCompact 前先问 `IContextCompactionService.GetHealthAsync`，不盲目压缩 ✅
