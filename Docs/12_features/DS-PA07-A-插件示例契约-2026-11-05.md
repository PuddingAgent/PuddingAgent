# DS-PA07-A 只读审计插件示例契约（冻结）

DS-PA07-A 只消费本文件与 `Source/Pudding.ToolPlugins.AgentSdk/PluginEvents.cs` 的冻结类型；不实现同步 Hook、不执行工具、不发消息、不改 Goal/Review 状态。

## 1 冻结接口（AgentSdk，已编译）

- `IPluginEventObserver.HandleAsync(PluginEventEnvelope envelope, IPluginEventContext context, CancellationToken ct = default)`
- `PluginEventEnvelope`：EventId/StreamId/Sequence/Kind/SchemaVersion/OccurredAt/WorkspaceId/PayloadRef/PayloadHash/Producer，可选 `ReviewCompleted = ReviewCompletedEventPayload(ReviewId, ReviewJobId, Finding, EvidenceLevel, ReasonCode, ReviewRevision)`。
- `IPluginEventContext`：宿主绑定的 `PluginId`、`Generation`、`WorkspaceId` 与 `Audit`；插件不能选择其他 workspace/generation。
- `IPluginAuditApi.RecordAsync(PluginAuditRecord, ct)`：`PluginAuditRecord(OperationId, EventId, ReviewId, Finding, EvidenceLevel, ReasonCode)`；宿主按 OperationId 幂等去重，重复事件返回 `Replayed=true`。
- 错误一律 `PluginEventsException(code, message)`；插件只读写本契约，不接触 Host/DI/数据库。

- `ReviewAuditPlugin.cs`：`namespace Pudding.Samples.Plugins.ReviewAudit`，`public sealed class ReviewAuditPlugin : IPluginEventObserver`。
- csproj：`Microsoft.NET.Sdk` 类库（OutputType=Library）、不显式写 TFM、`IsPackable=false`、仅 ProjectReference `../../../Source/Pudding.ToolPlugins.AgentSdk/Pudding.ToolPlugins.AgentSdk.csproj`、无包。
- test：`MSTest.Sdk/4.0.1`、`OutputType=Exe`、`UseVSTest=false`、仅引用 sample。

## 3 行为契约（逐条）

1. 唯一职责：观察已授权 `review.completed`，把 EventId/ReviewId/Finding/EvidenceLevel/ReasonCode 格式化为一条审计记录，经 `context.Audit.RecordAsync` 输出。
2. 非 `review.completed` 事件，或 `ReviewCompleted` 为 null：**不写审计、零输出、不抛错**。
3. 审计文本固定格式（逐字，`Environment.NewLine` 不使用）：
   `review.completed event={EventId} review={ReviewId} finding={Finding} evidence={EvidenceLevel} reason={ReasonCode}`；`ReasonCode` 缺失/空白时写 `无`。
4. `PluginAuditRecord.OperationId` 固定为 `envelope.EventId`（不得重试换 ID、不得使用新 GUID）；其余字段原样映射，中文原样保留。
5. 每次 `HandleAsync` 恰好调用一次 `RecordAsync`；重复投递同一 EventId 仍使用同一 OperationId（宿主去重，插件不自建状态/缓存/数据库/定时器）。
6. 调用方 `ct` 取消时：不得写入审计（若在调用前已取消），取消异常可向宿主流出；不得吞掉取消后继续写。
7. 不订阅自身审计输出、不发消息、不启动 Review/Goal、不执行工具、不修改 envelope 或 context。
8. manifest.json 只声明 `review.completed` 观察点与 scoped audit 写入，不申请通配权限；示例内容：

```json
{
  "schema": "pudding-tool-plugin/v2",
  "id": "review-audit",
  "name": "Review Audit",
  "version": "1.0.0",
  "description": "Formats authorized review.completed events into one audit record.",
  "sdkApi": "1.4",
  "coreApi": "1.3",
  "runtime": { "framework": "net10.0", "rid": "win-x64" },
  "entry": { "assembly": "ReviewAudit.dll", "type": "Pudding.Samples.Plugins.ReviewAudit.ReviewAuditPlugin" },
  "requestedCapabilities": ["events.observe.review.completed", "audit.record.write"],
  "events": [ { "kind": "review.completed", "schemaVersion": 1 } ],
  "limits": { "executionTimeoutSeconds": 10, "maxConcurrentCalls": 1 }
}
```

> 说明：`sdkApi=1.4`、`events` 与两个 capability 是 07A 冻结的新协议字段；运行时 `PluginValidation` 的接受与 generation/grant 绑定由主代理在 07A S5/07B 接入，本叶任务不得修改 `PluginManager`/`PluginValidation`/`PluginWorker`。

## 4 测试要求

用假 `IPluginEventContext`/`IPluginAuditApi` 覆盖：正常事件映射（含中文）、非 review 事件零输出、ReviewCompleted 缺失零输出、重复事件同一 OperationId（可断言调用两次但 OperationId 相同）、取消不写入、返回/异常语义；不得修改冻结类型或 manifest 之外的运行时文件。

## 5 停止条件

需要修改 AgentSdk/Contracts/运行时 Validation/Manager/Worker、需要真实宿主/插件进程、需要网络或凭据、需要新增 capability 语义实现时立即停止并报告；不得用 catch-all 吞错、不得伪造 `verified`/`replayed` 字段。
