# I2-c 执行统一设计决议：Bridge 页面命令进入工作区执行器

> 状态：proposed（待实施）。本文只定实施口径，不代表已完成；代码事实以当前 HEAD 为准。

## 1. 要解决的问题

ADR-097 D2/方案 §3.3 要求 Bridge 的导航、快照、交互、管理与截图**全部**调用同一个传输无关执行器；当前只做到"准入/账本统一 + 截图走执行器"，页面命令仍由 `BrowserWorkspaceController` 直接执行（方案 §5 的 I2 阻断项）。

## 2. 决议（最小改动、可回滚）

### D1 执行入口唯一

- `BrowserBridgeCommandDispatcher` 保留：协议解码后的**账本**、**会话准入/复检/释放**、活动记录。
- 新增 `BrowserBridgeCommandAdapter`（位于 `PuddingDesktop.WpfArchive/Browser`，可同时看到 Protocol 与 Contracts）：把 `BrowserBridgeCommand`（name + JSON args）映射为 `(DesktopCapabilityDescriptor, DesktopCapabilityRequest)`，并把 `DesktopCapabilityResponse` 映射回既有 Bridge 结果 JSON。
- 适配后调用**工作区执行器**（`DesktopBrowserExecutorComposition.Create` 产物）执行；`BrowserWorkspaceController` 不再作为 Agent 命令执行器，只保留 UI 生命周期/活动/目标状态职责（其 `IBrowserCommandHandler` 仅保留给 WPF 归档与渐进迁移，Bridge 不再使用）。

### D2 准入仍只有一个裁决者

- 会话权威（`BrowserPageLifecycle` + `AgentTargetSessionAuthority`）继续由派发器调用：`Authorize`→`Revalidate`→`Complete`，票据/写世代不复制。
- 执行器对 Bridge 调用**不重复做旧 authority 的 grant/lease 准入**：`DesktopCallContext` 增加宿主注入的 `SessionPermitMarker`（标量、**不上线缆**，与 `BrowserCaller` 同性质）；执行器看到该标记时跳过旧 authority 分支，只做页面存在/信任级/自动化状态/版本检查。标记缺失 ⇒ 按旧路径（能力通道）处理。
- 禁止"派发器判一次、执行器再判一次写租约"：写串行化只由会话权威承担。

### D3 账本仍由派发器唯一拥有

- `BrowserOperationLedger` 继续是 Bridge 唯一去重权威；执行器不新增第二份账本（Automation receipt 账本保持无生产持有者，不接线）。

### D4 通道边界

- 浏览器能力路由**固定 Bridge**（ADR-097 D2）：`TransportRoutedBrowserCapabilitySurface` 对浏览器能力不再因 channel 可用而改道；channel 继续服务非浏览器能力。
- channel 的浏览器 page handler 在迁移期保留但无默认路由；待引用清点后删除旧 grant/lease 路径（先审计 `Source/` 全部生产引用，再删）。

### D5 完成判据（内部侧）

1. 生产组合根（假 driver、channel 关闭/开启两配置）下，八工具命令都经同一执行器执行：断言 driver 调用次数与结果形状，**去掉适配器或执行器接线必红**。
2. 准入配对：无交页拒绝、暂停/接管读成功写失败、切目标旧票据失效、同 operationId 重传不双执行；全部在"经执行器"路径上断言。
3. 没有新增第二套账本/第二套写串行化；源码守卫钉住"派发器不直接调用 controller handler"。
4. 回滚：适配器+接线为一次提交，revert 即回到"controller 直执行"形态（禁止半套混合）。

## 3. 风险与待决

- **映射面大**：八类命令的 JSON↔typed request 映射与结果映射需逐项对表，任何字段丢失都会重演 F4；实施前先加字段哨兵测试（先红再改）。
- **控制器职责收缩**需要 UI 回归（tab 集合、活动、目标状态），建议把"执行"与"UI 事件"解耦后分两次提交：先适配读命令（snapshot/locate/getInfo/waitFor），再写命令与截图。
- `SessionPermitMarker` 属宿主内部字段，**不得**进入 wire/模型参数；实现时加"wire 编码不包含该字段"的测试。
