# B6 接线可执行拆解

**这是什么**：把 [B6 接线方案](B6-子代理委派接线方案-2026-10-08.md) 的"建议顺序"落成**可执行步骤表**，
每步都有：依赖、触及文件、验证方式、**现在能不能做**。
两项待决问题（B1 调用方身份、B4 字节归属）一旦下达，施工即可按步推进，不必重新拆解。

**判定口径**：每步都必须能**独立验证**（跑某个测试项目，或某个可复现命令），不接受"看代码觉得对"。

## 步骤表

| 步骤 | 依赖 | 触及文件 | 验证方式 | 现在可做 |
|---|---|---|---|---|
| S1 组件侧加固：租约账本多页归还 / 只读观察回收 | 无 | `Source/PuddingBrowser.Automation/SubAgentDelegationLeases.cs` | `dotnet test Source/PuddingBrowser.AutomationTests/PuddingBrowser.AutomationTests.csproj --filter SubAgentDelegationLeaseTests` | 已完成（2026-10-08） |
| S2 信封工厂：出站字段映射与工具清单 | 无 | `Source/PuddingBrowser.AgentTools/BrowserDelegationTasks.cs` | `dotnet test Tests/PuddingBrowser.AgentTools.Tests/PuddingBrowser.AgentTools.Tests.csproj --filter BrowserDelegationTasks` | 已完成 |
| S3 有界结论：≤2 KiB、按 UTF-8 字符边界截断 | 无 | `Source/PuddingBrowser.Automation/SubAgentDelegation.cs` | `dotnet test Source/PuddingBrowser.AutomationTests/... --filter SubAgentDelegation` | 已完成 |
| S4 账本行为在**接线前**的边界补齐：超时/取消/接管各自的归还路径 | 无 | `Source/PuddingBrowser.Automation/SubAgentDelegationLeases.cs` | 同上（新增用例：超时与取消都走 `EndDelegation`、接管走 `RevokePage`） | 可做（下一轮候选） |
| S5 只读范围先行：`CanRead=true` 的委派（不写页面）端到端组件级 | 无 | `Source/PuddingBrowser.Automation/BrowserAutomationAuthority.cs` | `AutomationTests`（Authority 与账本联动的用例） | 可做（不含 Runtime 接线） |
| S6 页面 grant 契约**提案**（字段与签发方，**不落地**） | 决定① | 提案文档（`Docs/12_features/`） | 文档门禁 + Core 侧 owner 评审（人工） | 被挡（等决定①） |
| S7 出站接线：Runtime 侧映射 + 期限断言 | 决定①（且 S6 评审通过） | `Source/PuddingRuntime/**`（**他方子系统**） | Runtime 测试 + 委派端到端 | 被挡（需他方 owner + 决定①） |
| S8 入站收窄：父代理只收有界结论（Artifact 引用） | 决定② | 同 S7 | 结论大小断言 + 不含整页断言 | 被挡（等决定②） |
| S9 结线验收：清单 S-10 与第五节 1–5 | S7、S8 | `Docs/14_reports/`（验收记录） | 外部 smoke `S-10` + `delivery-manifest.ps1` | 被挡（依赖前两步） |

**依赖小结**：S1–S5 全部可做且都在我的组件边界内（**5 步已可做，其中 3 步已完成**）；
S6 及以后分别被**决定①（调用方身份/授权签发）**与**决定②（artifact 字节归属）**挡住。

## 不得越界（照抄方案第六节，防施工时走样）

- 不动 `SubAgentTool` 的批量/同步/模型路由语义；不新增第二套执行器。
- 不动 `ISubAgentManager` 既有字段语义（只**新增**可选字段）。
- **不把页面授权交给模型**；不在浏览器侧复刻 Runtime 的授权判定（签发权在 Runtime）。
- **S7/S8 触及 `Source/PuddingRuntime`（他方子系统）**：施工前必须取得该子系统 owner 同意，
  不得单方面改。

## 诚实边界

- **本表是拆解，不是进度**：除 S1–S3 外，其余步骤**未开工**（S4/S5 标为可做但未做）。
- **S6–S9 的"验证方式"是预期**：它们依赖尚不存在的契约字段与 Runtime 接线，届时验证方式可能要调整。
- **"现在可做"不等于"应该现在做"**：S4/S5 的价值取决于决定何时下达；若长期不下达，它们仍能提升组件自证度。
- **不含 B4/B1 本体**：那两块各自另有拆解，本表只覆盖"接线"这一段。
