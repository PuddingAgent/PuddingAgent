# 金融情报信源清单：可靠性与时效的分层取舍

## 0. 一句话结论

**没有任何单一信源能同时满足"可靠"和"及时"。** 成熟系统不追求找齐，而是分层：
**法定披露定事实、官方统计定背景、产业数据定弹性、市场数据定预期**，
然后强制要求"同一结论至少两条相互独立的来源"。

这与已安装的 `a-share-equity-research` 技能的 P0–P4 层级一致，本文把它落到可采购、可接入的清单上。

## 1. 四层信源与分工

### L1 法定披露层（唯一可以当"事实"用的层）

| 来源 | 提供 | 时效 | 获取方式 |
|---|---|---|---|
| 巨潮资讯网 cninfo | 沪深北全部定期报告、临时公告、问询函 | 公告即时 | 网页/公开接口 |
| 上交所 / 深交所 / 北交所 | 同上 + 监管措施、纪律处分 | 即时 | 网页 |
| 证监会 | 行政处罚、立案调查、行政许可 | 即时 | 网页 |
| 中国货币网 / 上清所 | 债券发行、评级、违约 | 即时 | 网页 |

**用法纪律**：L1 是"是什么"，不是"好不好"。公告原文必须自己读，媒体转述只能当线索。
判定造假需要监管认定，公告异常只能写"异常/待解释"。

### L2 官方统计与政策层（定背景、定方向）

| 来源 | 提供 | 时效 | 备注 |
|---|---|---|---|
| 国家统计局 data.stats.gov.cn | 工业增加值、PPI/CPI、产量、投资 | 月度 | 有公开数据接口 |
| 海关总署 | 分商品/国别进出口量额 | 月度（滞后约 3 周） | 口径与协会数据常不一致 |
| 财政部 / 人民银行 | 财政收支、社融、利率、汇率 | 月度/日度 | 社融是需求侧领先指标 |
| 国家能源局 | 煤电油气产量与消费 | 月度 | 能源链的物理量基准 |
| 发改委 | 产业政策、价格机制、核准项目 | 不定期 | 官网有文件库与政策解读 |
| 工信部 | 行业规范、产能置换、规划 | 不定期 | 官网设"政策文件/政策解读"专栏 |

**已验证事实（2026-10-25 抓取）**：工信部 2026-10-22 印发《产业基础能力提升"十五五"规划》；
发改委同期发布《能源保供中长期合同管理办法（试行）》（2026 年第 50 号令）。
说明这类规划/办法往往**同时改变多个行业的供需假设**，是"预期差"的高发点。

### L3 产业与大宗层（定弹性、定拐点）

这是**最难替代、也最容易买错**的一层。

| 来源 | 覆盖 | 特点 |
|---|---|---|
| 上海钢联 Mysteel | 黑色、有色、能源化工、建材、农产品 | 官方披露"百万余条指标、2.1 亿个数据、约 10 万家样本库企业"；与国家统计局共同编制 MyBCIC 等指数；通过 IOSCO 认证 |
| 卓创资讯 / 生意社 | 化工、能源、农产品 | 现货价、开工率、库存 |
| 长江有色 | 铜铝锌锡现货与冶炼 | 有色金属专项 |
| 行业协会（钢协、棉花协会等） | 产量、库存、开工率 | 免费但滞后、口径常变 |
| 国际：USDA / IEA / LME / ICSG | 全球农产品、能源、有色供需 | 影响全球定价的锚 |

**一个有力的旁证**：上海期货交易所自己的市场研究报告在图表下标注"数据来源：钢联数据"
（详见 `shfe.com.cn` 的 2024 上半年钢铁市场回顾 PDF）。**交易所引用第三方产业数据**，
说明 L3 的权威性来自采样与审计，而不是来自"官方"身份。

### L4 市场与舆情层（定预期、定位置）

| 来源 | 提供 | 用途 |
|---|---|---|
| 交易所行情与成交量 | 价格、量、换手 | 判断"信息是否已计价" |
| 龙虎榜、资金流向 | 席位与主力行为 | 只作线索，不作结论 |
| 券商研报 / 一致预期 | 市场基准预期 | **必须注发布日期**，否则"预期"变成幻觉 |
| 互动易 / 投资者关系问答 | 公司口径的即时回应 | 敏感但非正式，只能当线索 |

## 2. 产业链上下游数据：三级核验

技能里要求"物理量 → 经济量"的贯通，落地到三个可核验层级：

1. **物理量**：产量、开工率、库存、运量、能耗、进出口量（来自 L2/L3）
2. **价格量**：现货价、期货价、价差、基差（L3/L4）
3. **口径量**：同一指标在不同来源的差异（统计局 vs 协会 vs 数据商）

**关键纪律**：上下游总量**不能**机械换算成某一家公司的订单或利润。
拿不到客户真实采购量和 BOM 时，只能给区间估计 + 明确标注证据缺口。
这条是技能里写死的，也是实际研究中最常被违反的一条。

## 3. 国内政策变化的监控

### 3.1 渠道（按信号强度排序）

| 强度 | 渠道 | 为什么 |
|---|---|---|
| 最强 | 国常会公报、政治局会议通稿 | 定调，措辞变化即信号 |
| 强 | 发改委/工信部/财政部/央行正式发文 | 有文号，可追执行 |
| 中 | 部门新闻发布会、答记者问 | 解释执行口径 |
| 弱 | 征求意见稿、行业协会吹风 | **可能不落地** |

### 3.2 三个必须避开的陷阱

1. **征求意见稿 ≠ 政策**。把征求意见稿当已生效，是最常见的误判来源。
2. **发文 ≠ 执行**。同一文件在不同省份的执行细则可能相差很大。
3. **措辞变化比金额重要**。从"鼓励"到"有序推动"到"规范"，方向可能相反。

## 4. 交叉验证规则（写进系统，不靠自觉）

- 同一份公告被三家媒体转载，**只算一条**原始证据；
- 关键结论至少一条独立佐证（上下游、同行、政府、监管任选其一），找不到就标"未独立证实"；
- 每个数据点必须带**发布日期**与**统计区间**，否则不进证据账本；
- 冲突时不取平均、不取最新，而是**并列呈现并解释口径差异**。

## 5. 落地到 PuddingAgent：信源注册表

不要为每个信源写一个工具。建议：

```
source registry (JSON, 每源一条)
  ├─ id, 名称, 层级(L1-L4), 覆盖范围
  ├─ 访问方式: api / http / manual-upload
  ├─ 时效标签: realtime / daily / monthly / irregular
  ├─ 凭据引用: config key（不进仓库）
  └─ 可信度: primary / secondary / tertiary
```

工具面只需两个：
1. `finance_query(source, ...)` —— 按注册表路由到具体信源（必盈只是其中一个 `source`）；
2. `finance_evidence(...)` —— 把查到的数据点写入证据账本（含来源、时间、置信度）。

这样加信源 = 加一条注册表记录，**不动工具骨架**，也不改模型看到的 schema。

## 6. 现实取舍（按预算）

| 场景 | 建议 |
|---|---|
| 日频历史 + 财务研究 | AkShare / Baostock 免费源打底 |
| 需要稳定实时、五档盘口、全市场批量 | 付费（这是"免费源的性价比拐点"） |
| 需要产业弹性与拐点 | 买 L3（钢联/卓创），**这层没有免费替代** |
| 需要一致预期与研报 | 付费（Wind/Choice）或不依赖（改用自己的假设） |

**已验证旁证**：2026-09 的一篇实务总结明确指出，AkShare 这类抓网页的库在高并发下会被限流、
字段口径随页面改版漂移；Tushare Pro 是积分制（日线 120 分起，龙虎榜等 2000 分起），
即"免费"省的是订阅费、花的是稳定性与维护时间。

## 7. 我们目前缺什么（诚实清单)

- **L1 覆盖**：必盈有公告摘要类接口，但**没有全文**——读年报原文仍需直接抓交易所；
- **L3 完全缺失**：没有产业数据商的接入，意味着"上下游交叉验证"目前**做不实**；
- **L4 的一致预期没有**：没有券商预期数据，就不该在报告里写"市场预期是多少"；
- **政策监控没有自动化**：只能靠搜索工具临时查，没有持续盯。

这四项里，**L3 是最大的实质缺口**，也最贵。是否采购需要你决定。
