# KeyVault 迁移后的重启校验与回滚手册

## 1. 当前状态（2026-11-17 10:20 实测）

| 项 | 事实 |
|---|---|
| 保管箱 | `KeyVaults` **18 行**，建于 09:18:57–09:22:20 |
| config 引用 | 15 处 `{{vault:}}`（llm 8 / search 4 / caldav 1 / feishu 1 / voice 1） |
| 其它引用 | channel manifest 2 处、Home Assistant token 1 处 |
| 全域明文残留 | **仅 1 处**：`config/system.json` 的 `controlToken`（64 位，刻意保留，Guardian 早于 KeyVault 启动） |
| 历史备份 | 6 份 `.before-*` 已被迁移脚本清除（`dir /s *.before-*` 为空） |
| 回滚副本 | **8 份** DPAPI 封装，见 `.work/keyvault-migration/20261117/recovery/*.dpapi` |
| live 进程 | 迁移前二进制（08:03 构建、08:04 启动） |

### 由此产生的窗口性问题

配置文件已是占位符，而运行中的进程没有解析代码：

- LLM ✅ 可用——`LlmProviderFileService` 本就调用 `InjectAsync`，且无内存缓存（每次读盘），连续多轮真实模型调用成功即反证主密钥与解密链路可用。
- 语音 TTS / ASR ❌ 失败——`VoiceProviderFileService.LoadAsync` 裸读 `ApiKey`，把 `{{vault:...}}` 原样发给上游。
- Home Assistant ❌ 失败——同理。

**结论：一次 `build-restart` 即可闭合；在部署前不得宣称语音功能可用。**

## 2. 重启前检查（三项，任一不过则先别重启）

1. `git status --porcelain` 为空、`git log -1` 为期望提交，且已推送。
2. `dotnet build PuddingAgentNetwork.slnx -c Debug` 无 `error CS`（`MSB3027/MSB3021` 是宿主锁 DLL，不算编译失败）。
3. `D:\Data\secrets\keyvault.master` 存在且未被改动（换机/换账户后 DPAPI 解不开，会让启动校验直接失败）。

## 3. 重启后验收（四项）

| # | 判据 | 期望 |
|---|---|---|
| 1 | 启动日志 | `[KeyVault] Startup decryption check passed for 18 credentials.` |
| 2 | 进程与二进制 | 进程启动时刻晚于目标提交；live `PuddingPlatform.dll` 时间戳更新 |
| 3 | 语音 | 播放条 ▶ 出声；切 Cherry / Stella / Serena 均可 |
| 4 | LLM | 发起一次真实对话 |

第 1 项是 fail-closed 的开关：`KeyVaultStartupValidationService` 在启动时把**每一条**凭据解密一遍，任何一条失败即拒绝启动。因此"能起来"本身就是 18 条全部解密成功的证据。

## 4. 回滚（可执行）

脚本**没有** `--restore` 子命令，恢复必须直接调用它的 `dpapi()`，熵串固定为 `PuddingAgent.MigrationRecovery.v1`。`.dpapi` 文件内容是原始 DPAPI 字节（不是 base64 文本）。

本机没有 Windows Python，必须走 WSL（实测 `python3 3.14.4`），且脚本内部再调 `pwsh`（Windows PowerShell 5.1 无法加载 .NET 类库，必须 `pwsh`）。

```bash
# 单个文件回滚：.dpapi → 目标路径
wsl -e python3 -c "
import base64, pathlib, sys
sys.path.insert(0, '/mnt/d/CodeProject/PuddingAgent/PuddingAgent/Tools/Secrets')
import migrate_config_credentials as m
src  = pathlib.Path('/mnt/d/CodeProject/PuddingAgent/PuddingAgent/.work/keyvault-migration/20261117/recovery/config_voice_providers.json.dpapi')
dst  = pathlib.Path('/mnt/d/Data/config/voice/providers.json')
text = m.dpapi('unprotect', base64.b64encode(src.read_bytes()).decode(), 'PuddingAgent.MigrationRecovery.v1')
dst.write_bytes(text.encode('utf-8'))
print('restored', dst, len(text))
"
```

副本与目标路径的对应关系（8 份）：

| 副本 | 目标 |
|---|---|
| `config_llm.providers.json.dpapi` | `D:\Data\config\llm.providers.json` |
| `config_search.providers.json.dpapi` | `D:\Data\config\search.providers.json` |
| `config_voice_providers.json.dpapi` | `D:\Data\config\voice\providers.json` |
| `config_caldav.json.dpapi` | `D:\Data\config\caldav.json` |
| `config_feishu.json.dpapi` | `D:\Data\config\feishu.json` |
| `channels_feishu-default.global_general-assistant.6a8_manifest.json.dpapi` | `D:\Data\channels\feishu-default.global_general-assistant.6a8\manifest.json` |
| `channels_59897cf892f54e9ea26acb7ee267f797_manifest.json.dpapi` | `D:\Data\channels\59897cf892f54e9ea26acb7ee267f797\manifest.json` |
| `agents_default.global_general-assistant.6a8_secrets_home-assistant.json.dpapi` | `D:\Data\agents\default.global_general-assistant.6a8\secrets\home-assistant.json` |

回滚只恢复**文件**；保管箱里的 18 条记录留着不影响（配置不再引用它们）。

## 5. 未做的事（有意）

- 未迁移 `controlToken`：Guardian 在 KeyVault 可用之前就需要它，只能走启动前缓存，不能按普通配置处理。
- 未删除 `.work/keyvault-migration/20261117/recovery/`：它是当前唯一的回滚手段，待重启验收通过后再议。
- 未在无人工授权时执行破坏性重启。
