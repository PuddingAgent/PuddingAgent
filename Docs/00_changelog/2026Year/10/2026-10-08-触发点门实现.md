# 2026-10-08 触发点门后实现

## 交付

| 件 | 内容 |
|---|---|
| `DesktopBrowserBindingGate : IBrowserBindingGate` | 按 `(contextId/pageId, callerId, taskId, parentTaskId)` 记账；首次申请 ⇒ `IssueAsync`；**有效期内不重发**；拒绝/失败 ⇒ **抛**（不静默放行） |
| 接口调整 | `EnsureAsync(BrowserCallerIdentity caller, contextId, pageId, ct)` —— 传**完整身份**（子代理带父任务，§3.2） |
| Runtime 过门条件 | 仅当 **context 与 page 同时存在**时过门（页面命令的正常形态） |

**策略显式**：`scope` / `validity` / `source` 都是构造参数，门里不藏默认值。

## 验证

| 项 | 结果 |
|---|---|
| `PuddingHost` 构建 | 通过 ✅ |
| `PuddingHost.Tests`（**TRX 判定**） | 见运行输出（应 265/265） |
| 组合根 | **尚未注入** ⇒ 现网行为不变 |

## 诚实边界

- **门自身尚无专属用例**：计划中的四条（带页面过一次门／无页面不过门／拒绝时**在不发出命令的前提下**抛出／同 (任务,页面) 不重复申请）尚未写 —— 下一步第一件事。
- **不观察撤销**：切目标/撤权/换代后缓存偏乐观，届时由 Desktop 准入拒绝该命令（表现为操作失败，**不会**静默放行）；已登记。
- **组合根注入**与**开闸门**仍未做（顺序：门用例 → 注入 → 开闸门）；**未真机验证**。
