# PuddingPlatform code_map 波次 8

## 改了什么

`Source/PuddingPlatform/code_map.md` 的 **`## Token 计量`** 一节：2 列 → v2 五列，**18 行全部改写**（行数守恒）。覆盖 Token 记录/投影/仓储/重建/日聚合/层级 rollup 六类服务与 5 张统计实体、`StatsApiController`、`DailyCacheUtility`、`TokenCostService`。
