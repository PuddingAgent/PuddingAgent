# 2026-10-18 I2-c 错误码对表测试与架构进度更新

## 改动

- 新增路由错误码对表测试：Unauthorized/Paused/UserTakeover/InvalidRequest/InvalidTarget/PageVersionMismatch/NotConnected/UiUnavailable/UnsupportedCapability → 对应稳定 Bridge 码；**未列入对表的 InternalError 必须落 `browser_operation_failed`**（不得伪装成授权/暂停等可重试语义）。
- 架构页 §7 I2-c 行更新：从"主体未做"改为"生产路由全覆盖、清理未做"，附提交区间与已知字段缺口；明确未做项为 controller 旧 handler 删除/收缩、能力通道旧 authority/lease 退役。

## 验证

- 新用例 1/1 通过（Desktop 全量下轮回归）；
- 未运行产品/真实模型。

## 未完成与影响

- 对表目前是"测试锁定"而非枚举驱动：新增能力错误码时必须同步改路由映射与测试（已注释说明）；
- controller 旧执行路径代码仍存在（路由全覆盖后不再被触达，但删除属独立谨慎切片）；
- F5 后置观察、`browser_context` 发现面、I3/I4 外部证据未完成；
- 回滚 = revert 本提交。
