# §5.3 定位：`BrowserTabs` 被统一当作 `TabClose`

| 位置 | 现状 |
|---|---|
| `BrowserOperationMapping.TryGetBrowserOperation` | **只看 capability**；`BrowserTabs` ⇒ **一律 `TabClose`** |
| `BrowserControlContracts` 策略表 | `TabClose` ⇒ Page + `Manage\|Read`；`TabNew` ⇒ Management |
| 后果 | `tabs.list` 被要求**管理级页面授权**；`tabs.new` 拿不到 Management 准入；未知 action 不拒绝 |

## 下一轮执行清单（五步）

1. 增 `TabsList`（None/None）与 `TabActivate`（Page + Write）到 `BrowserAutomationOperation`；
2. `TryGetBrowserOperation` 增 **request-aware 重载**（按 `Tabs.Action` 分派，**未知 ⇒ false**）；
3. 策略表补两项；
4. `RunOnUiAsync`/`ValidateAdmission` 增 `operationOverride`，由 `TabsAsync` 传入；
5. 测试：`tabs.list` 无页面授权可过 · 未知 action 拒绝 · `tabs.close` 仍要 Manage。

## 诚实边界

- **本轮未改代码**（只定位 + 记成清单）；**未真机验证**。
