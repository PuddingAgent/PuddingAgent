# 2026-10-18 I2-c 适配器第一片：page.getInfo → webview.page_state

## 改动

按 I2-c 设计决议 D1，先落**映射层**（不接管执行）：

- 新增 `BrowserBridgeCommandAdapter`（WpfArchive）：`TryMapReadCommand` 把 Bridge 命令映射为 `(DesktopCapabilityDescriptor, DesktopCapabilityRequest)`；
- 第一片只映射 `page.getInfo` → `webview.page_state`，其余命令与缺 context/page id **显式失败并给出可行动原因**（不得静默回退到 controller）；
- 测试 3 条：映射成功的 descriptor/请求目标；缺显式目标拒绝；未映射命令失败且不回退。

## 验证

- `dotnet test Tests/PuddingDesktop.Tests --filter BrowserBridgeCommandAdapterTests` ⇒ **3/3 通过**；
- Shell 产品工程编译验证（见提交说明；适配器只出现 Contracts/Protocol 类型，满足链接文件可编译约束）。
- 未运行产品/模型：本片**不改变**任何命令的执行路径（派发器仍走 controller）。
