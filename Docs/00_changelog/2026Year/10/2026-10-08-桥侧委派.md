# 2026-10-08 桥侧表面委派

| 分支 | 结果 |
|---|---|
| 运行时不是 Bridge 运行时 | **明确不支持**（fail-closed） |
| detail 线名未登记 | 明确失败 |
| 执行异常 / Base64 非法 | 明确失败（不静默） |
| 成功 | `BrowserScreenshotResult`（映射 20 项 + `Validate()`） |

## 端到端链路（代码层已通）

```
Host 表面 → RemoteBrowserRuntime.ScreenshotAsync → page.screenshot 命令
  → 桌面 BrowserWorkspaceController.HandlePageScreenshotAsync
  → 同一个 IDesktopCapabilityExecutor（DesktopService，准入/闸门/预算一致）
  → BrowserScreenshotDescriptor（含几何/裁剪/修订，Base64 分块）
  → 回到 Host 表面映射为 BrowserScreenshotResult
```
