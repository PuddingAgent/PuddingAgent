# 2026-10-08 截图分发缺陷修复

| 处 | 改动 |
|---|---|
| `UiSeams.cs` | `IDesktopUiSurface.ScreenshotAsync(...)` |
| `DesktopSurfaceComposition.cs` | 委托到 `_browser.ScreenshotAsync` |
| `TestInfrastructure.cs`（替身） | `RecordingUiSurface.ScreenshotAsync` |
| `DesktopService.cs` | **独立** `BrowserScreenshot` 分支（不再落到 Snapshot 体） |

## 为什么之前没被发现

- 用例覆盖：契约 / proto 守卫 / 线缆两侧 / 表面 `ScreenshotAsync` / 工具 / 委派 —— **唯独缺"分发级"用例**；
- 共享 `case` 标签是**语法合法**的，编译器不会提醒（这正是"case 无 break ⇒ 语义由位置决定"的那类陷阱，我在 round-419 踩过并记录过，但**同一个坑又踩了一次**）。

## 教训

**"产物存在"≠"分发正确"**；**共享 `case` 标签必须核实分支体是否真的处理该能力**（不能只看有没有那个标签）。
