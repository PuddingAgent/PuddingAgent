# R6：`bool? Dirty` 三态落地

| 值 | 含义 |
|---|---|
| `true` | 有未提交改动 |
| `false` | 干净 |
| **`null`** | **尚未采集**（诚实说"不知道"） |

**证据**：整链 **12 套件 / 2095 条 / 0 失败** ✓

**方法教训**：含引号的代码插入用 **`edit` 工具**，不要走 Shell（上轮被 `ParserError` 挡下）。
