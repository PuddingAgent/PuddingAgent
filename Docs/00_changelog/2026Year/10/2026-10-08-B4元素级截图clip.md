# 2026-10-08 B4 元素级截图 clip：0×0 的盒子要拒绝

## 目标 / 背景

B4（截图视觉）的主体被 **artifact 字节归属**这个待决问题挡着（全文落地与工具面暴露都需要它）。
本轮只做**不依赖该决定**的一块：**元素级截图**（设计 §6 的视觉观察里"截某个元素"）。

## 改动

`ScreenshotPlan`（既有纯组件）新增两个成员：

| 成员 | 作用 |
|---|---|
| `BuildForElement(x, y, width, height, quality)` | 用**元素盒子**作 clip 构造 `Page.captureScreenshot` 参数；`quality` 走与整页**同一套**格式规则（有损才有 quality） |
| `TryReadElementBox(boundingBox, out box)` | 从元素包围盒读 `x/y/width/height`；缺字段即拒绝（不补 0） |

**被拒绝的"看起来对"**：`width ≤ 0` 或 `height ≤ 0` 的盒子 ⇒ 那是隐藏/未布局的元素，
必须**明确拒绝**，而不是截一张空图交差（空图会让读者以为"页面上什么都没有"）。
另外文档里写明坐标是**视口坐标**（滚动位置不同会得到不同区域），因此调用方必须用**刚观测到**的盒子；
引用过期由既有的元素身份与页面版本负责，本函数不猜。

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingBrowser.AutomationTests` | **309 / 309**（原 306 ＋ 3） |
| `AgentTools` · `DesktopServiceTests` · `Contracts` · `DesktopSurface.BrowserTests` · `PuddingDesktop` · `Host` | 70/70 · 302/302 · 153/153 · 67/67 · 320/320 · 258/258 |

新增门禁：元素盒子被正确用作 clip（x/y/width/height/scale 逐项断言）+ 有损格式带 quality；
**空盒子（0/0 与负值）被拒** + 非法 quality 被拒；包围盒缺字段时读取失败。

**取红实测**：把"空盒子拒绝"短路 ⇒ `AnEmptyElementBoxIsRefusedInsteadOfCapturingNothing`
**恰好变红**；复原后 309/309 复绿。

## 已知边界（诚实登记）

- **未接驱动/工具面**：`ScreenshotPlan` 是纯策略；把它接到驱动的元素截图路径（读盒子 → 取图 → 预算判定）
  与"截图能力是否成为一个 Agent 工具"属**工具面设计**，本轮不动。
- **仍无 artifact 落地**：超过字节预算时依旧**如实报资源耗尽、绝不截断**（选项 C 的现状）；
  全文落 Artifact 需要 B4 的字节归属决定。
- **不做滚动拼接**：元素比视口高时截到的是"视口可见部分"（CDP clip 语义），不拼接整元素。
- **不做坐标变换**：传进来的盒子必须是视口坐标（页面缩放/嵌套滚动由调用方在观测时处理）。
- 真机无关（纯参数构造）。

## 影响与回滚

- **无对外行为变化**：新增 API 尚无生产调用方（既有截图路径不经过它）。
- 回滚：删除两个成员与三条用例、还原冻结计数。
