# 2026-10-08 observationId 放行（③）

| 环节 | 失败时 |
|---|---|
| 几何事实（`Page.getLayoutMetrics`） | 明确拒绝（`InvalidRequest`） |
| 页内计数（`Runtime.evaluate`） | 明确拒绝（"观察须先由截图建立"） |
| `TryResolve(id, 三代)` | 明确拒绝（未知/过期） |
| `TryToCssViewport(...)` | 明确拒绝（越界/几何非法） |
| 全部通过 | 用**变换后**坐标执行；裸坐标不受影响 |

## 为什么"读不到计数"必须拒绝

把"读不到"当成"没变过"，等于**假定页面没变** —— 正是 §8.2 要防的静默失效。⇒ 拒绝，且信息告诉调用方"先截图建立观察"。

## 诚实边界

- **尚无用例覆盖"带 id 成功"与"过期 id 拒绝"**（下一轮补：注入登记处的表面 + 假页提供布局指标/计数）；
- **截图端仍未登记观察**（② 待 A/B/C 决策）⇒ 真实 id 目前只能由测试注入 ⇒ **端到端仍不可用**；**未跑全量链**；**未真机验证**。
