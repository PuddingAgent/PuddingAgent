# 2026-10-08 横向：外部验收脚本的用法示例 + 门禁

## 起因（我上一轮犯的错）

round-119 我第一次调用外部脚本时把 `-Template` 当成"模板输出路径"传 —— 它其实是**开关**，
于是后面的路径被**静默绑到位置参数**上：命令看着成功、文件名也像是被接受了，但**参数绑定是错的**。
真正的观察文件参数是 `-Facts`。（当时是靠"打印出来的文件名与预期不符"才发现的。）

## 改动

`TestScripts/external-acceptance.ps1` 的帮助块补齐：

1. **模板**：`... -Template -Facts temp/test-out/facts.json`；
2. **结论**：`... -SkipTemplate -Conclude -Facts temp/test-out/facts.json`
   （并写明 exit 0 = 允许 `external-lifecycle-verified`；exit 2 = 被拒并给出原因，例如任何 `not-run`）；
3. **明确警告**：`-Template` / `-Conclude` / `-SkipTemplate` 是**开关**，给开关传路径会落到位置参数上；
   观察文件是 `-Facts`。

## 门禁

`BrowserSmokePlanTests.TheExternalScriptDocumentsHowToCallItsSwitches`：断言帮助块里必须出现
`-Template -Facts`、`-SkipTemplate -Conclude -Facts`、以及"开关/位置参数"的说明；
并断言帮助块提到的参数（`$Facts`、`[switch]$Template`、`[switch]$Conclude`）仍然存在。

## 验证

| 项 | 结果 |
|---|---|
| `Pudding.DesktopServiceTests` | **316 / 316**（＋1） |
| 脚本仍可运行 | `-Template -Facts <path>` 正常生成模板（13 项 + 生命周期四步） |
| 脚本仍纯 ASCII | 非 ASCII 字符 **0**（PS 5.1 按 ANSI 读无 BOM 脚本 ⇒ 中文会变成解析错误） |
| **取红实测** | 从帮助块删掉 `-Template -Facts` 示例 ⇒ 门禁**变红**；还原 ⇒ 316/316 |
| 实现中被自己的门禁抓到 | 首版断言区分大小写（脚本里是 `POSITIONAL`/`SWITCHES`）⇒ 首跑即红，已改为忽略大小写 |

## 诚实边界（诚实登记）

- **门禁只查"帮助块是否写了这些要点"**，不校验示例命令**真的能跑**（后者需要外部环境与真机观察）。
- **没有把用法加进 runbook**：runbook 是给外部观察者的步骤说明，脚本帮助块是给操作者的命令说明；
  两者目前各自独立（登记为可合并项，未做）。
- **本轮仍无真机验证**；也没有触碰那两项待决取舍。
- 无产品行为变化（脚本注释 + 用例）。
