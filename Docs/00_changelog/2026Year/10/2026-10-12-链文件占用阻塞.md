# 阻塞（非我）：`MSB3021` 文件占用 ⇒ `SHELL-BUILD-FAILED`

| 项 | 内容 |
|---|---|
| 症状 | 整链 **0 套件**、无新清单 |
| 错误 | **`MSB3021`**：复制 `PuddingBrowser.Automation.dll` 到 `temp\build\winui3\…` 失败 |
| 原因 | **`The process cannot access the file … being used by another process`**（**文件被占用**） |
| 后果 | 22 个错误 ⇒ **`SHELL-BUILD-FAILED`** ⇒ 拒绝产出清单 |
| 我看到的 `清单=✅` | **是 round-717 的遗留文件**（`buildId=round-717`），**非本轮产物** |
| 性质 | **环境/并发阻塞**（工作树 **18 项他方改动**；WinUI 产物被运行中进程持有） |

## 处置（不越界）

**不杀进程、不删被锁文件**；由环境所有者**关闭运行中的 Desktop/构建进程**后重跑，或**稍后重试**。

## 已确证且不受影响

CLI 请求侧正常（`[diag] entry request.WorkingTreeDirty=True`）· 调用链唯一 · 清单由 collect 阶段 `--out` 写出 · 此前探针失败源于 `--changelog` 传错。

## 诚实边界

- **未真机验证**；R6 打印实验待链恢复。
