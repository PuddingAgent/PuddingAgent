# 2026-10-31 R1-04 补齐 C# 继承类关系边

## 改动

- `Source/PuddingCodeIntelligence/CSharp/RoslynCSharpIndexer.cs`：
  - `AddDeclaration` 末尾调用新的 `AddInheritanceRelations`；它在声明处直接由 Roslyn 语义模型产出三类边：
    - 非 `object` 的基类 ⇒ `Inherits`
    - 接口 ⇒ 类用 `Implements`、接口继承接口用 `Inherits`
    - `IMethodSymbol.IsOverride` ⇒ `Overrides`（目标取 `OverriddenMethod`）
  - 端点方向固定「派生 → 基」，与既有 `Contains` / `Calls` 一致。
  - **只对源内定义的基类型建边**（`IsDefinedInSource`）：`System.IDisposable` 这类外部类型在索引里没有符号，建边只会产生悬挂引用，让「谁实现了 X」掺入打不开的端点。
- `Source/PuddingCodeIntelligenceTests/CSharp/RoslynCSharpIndexerTests.cs`：新增 3 条门禁测试 + 继承夹具（`IShape` / `ShapeBase` / `Circle : ShapeBase, IShape`）。
