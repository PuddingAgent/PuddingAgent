# 2026-10-18 会话读模型阶段C2a事件映射与持久化适配

## 改动

- 组件 S5 接入第一步：`PuddingPlatform.csproj` 增加 `PuddingConversationReadModel` ProjectReference；`PuddingAgentNetwork.slnx` 登记组件与独立测试工程（DI 装配与宿主组合测试留到阶段 C 门禁通过后）。
- 新增 `Services/AgentChat/ConversationReadModelEventMapper.cs`：canonical `ConversationEvent` → 纯组件 `ConversationEventInput`：
  - 20 类事件映射（turn 生命周期、message/tool、子代理生命周期、压缩）；
  - content/thinking 读生产字段 `delta`（content 兼容 `text` 防御），进入组件前 64 KiB UTF-8 上限且不切码点；
  - `producer_component=subagent.runtime` 的非生命周期事件标 `ParentRunId`，避免子 run 正文污染父摘要；
  - 缺失身份字段为 null，不推断、不补造。
- 新增 `Services/AgentChat/ConversationReadModelProjectionStore.cs`：
  - `LoadForBatchAsync`：只加载本批受影响的 Turn 摘要（避免每批读全会话历史）；无 read_state 且 checkpoint=0 ⇒ Ready、checkpoint>0 ⇒ **Partial 旧库基线**；损坏 `sub_agent_runs_json` 抛明确异常（fail closed）；
  - `PersistAsync`：upsert `conversation_read_state` + 受影响 Turn 摘要，并在**同一事务**内推进 `conversation_projection_checkpoints`；不执行 SaveChanges/Commit（由调用方持有事务）。
- 新增 43 个定向测试：映射合同（20 类 kind、delta/UTF-8 边界、子代理 producer 标记、空身份、未知类型），持久化（往返、仅 affected turns、upsert+checkpoint 更新、事务回滚全部不写、子代理 JSON/omitted 往返、损坏 JSON fail closed、legacy partial）。
- 更新 `Source/PuddingPlatform/code_map.md` 与根 `code_map.md` 组件接入状态/指纹。
