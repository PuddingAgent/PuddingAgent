# 2026-10-18 Bridge 协议修订提升到 3（D9 迁移隔离）

## 改动

- `BrowserBridgeProtocol.CurrentVersion` 2 → **3**：本次命令结果合同修复（D8）整体发布，两端握手严格相等，不提供旧/新载荷兼容分支。
- 新增合同修订断言（Host 契约门禁内）：`CurrentVersion == 3`，未来任何修订必须显式更新该测试。
- 既有的 envelope 版本严格比较（`BrowserBridgeSerializer.Deserialize` 与两侧 Hello/Ack 校验）自动把旧构建隔离在握手阶段。

## 验证

- Host BrowserBridge 过滤 **141/141**、Desktop Browser 过滤 **160/160** 通过（版本常量不破坏既有握手/往返测试）；
- 未运行产品；旧构建（v2）与新构建（v3）不能互连——这是预期隔离，不是缺陷。

## 未完成与影响

- D9 还要求 Hello/Ack 携带可诊断构建身份（buildId/源 revision/dirty）与发布清单哈希绑定，未做；
- 运行中进程仍是 v2 旧构建：需要 R4 成套构建 + R5 外部控制器部署后才能验证真实 Agent；
- 未做旧新载荷双解析（按 ADR 明确不做）；
- 回滚 = revert 本提交（常量 + 断言）。
