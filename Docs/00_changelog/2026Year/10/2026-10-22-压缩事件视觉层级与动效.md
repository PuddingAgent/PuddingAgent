# 压缩事件视觉层级与动效

- `CompactionCard.tsx`：后台准备、候选就绪、请求暂缓、保存、完成、未执行、失败与待确认采用明确文案；用归拢图标代替扫光进度条，就绪即静止。完成和未执行默认折叠；详情保留完整输出、时间与关联 ID。仅状态标题进入 live region，计时不触发重复播报，非法时间不渲染。
- `panel.styles.ts`：使用主题语义色、请求暂缓强调边、可换行阶段序列、键盘焦点、限高可滚动详情；减少动画偏好停用运动。未修改会话接收、压缩调度或提交策略。
- 前端版本从 `6.10.0` 升为 `6.10.1`；更新子项目代码地图及[设计说明](../../../07_architecture/前缀缓存友好的会话压缩.md)。

验证：组件测试 20/20，TypeScript 检查通过。临时浏览器夹具直接加载实际 React 组件、样式与全局主题，在 Edge 验证 9 种状态、浅深色、360px 无横向溢出、键盘展开完整记录、减少动画偏好、零页面异常；人工检查三张截图。测试证据位于 `temp/test-out/compaction-ui/`，测试脚本 `temp/compaction-ui-visual.cjs` 不进入产品。

未完成：此提交尚未生成正式前端产物、部署和重启 Desktop；后续部署记录补充实际构建身份和健康检查。不以合成视觉夹具替代真实长会话验收。
