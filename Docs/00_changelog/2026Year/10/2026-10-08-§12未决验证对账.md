# 2026-10-08 §12「未决验证」逐条对账

## §12 的要求

> 实现前需核验 native 输入/截图对当前 Runtime 与隐藏表面的支持、滚动无位移根因、只读期间版本变化事件及子代理实际工具注入。
> **每项安排对应探针和明确失败路径**，不能用未验证假设继续声称已支持。

## 对账结果

| §12 待核验项 | 探针 / 失败路径 | 判定 |
|---|---|---|
| native 输入**按动作**是否支持 | native 模式下未实现的动作 ⇒ `UnsupportedCapability` 明确拒绝（代码注释写明"静默回落成 DOM 会让调用方以为走了真实输入路径"）；用例 `NativeInputMode_ReachesTheDriver_AndUnsupportedActionsAreRefused` | ✅ |
| native 输入**当前 Runtime/SDK** 是否支持 | ❌ 没有"本 Runtime 不支持 native"的探针（只有"某动作未实现"） | ⚠️ **未核验** |
| **截图对隐藏表面**（托盘后）的支持 | ❌ 代码与清单此前**都未表示** ⇒ 本轮给 **S-09** 加了观察要求：**必须给出可判定结果（可用或明确不可用），不得返回黑图/旧帧冒充成功** | ⚠️ **未核验**（已加要求） |
| 滚动**无位移根因** | 行为侧 `AStalledPositionStopsTheScroll`（不假称位移）✅；**根因**需观测容器/overflow/视口/输入路径 | ⚠️ **根因未定位** |
| **只读期间版本变化事件** | `ReadOnly_Calls_Advance_Nothing`、`Ordinary_Dom_Change_And_Viewport_Change_Invalidate_Nothing` | ✅（真实站点的"只读却推进版本"仍需观察） |
| **子代理实际工具注入** | `AReadOnlyBrowserTaskRequiresSnapshotAndInjectsTheRealToolIds`、`AWriteCapableTaskAlsoRequiresNavigateAndInteract` | ✅ 注入面；**"子代理真的发现工具"只能真机** |

**结论**：§12 的四类核验里 **两类已有明确失败路径**，**两类仍属未核验**。在真机核验之前，
交付物**不得**声称"截图在隐藏表面可用"——这条已写进清单（S-09）而不是只写在日志里。

## 诚实边界（诚实登记）

- **"加了观察要求"≠"已核验"**：隐藏表面截图**仍然没有真机结论**；本轮只保证它**可判定**（不许拿黑图冒充成功）。
- **native 的 Runtime 级可用性**仍无探针：需要当前 WebView2 Runtime 的样本才能声明（§12 的原话）。
- **滚动无位移根因**属观测性工作，进程内只能证明"不假称位移"。
- **本轮又一次被严格门禁拦下**（第 4 次）：把生产类名加反引号（`BrowserRuntimeDesktopSurface`/`UnsupportedCapability`）会被当成用例名 ⇒ 已改为普通文字；这条纪律已反复踩到，登记为"表格中反引号只用于用例名"。
- **未真机验证**；决策①（A/B/C）与②③④仍未拍板。
