# R6：`Validate` 拒绝规则

| 条件 | 结果 |
|---|---|
| `Dirty == true` | ❌ 校验失败：*working tree had uncommitted changes … not reproducible … cannot be declared 'ready-for-external-deploy'* |
| `Dirty == false` / `null` | 不因本规则拒绝（`null` = 尚未采集，**不等于干净**） |

**证据**：整链 **12 套件 / 2095 条 / 0 失败** ✓（当前清单 `dirty: null` ⇒ 未触发）
