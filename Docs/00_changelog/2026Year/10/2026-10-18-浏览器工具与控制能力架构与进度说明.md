## 编写中发现的两件事（均已写入文档）

1. **2026-10-13 的后续生产接线修复 `ace0100`**（在 2026-10-12 验收之后）：
   - 根因：`NotifyConnectionGeneration` 生产代码零调用者 ⇒ `ConnectionGeneration.None` ⇒ 所有浏览器命令停在
     “the desktop connection is not established”；且 UI“设为 Agent 目标”不下发到准入侧。
   - 修复：桥握手/断开驱动权威活性（`NotifyBridgeConnected/Disconnected`）；`SetAgentTarget` 下发链；
     `HasSufficientPageGrant` 改为**三级判据**（用户选中目标 / V1 基线（桥在线即视为 Agent 自己的浏览器在线）/ 既有页级 grant）。
   - **影响**：这是**授权语义变更**（逐页 grant 不再是桥在线时的否决条件）；文档 §5.3 显式标注，
     外部验收应按新语义审查（暂停/接管仍能阻止写入、只读仍可用、撤权/断连仍失效）。
2. **文档编码损坏**：2026-10-12 写《浏览器交付验收索引》时使用 PowerShell 双引号 here-string 插值，
   反引号转义序列 `r 把 “`r” 变成回车，导致多处单词首字母丢失（如 `stage` 显示为 “eady-for-external-deploy”）。
   本次按原意重写该文件（保留全部结论与数字），新增 2026-10-18 复核行并链接新清单。
