# 2026-10-08 发布产物结构核查

| 检查 | 结果 |
|---|---|
| 目录存在 | ✅（链的守卫已覆盖） |
| **`PuddingDesktop.exe`** | ✅ 0.4 MB（Shell 主程序） |
| **`core/PuddingAgent.exe`** | ✅ 0.2 MB（**Core 子进程**） |
| 结构一致性 | ✅ 与"**Shell + 独立 Core 子进程**"的进程模型一致 |
