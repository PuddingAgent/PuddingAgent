# 2026-10-18 会话内容分段与过程结构化契约

## 改动

- 后端 `ConversationOpenContracts` / `ConversationOpenQueryService`：
  - 新增 `ConversationMessageContentPage` 与 `GetMessageContentAsync`：按 **UTF-8 字节窗口**读取 `ChatMessages.Content`（SQL `substr(CAST(Content AS BLOB), ...)`），只解码完整码点前缀，不完整尾字节留到下一页；短消息一次返回全文（`HasMore=false`）。默认 32 KiB/段、最大 128 KiB；越界/非边界/消息不存在返回稳定 `invalid_content_offset` / `message_not_found`。
  - 过程分页 `ConversationProcessItem` 增加结构化字段：`toolCallId/name/status/exitCode/error/subAgentId/runId/arguments/output`；单字段 ≤16 KiB UTF-8 有界，JSON 片段解析失败时只返回有界片段并保留截断标记。
- `ConversationOpenApiController` 新增 `GET /api/conversations/{id}/messages/{messageId}/content?offsetBytes=&maxBytes=`；`message_not_found` 映射 404，其余查询失败 400 稳定 code。
- 前端 `conversationOpenTypes.ts` / `conversationOpenApi.ts`：同步过程结构化字段与 `ConversationMessageContentPage`，新增 `getConversationMessageContent`（offsetBytes/maxBytes/AbortSignal）；版本 `6.5.1 → 6.6.0`。
- 测试：服务端内容分段/短消息/缺失消息 3 例、过程结构化 1 例、控制器内容端点 1 例；前端 API 客户端内容分段 1 例。
- 更新 Platform / 前端 `code_map.md`；根 `code_map.md` 刷新 `Source/**` 指纹。
