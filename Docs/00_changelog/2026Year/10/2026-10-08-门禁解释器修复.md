# 2026-10-08 修复提交门禁的解释器解析

| 项 | 内容 |
|---|---|
| 问题 | 硬用裸 `python`（本环境为应用别名）⇒ 提交门禁中断 ⇒ 我只能绕道 `git` 提交 |
| 修复 | `param()` 之后插入单行解析器；3 处调用改用 `$pythonExe` |
| 解析顺序 | `$env:PUDDING_PYTHON` → `py`（校验 `--version` 为 Python 3）→ 可用 `.venv` → 回退 `python` |
| **实跑** | 前导字段 **1174 / 不合规 2**（基线 2）· 链接 **1282 / 坏链 32**（基线 32）· BOM **0** ⇒ **exit=0** |

## 两次失败（值得记住）

| 次 | 插入点 | 结果 |
|---|---|---|
| 1 | 首个调用点之前（**在 `try{}` 内**） | 花括号配平被破坏 ⇒ 解析失败 |
| 2 | 头部注释块之后（**在 `param()` 之前**） | `[CmdletBinding()]`/`param` 位置非法 ⇒ 解析失败 |

⇒ 第 3 次改为**单行**、插在 **`param()` 之后**，并**先解析校验再运行**（校验不过自动回退）⇒ 成功。

**教训**：**改全仓脚本先弄清它的"结构约束"**（这里是 PowerShell 的 `[CmdletBinding()] param()` 必须最前），并**每次都用解析器校验兜底**。
