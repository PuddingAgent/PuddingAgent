# 2026-10-08 发布守卫加强（已证伪）

| 项 | 内容 |
|---|---|
| 缺口 | 守卫只查**目录存在** ⇒ 缺 Core 子进程 exe 时链仍绿，但发布包**无法启动** |
| 加强 | 校验 **`PuddingDesktop.exe`** + **`core\PuddingAgent.exe`** 都在；缺失 ⇒ **`PUBLISH-INCOMPLETE`** + **exit 1** |
| **证伪** | 移走 Core exe ⇒ **正确拒绝** ✓（随后还原） |
| 回归 | 正常路径跑链 ⇒ **不误报**、清单正常产出 |

## 纪律

**找到一个"守卫没覆盖的环"，就把它补进守卫本体** —— 而不是只在文档里记一句"已人工核查"。

## 诚实边界

- 检查的是**文件存在性**（不验证可执行文件内容/依赖完整性）；**未真机验证**。
