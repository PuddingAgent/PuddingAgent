# 2026-10-08 生产装配第一刀（缝）

## 交付

| 件 | 内容 |
|---|---|
| `DesktopCapabilityChannelComposition.StartAsync` | 末尾可选 `BrowserTaskBindingService? taskBindings = null`（additive，既有调用方与用例不受影响） |
| 同上 | 转发给 `new DesktopService(..., taskBindings: taskBindings)` |

**无行为变化**：生产尚未传值 ⇒ `DesktopService._taskBindings` 为 null ⇒ 控制面能力维持"明确拒绝"（fail-closed）。

## 验证

| 项 | 结果 |
|---|---|
| `PuddingDesktop` 构建 | 通过 |
| `Pudding.DesktopServiceTests`（**TRX 判定**） | 见运行输出（应 360/360） |
| 全量链 | **未跑** |

## 诚实边界与下一步

- **组合根未装配**（本轮回退）：需要在 `DesktopApplicationCoordinator.Capability.cs` 构造
  `BrowserGrantIssuer(_browserAutomation, new DesktopInstanceId("default"), new DesktopProcessInstanceId($"desktop-{Environment.ProcessId}"), () => _browserAutomation.Authority.ConnectionGeneration)`
  与 `BrowserTaskBindingService`，并把**同一实例**交给 `new BrowserWorkspaceTargetBridge(lifecycle, taskBindings)`（L72）与 `StartAsync(..., taskBindings: …)`（L99 调用）。
  失败原因：该 `StartAsync(...)` 调用的收尾**不是独立一行的 `);`** ⇒ 按行号定位失败；下轮应**先读该调用全文**（L99–L115）再改。
- **闸门仍未启用**（生产未注入世代提供者）。
- **未真机验证**。
