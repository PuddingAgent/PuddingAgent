# 组合根传输路由切换落地：窄端口按 `DesktopTransportRouting` 二选一

## 目标 / 背景

切片 D 第③步的最后一块（§8.4 的 ①②③ 之 ③）：**组合根按开关在"端口走能力通道 / 端口走 Bridge"
之间二选一，不做跨传输回退**。规则不新造——`CapabilityBroker` 里已有
`DesktopTransportRouting`（本次会话早些时候建的），本次把它接到窄端口上。

## 改动

| 文件 | 改动 |
|---|---|
| `Source/PuddingHost/BrowserBridge/TransportRoutedBrowserCapabilitySurface.cs`（新增） | 组合根侧的窄端口实现：每次调用只做**一次**决策（`DesktopTransportRouting.Decide`），只调用一侧，并记数 |
| 同上（`DesktopTransportUsageTracker`） | 线程安全的用量计数持有者（`Record(route)` 是不可变记录 ⇒ 需要一个持有者） |
| `Source/PuddingHost/BrowserBridge/BrowserBridgeServiceCollectionExtensions.cs` | 端口注册由"固定 Bridge 实现"改为**路由实现**：通道 = `CapabilityBroker.Sessions` 的活动会话（`DesktopSession` 本来就实现该端口），Bridge = `BridgeBrowserCapabilitySurface`，可用性 = `IDesktopBrowserConnectionRegistry.IsDesktopConnected` |
| `Tests/PuddingHost.Tests/BrowserBridge/TransportRoutedBrowserCapabilitySurfaceTests.cs`（新增 3 项） | 通道就绪优先且**绝不**碰 Bridge、无通道走 Bridge、两条都没有时**如实失败**且不换一条重试 |

## 关键不变量（本轮的测试焦点）

**同一次操作绝不执行两次**：选了通道就绝不再碰 Bridge——通道超时不代表 Desktop 没执行，
回退会把它再做一遍。因此决策是单次、单侧的，且"无路由"是**明确失败**（`NotConnected`）而不是重试。

计数（`CapabilityChannelCalls` / `LegacyBridgeCalls` / `NoRouteCalls`）由此开始真实累积，
它们正是"可退役旧 Bridge"判据（窗口内零回退）的输入。

## 为什么先做这个而不是缺口 #1

缺口 #1（上下文 `create`/`close`）需要**两个新能力**：proto payload oneof + 契约联合成员 +
端口两个新方法 + 目录/准入/探针，规模约 3~5 轮；而 `browser_context` 工具**继续走 Bridge 且没有任何能力损失**
（它尚未迁移 ⇒ 不违反"迁移不得削功能"）。相比之下，本轮的切换让**已迁移的五个工具真正开始按通道路由**，
把整条切片变成可用的运行时路径——**按价值排序，本轮先做切换**。缺口 #1 明确留待后续。

## 验证

- 构建：`PuddingHost` **0 错误**；
- 测试：`PuddingHost.Tests` **231/231**（新增 3 项路由用例）；
  另抽查 `PuddingBrowser.AgentTools.Tests` **15/15**、`Pudding.CapabilityBrokerTests` **90/90**、
  `Pudding.Rpc.ProtocolTests` **20/20** 均绿；
- **未验证**：真实 Desktop 会话下的路由行为（需要能力通道真的就绪 + 外部重启窗口）——
  本轮的验证是"决策与委托逻辑"的单元级证明，**不是**端到端证明。

## 重复踩到的坑（第三次，值得成为硬约定）

`CapabilityResult<T>` 与 `DesktopCallContext` 位于**根命名空间** `Pudding.Contracts`
（接口文件之所以不写 using，是靠父命名空间查找）。因此**任何新的消费方都必须同时**：

```csharp
using Pudding.Contracts;          // CapabilityResult / DesktopCallContext / Identity
using Pudding.Contracts.Desktop;  // 桌面契约 DTO 与窄端口
```

本轮与前面迁移工具时都因缺第一行而得到成片 `CS0246`（本轮 40 个）。已记录为固定动作。
