# R5 残余窗口：定性并**关闭**（自愈，非缺陷）

| 检查（`ResolveLocalFileAsync` L251–286） | 结论 |
|---|---|
| **元数据必须存在**（L261–263） | "只有字节没有元数据" ⇒ **判为不存在** ⇒ 保存路径**重跑并覆盖孤字节** = **自愈** ✓ |
| 读/反序列化失败（L271–275） | ⇒ `null` ✓ |
| `artifactId` 不匹配（L277–278） | ⇒ `null` ✓ |
| 字节路径由元数据决定（L281） | `artifactId` **内容寻址** ⇒ 同 id 必同字节 ⇒ **不可能"元数据指向别的字节"** ✓ |
| 字节存在 + **根目录包含校验**（L280–285） | 否则 `null`；**同时是路径穿越防护** ✓ |

⇒ **"工件与元数据不一致"的推断不成立** ⇒ round-780 的开放观察项 **关闭** ✓

## 顺带记录的安全性质

元数据中的 `FileName` 用于拼接读取路径 ⇒ 实现**先做根目录包含校验再读**（L282–283）⇒ **防止元数据被篡改后读取工作区外文件** ✓（可作为复核材料中的**正向证据**）
