# R6 端到端验证通过 + 修掉一处谎报

| 情形（直调 CLI 实测） | 结果 |
|---|---|
| `--dirty true` | **清单被拒绝产出**（`Validate` 规则生效）✓ |
| `--dirty false` | `dirty = false` ✓ |
| **缺省** | **`dirty = null`**（未采集）✓ —— 修正前是 **`false`（谎称干净）** ❌ |

**修法**：请求字段改 **`bool?`**；CLI **仅在提供开关时**映射（缺省 ⇒ `null`，绝不 `false`）。

## 重要设计结论

**脏树上跑链 ⇒ CLI 拒绝产出清单**（`dirty=true` 触发规则）⇒ 当前仓库有 **18 项他方未提交改动**，故整链 `NO-MANIFEST` 属**正确拒绝**而非故障。
