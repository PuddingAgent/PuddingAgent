# R6 交班：投影插入改用 `edit` 工具

| 项 | 内容 |
|---|---|
| 本轮查实 | `841f409` 的**假阴性检查**（匹配到请求字段 ⇒ 投影被静默跳过） |
| 本轮尝试 | 真插投影 + 初始化器 + CLI 字段 ⇒ **探针无输出**（CLI 编译/运行失败）⇒ **守卫回退**（树绿） |
| 已确证 | 四处链接内容/位置 · CLI 直接接受 `--dirty true` · 序列化与夹具已排除 |
| **失败原因** | 盲文本插入可能落入**非预期作用域**（或变量名非 `request`）；且探针命令**未回显 `error CS`** |
| **下一轮** | 用 **`edit` 工具**逐处插入（上下文见 L166–176）· **每处插入后立即 build 并回显 `error CS`** · 编译通过 → 探针 → 整链断言 |

## 纪律（第 15/16 条）

1. 存在性检查**必须匹配要插入的确切文本**；2. **盲文本插入后必须回显编译错误**（不能只看"未命中"）。

## 诚实边界

- 本轮**无净产出**；清单仍 `dirty=null`（**诚实"未采集"**）；**未真机验证**。
