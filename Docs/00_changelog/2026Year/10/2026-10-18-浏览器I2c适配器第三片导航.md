# 2026-10-18 I2-c 适配器第三片：导航命令 → webview.navigate

## 改动

- `BrowserBridgeCommandAdapter` 扩展导航映射：`page.goto` → `NavigateRequest(Goto, url, timeout)`，`goBack/goForward/reload/stop` → 对应动作且 `Url=null`；能力均为 `webview.navigate`；
- 参数逐字段搬运：`url`（必须绝对 http/https）、`timeoutMs`；无 `expectedPageVersion` 字段的线缆形态使用 `DesktopPageVersion.Unknown`（不猜测版本）；
- 非法 URL / 空 URL / 非法 JSON 一律 fail-closed，并保留可行动原因（不再被后续"未映射"分支覆盖）；
- 测试新增 3 条：goto 动作+URL+超时、back 动作无 URL、非法 URL 拒绝；原"未映射"用例改用 `page.interact`。

## 验证

- `dotnet test Tests/PuddingDesktop.Tests --filter BrowserBridgeCommandAdapterTests` ⇒ **7/7 通过**；
- 未运行产品/模型；适配器仍未接管执行（派发器仍走 controller），无生产行为变化。

## 未完成与影响

- 仍缺 snapshot/locate/waitFor、interact/tabs、截图映射；`expectedPageVersion` 在 goto 线缆缺失，接入执行器前需确认是否补协议字段（否则执行器版本门禁只能接受 Unknown，即不校验旧版本，属于已知取舍）。
- 派发器入口切换、controller 收缩、删除旧路径未做。
- 回滚 = revert 本提交（适配器+测试）。
