# 2026-10-08 注入改为执行器

| 改动 | 内容 |
|---|---|
| 注入 | `IDesktopUiSurface?` ⇒ **`IDesktopCapabilityExecutor?`** |
| 理由 | 表面**不含准入**；执行器 = `DesktopService`（`RunOnUiAsync` 里才有准入/闸门/预算） |
| `desktopId` | `new DesktopInstanceId("default")`（协调器既有写法） |
| using | `Pudding.DesktopConnection`（IVT 让 internal 接口可见） |
