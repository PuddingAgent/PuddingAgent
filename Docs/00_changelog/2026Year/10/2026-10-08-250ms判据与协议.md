# 2026-10-08 §12 250ms 判据与协议

| 项 | 内容 |
|---|---|
| 判据 | 250ms = **待校准候选**；**禁止**用单测/固定 delay 宣布通过；**校准前不引入硬切断**；达上限须 `incomplete_*` |
| 协议 | 真实 Runtime + 固定 fixture + 热身 + 重复样本 + **P50/P95/P99** + 繁忙情形 + 驱动扫描单独记 |
| 出处 | 方案 §6.1 / §E1 |
| 关联 | S-05（阅读预算）· S-09（视觉与坐标） |

## 价值

把"**250ms 待校准**"从我 changelog 里的一句口头待办，变成**外部可直接照做的判据 + 协议**；同时明确"**未认定 ≠ 通过**"的报法。

## 诚实边界

- 仅**整理判据与协议**（未做任何测量）；**未真机验证**。
