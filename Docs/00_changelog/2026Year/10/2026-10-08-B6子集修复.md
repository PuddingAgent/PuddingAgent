# 2026-10-08 B6：子代理绑定打通（父范围 + 期限夹取）

## 修复

| # | 规则 |
|---|---|
| ① | 子代理绑定必须带 `ParentTaskId`，否则明确拒绝 |
| ② | 找不到该父任务在**同一目标页**上的活跃授权 ⇒ 明确拒绝（可区分原因） |
| ③ | 父授权即将过期（剩余 ≤ 1s）⇒ 拒绝 |
| ④ | 子授权期限超过父**剩余期限** ⇒ **夹取**（§5），留 1 秒安全边界 |
| ⑤ | 服务新增可选 `TimeProvider? clock`；组合工厂传入 clock |

## 验证（4 条用例，TRX 判定）

| 用例 | 判据 |
|---|---|
| 合法子集（父 R\|W、子 R、5min） | **接受**且带 `GrantId` ✅ ← 本轮打通的关键 |
| 无父授权 | 拒绝，原因含 `parent` |
| 越范围（父 R、子 W） | 拒绝，无 `GrantId` |
| 期限夹取（父余 2min、子要 30min） | 接受，且子到期**不晚于**父 |

## 过程教训（第 N 次同一根因，已按硬纪律执行）
