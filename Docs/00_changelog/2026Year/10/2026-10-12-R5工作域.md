# R5 第三步（前置）：发布请求带 `WorkspaceId`

| 项 | 内容 |
|---|---|
| 缺口 | 发布请求不携带 workspace ⇒ 发布端无从决定工件域（§7.2 要求"调用 workspace 的工件域"） |
| 修法 | `BrowserScreenshotPublishRequest` 首字段加 `WorkspaceId`；工具传 `context.WorkspaceId` |
| 已读实的 Host 范式 | `VisionArtifactStorageService` 导入字节 ⇒ `artifactId`；`artifact://<id>` + `OkWithParts`；`read` 前判 `SupportsVision`/`Protocol=="responses"`，否则明确 `ModelCapabilityMismatch`/`ToolOutputNotSupported` |

## 未完成

Host 发布端实现（`Source/PuddingHost/BrowserBridge/`）+ 组合根注册 + "工件可解析为非空图片"/"坏块被拒"用例。

## 诚实边界

- 本轮只改**接口载荷与调用点**；**发布端仍未实现** ⇒ **端到端视觉通道尚未成立**；**未真机验证**。
