# 2026-10-08 结果编码用例（4 条）

| 用例 | 判据 |
|---|---|
| 标量保真 | 观察 id/MIME/字节/版本/世代/detail |
| **presence 语义** | `0` ⇒ `Has*==true` 且值为 0；未给 ⇒ `Has*==false` |
| 分块 | 顺序 + `IsLast` + 字节 |
| 空分块 | 保持空 |

## 为什么这几条重要

"可选 double = 0"与"未设置"在坐标语义里**完全不同**（0 是合法坐标）；分块顺序错会导致图片损坏。这两点在这条链路上**只能靠直接断言**保证。
