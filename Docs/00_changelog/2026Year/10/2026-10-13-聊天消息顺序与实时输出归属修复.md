# 2026-10-13 聊天消息顺序与实时输出归属修复

## 改动

- `Source/PuddingPlatformAdmin/src/pages/chat/client/canonicalMerge.ts`：较新快照按服务端消息顺序合并，分页遗漏历史通过共享身份锚点保留；同 ID 的 activeRun 输出、状态变化参与等价判断，拒绝旧游标回退；历史未变时复用 messages 引用。
- `Source/PuddingPlatformAdmin/src/pages/chat/components/MessageList.tsx`：优先用快照 window.turnId 匹配当前回合，反向寻找同回合最新消息；明确的续轮身份不再按旧 commandClientId 归入历史回复。同回合只有最后一条助手消息接收 canonical 内容投影及渲染权重，减少重复 Markdown/工具树渲染；messages 未变时跳过历史投影重建。
- `Source/PuddingPlatformAdmin/src/pages/chat/hooks/useTurnSurfaceStore.ts`：快照按 window.turnId 优先归属，初始化调度器并重置会话后再摄入首个快照，避免首次实时内容被清空。
- 对应 `canonicalMerge.test.ts`、`messageTurnMerge.test.ts`、`MessageList.test.tsx`、`hooks/__tests__/turnSurfaceStore.hydration.test.ts` 增加顺序、续轮、单一投影归属及首快照回归；更新子项目 `code_map.md`；`package.json` 升至 6.4.5。
