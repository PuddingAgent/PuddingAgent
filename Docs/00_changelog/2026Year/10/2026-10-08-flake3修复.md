# 2026-10-08 flake #3 修复

| 项 | 内容 |
|---|---|
| 现象 | 整链第 2 次未产出清单；`PuddingHost.Tests` 274/275 |
| 用例 | `WatchdogTimeout_CancelsBlockedReceiveAndDetachesConnection` |
| 异常 | `TimeoutException: Condition was not reached before the test timeout.` |
| 根因 | 等待助手**默认 2s**；整链负载下 watchdog 拆卸偶超时 |
| 修法 | 默认 **2s → 15s**（**谓词仍必须成立**，不放宽断言）；**两处**同型助手都改 |
| 验证 | `PuddingHost.Tests` **5 次连跑 275/0**；`PuddingDesktop.Tests` 全绿 |

## 意义

这是"**20× 门禁真正要找的东西**"：低概率、只在整链负载/多次连跑下暴露。⇒ 一键脚本的 `-Times` 委托分支**首次使用就抓到它**（脚本自身错误处理也正确：`CHAIN-FAILED` + exit 1）。

## 诚实边界

- 提高超时**不改变判据**（谓词必须达成）；**未真机验证**。
