# 2026-10-08 分发级用例

| 断言 | 含义 |
|---|---|
| `ScreenshotCount == 1` | 请求**分发到了截图入口** |
| `SnapshotCount == 0` | **没有**落回快照分支（原缺陷的形态） |

## 关键写法（照既有用例）

```csharp
var harness = ServiceHarness.Create(allowed: DesktopCapability.BrowserScreenshot, hasThreadAccess: true);
harness.Targets.RegisterPage(target, DesktopPageVersion.Require(1), DesktopPageReadiness.Interactive);
var response = await harness.ExecuteAsync(
    DesktopCapability.BrowserScreenshot,
    DesktopCapabilityRequest.ForScreenshot(new BrowserScreenshotRequest(target, DesktopPageVersion.Require(1))));
```

## 教训

**"分发级"是被长期漏掉的一层**：契约、proto、线缆、表面、工具都有用例，**服务分发没有** ⇒ 一个语法合法的共享 `case` 标签就能让功能整体失效而全绿。**新增能力时应包含"分发级"用例**（已补入《新增能力一致性清单》待办）。
