# 2026-10-08 B5 坐标 P4b：Bridge 转发

| # | 改动 |
|---|---|
| ① | `PageInteractArguments` 加 `double? X` / `double? Y` / `string? ObservationId` |
| ② | `InteractAsync(..., CancellationToken ct, double? x = null, double? y = null, string? observationId = null)` + 命令里写入三字段 |
| ③ | `case "pointer_click" or "pointer_move" when args?.X is { } px && args.Y is { } py` ⇒ 非 `IPointerInputPage` **明确失败**；`observationId` 非空 **拒绝**；否则 `PointerAsync(kind, px, py)` |

## 过程记录（两处教训）

1. **签名改错位置**：把 `x/y/observationId` 加在 `ct` **之前**（成了必填）⇒ 7+ 既有调用点全部编译失败 ⇒ 按纪律整体回退。正确做法：**可选参数放末尾**（C# 规则：可选参数必须在必填参数之后）。
2. **多行锚点再次失配（CRLF）**：改用**行数组插入**（先定位 `InteractAsync(` 再找其 `CancellationToken ct)` 行）⇒ 一次命中。
3. ③ 的插入锚点用**正则捕获缩进**（实际 12 空格，我先猜 16）—— 若失败会留下"发送方已发、消费方忽略"的静默丢弃。
