# 抖动调查推进

| 项 | 内容 |
|---|---|
| 失败栈（来自保留的 TRX） | `Assert.Fail` ← **`WaitUntilAsync`（L332）** ← `A_Replaced_Waiter_Stops_Consuming_Notifications()` |
| **位点缩小** | 发生在**条件等待**内 ⇒ **L140 或 L145**（**不是** L155 的 `consumer.WaitAsync(10s)`） |
| 诚实留白 | 现有证据**无法区分** L140 / L145（助手消息**不回显条件**） |
| **本轮改进** | `WaitUntilAsync` 加 **`[CallerArgumentExpression]`**（末位可选 ⇒ 既有调用点零改动）⇒ 失败消息变为 **`条件在 10 秒内没有成立: {expression}`** ⇒ **下次抖动自报是哪条条件** |
| 验证 | `SessionEventStreamServiceTests` **9/9** |

## 仍未做（刻意）

**未加入 `known-flaky.txt`**（证据不足以证明无害）；链遇此失败仍应记 **NEW INSTABILITY** 并**拒绝清单**。

## 范围

该用例/服务**不在**浏览器交付目标 R1–R6 内；本轮把"未知"缩小为"**两条候选条件之一**"并让**下一次自证**。
