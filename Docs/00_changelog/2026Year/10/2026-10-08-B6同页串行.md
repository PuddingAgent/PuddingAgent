# 2026-10-08 §5 父子同页写串行 + 全量链复跑

## 用例（TRX 判定 1/1）

| 步骤 | 判据 |
|---|---|
| 父代理同页写在途（surface 用 `Gate` 卡住） | `Surface.NavigateCount == 1`（父已进驱动） |
| **子代理**此时发同页写 | **失败**，且 `NavigateCount` **仍为 1**（拒绝发生在触碰页面之前） |
| 放行父操作（`finally` 释放租约）后子代理重试 | **成功**，`NavigateCount == 2` |

⇒ §5 要求的"父代理同页写许可先停止并等待在途操作结算，子代理取得独立授权/租约后才输入"**机制成立**：
判据是唯一权威的"**每页一份写租约**"（`BrowserAuthorizationDenial.PageBusy`），与调用者是谁无关。

## 全量链复跑（round-241）

- 清单**再次产出**（`temp/test-out/delivery-manifest.json`），`stage: ready-for-external-deploy`；
- 自报**未验证项 20 条** + 外部四步（`startup`/`restart`/`crash-recovery`/`exit-reclamation`）；
- ⇒ round-240 的 B6 修复与更早改动**无回归**。

## 诚实边界

- 本用例覆盖**写租约串行**；§5 其余仍缺：真实 Runtime child/parent run、工具发现/注入、取消/超时/父撤权/重连的**级联释放**、有界父结果。
- **未真机验证**（本用例是进程内逻辑，真机并发仍需外部观察）。
