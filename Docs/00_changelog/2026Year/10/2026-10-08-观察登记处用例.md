# 2026-10-08 观察登记处用例（xUnit）

| 用例 | 判据 |
|---|---|
| 同版本同世代 | 解析成功且 `ScrollY` 如实 |
| **新页面版本** | 失败 **且 `Count == 0`** |
| **新连接世代** | 失败且移除 |
| 未登记 / 空 id | 永不解析 |
| `zoom = 0` | **登记时** `ArgumentOutOfRangeException` |
| `InvalidateForPage` | 只保留给定范围 |
