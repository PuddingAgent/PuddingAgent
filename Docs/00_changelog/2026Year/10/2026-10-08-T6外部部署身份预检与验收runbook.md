# 2026-10-08 T6 准备：外部部署身份预检门禁与验收 runbook

> 新增：`TestScripts/verify-external-deploy-identity.ps1`、

> [修复方案](../12_features/首Token等待与上下文指示器修复方案-2026-10-07.md) §5（产品验收）

## 1. 问题

前端产物要经 `PuddingHostContent.props`（`PuddingPlatformAdmin/dist/**` → `wwwroot/admin/**`）
才会被 Core 读取：**只重建前端不生效，只重启 Core 也不重新部署静态产物**。而「运行中实例到底加载了
哪一份构建」只能靠页角徽标的 `v版本号[+dirty] · 短哈希 · 构建时间` 判断。此前没有任何门禁核对这条链路。

## 2. 交付

### 2.1 身份预检门禁（只读，不重启任何进程）

`TestScripts/verify-external-deploy-identity.ps1` 核对**三方**身份并给结论：

| 环节 | 来源 |
|---|---|
| 源码 | `Source/PuddingPlatformAdmin/package.json` 的 `version` + `git rev-parse --short HEAD` + 工作树是否脏 |
| `frontend-dist` | `dist/**.js` 里的构建期注入身份 |
| `served` | `Source/PuddingAgent/bin/**/wwwroot/admin/**.js`（Core 实际读取的产物） |

不一致、或 dist 带 `+dirty` ⇒ 非零退出。脚本实现上踩过三个坑，都已在代码注释里写死：

1. **注入有两种形态**：开发期是 JSON 字面量，生产压缩（umi/terser）成 **JS 对象字面量** ——
   键不带引号、`true` 变 `!0`、键顺序任意（实测 `version` 在对象**末尾**）。
2. **兜底常量会冒充身份**：产物里必然同时存在 `FALLBACK_FRONTEND_BUILD`（`0.0.0`/`unknown`），
   必须显式排除，否则会把「未构建」读成「已构建」。
3. **固定窗口会把两个相邻对象串起来**：兜底对象与真实注入对象相邻（实测索引 599524 / 599945），
   用「version 前 400 字符」取字段会把兜底的 `commitShort/dirty` 配到真实 version 上。
   改为**只在包含该 version 的对象字面量内**取字段（花括号配对扫描）。
4. 另外：脚本是**非 ASCII**，Windows PowerShell 5.1 只按 BOM 判定 UTF-8 ⇒ 必须带 **UTF-8 BOM**；
   且不能用 PS7 专有的数值分隔符（`1_200`）。仓库自带 `check-script-encodings.ps1`（C-5 门禁）
   已对本文件报 `OK bom=True nonascii=True errors=0`。

### 2.2 验收 runbook

`Docs/13_runbooks/外部部署与产品验收-上下文治理修复-2026-10-08.md`：干净检出 → 前端构建 →
Core 构建 → 预检门禁 → 外部控制器重启 → 徽标/loaded identity 核对 → 新会话 smoke；
并写明**新会话 smoke 必须分别记录**「accepted→首个推理增量」「accepted→首个正文增量」「浏览器首绘」，
不得合并成一个数、不得据此声称省时。

## 3. 实测状态（本机 2026-10-08）：NOT READY

| 环节 | 实测 |
|---|---|
| 源码 | `package.json` **6.4.4**；HEAD `5ee0499`；工作树**脏**（并行写入方 WIP） |
| `frontend-dist` | **6.4.4** / `7545ea1` / builtAt `2026-10-08T17:40:22Z` / **dirty=true** |
| `served(wwwroot/admin)` | **6.4.1** / `6e978cb` / builtAt `2026-10-08T13:48:34Z` |
| 预检结论 | `PREFLIGHT FAILED`：dist 带 dirty，且 Core 未重新复制 dist（served 比 dist 旧） |

⇒ 「代码侧 `ready-for-external-deploy`」与「运行中实例已加载新代码」是两件事，必须分开表述；
本批**没有**做部署，也**没有**重启任何进程。
