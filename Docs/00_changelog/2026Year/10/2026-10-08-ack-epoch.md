# 2026-10-08 ack epoch 如实往返

## 改动

| 侧 | 改动 |
|---|---|
| 编码（Desktop→Core） | `Epoch = ack.Epoch.IsKnown ? (ulong)ack.Epoch.Value : 0UL`（apply 与 revoke 两处） |
| 解码（Core） | `ack.Epoch == 0 ? BrowserPageGrantEpoch.None : new BrowserPageGrantEpoch((long)ack.Epoch)` |
| 用例 | 已知 epoch(7) **原值往返**；未指定(0) ⇒ **None** 且 `IsKnown == false`（**不臆造成 1**） |

依据：`BrowserPageGrantEpoch(long Value)`，`None = 0`、`Initial = 1`、`IsKnown => Value > 0`。

## 验证

| 套件 | 结果 |
|---|---|
| `Pudding.CapabilityBrokerTests` | 见运行输出（应 102/102） |
| `Pudding.DesktopConnectionTests` | 93/93 ✅ |

## 过程记录（又一次同一个坑）

第一次我用**多行文本替换**改这两处 ⇒ **0 处匹配**（CRLF），于是新用例失败（期望 7 实得 0）、自动回退。
改用**行定位**（`Epoch = 0,` 逐行替换 + 依据邻近行判断 applyAck/revokeAck）后一次通过 —— **多行改动一律行定位**这条纪律再次被验证。
