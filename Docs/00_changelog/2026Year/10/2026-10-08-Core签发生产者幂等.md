# 2026-10-08 Core 侧签发生产者（第二刀）：单飞与幂等

## 交付

| 项 | 内容 |
|---|---|
| **单飞** | `_inFlight` = `ConcurrentDictionary<string, Lazy<Task<…>>>`，键为 `目标|行动者|任务|父任务`；在途期间相同申请**加入同一次**；记账在 `finally` 清理 |
| **不自动重发** | 拒绝只如实带回原因（避免把权威的"拒"放大成重试风暴） |

## 验证（5 条，TRX 判定）

| 用例 | 判据 |
|---|---|
| accepted | `Issued=true` + `GrantId` |
| rejected | `Issued=false` + 可区分原因（`parent grant`） |
| 通道抛异常 | `Issued=false`（不当成功） |
| **并发相同请求** | 发送 **1** 次，两个调用方拿到**同一** outcome |
| 不同目标 | 发送 **2** 次 |

## 过程记录（三次尝试才落地）

前两次分别因 **`out var` 可空性告警（CS8600）** 与 **`ContinueWith` 重载解析（CS1503）** 失败。
最终形态刻意避开两者：**`Lazy<Task<…>>` 做单飞** + **`finally` 清理** —— 无 `out var`、无 `ContinueWith`。

## 诚实边界

- **仍未接真实通道**：`DesktopSession` 的泛型执行入口尚未定位（向上找不到 `public …Task<CapabilityResult…>` 签名）⇒ 下一步读**方法头**而非猜测。
- **仍未接真实触发点**（目标事实来自 Bridge 的 `IsAgentTarget` 描述符 + 当前任务身份）。
- **未跑全量链**（本轮改动仅 CapabilityBroker 两文件 + 文档）；**未真机验证**。
