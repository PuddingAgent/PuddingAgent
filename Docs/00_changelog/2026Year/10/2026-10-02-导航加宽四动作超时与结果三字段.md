# 导航加宽完成：#3 四动作 / #4 超时 / #5 结果三字段 —— `browser_navigate` 因此完全解锁

## 改动（跨侧协议变更，两侧同提交）

| 层 | 文件 | 改动 |
|---|---|---|
| 线缆 | `desktop_capability.proto` | `NavigateCommand` 新增 `action = 4`（**字符串线名**）、`timeout_ms = 5`；`NavigateOutcome` 新增 `optional navigation_ok = 4`、`optional status_code = 5`、`error_text = 6` |
| 契约 | `Contracts/Desktop/WebViewContracts.cs` | 新增 `DesktopNavigationAction`（Goto/Back/Forward/Reload/Stop）+ 冻结线名表 `DesktopNavigationActionWire`（严格解析，空串按 goto 兼容旧帧）；`NavigateRequest` 支持 action/timeout、`Url` 变可空且**仅 goto 必填**；`NavigateResult` 新增 `Ok?`/`StatusCode?`/`ErrorText?` |
| Core→proto | `CapabilityBroker/WireMapping.cs` | 写 action/timeout；非 goto 的地址写空串；**幂等键补上 action 与 timeout**（不同动作是不同请求）；结果端读三个 optional |
| proto→DTO | `DesktopConnection/Mapping.cs` | 解析 action（未登记即拒绝）、仅 goto 校验绝对地址、超时 0⇒默认；结果端三个 optional **有 presence 才写** |
| Desktop 侧 | `DesktopSurface.Browser/BrowserRuntimeDesktopSurface.cs` | goto 走 `GotoAsync`（带 `TimeoutMs`）并把 ok/status/error 作为**结果事实**回带；back/forward/reload/stop 走运行时对应 API，ok/status/error **如实留空** |
| Bridge 侧 | `Host/BrowserBridge/BridgeBrowserCapabilitySurface.cs` | 与 Desktop 侧**同一套**语义（含结果事实与"未知即空"） |
| 测试 | `Rpc.ProtocolTests` / `Host.Tests` / `DesktopSurface.BrowserTests` | 线缆字段号快照；`Navigate_Back_…` 新用例；导航失败语义用例**改判**为"事实而非失败" |

## 语义更正（重要，Agent 可见）

**导航"没成功"从能力失败改为结果事实**（`Ok=false` + `StatusCode` + `ErrorText`）：
① 上层要能区分"这个地址去不了"与"运行时坏了"——结果事实比错误码表达得更准；
② 迁移前的 `browser_navigate` 工具正是把 ok/status 当结果字段返回，若这里仍升级为失败，
**两条传输的 Agent 可见行为就会分叉**。原用例
`FailedNavigationIsATargetErrorNotAnInternalError` 已改判为 `FailedNavigationIsAFactNotAFailure`
（保留其"不得报 Internal"的原始意图）。

## 过程教训（工具层，记下来避免重犯）

1. **改了契约的可空性，必须立刻构建"依赖它的项目"，不能只构建契约本身**：Phase A 把
   `NavigateRequest.Url` 改成可空，我只构建了 Contracts/Protocol，结果 Core 与 Desktop 侧
   三处空引用在 Phase B 才暴露（多花两次构建往返）。
2. 正则里 `\s*` 已吃掉 `\r\n`，**再写一个显式 `\n` 必然不匹配**；以及替换多括号表达式时
   **必须数清收尾括号**（本轮两次因少一个 `)` 而编译失败）。⇒ 跨行锚点优先用单行锚点或让正则
   自带缩进捕获。

## 解锁与剩余

`browser_navigate` 的缺口（#3/#4/#5 + #12 标题）**全部闭合** ⇒ 第三个可迁移工具（继 locate/snapshot/wait_for/interact 之后的第五个）。

| 剩余缺口 | 内容 |
|---|---|
| #6 | 标签页 `new`（解锁 `browser_tabs`） |
| #1 | 上下文 `create`/`close`（解锁 `browser_context`） |
| #13 | `fill`/`type` 空文本（低优先） |
