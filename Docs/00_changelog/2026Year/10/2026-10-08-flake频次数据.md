# 2026-10-08 把"它偶尔失败"变成可查频次

## 为什么

上一轮把未知不稳定**拦住**了，但"这条已知 flake 多久发生一次"仍无数据 —— 其所有者无法判断该不该修。
本轮补上频次数据，**全部落在交付链自己的文件里**（不碰他方测试代码）。

## 三个件

| 件 | 作用 |
|---|---|
| `TestScripts/flake-observations.txt` | **append-only** 日志：每行 `<yyyy-MM-dd> <套件> <用例全名>`（ASCII，`#` 注释） |
| `TestScripts/flake-stats.ps1` | **只读统计**：按次数降序列出 `count<TAB>用例名` + `TOTAL`；缺日志**退 2**（区分"没有数据"与"零次"）；支持 `-TestName` 过滤 |
| `delivery-manifest.ps1` | 重跑吸收失败时：**追加**一行观测，并把该用例的**累计次数**写进 notes（⇒ 清单里就能看到"这是第几次"） |

## 验证（实跑）

| 项 | 结果 |
|---|---|
| `flake-stats.ps1` 对真实日志 | `1 ⇥ …SecondConnection_CannotReplaceAwaitingHelloConnection` + `TOTAL 1` ✅ |
| `-TestName` 过滤 | 命中 1 / 未命中 0 ✅ |
| 缺日志 | `警告: … not found` + **exit 2** ✅（不假装零次） |
| `delivery-manifest.ps1` | **解析通过**、**纯 ASCII（0）** ✅ |
| 门禁（`GateEvidenceReportTests`） | 脚本必须引用两个新文件，且两文件必须存在 ✅（338/338） |
| **全量链** | **1608 / 0**、首跑即绿、无重试（本轮 Host **未** flake） |

## 诚实边界（诚实登记）

- **脚本自动追加那一行尚未被真实触发**：本轮 Host 没复现，日志里的 1 行是我按 **round-162 的真实观测**
  （该轮 notes 明确记了这条用例）**手工补录**的 ⇒ "写入口"目前只有**源码核对 + 统计侧实跑**保证。
  （对照：round-162 已实跑过"重跑吸收失败"这个**分支**本身，故该分支可达性是实证的。）
- **日志会持续增长**：当前无轮转/上限（登记；量级极小，一轮至多几条）。
- **只有"重跑吸收"的失败会被记录**：直接失败的套件**不**进日志（它们的失败本来就会拦住清单，不需要频次）。
- **不改他方测试**：因此这条 flake 的**修复**仍在其所有者手里；本件只是把"它多久一次"变成可查数据。
- **未真机验证**；B1 身份与 250ms 门限仍未拍板。
