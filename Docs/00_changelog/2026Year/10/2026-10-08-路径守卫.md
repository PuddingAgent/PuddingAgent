# 2026-10-08 commit-round.ps1 路径存在性守卫

| 项 | 内容 |
|---|---|
| 症状 | 路径写错 ⇒ `MSB1009 项目文件不存在`，却被报成 **"tests failed"** ⇒ 误导（险些误判为 flake/产品失败） |
| 修法 | 跑测试前 `Test-Path $project`；不存在 ⇒ **`test project not found: <path>`** + exit 1 |
| 反向验证 | 传 `Source/NoSuchProject/…` ⇒ 输出 **`test project not found`** ✓ |
| 附带更正 | AgentTools 测试工程在 **`Tests/`** 下（`Source/` 下不存在）；正确路径 **93/93 绿** |

## 教训

**门禁的报错信息本身也要准确**：含糊的 "tests failed" 会让人**先怀疑产品**（我本轮就先怀疑了 flake）——**报错要指向真实原因**。

## 诚实边界

- 仅改进错误信息与提前拒绝；**未真机验证**。
