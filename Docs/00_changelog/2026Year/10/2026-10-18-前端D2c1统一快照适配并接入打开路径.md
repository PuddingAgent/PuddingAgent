# 2026-10-18 前端D2c1统一快照适配并接入打开路径

## 改动

- 新增 `src/pages/chat/client/conversationSnapshotAdapter.ts`：
  - `getAgentConversationFromSnapshot` 把统一打开快照转换为现有 `AgentConversationView`：
    - 最近消息页直接映射消息身份/角色/时间/TurnId；短消息使用快照全文；
    - 长消息（`hasMoreContent`）按 UTF-8 字节分段调用 `getConversationMessageContent` 续读；单条 ≤256 KiB、整页自动读取合计 ≤1 MiB，超出保留预览（后续显式展开入口）；
    - `visibleTurns`/`activeTurn` 摘要映射为旧 `processSummary`（计数）与 `turnOutcome`（终态）；不伪造未知计数；
    - `eventCursor` 使用事件 head（与旧契约/状态投影一致），`mainSessionId` 使用快照 conversationId；
  - 回退边界：新端点不可用（旧 Core 未部署）→ 旧投影；活动 Turn 未终态 → 旧投影一次（活动正文/工具轨迹仍由旧实时投影负责）。
- `ChatClientStore` 的 `AgentChatApiPort` 新增可选 `getConversationFromSnapshot`，提供时优先于旧 `getConversation`；单飞/取消/版本守卫沿用。
- `agentChatApi` 新增包装函数（注入旧投影作为回退）；`chat/index.tsx` 接线到 Store。
- 前端版本 `6.7.1 → 6.8.0`；frontend code_map 登记适配层。

## 验证

- `pnpm exec jest conversationSnapshotAdapter.test.ts chatClientStore.test.ts`：**20/20 通过**：
  - 快照映射消息/过程摘要/终态/eventCursor；
  - 长正文两段拼接；
  - 活动 Turn 未终态回退旧投影；
  - 新端点 404 回退旧投影；
  - Store 优先使用快照路径且不调用旧 `getConversation`。
- `pnpm run build`：成功，`[chat-bundle-budget] ok sync=1383742 chat=362040 common=435912`。
- `pnpm run tsc`：仅基线既有错误，本次文件无新增类型错误。
- 未部署、未重启 Core、未改 `D:\data`（索引维护已在 `79dd3b7` 单独提交）。

## 未完成与影响

- **当前运行中的旧 Core 没有 `conversation-open` 端点**：适配层会立即回退旧投影，所以线上行为不变；部署新 Core 后才会真正走快照路径。
- 活动 Turn 未终态仍回退旧 `/conversation`：生成期间的正文/工具轨迹仍依赖旧实时投影，D3c 需让 SSE 合并接管终态消息物化后再移除回退。
- 历史向上翻页未接入新 `/history`：当前适配层只有首屏 20 条；`hasMore`/滚动加载仍走旧 chat 状态，D2c2 处理。
- 过程明细分页未接入新 `/process`：仍由 TurnSurfaceStore 懒水合旧单消息明细接口（真实库已有 message 索引，单条查询已收敛）。
- 未在真实 WebView2 验证首屏/长正文/活动 Turn 观感；D 门禁（不重复三套查询、正文完整性、分页）尚未全部满足。
