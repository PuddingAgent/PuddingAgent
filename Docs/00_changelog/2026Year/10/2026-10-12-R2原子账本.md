# §4.2 原子执行账本

| 语义 | 处理 |
|---|---|
| 不存在 | **Execute**（唯一获胜者） |
| 同指纹 · 在途 | **AwaitPending**（等同一完成源） |
| 同指纹 · 已完成 | **ReplayCompleted**（同一终态） |
| **指纹不同** | **Conflict**（`operation_id_conflict`，不透露原结果） |
| **结果未知** | **不复用、不当安全重试**；记录**永不清理** |
| 在途记录 | **永不被驱逐**（容量与保留期都不动它） |

**证据**：8 条测试 · 套件 **388/388** ✓
