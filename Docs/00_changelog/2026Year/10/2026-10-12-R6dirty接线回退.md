# 更正：回退 `--dirty` 接线

| 项 | 内容 |
|---|---|
| 症状 | 套件全绿，但链 fact 阶段 **`参数 --dirty 缺少取值`** ⇒ **`manifest NOT emitted`** |
| 严重性 | **交付路径退化**（没清单就没交付证据）—— 比"dirty 未接线"严重 |
| 处置 | 回退两文件到 `6504c0d` ⇒ 重跑整链**确认清单恢复产出**；`dirty = null`（**尚未采集，诚实**） |
| **新纪律** | **"套件全绿" ≠ "交付链完好"**：改采集/发布路径后必须**断言清单真的产出** |

## R6 剩余

**先确认 CLI 参数解析语义**（不猜）再传 `--dirty`，或改走 facts.json/环境变量；真机 G1–G11 · 250ms。

## 诚实边界

- 本轮为**回退与恢复**；**未真机验证**。
