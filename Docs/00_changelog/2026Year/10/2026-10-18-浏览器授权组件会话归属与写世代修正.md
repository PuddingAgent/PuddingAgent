# 2026-10-18 浏览器授权组件会话归属与写世代修正（I1）

## 目标与结论

按 [ADR-097](../../../07_architecture/111ADR-097Agent浏览器控制一期闭环与单一执行链ADR.md) D3/D4 与[一期整体实施方案](../../../12_features/Agent浏览器控制一期整体实施方案-2026-10-18.md) §3.2 的 I1 要求：先修正并独立验证候选会话组件，再谈宿主接入。本轮**只改 `PuddingBrowser.Authorization` 组件与其测试工程**，不改宿主、不修改旧 `BrowserPageLifecycle`/`BrowserAutomationAuthority`，因此产品行为与历史链级证据不受影响。

## 改动

- `Source/PuddingBrowser.Authorization/AgentTargetSession.cs`：新增宿主注入的 `AgentTargetOwnerId` 与 `AgentTargetControlHandle`（所有者 + 仅诊断用展示名）；`AgentTargetSession` 记录控制句柄并暴露 `Owner`；快照增加独立写世代与两轴运行控制态 `AgentTargetControlState`（`Paused` / `UserTakeover`）。
- `Source/PuddingBrowser.Authorization/AgentTargetAuthorization.cs`：请求携带可信控制句柄（缺失 fail-closed）；票据增加唯一 `AgentTargetPermitId`、`AgentTargetWriteEpoch` 与取消信号；拒绝码从 6 种扩到 9 种（新增 `browser_control_handle_required`、`browser_owner_mismatch`、`browser_permit_invalid`）。
- `Source/PuddingBrowser.Authorization/AgentTargetSessionAuthority.cs`：
  - **会话归属**：选页必须带可信控制句柄（无句柄不产生目标）；调用方所有者不匹配拒绝；换所有者原子替换会话并作废旧票据；新增 `NotifyOwnerUnavailable`（所有者失效收回控制权）与 `NotifyPageClosed`（关页只作废匹配目标）。
  - **写世代**：进入暂停/接管立即推进写世代并取消在途写；退出不推进、不回退，旧写票据不能复活；重复进入幂等。控制世代仍只表达目标作废。
  - **唯一票据与精确释放**：`CompleteOperation`/`CancelOperation` 只按 `PermitId` 精确释放；释放后 `Revalidate` 必拒；迟到/重复完成不清后来票据的占用；`Revalidate` 核对连接世代、控制世代、会话、写世代、取消状态与票据仍在途。
- `Source/PuddingBrowser.AuthorizationTests/AgentTargetSessionAuthorityTests.cs`：由 20 条扩到 37 条状态机用例（另有 3 条边界用例，合计 40），覆盖 F7 反例、归属、两轴控制、取消与精确释放。
- `Source/PuddingBrowser.Authorization/code_map.md`：按当前语义更新，并明确仍无生产消费者。

## 验证

- **先红**（修复前，旧实现 + 3 条 F7 反例）：`dotnet test Source/PuddingBrowser.AuthorizationTests` ⇒ 失败 3 / 通过 21；三条失败正是
  `TakeoverRestoreDoesNotReviveAQueuedMutation`、`ADuplicateCompletionCannotReleaseAnotherOperationsOwnership`、`AReleasedPermitCannotBeRevalidated`（与审阅报告 F7 的静态推演一致）。
- **后绿**（修复后）：同一命令 ⇒ **通过 40 / 失败 0**（1 s）；组件行覆盖 88.18%、分支 76.11%、方法 84.04%。
- **无生产消费者复核**：`Source/`、`Tests/` 内除组件与测试工程外，检索 `PuddingBrowser.Authorization`、`AgentTargetSessionAuthority`、`AgentTargetControlHandle`、`AgentTargetPermit` 为 **0 命中**（结论与审阅报告 F7 一致，本轮未接入宿主）。
- **未验证**：未运行 PuddingDesktop/PuddingAgent，未调用真实模型，未重跑历史链级与 11 条反例；本切片是组件级证据，不能替代 I2/I3 主链与真机验收。

## 未完成与影响

- I0 主链反例（默认截图依赖通道、暂停拒读、未统一执行器、inputMode/滚动丢失、回执）尚未落成可执行断言；I2 宿主接入、I3 真实模型闭环、I4 外部验收均待施工。
- 本轮组件 API 有破坏性签名变更，但组件无生产消费者，回滚 = revert 本提交 + 重启无需改配置。
- 旧 `BrowserPageLifecycle`/`BrowserAutomationAuthority` 未动；在新旧权威同时在场期间不得把本组件误当作已生效权威。
