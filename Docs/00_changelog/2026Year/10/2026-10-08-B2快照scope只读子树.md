# 2026-10-08 B2 快照 scope：只读该元素子树，两条传输都过线

## 目标 / 背景

设计 §151：「`browser_snapshot` 参数新增 mode、format、**scope(locator/ref)**、fields、limit、maxBytes、
cursor、sinceRevision。」

此前要"只看这个表/这块区域"，调用方只能先快照整页再自己筛（整页在多列表格里是几千行）。
本轮把 `scope` 做出来。**并刻意一次把两条传输都做通**——前几轮的经验是：只做一条必然留下
"同一参数在另一条传输上不存在"的不对称（滚动与游标都各栽过一次）。

## 改动

| 层 | 文件 | 改动 |
|---|---|---|
| 契约 | `Desktop/SnapshotContracts.cs` | `DesktopSnapshotOptions.ScopeRef`（null = 整页） |
| 运行时 | `PuddingBrowser.Abstractions/ScriptAndSnapshot.cs` | `SnapshotOptions.ScopeRef` |
| 驱动 | `WebView2DomClient.cs` | 快照脚本从 `scopeRef` 的节点（含自己）开始遍历（HTML 也取该子树）；**进入脚本前**先用与普通引用**同一条** `ValidateLocator` 规则校验作用域 ref；脚本内找不到即 `stale_element_reference`——**绝不退化成正页扫描** |
| 工具 | `BrowserSnapshotTool` | `scope` 参数（与定位器同形）：`kind=ref` 直接用；其它定位方式先 `LocateAsync(maxResults: 2)` 解析成**唯一** ref，**0 命中 ⇒ `browser_element_not_found`、多命中 ⇒ `browser_locator_ambiguous`**（不猜"大概就是这个"） |
| 桥接 | `BrowserBridgeCommandPayloads.PageSnapshotArguments.ScopeRef` + `RemoteBrowserPage` + `BrowserWorkspaceController` | 作用域随命令过线，由宿主交给驱动；两条传输同形 |

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingBrowser.AgentTools.Tests` | **53 / 53**（原 51 ＋ 2） |
| `PuddingDesktop.Tests` | **317 / 317**（原 316 ＋ 1） |
| `PuddingHost.Tests` | **258 / 258**（原 257 ＋ 1） |
| `ContractsTests` · `DesktopSurface.BrowserTests` · `DesktopServiceTests` · `AutomationTests` | 127/127 · 63/63 · 220/220 · 194/194 |

新增门禁：

- 工具层：`scope` 用 ref ⇒ `options.ScopeRef` 就是它，**且不产生额外定位跳**；用 css ⇒ 先定位再把
  **解析出的 ref** 传下去；0 命中 ⇒ `browser_element_not_found`；多命中 ⇒ `browser_locator_ambiguous`
  （为此给替身加了"命中数可控"的开关）；
- 驱动层（脚本结构断言）：`input.scopeRef` 存在、找不到时**先返回** `stale_element_reference`、
  遍历发生在其后（"绝不退化成整页"是结构上可验证的）；
- 桥接层：`scopeRef` 确实上了线（断言线缆 JSON 的 `scopeRef`/`includeDom`/`includeAccessibilityTree`）。

**取红实测**：把脚本里的"找不到就报错"改成 `root = root || document.documentElement`
（即静默退化成整页）⇒ `SnapshotScript_ScopesTheScan_AndNeverFallsBackToTheWholePage`
**恰好变红**；复原后 317/317 复绿。

## 已知边界（诚实登记）

- **真机作用域行为未验证**：本环境跑不了真实 WebView2；shadow DOM 内元素作为作用域、跨 iframe 作用域
  等场景需外部进程内 smoke 复核（脚本用 `document.querySelector` 找作用域节点，**不穿越 shadow root**）。
- **作用域不钉版本**：快照本身允许 `ExpectedPageVersion.Unknown`（"当前版本即可"），因此作用域 ref 与
  实际扫描之间理论上存在极小的版本漂移窗口；过期的 scope ref 会被校验拒绝，但"刚推进一版"的窄窗口
  不做额外加锁（与快照既有语义一致）。
- **非 ref 作用域多一跳**：css/role 等定位方式要先定位再快照（这是"唯一命中"判定的代价）；
  ref 作用域没有这一跳。
- **`format`（markdown/compact_json）与 `sinceRevision` 仍未实现**。

## 影响与回滚

- **行为变化（Agent 可见）**：`browser_snapshot` 新增 `scope`；不传时行为完全不变（整页）。
  传了以后只读该子树，payload 显著变小；作用域解析失败/过期都明确报错而不是悄悄退回整页。
- 线缆新增**可选**字段 `scopeRef`（旧宿主忽略它 ⇒ 退回整页行为，调用方须注意版本匹配）。
- 回滚：还原上表 6 个生产文件与 3 个测试文件及 code_map。
