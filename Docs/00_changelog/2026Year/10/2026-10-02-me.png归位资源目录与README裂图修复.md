# 2026-10-02 me.png 归位到 Docs/20_resources/Images 并修复 README 裂图

## 改了什么

按用户 2026-10-02 裁定（第 6 条「放到 Docs 目录的子目录（资源/图片），并修复裂图；用工具生成小图」）：

- 新建资源目录 `Docs/20_resources/Images/`（`Docs/20_resources/` = 资源文件夹，`Images/` = 图片文件夹）。
- 根目录 `me.png`（1024×1024 RGBA，1,778,273 B）移动到 `Docs/20_resources/Images/me.png`。
- 用 Pillow 生成小图 `Docs/20_resources/Images/me-200.png`（200×200，66,401 B，LANCZOS + optimize），供 README 使用。
- `README.md`、`README_zh-CN.md` 第 4 行图片源：`me.png` → `Docs/20_resources/Images/me-200.png`。
  （此前 `me.png` 被 `.gitignore` 的 `/me.png` 规则忽略且未入库，README 在 GitHub 与任何新克隆上都是裂图。）
- `.gitignore`：删除 `/me.png` 规则并留下说明（图片已入库；`/checkpoint.json`、`/$null` 等根级运行时规则保留）。

## 验证

- `Pillow 12.3.0`：原图 `(1024, 1024) RGBA` → 小图 `(200, 200)`，字节 1,778,273 → 66,401（−96.3%）。
- 路径核对：`Docs/20_resources/Images/me-200.png` 存在，README 中的相对路径 `Docs/20_resources/Images/me-200.png` 可解析；根目录已无 `me.png`。
- 未运行构建/测试：仅静态资源与文档改动。
