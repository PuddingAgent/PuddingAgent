# 2026-10-18 前端D2a统一打开与分页API客户端

## 改动

- 新增 `src/pages/chat/client/conversationOpenTypes.ts`：阶段 C3 统一打开/历史/过程分页响应契约的前端镜像。
  - ASP.NET Core 当前未全局启用 `JsonStringEnumConverter`，DTO 枚举按数字序列化；这里冻结 `ReadModelInitializationStates` / `ConversationSyncStates` / `TurnTerminalStates` / `SummaryCompletenessStates` / `SubAgentRunLifecycleStates` 取值，禁止按字符串猜。
  - 明确 `snapshotCursor`/`eventHead` 分离、`representationTag`、`partial/syncing`、历史键集游标、过程分页边界字段。
- 新增 `src/pages/chat/client/conversationOpenApi.ts`：
  - `getConversationOpen`（`conversation-open`，支持 `messageLimit`、`If-None-Match`，304 映射为 `null` 保留缓存）；
  - `getConversationHistory`（`/api/conversations/{id}/history`，键集 createdAt+messageId）；
  - `getConversationProcess`（`/api/conversations/{id}/process`，turnId/beforeSequence/throughSequence）；
  - 全部支持 `AbortSignal` 真实取消；除 304 外错误原样抛出，不伪造空会话。
- 新增 `conversationOpenApi.test.ts` 6 个用例（URL/条件头/304/失败传播/空过滤器省略/取消信号透传）。
- 前端版本 `6.4.8 → 6.5.0`（新增 API 契约/模块）；`Source/PuddingPlatformAdmin/code_map.md` 登记新文件；根 `code_map.md` 刷新 `Source/**` 指纹。

## 验证

- `pnpm exec jest src/pages/chat/client/conversationOpenApi.test.ts src/pages/chat/client/chatClientStore.test.ts`：**19/19 通过**（D2a 新增 6 例 + D1 store 13 例）。
- `pnpm run build`：成功，`[chat-bundle-budget] ok sync=1383742 chat=357935 common=432161`（新模块尚未接入应用入口，未进入 bundle）。
- `pnpm run tsc`：与基线相同的既有错误（`onEditAndRerun`、`executionFlowProjector`），新增文件无类型错误。
- 运行时零变化：尚无调用方消费新客户端；旧 `/conversation` 仍是前端唯一打开路径。未部署、未重启 Core、未改 `D:\data`。

- D3：SSE 增量缝合、`partial/syncing` UI、取消/generation 全链路、退役旧 `getAgentConversation` 与后端旧 `/conversation`；随后构建部署并核对版本徽标。
