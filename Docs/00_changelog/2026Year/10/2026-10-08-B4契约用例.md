# 2026-10-08 B4 契约用例

| 用例 | 判据 |
|---|---|
| 视口 | 带定位或矩形 ⇒ 拒绝 |
| 元素 | 缺定位 ⇒ 拒绝 |
| 区域 | 缺值 / 非正 ⇒ 拒绝 |
| 版本 | 未钉住（0）⇒ 拒绝 |
| 线名 | `viewport/region/element`、`low/high/original` 往返；未登记名 ⇒ false；`NameOf(非法值)` ⇒ 抛 |
| 校验 | 空观察 id ⇒ 抛；缺失部件 ⇒ `Validate()` 抛 |

## 过程记录

首版最后一条我期望**构造函数**拒绝 `null` 元数据 ⇒ 实际未抛（位置记录不校验）。改为**显式 `Validate()`** 后通过。
**规则**：本仓库的契约记录把校验放在 `Validate()`；用例必须**显式调用**它。
