# R4 第一步：标量委派意图

| 字段 | 含义 |
|---|---|
| `BrowserDelegationContextId` | 委派目标 context（空 = 不委派浏览器权限） |
| `BrowserDelegationPageId` | 委派目标页（与 context 成对；只给其一 ⇒ Runtime 明确拒绝） |
| `BrowserDelegationScopeName` | 允许子运行使用的最小范围线名；**未知线名明确拒绝** |

**为什么标量**：`PuddingCore` 只引用 `PuddingDiagnostics` ⇒ 强类型会造成 **Core → Contracts 反向依赖**。

**证据**：Core **已成功生成** · Runtime **已成功生成** ✓

## 未完成

字段**尚未填充**（两条 `BuildSpawnRequest` 还没从可信父上下文取值）；`SubAgentManager` 未申请/撤销子集授权；Host 实现未做；装配测试未做 ⇒ **R4 端到端行为未成立**。

## 诚实边界

- 本轮为**接口/载体**改动；**未真机验证**。
