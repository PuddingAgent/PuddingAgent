# 2026-10-08 观察登记处（纯逻辑核心）

| 类型 | 内容 |
|---|---|
| `BrowserObservationId` | 非空即已知（`IsKnown`） |
| `BrowserObservation` | `PageVersion`/`Generation`/`ScrollX,Y`/`Zoom`/`Viewport`/`LayoutRevision`/`ObservedAt`；`Validate()`（id 非空、版本/世代/缩放为正） |
| `IBrowserObservationRegistry` | `Register` / `TryResolve(id, pageVersion, generation, out obs)` / `InvalidateForPage` / `Count` |
| `InMemoryBrowserObservationRegistry` | `ConcurrentDictionary`；**版本或世代不符 ⇒ 移除 + 失败**；`InvalidateForPage` 按不符项清理 |

## 设计要点（安全）

- **失效即移除**：不保留"过期但可查"的条目，避免过期观察被反复命中；
- **失败即拒绝**：解析失败不返回"部分信息"，调用方只能明确拒绝（不得用过期的滚动/缩放/布局去点击）；
- **只增不改**：观察是事实快照，不做原地更新。
