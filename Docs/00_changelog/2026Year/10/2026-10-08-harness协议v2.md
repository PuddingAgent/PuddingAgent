# 2026-10-08 harness 协议版本滞后（一行修复）

| 项 | 内容 |
|---|---|
| 症状 | 该套件 10 条失败，全为 `RpcException(InvalidArgument, "unsupported_capability")`（含握手） |
| **根因** | `DesktopProtocolVersion.Current = Minimum = 2`；harness 声明 `{1,1}` ⇒ 协商必失败 ⇒ **每次 hello 被拒** |
| 修复 | harness 声明 `{2,2}` |
| 结果 | **43 / 43 全绿** ✅ |

## 关键经验（本轮最值钱的一条）

`Detail="unsupported_capability"` **无法区分**"协议版本失败"与"能力未授予"（同一个错误码）⇒ **不能靠消息猜**；本轮是靠**读 `TryNegotiate` 的区间逻辑**与"**每个 hello 都失败**"这一形态确定的。**先取证据、再看形态、最后才推演**。
