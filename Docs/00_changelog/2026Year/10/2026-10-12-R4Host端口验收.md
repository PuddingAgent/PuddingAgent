# R4 ⑥ 验收用例：Host 侧端口 8 条

| # | 用例 | 断言 |
|---|---|---|
| ① | 无会话 | **拒绝**（理由含 `session`）—— 与"门"的无会话 no-op 形成**语义对照** |
| ② | 未知范围线名 `teleport` | 拒绝且**理由回显线名**（不降级） |
| ③ | 超出 host 发放范围（只发 Read） | 拒绝 |
| ④ | 缺 `pageId` | 拒绝（理由含 `page id`） |
| ⑤ | 缺真实子 run | 拒绝（理由含 `child run`） |
| ⑥ | 空 `callerId` | 拒绝并带理由（**不抛**出端口） |
| ⑦ | 撤销未签发过的运行 | **幂等**（两个撤销方法都不抛） |
| ⑧ | 连接丢失 | 清空登记、不抛 |

**验证**：`PuddingHost.Tests` **284/284**（276 → 284，**不需 WinUI**）
