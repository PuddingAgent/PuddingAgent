# R4 步骤② 侦察：`SubAgentManager` 锚点

| 锚点 | 行 |
|---|---|
| `SpawnAsync(SubAgentSpawnRequest, …)` | **L63** |
| **真实子 runId 产生**：`_runStore.CreateRunAsync(...)` | **L1018**（外围方法 L1013） |
| `NormalizeRequestIdentity` / `NormalizeExecutionBudget` | L936 / L947 |
| 结果构造 `RunId = runHandle.RunId` | L328 / L443 |

## 接线方案（下一轮）

1. 注入 **可选** `IBrowserDelegationLifecycle?`（**可选** = 不破坏大量既有测试的构造/DI）；
2. **L1018 之后**（真实子 runId 已产生）：解析三个标量 → 强类型（**未知线名明确拒绝**）→ `RequestChildGrantAsync`；
3. **统一 `finally`** 里 `RevokeForRunAsync(真实子 runId)`；
4. Host 实现 + 注册；5. **装配测试**。

## 诚实边界

- 本轮**未改代码**（高风险面，选择先钉锚点）；**未真机验证**；R4 端到端仍未成立。
