# 2026-10-08 拖拽契约（1/8）

| 改动 | 内容 |
|---|---|
| ctor | `string? observationId = null, double? toX = null, double? toY = null)` |
| 属性 | `public double? ToX { get; }`、`public double? ToY { get; }` |
| 赋值 | `ToX = toX; ToY = toY;` |

| 项 | 结果 |

## 剩余（施工单 2–8，见任务卡）
