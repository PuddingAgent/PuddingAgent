# 链守卫目的已在锁下独立证实

| 项 | 内容 |
|---|---|
| 守卫理由（脚本注释） | Shell 曾因**引用边界**破坏而"链全绿但 Shell 构建不了"（**CS0012**：Automation 类型进入 Shell 编译面）⇒ 单独构建、失败即拒绝清单 |
| **本轮做法** | `dotnet build Source/PuddingDesktop/PuddingDesktop.csproj -p:BaseOutputPath=<repo>/temp/build/shell-guard/bin/` |
| 结果 | **32 秒 · 0 个错误 · 已成功生成** ✓（**未写入被锁的 `bin\Debug`**） |
| 含义 | **引用边界未破裂**（否则会复现 CS0012 / `SHELL-BUILD-FAILED`） |

## 链的三类证据现已分别独立取得

| # | 证据 | 结果 |
|---|---|---|
| ① | 全部套件（8 个，非 WinUI） | **2962 / 2962** ✅ |
| ② | **Shell 可构建（守卫目的）** | ✅ **本轮** |
| ③ | collect 管线端到端（CLI 三情形）+ 评审者注入 | ✅ `true`⇒拒 · `false`⇒`false` · 缺省⇒`null` · **11/11** |

## 仍未完成

**整链脚本的聚合执行**（step 0 的无条件 Shell 构建会覆写被两个运行中进程持有的 23 个 Debug 产物 ⇒ 必须先停进程或改从发布副本运行）· **真机 G1–G11 / 250ms**

## 纪律

**不杀产品进程** · **不绕过守卫语义**（本轮仅**隔离输出路径**以避开与运行中进程的文件锁冲突；Shell 仍被要求**真的编译通过**）

## 诚实边界

- 这是**守卫目的的等价验证**，**不等于整链聚合执行**；**未真机验证**。
