# 2026-10-08 B2 定位分页补齐桥接路径：分页判定收敛为单一实现

## 目标 / 背景

上一轮（见 [B2 定位 cursor 分页与游标过期](2026-10-08-B2定位cursor分页与游标过期.md)）把 §6.2 的
`cursor` 分页做到了能力通道路径，并明确登记「桥接路径尚未支持 locate 游标」这一**传输不对称**。
本轮把它补上。

**关键发现**：不需要扩桥接命令/响应。桥接侧的 `BridgeBrowserCapabilitySurface.LocateAsync` 本来就
通过 `page.QueryAllAsync` 在**本地拿到全量匹配**，再自己截断——因此游标的分页与校验可以完全在
这一层完成，线缆上一个字段都不用加。真正需要动的是**别把分页语义写第三份**。

## 改动

| 文件 | 改动 |
|---|---|
| `Source/Pudding.Contracts/Desktop/LocateCursor.cs` | 新增 **`TryResolve(wire, pageVersion, fingerprint, out offset, out failure)`**：解析 + 校验 + **分类**（过期 ⇒ `CursorExpired`；格式坏 ⇒ `InvalidRequest`）。两条传输共用它，分页语义只写一份 |
| `Source/Pudding.DesktopSurface.Browser/BrowserRuntimeDesktopSurface.cs` | 能力通道改为调用 `TryResolve`（删掉内联的解析/校验分支），行为不变 |
| `Source/PuddingHost/BrowserBridge/BridgeBrowserCapabilitySurface.cs` | 桥接路径实现同一套分页：`TryResolve` → 按偏移切片 → 截断如实标注 → **还有下一页才签发** `NextCursor` |

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingHost.Tests` | **257 / 257**（原 256 ＋ 1） |
| `Pudding.ContractsTests` | **120 / 120**（原 119 ＋ 1） |
| `Pudding.DesktopSurface.BrowserTests` · `AgentTools.Tests` · `PuddingDesktop.Tests` · `DesktopServiceTests` · `AutomationTests` | 63/63 · 46/46 · 312/312 · 220/220 · 194/194 |

新增门禁：

- 契约层 `TryResolve_ClassifiesExpirySeparatelyFromMalformedInput`：不给游标 ⇒ 从头开始（不算失败）；
  适用游标 ⇒ 给出偏移；**版本变了**与**查询变了**都 ⇒ `CursorExpired`（不可重试）；格式坏 ⇒
  `InvalidRequest`。这一条同时锁住两条传输的分类；
- 桥接层 `Locate_PagesWithTheCursor_AndExpiresItWhenThePageMovesOn`：三命中分两页取完
  （末页 `NextCursor == null`）；页面版本推进后旧游标 ⇒ `CursorExpired`；畸形游标 ⇒ `InvalidRequest`。

**取红实测**：让桥接路径"收下游标但不使用、也不校验"（`offset` 强制为 0）⇒
`Locate_PagesWithTheCursor_AndExpiresItWhenThePageMovesOn` **恰好变红**（第二页会重复返回前两条）；
复原后 257/257 复绿。

## 已知边界（诚实登记）

- **分页窗口仍是驱动上限内的**：桥接侧一次 `QueryAllAsync` 拿到的是宿主 `page.locate` 返回的那一批
  （受宿主侧上限约束），因此命中极多时翻页会在批次尽头停止；`Truncated` 与 `NextCursor` 分开表达，
  调用方不会被误导成"页面只有这些"。
- **桥接侧不再校验 locator→运行时的可映射性之外的东西**：与之前一致，`Ref` 定位在桥接侧没有等价物
  （快照注册表只在 Desktop 侧），该分支仍明确拒绝。
- 驱动侧真机行为仍未验证（与上一轮相同）。
- `fields` 参数仍未实现。

## 影响与回滚

- **行为变化（Agent 可见）**：走 WebSocket Bridge 的 `browser_locate` 现在也支持 `cursor`/`nextCursor`，
  过期与非法游标的错误码与能力通道**完全一致**（同一个判定函数）。
- 线缆无变化（未新增字段）；无数据/配置影响。
- 回滚：还原上表 3 个生产文件与 2 个测试文件及 code_map。
