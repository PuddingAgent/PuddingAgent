# R4 契约用例：委派端口

| 用例 | 钉住 |
|---|---|
| `DeniedGrantIsNotGrantedAndMustCarryAReason` | **拒绝 ⇒ `Granted=false` 且理由非空**（可判 + 可诊断 ⇒ 调用方 fail-closed） |
| `GrantedGrantCarriesAnIdentifierAndADeadline` | 已授权带 `GrantId` + **绝对到期** |
| `RequestCarriesTheTrustedParentAndTheRealChildRun` | 请求带**父身份** + **真实子 runId** + **范围线名** |

**意义**：该端口是 Runtime/Platform 与 Host 的**唯一接缝**，此前**零覆盖**。

**验证**：`Pudding.DesktopServiceTests` 全绿（不依赖 WinUI）。
