# 2026-10-08 坐标解码用例（presence 证据）

| 用例 | 判据 |
|---|---|
| `CoordinatesAtTheOriginSurviveInsteadOfLookingUnset` | `(0,0)` ⇒ X=0、Y=0（**非 null**）、`observationId` 如实、动作 `pointer_click` |
| `FractionalCoordinatesAndMoveActionTravel` | 12.5 / 44.25 如实、动作 `pointer_move`、空 observationId ⇒ **null** |

## 过程记录（四处我自己的错，均已处理）

1. 一条断言**胡写**（`NameOf(desktop: default) is null ? …`）⇒ `CS1739` → 改为直接断言动作；
2. 命令缺**信封字段**（`Caller`/`OperationId`/`Generation`/`Deadline`）⇒ 三条全在 `IsSuccess` 失败。**教训**：`CoreFrameMapping.Decode` 吃**完整能力命令**；
3. 把 `pointer_drag` 当"无需附加参数"的例子 ⇒ 契约要求拖拽**两端点**，解码失败 → 改用 `pointer_move`；
4. 我曾写一条"缺坐标 ⇒ X/Y 保持 null"的用例 —— **前提错误**：契约要求指针动作**成对给 X/Y**，缺坐标时**解码就该失败**（fail-closed），不可能产出 null 坐标的请求。该用例已**移除**。

## 诚实边界

- **未覆盖**"缺坐标 ⇒ 解码失败"（正确的断言应是 `IsFailure`）与**编码方向**（`WireMapping` 写 proto）⇒ 上一轮 presence 修正目前只有**解码侧两条**背书；
- **表面 `observationId` 失效判定未做**（安全关键）；**驱动指针路径未做**；**未真机验证**；端到端仍不可用。
