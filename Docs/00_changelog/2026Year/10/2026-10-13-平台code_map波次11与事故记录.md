## 事故记录（诚实存档）

**现象**：第一版多节脚本落盘后，`## 多媒体` 与 `## 提供商配置` 两节**标题消失**、且**旧行未被删除**（新表插在旧行之上）。

**发现方式**：改造后用「标题清单」核对（`## ` 行数 16 → 14）即暴露；`code_map_check` 的计数异常同时报警。

**恢复**：该文件尚未提交 ⇒ `git checkout -- Source/PuddingPlatform/code_map.md` 直接回到 HEAD（波次 10 状态，error 13），**零损失**。

**根因**：脚本用 `row_start = h + 2`（h=旧表头行）切片并**在块内插入新表头** ⇒ ①旧表头原地保留；②当切片/home 位置与实际表体不一致时，把「标题+空行+旧表头+分隔行」一并吞掉；③四节改写按逆序应用，掩盖了单节可发现的错位。

**修正**：改为**按「本标题 → 下一标题」整段替换**（`lines[s:e] = block`），并新增**结果态断言**——落盘前对**整份新文本**校验：16 个原标题齐全、每个被改节内不得再出现旧表头、被改节必须恰好含一个五列表头、token 零丢失、列长/行长上限。断言不过则**不写盘**（本次因此被拦下两次，属预期行为）。
