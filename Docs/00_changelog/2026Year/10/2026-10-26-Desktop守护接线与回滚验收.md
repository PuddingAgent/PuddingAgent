# Desktop 守护接线与回滚验收

- 在独立组件门禁通过后登记 `PuddingAgentNetwork.slnx`；Desktop 串行打包 Guardian，通过 `DesktopApplicationCoordinator.Guardian.cs` 生成无令牌配置、启动独立主管并校验安装身份。修正 Desktop 构建路径以真正遵守隔离 artifacts 参数。
- `PuddingConfigModels.cs` 增加 `desktop.guardian`；共用 `DesktopBootstrapHttpEndpoint.cs` 提供认证 UI ping/协调退出。主管接管后关闭 Desktop 内部自动恢复、拦截旧部署入口，主动停止/退出不复活。
- `BootstrapRebootTool.cs` 支持 core/desktop 目标及 build/build-restart/restart/rollback/start/stop，默认提交给 Guardian；202 回执与最终验收分开，令牌只放请求头。
- 完善 Guardian 事务、快照清理、父进程/启动时间核验、故障恢复上限、工作台健康、UTF-8 构建日志及中断恢复。Guardian 自身排除在线替换。
- 更新 `Agents.md`、受影响代码地图和桌面诊断分册；新增运行手册、WinUI 集成测试及 `TestScripts/test-pudding-guardian.ps1`。
- 验证：49 项测试通过；完整发布成功；进程外完整 smoke 8 项通过，最终 Guardian 再验 4 项通过，包含 Core/Desktop 强制退出恢复与锁释放。详情见 [验收报告](../../../14_reports/Desktop-Guardian-验收-2026-10-26.md)。
- 基线限制：原 WPF 归档测试有两个既有接口编译错误，使用真实 WinUI 集成测试覆盖本次控制面；Docs 全量链接存在 26 个既有失效目标，本次无新增。
- 未完成部分：当前用户旧运行包未替换；首次启用需外部部署完整新包。自动审批以 `blocked by policy` 拒绝本次专属临时目录清理，产物留在已忽略的 `temp/`。Guardian 自升级与数据库回滚不在本次实现范围内。
- 关联：[运行手册](../../../13_runbooks/Desktop-Guardian.md)；本任务为用户要求的独立 Desktop 守护、Agent 点火及程序集回滚。
