# 2026-10-08 B2 定位：visible 与 inViewport 分成两个事实，写操作先滚入复检

## 目标 / 背景

设计 §6.2：「`visible` 与 `inViewport` **分开**：屏外但有尺寸的元素仍可定位，
**写操作先滚入可见区域并复检**；隐藏/禁用/遮挡目标不按成功处理。」

上一轮只做了「隐藏即不匹配」，把「屏外」与「隐藏」混为一谈。本轮把它们拆成两个独立事实，
并补上写操作的滚入 + 复检。

## 改动

| 层 | 文件 | 改动 |
|---|---|---|
| 运行时抽象 | `Source/PuddingBrowser.Abstractions/Locator.cs` | `BrowserElementInfo` 新增 `InViewport`（`bool?`，未观测即 null）；`Locator` 新增 `InViewportOnly` |
| 契约 | `Source/Pudding.Contracts/Desktop/LocateContracts.cs` | `DesktopLocator` 新增 `InViewportOnly`；`DesktopElementRef` 新增 `inViewport` |
| 驱动 | `Source/PuddingBrowser.WebView2/WebView2DomClient.cs` | 两份脚本各加 `inViewport(el)` 判定并在元素投影里上报；定位脚本按 `inViewportOnly` **正交**过滤；**交互脚本对写操作先 `scrollIntoView` 再复检**，仍不在视口内 ⇒ `browser_element_not_in_viewport`（不静默点一个看不见的节点） |
| 两条传输 | `BrowserRuntimeDesktopSurface` · `BridgeBrowserCapabilitySurface` | 映射 `InViewport` |
| 工具 | `BrowserToolContracts`（输出 `inViewport`）· `BrowserLocatorInput`（`inViewportOnly`）· `BrowserOperationFailure`（新错误码 → 不可重试 + 「调整滚动/换目标」提示） | |

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingDesktop.Tests` · `PuddingHost.Tests` · `Pudding.DesktopSurface.BrowserTests` · `PuddingBrowser.AgentTools.Tests` | **307/307**（+1）· **254/254**（+1）· **60/60**（+1）· **39/39**（+2） |
| `ContractsTests` · `DesktopServiceTests` · `AutomationTests` | 97/97 · 215/215 · 194/194 |

四层各有一条门禁：驱动脚本两次断言（`inViewport` 上报 + `inViewportOnly` 过滤 + 滚入复检 + 新拒绝码）；
能力通道映射（visible=true **且** inViewport=true 同时带出）；桥接映射（**visible=true 而 inViewport=false**
的屏外元素如实报告——这正是"两个事实"的可证伪点）；工具输出两个字段并存 + `inViewportOnly` 到达能力层；
新拒绝码的重试建议（不可重试 + 提示片段）。

**取红实测**：删掉桥接侧的 `handle.Info.InViewport` 映射 ⇒
`Locate_CarriesInViewportSeparatelyFromVisible` **恰好变红**，其余全绿；复原后 254/254 复绿。

## 已知边界（诚实登记）

- **滚入与复检的真机行为未验证**：本环境跑不了真实 WebView2，脚本只有文本断言。
  固定定位元素、`overflow:hidden` 容器、iframe 内滚动等真实场景需外部进程内 smoke 复核。
- **`cursor` / `fields` 仍未实现**（§6.1/§6.2 的其余参数）。
- **"遮挡"只做了弱判定**：驱动只判断元素与视口相交，没有做 `elementFromPoint` 命中测试，
  因此"被浮层挡住"仍会按可操作处理（设计里"遮挡目标不按成功处理"尚未完全覆盖）。
- 交互脚本的 `mutating` 列表按动作名判断（click/fill/type/select/check/press/drag）——
  scroll 单独处理、hover 不要求视口（只读观察）。

## 影响与回滚

- **行为变化（Agent 可见）**：定位输出新增 `inViewport`（与 `visible` 并存）；
  `locator.inViewportOnly`（默认 false）可只取视口内元素；写操作在屏外时不再直接失败或静默执行，
  而是**先滚入再复检**，滚不进去返回明确错误（并在工具层得到"调整滚动/换目标"的提示）。
- 无数据/配置影响；线缆 DTO 与 proto 未改动。
- 回滚：还原上表 6 个生产文件与 4 个测试文件及 code_map。
