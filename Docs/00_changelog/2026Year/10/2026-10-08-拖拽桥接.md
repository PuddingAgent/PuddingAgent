# 2026-10-08 拖拽 7/8（Bridge）

| 改动 | 位置 |
|---|---|
| a. `ToX`/`ToY` 字段 | `PageInteractArguments` |
| b. `InteractAsync(..., ct, x, y, observationId, toX = null, toY = null)` + 命令写入 | `RemoteBrowserPage.cs` |
| c. `PointerAsync` 的 `Drag` 臂 ⇒ 转发 `pointer_drag` + `(x, y, toX, toY)` | 同文件 |
| d. `case "pointer_drag" when args?.X/Y/ToX/ToY 齐全` ⇒ 非 `IPointerInputPage` 明确失败，否则 `PointerAsync(Drag, …)` | `BrowserWorkspaceController.cs` |

## 过程记录（一处锚点失配）

b 的签名插入第一次**未命中**：round-337 插入时三个参数被**折到同一行**（`double? x = null,  double? y = null,  string? observationId = null)`），与"逐行"假设不符 ⇒ 编译报 `CS1739/CS0103`。
改用**正则匹配行尾 `observationId = null)`** 后一次命中。**教训**：不要假设"一个参数一行"——行式插入后要按**内容**匹配，而不是按形状。
