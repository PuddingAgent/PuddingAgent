# 2026-10-20 Agent 权限请求设计方案

## 目标与改动

用户要求输出设计方案，覆盖 Agent 在高风险或特殊情况下申请单次、短时授权，用户通过弹窗或消息指令决定。

- 新增 `Docs/12_features/Agent权限请求与单次短时授权设计方案-2026-10-20.md`：现状与缺口、会话卡片和弹窗草图、单次与 1/5/10 分钟许可、主体/资源范围、状态机、自动审批关系、独立组件边界、原子消费、等待恢复、API/指令、审计和分阶段验收。
- 更新 `code_map.md` §6：登记设计入口，标为提案；不登记尚未创建的组件。
- 静态核查确认既有工具授权指令和卡片有基础实现，但决定事件与运行时 grant 尚未由现有卡片控制器贯通；方案同时覆盖 Timed 跨会话匹配及 Once 消费的并发窗口。
