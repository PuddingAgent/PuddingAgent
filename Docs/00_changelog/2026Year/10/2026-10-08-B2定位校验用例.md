# 2026-10-08 B2 首个代码：定位器校验层用例

## 交付

| 用例 | 判据 |
|---|---|
| 空白 `Value` | 抛 `BrowserOperationException`，消息含 `Locator value is required` |
| 合法 Css 定位器（**对照组**） | **不抛** |

对照组是必需的：没有它，"空值会抛"无法排除"整段逻辑无条件抛异常"。

## 为什么只测这一层（分层依据）

`ValidateLocator`（C#，`WebView2DomClient.cs:28`）只做**校验**（非空、`Frame`/复合 `Has` 在 Phase 2A-3 不可用、Ref 需匹配 `BrowserRefRegex`）；
真正的**匹配语义**在 **`LocateScript`（L558 起的内嵌 JS 原始字符串）**，由 `webView.ExecuteScriptAsync` 执行于**真实 DOM** ⇒
其行为**无法**在进程内单测，属**真机/外部验收**（两段式验收的适用范围）。**不在本层用替身假装验证 JS 语义。**
