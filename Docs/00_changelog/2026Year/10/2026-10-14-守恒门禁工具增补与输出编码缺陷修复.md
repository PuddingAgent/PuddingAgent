# 2026-10-14 code_map 守恒门禁工具增补与输出编码缺陷修复

## 目标 / 背景

在 `code_map` 波次治理中，**格式门禁（`error 0`）无法证明内容未被截断**：一夜实测到
「仅软折行、信息零丢失」的自述与「长段落尾部被截断（370/365/444 → 289/283/287）却格式门禁仍全绿」
并存。故需要更强的**内容守恒**判据，并把临时补检能力固化为仓库内正式工具。

## 改动

### 1. 新建 `Tools/Docs/verify_codemap_global.py`（全局守恒门禁）

按**改动形态分型**选择检查单位：

| 行型 | 检查方式 |
|------|----------|
| 围栏标记行（```` ``` ````） | 预期被删（`fence-forbidden`），**跳过并计数**，不判红 |
| 表格行（`\|` 开头） | 逐**单元格**检查（行被改写时整行已变，只有单元格原文会被迁移） |
| 其他非空行 | 整**行**检查（长行用 32 字符窗 / 步长 16 兜底，容忍软折行） |

- 比对口径：两侧去全部空白后做包含判断。
- 自带 `--selftest`：3 个用例（1 绿 + 2 红）；夹具用**非重复文本**
  （重复文本会让被截断的尾部窗口在别处命中 ⇒ 该红的用例会假绿）。
- 与既有 `verify_codemap_wave.py` 的分工已登记到 `Docs/README.md`：前者**定向**
  （长单元格 >80 / 长段落 >300），后者**全局**（覆盖短行 / 围栏 / 被改写行）；**建议两者都跑**。

**它为什么必要（实测对照）**：`verify_codemap_wave.py` 的 `[2]` 只覆盖「**去空白后**仍 > 300」的非表行。
某文件 `L7`(raw 336) / `L16`(raw 326) 去空白后 ≤300 ⇒ 落在其覆盖外。用两个变异体对照：
命中覆盖内 ⇒ wave 红；命中覆盖外 ⇒ **wave 绿（漏检）而 global 红（抓到）**。
⇒ 结论：**「wave 绿」不能推断「无截断」，须以全局门禁为准**（该结论此后被 4 个独立来源先后印证）。

### 2. 修复输出编码缺陷（`521c996`）

- 现象：两门禁会打印**文档内容片段**（可能含 `✅` `⇒` 等）。若调用方 stdout 是 GBK/cp936，
  `print` 抛 `UnicodeEncodeError` ⇒ **在打印 VERDICT 前崩溃**，而退出码仍为 1
  ⇒ 消费者会误判为「工具坏了」而不是 FAIL。
- 修复：两工具启动时对 `sys.stdout`/`sys.stderr` 执行 `reconfigure(errors="replace")`。
  **只改 `errors`、不动 `encoding`** ⇒ utf-8 调用方行为完全不变；GBK 调用方降级为 `?` 而不中断判定输出。
- 改动面：`10 insertions / 0 deletions`（wave）、`9 / 0`（global）。

## 验证

- `verify_codemap_global.py --selftest` ⇒ **3/3 ok**（含 2 个取红用例）；
  `verify_codemap_wave_selftest.py` ⇒ **5/5 ok**。
- 真实用例：对仓库根 `code_map.md` 的波次对跑 ⇒ 全局门禁 `306 单元格 + 26 非表行 0 丢失`；
  对 `PuddingRuntime`（全仓条目最多）⇒ `1494 单元格 + 27 非表行 0 丢失`。
- 编码缺陷的**对照实验取红**：`PYTHONIOENCODING=gbk` 下复现
  `UnicodeEncodeError: 'gbk' codec can't encode character '\u2705'`（`print(m)` 处）。
  ⚠️ 诚实记录：默认环境下 `sys.stdout.encoding == utf-8`，**首次复现失败** ⇒ 该缺陷**依赖执行环境**。
- 修复后**闭环验证**：取另一波子代理撞上的同一变异件，在强制 GBK 下两门禁**都完整打印 `VERDICT: FAIL`**
  且退出码正确（1）⇒ 修复正好覆盖该案例，此后**不再需要 `PYTHONIOENCODING=utf-8` 绕过程序**。
- 三方独立佐证：该缺陷先后由 ① 一个子代理报告、② 父代理对照实验复现、③ 另一波子代理独立命中。

## 影响与回滚

- 影响：`Tools/` 下两个只读校验脚本；**不改文档、不改运行时**。新增工具为纯增量。
- 回滚：`git revert 521c996`（编码防御）或删除新增文件（不影响其它工具）。
