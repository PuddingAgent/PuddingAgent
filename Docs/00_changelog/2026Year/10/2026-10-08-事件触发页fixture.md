# 2026-10-08 横向：S-13/S-12 触发页 fixture

## 目标 / 背景

上一轮把 S-12/S-13 加进观察清单时**如实登记了缺口**：TestSite 里没有能触发"对话框/权限/新窗口/下载/选择框"
的页面 ⇒ 两项**暂时无法执行**。本轮补齐。

## 改动

| 文件 | 内容 |
|---|---|
| `fixtures/events.html`（新增） | 每个钩子只做一件事，便于判断"接管是否生效、流程是否被卡住"：`#dialog-alert`/`#dialog-confirm`/`#dialog-prompt`（三种脚本对话框）、`#permission`（geolocation 权限请求）、`#new-window`（记录 `window.open` 是否返回 null）、`#download`（可下载文本链接）、`#picker`（`input[type=file]`，真实上传目标）、`#open-picker`（**页面自弹**选择框，S-12 第②步）、`#log`（**页面自己**观察到的事实，供对照——明确不是自动化回执） |
| `Program.cs` | 新增 `/fixtures/events` 路由（同样从文件读，缺文件即 404） |
| `TestSiteFixtureTests`（＋1 用例） | 结构契约：九个钩子齐备 + 路由存在（少了任何一个，外部一方照手册做会"点了没反应"） |
| 运行手册 | 新增 fixture 表行；S-12/S-13 步骤改为**照该页操作**（含具体按钮 id）；并把 `events` 纳入"手册引用即存在"的路由检查 |

## 验证

| 项 | 结果 |
|---|---|
| `Pudding.DesktopServiceTests` | **313 / 313**（＋1） |
| **起站真机验证** | `/fixtures/events` ⇒ HTTP **200**、2868 字符；**九个钩子逐一存在**（dialog 三键/权限/新窗口/下载/picker/open-picker/log） |
| **门禁先红后绿** | 运行手册未提到新路由时，`TheRunbookOnlyReferencesRoutesThatExist…` **立刻变红** ⇒ 更新手册后复绿 |
| 构建 | `PuddingBrowser.TestSite` 通过 |

## 已知边界（诚实登记）

- **fixture ≠ 真机结论**：它只保证"能触发"；"我们的接管是否生效"仍必须由外部一方在真机上观察（S-12/S-13）。
- **页面自记录是页面事实**：`#log` 的文本可能被页面脚本改写，**不能**作为自动化回执；smoke 时应以工具回执/快照为准。
- **下载链接用 `data:` URL**：真实站点可能是附件响应；fixture 只覆盖"触发下载"这一行为。
- **`window.open` 的返回**在真实浏览器里可能因策略不同而不同（fixture 只记录，不做断言）。
- **未覆盖 `beforeunload`/`unload` 提示框**等其它会阻塞的事件（清单里也没有；登记为未覆盖面）。
- 无产品行为变化（测试站点与文档）。
