# R6 决定性隔离诊断

| 观察 | 结果 |
|---|---|
| 基线链 | **12 套件 / 2096 条 / 0 失败** · 清单 ✅ · `dirty=null`（未接线，诚实） |
| **直接 CLI + `--dirty true`** | **无报错**（无"缺少取值"）· 清单产出 · **`dirty` 仍为 `null`** |
| ⇒ 结论 1 | **CLI 参数解析无问题**；早前"缺少取值"**源自我的脚本插入** |
| ⇒ 结论 2 | 缺口纯粹是**四处代码链接**（事实记录字段 → 采集器投影 → 清单初始化器 → CLI 请求字段 + 脚本追加） |

2. 编译通过后，补 **CLI 请求字段 + 初始化器 + 脚本追加**；
3. 验收：**清单产出且 `dirty` 非 null**。
