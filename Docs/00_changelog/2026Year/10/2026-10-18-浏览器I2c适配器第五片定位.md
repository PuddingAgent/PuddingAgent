# 2026-10-18 I2-c 适配器第五片：page.locate → browser.locate

## 改动

- `BrowserBridgeCommandAdapter` 扩展 `page.locate` → `browser.locate`；
- 定位字段逐项搬运：`kind`（`DesktopLocatorKindWire.TryParse` 严格解析）、`value/name/exact/nth/hasText`；
- 未知 kind **拒绝且不猜测**；缺 locator/非法 JSON/不合法 locator 值 fail-closed 并给出原因；
- 线缆无 `includeHidden/inViewportOnly` ⇒ 如实默认 `false`（与 controller 旧映射一致，已在注释/日志标记为已知线缆缺口）；
- 测试：一次覆盖全部字段 + 未知 kind 拒绝。

## 验证

- `dotnet test Tests/PuddingDesktop.Tests --filter BrowserBridgeCommandAdapterTests` ⇒ **9/9 通过**；
- 未运行产品/模型；适配器仍未接管执行。

## 未完成与影响

- 仍缺 waitFor、interact/tabs、截图映射；
- 线缆 `includeHidden/inViewportOnly` 缺失会造成"隐藏/视口外元素定位"语义丢失（旧 controller 映射同缺口），接入执行器前应决定是否补协议字段或明确 V1 限制；
- 派发器入口切换、controller 收缩、删除旧路径未做。
- 回滚 = revert 本提交。
