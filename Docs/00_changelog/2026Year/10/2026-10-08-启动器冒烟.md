# 2026-10-08 隔离启动器冒烟：12 项全过

| B7 步骤 | 冒烟中的对应检查 |
|---|---|
| **startup** | 独立 Core 就绪 + Web 工作台加载；**Shell 未装配业务 Host** |
| **restart** | **替换 Core 进程**并重载 Web |
| **crash-recovery** | **Core 崩溃后 Shell 存活**；手动启动恢复 Web |
