# R4 合法授权成功用例

| 断言 | 含义 |
|---|---|
| `result.Success` | 委派**不阻断**正常 spawn |
| `RequestCount == 1` | 只申请**一次** |
| **`LastRequest.ChildRunId == result.RunId`** | 申请带的是**真实子 run**（不是模板/父 id）—— R4「身份统一解码」核心判据 |
| `LastRequest.ParentRunId == "parent-run"` | 父身份来自**可信执行上下文** |
| 目标 `ctx-1`/`page-1` · 范围线名 `read` | **原样传递** |
| 完成后 `RevokedRunIds` 恰 1 且 == `result.RunId` | 成功收尾**撤销同一 run** |

假件新增 `LastRequest`（原先只记次数）。

**验证**：`PuddingPlatformTests` **1444/1444**（1443 → 1444，**不需 WinUI**）
