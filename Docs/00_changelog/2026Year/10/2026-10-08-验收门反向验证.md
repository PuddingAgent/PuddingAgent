# 2026-10-08 验收门反向验证（拒绝路径）

| 项 | 结果 |
|---|---|
| 输入 | `-Template` 生成的 facts（**全 not-run**） |
| 命令 | `external-acceptance.ps1 -SkipTemplate -Conclude -Facts …` |
| 结果 | **`exit=2`** · 输出 `NOT allowed: external-lifecycle-verified` |
| 记录 | `external-acceptance-record.md`：S-01…S-13 全"未执行"；四步生命周期全"失败"；**逐条校验问题** |
| 观察/交付构建 | 均为 `round-574-2`（模板读取 manifest ✓） |

**⇒ 意义**：证明**验收门是 fail-closed**（未验证不得通过），且给出了**预期拒绝形态**作为外部比对基线。

## 诚实边界

- **只验证了"拒绝路径"**；"通过路径"需**真机**填 facts 后由外部执行；**未真机验证**。
