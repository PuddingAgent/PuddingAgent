# 2026-10-18 I2-c 路由扩面：locate/waitFor/interact/snapshot 也走执行器

## 改动

- `BrowserBridgeExecutorRoute.RoutedCommands` 从 4 类扩到 8 类：新增 `page.locate`、`page.waitFor`、`page.interact`、`page.snapshot`；
- 结果分支使用前几轮已完成的 `FromLocate` / `FromWait` / `FromInteraction` / `FromSnapshot`（不存在"没有反投影就路由"的缺口：缺结果时抛错→失败，而不是谎报成功）；
- 测试新增：snapshot 路由到 `browser.snapshot` 并投影 domText/nodeCount；locate 路由到 `browser.locate` 并投影元素 ref；路由测试 **8/8**。
