# 2026-10-18 I2-c 路由再扩面：navigate 与 screenshot 经执行器

## 改动

- 结果反投影补齐两类：
  - `FromNavigate`：Url / Ok（`Ok` 为 null 时只用 `Completed` 判定成功，不猜）/ StatusCode / ErrorText / Page（目标来自命令 envelope，标题/URL/版本来自结果事实）；
  - `FromScreenshot`：observationId/mime/字节数/尺寸/版本/detail/设备与视口/裁剪/修订 + 分块 Base64。
- `BrowserBridgeExecutorRoute` 路由集合加入 `page.goto/goBack/goForward/reload/stop` 与 `page.screenshot`；缺结果抛错→失败，不伪造。
- 测试：goto 导航结果投影 ok/url/pageVersion、screenshot 分块 Base64 投影；路由测试 **9/9**。
