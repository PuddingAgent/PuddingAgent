# 修复 Shell 构建断裂（准入判据下沉）

| 项 | 内容 |
|---|---|
| 症状 | 整链 `SHELL-BUILD-FAILED`（0 套件、无清单） |
| 根因 | 链接编译进 Shell 的文件里直接读了 `_lifecycle.Authority`（**Automation 类型**）⇒ `CS0012`；Shell 白名单不含 `PuddingBrowser.Automation` |
| 修法 | 判据**下沉**为 `BrowserPageLifecycle.HasSufficientPageGrant(...)`，**签名只含 Contracts 类型** |
| 验证 | Shell **构建成功** · Desktop **332/332** · DesktopService **388/388** |

## 纪律（第二次撞同一堵墙）

**凡是会被链接编译进 Shell 的源文件，签名里不得出现 Automation 类型** —— 这是 2026-10-08 已记过的边界，本轮**再犯一次**；链的 Shell 构建守卫**当场拦住**（这正是它存在的理由）。
