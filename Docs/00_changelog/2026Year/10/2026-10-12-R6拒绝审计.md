# R6 审计：收集不静默 · 校验 18+ 条拒绝规则

## 收集端（`DeliveryFactCollector.cs`）

| 证据 | 含义 |
|---|---|
| L186 注释 | "读文件；**读不到就返回 `null`**（由上层按'**事实缺失**'处理，**不静默当成空内容**）" |
| L105–107 | TRX 解析失败 ⇒ **把 errors 收进 collected**（把"解析不了"当**显式事实**） |
| L166 | `return false` = `TryCollect` 的**拒绝出口** |

## 校验端（`DeliveryManifest.Validate`，18+ 条）

`buildId` 必需 · `commit` 必需（"a build nobody can trace back is not deliverable"）· 不可复现构建不得声明 `ready-for-external-deploy` · 工件非空 · **至少一条已记录检查** · 检查名非空 · **不得含失败检查** · 计数非负 · **"至少一条检查真的跑过（全零计数即拒）"** ← 防"看起来完整" · **`knownUnverified` 必须显式声明** · `requiredExternalSteps` 必需

## 经验事实（本会话实测）

- 套件未产出 TRX ⇒ 链**拒绝**（`REFUSING … no TRX`）✓
- **`dirty` 三态**：`true` ⇒ **清单被拒** · `false` ⇒ `false` · 缺省 ⇒ **`null`** ✓

**⇒ 无"缺失事实仍产出完整清单"的缝隙** ✓
