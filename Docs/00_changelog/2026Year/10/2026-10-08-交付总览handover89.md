# 2026-10-08 横向：全量交付链实测 + 面向决策的交付总览

89 轮之后需要一份**用最新证据说话**的收敛文档：能力面已经没有不依赖未决问题的活，
再往下走必须由产品方拍板。本轮先用**真实执行**取到当前数字，再据此写总览。

**门禁行为再次被验证**：第一次运行时 Host 的已知 flake（`DesktopBrowserBridgeHandshakeTests.SecondConnection_CannotReplaceAwaitingHelloConnection`）
失败 ⇒ CLI **拒绝产出清单**（退出码 2）；重跑通过后才产出。这正是"有失败项就没有可交付结论"的设计意图。

嵌套容器/影子 DOM、真机从未运行、生命周期未执行），以及**两项决定的选项与影响面**：

|---|---|---|
| ① B4 artifact 字节归属 | A bridge+Host 落库 / B Desktop 直写 / **C 仅内联（=现状）** | 决定截图视觉能否全文落地、B6 父结论能否带 Artifact 引用 |
| ② B1 调用方身份 | 接受「进程内身份 + 显式拒绝跨进程推断」/ 不接受 | 决定 `Admit`/写租约能否接入活路径、B6 页面 grant 契约的签发依据 |

## 已知边界（诚实登记）

- **数字是"内部一侧"的**：1497/0 证明的是进程内测试全绿，**不证明任何真机行为**；
  20 条未验证项随清单交付外部一方。
- **总览是快照**（提交 `61f0d98`）：没有自动门禁把它与代码绑定；代码继续演进后需更新。
- **未执行外部 smoke**：本环境无 WebView2/无产品 Shell（这属外部控制器职责）。
- **未触碰两项决定**：总览只是把选项与影响写清楚，**不替产品方选择**。
- 本轮无代码改动（只有文档）。
