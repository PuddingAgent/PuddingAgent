# R4 ⑦ 取消路径：单测不可达（`cancelled=0`）

| 项 | 内容 |
|---|---|
| 实现 | 可挂起 dispatcher 假件（`suspend: true` + `Release()`，`TaskCompletionSource`）+ `BrowserDelegation_RevokesOnCancellation` |
| 实测 | **失败**：`Assert.IsTrue 失败。'condition' 表达式:'cancelled >= 1' … cancelled=0` ⇒ **100 次轮询内 `CancelAllAsync` 始终返回 0** |
| **结论** | **单测无法建立"可被取消的在途运行"**：dispatch 挂起时运行**尚未**登记（`cancelled=0`）；dispatch 完成后运行很快被收尾 ⇒ **取消站点需"dispatch 之后、收尾之前"的窗口** ⇒ **单测不可达**，归**集成/真机**验证 |
| **纪律收获** | 我**先断言 `cancelled >= 1`** 再断言撤销 ⇒ **把"夹具前提未建立"与"产品未撤销"分开** ⇒ **避免了误报"取消路径泄漏"的假红** |
| 自记失误 | `Release()` 里直接 `new RuntimeDispatchResult { … }` 缺必需成员 ⇒ `CS9035`；改**复用既有构造范式**后通过 |
