# 2026-10-20 Agent编辑与推理提示词一致性修复

## 改动

- `Source/PuddingPlatformAdmin/src/pages/workspace/[id]/WorkspaceAgentSettingsDrawer.tsx`：保存时同步 name/displayName，避免旧详情显示名覆盖输入；八份提示词随完整草稿保存。前端修订版本递增。
- `Source/PuddingPlatform/Services/WorkspaceAgentFileService.cs`：Markdown 原样写入；空串清空，null 保留；首次保存文档同时登记 manifest 引用；保存响应返回全部文档。空心跳配置运行时使用默认提示词，但不覆盖用户保存的空文件。
- `Source/PuddingCore/Configuration/AtomicFileWriter.cs`：严格无 BOM UTF-8、失败不替换原文件；磁盘 JSON 默认输出可读中文，保留调用方显式编码器、命名和转换器。`AgentTemplateFileService.cs` 的 Markdown 写入也复用原子写入。
- `Source/PuddingRuntime/Services/AgentPromptSnapshot.cs`：按实例 manifest 引用读取提示词。`ContextPipelineLayers.cs` 与 `SystemPromptBuilder.cs` 共用快照，使用实例名称/角色，分别注入系统提示词与协作规范，补齐工具约定和记忆策略，空文档不引入模板指令。
- `ContextPipeline.cs` / `ContextPipelineLayers.cs`：静态缓存比较配置正文指纹；配置变化后已有会话下一轮更新，未修改时保留相同前缀字节。使用 ConfigurationAgentInstanceId 读取持久实例，避免临时执行身份串目录。
- 维护根及相关子项目代码地图；界面明确用户消息模板目前仅保存文本，不执行变量替换，避免误认为已应用。
