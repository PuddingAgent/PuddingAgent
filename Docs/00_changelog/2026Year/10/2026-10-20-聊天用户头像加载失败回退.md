# 2026-10-20 聊天用户头像加载失败回退

## 背景与改动

运行中账户的自定义头像请求返回 HTTP 404，本地默认头像 `/admin/assets/images/me.png` 返回 HTTP 200、`image/png`。原组件仅在 URL 为空时提供图标，非空失效地址被 Ant Design Avatar 隐藏后无任何内容，显示为空灰圆。

- `Source/PuddingPlatformAdmin/src/pages/chat/components/UserMessageBubble.tsx`：优先显示配置头像，空白地址或图片加载失败时切换本地默认头像；默认图也失败时显示用户图标；新 URL 到达时恢复加载，补充头像替代文本。
- `Source/PuddingPlatformAdmin/src/pages/chat/styles/user.styles.ts`：统一头像边框与回退颜色，删除未使用的图片专属样式。
- `Source/PuddingPlatformAdmin/src/pages/chat/components/UserMessageBubble.test.tsx`：新增 6 个头像行为用例，覆盖正常、自定义缺失、空白地址、两级失败和更新 URL。
- `Source/PuddingPlatformAdmin/package.json`：前端修订版本递增至 `6.9.13`；任务开始时其他任务已在工作树预占 `6.9.12`，本次使用下一版本。
- `Source/PuddingPlatformAdmin/code_map.md`：登记聊天头像的加载与回退规则。

## 验证

- `pnpm exec jest --runInBand src/pages/chat/components/UserMessageBubble.test.tsx`：1 个套件、25 个用例全部通过，退出码 0。Jest 报告既有异步句柄退出提示。
- 新增代码按 Biome 格式整理，保留原有区域格式。定向 Biome lint 仍报告原有图片预览容器的 `aria-label` 规则错误及两项警告，均位于头像改动之外。
- 全量 Front Matter 门禁：1680 个文档，0 项不合规；全量文档链接检查发现 25 个既有失效目标、0 个失效锚点，位于未修改的架构、任务和 QA 文档。
- 生产构建、部署与 Desktop 页面验收待本提交后从干净源码进行，结果追加到本记录。

## 未完成部分与边界

原自定义图片在当前仓库、DataRoot 与部署备份中未找到，无法还原原图；本次修复失效头像的显示回退，不伪造原图或修改账户头像记录。用户若需原自定义图，应在用户管理中重新上传。头像上传持久化路径仍沿用现有后端合同。

本次仅修改前端，不重启 Core；其他任务的工作区改动不纳入本提交或本次前端构建。回滚可恢复原前端静态产物。
