# 2026-10-12 SSH B3：传输接入协调器（复用准入/围栏/租约/关闭预算）

## 目标 / 背景

切片 B 的传输不能另起一套生命周期：必须与执行路径共用准入、前置围栏、操作 lifetime、
资源租约、单一清理预算与隔离区，否则会重复 R2/R3 的老问题。本步把 `ssh_upload`/`ssh_download`
的**组件内**入口接进 `SshOperationCoordinator`（工具与审批仍属 S5）。

## 改动

- `Source/PuddingSsh/Contracts/SshTransferPorts.cs` — 新增 `ISshTransferFactory`（切片 B 的独立装配点）；
  `ISshTransferSession` 增加 `Closed` 关闭证据（与执行会话同一口径）。
- `Source/PuddingSsh/Contracts/SshTransferContracts.cs` — 新增 `SshTransferResult`
  （状态/阶段/字节/路径/`CleanupState`/`TemporaryLeftBehind`/实测 `Capabilities`/耗时；`RetrySafe` 恒 false）。
- `Source/PuddingSsh/Contracts/SshPorts.cs` — `ISshClient` 增加 `UploadAsync`/`DownloadAsync`。
- `Source/PuddingSsh/Execution/SshResourceLease.cs` — 租约增加传输会话槽
  （`AttachTransferSession`/`TransferSession`，`HasSession` 覆盖两类会话），资源记账与身份释放口径不变。
- `Source/PuddingSsh/Execution/SshOperationCoordinator.cs`
  - 构造新增可选 `transferFactory`（未显式给定时按同一实例探测 `ISshTransferFactory`）；
  - 新增 `TransferCoreAsync`：校验（目标/主机限额/**传输限额存在性**）→ 计划（本地/远端路径策略）→
    停止与隔离区检查 → lifetime → 围栏 → 准入 → 身份 → **SFTP 连接**（能力探测在允许根内进行）→
    **传输在有界 worker 上**（与 exec 同样的同步入口隔离）→ 有界关闭 → 结果；
  - 传输会话的关闭走**同一个**关闭池与预算合同（`CloseTransferCoreAsync`），`CleanupState` 需要
    `Closed` 证据；迟到连接照旧只回收、绝不执行传输；
  - 主机未配置传输限额（`SshHostContext.Transfer == null`）⇒ `ssh.transfer_unavailable`，
    未装配传输工厂同样关闭式失败。
- `Source/PuddingSshTests/SshFakes.TransferSession.cs` + `SshTransferCoordinatorTests.cs` — 假传输工厂/会话 +
  **10 例门禁**：未配置限额零副作用、上传/下载happy path（含能力探测目录=允许根、计数器回零）、
  本地路径越界、远端路径越界、`transfer_unsupported` 透传并带实测能力、预先取消零副作用、
  释放不收敛→隔离区占账 + Stop 如实报告、迟到连接不执行传输、非法主机限额 `config_invalid`。
- `Source/PuddingSshTests/SshFakes.cs` — `FakeSsh.Host` 支持 `transfer:` 限额。

## 验证

- `dotnet test Source/PuddingSshTests/PuddingSshTests.csproj` → **288/288 通过**，0 警告 0 错误（新增 10 例）。
- 真实 OpenSSH 矩阵（工厂在 B2 被重构成共用建连准备，执行路径回归）：**23 场景 `failures = 0`**，
  含 `build.source_sha`/`source_dirty`/`probe_dll_sha256` 身份与 `rounds` 的峰值、每轮 `cleanup_state`、
  服务端零残留 socket 断言。

## 未完成 / 后续

- **B4**：真实 OpenSSH 的传输探针场景（往返字节一致、超限中止、覆盖策略、临时文件不残留、
  取消/超时、路径拒绝、**能力实测结果落盘**）与切片 B 结项报告。
- 仍未改宿主；`ssh_upload`/`ssh_download` 两个 Agent 工具与审批属 S5。
