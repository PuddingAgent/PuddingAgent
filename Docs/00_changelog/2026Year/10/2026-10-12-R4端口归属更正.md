# 更正：注入回退（Platform 不引用 Contracts）

| 项 | 内容 |
|---|---|
| 症状 | 整链构建 `SubAgentManager.cs(39,22) error CS0246` |
| 根因 | Platform 的 ProjectReference **不含 `Pudding.Contracts`** ⇒ 看不到该端口类型 |
| 假绿来源 | 单项目**增量构建**未真正重编译（与 `--no-restore`/artifacts 混用同源） |
| 处置 | 回退注入 ⇒ `PuddingPlatform` **已成功生成** ✅ |

## 架构结论（修正 R4 设计）

**端口应声明在 `PuddingCore`**（Platform/Runtime/Host 均引用它），且**签名只用标量** ⇒ Core **无需新增 Contracts 引用**（与"标量过桥"一致）；Host 侧另写适配器映射到 Contracts 类型。

## 教训（并入纪律）

**单项目增量构建不能作为接线正确性的证据 —— 必须跑整链。**

## 诚实边界

- 本轮为**更正/回退**（无净新增行为）；R4 端到端仍未成立；**未真机验证**。
