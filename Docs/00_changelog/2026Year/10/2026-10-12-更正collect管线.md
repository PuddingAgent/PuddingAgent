# 更正：只有一次 CLI 调用 ⇒ 丢值在 collect 管线内

| 项 | 内容 |
|---|---|
| 静态证据 | 脚本**仅** L347 一次 CLI 调用（参数含 L338 `--out …/delivery-manifest.json`）；**无 `--conclude`** |
| ⇒ 更正 | round-720"清单来自 conclude 路径"的假设**不成立** |
| ⇒ 结论 | `dirty=null` 只能意味着丢值在 **collect 管线内**（`request` → `facts` → `manifest`） |
| **自省验证缺口** | 我**从未**在"请求=True **且**清单成功产出"的运行中确认四处链接**同时**生效（round-718b 未打印各编辑命中情况） |
| 唯一决定性实验 | 四处链接 + **三处打印** + **每处替换的命中结果** ⇒ 一次定位（待链可跑） |
| 阻塞 | 产品进程 `19240/83832` 持有构建锁 ⇒ `SHELL-BUILD-FAILED`；**不杀** |
