# 2026-10-18 会话读模型纯组件阶段B

## 改动

- 新增叶子组件 `Source/PuddingConversationReadModel/`（组件化交付规程 S1–S4；方案 §3.1/§4.1/§4.2/§5.3/§5.4）：
  - `Contracts/ConversationEventContracts.cs`：中性事件类别与输入 DTO；不引用事件存储/EF。
  - `Contracts/ReadModelContracts.cs`：Turn/过程摘要、压缩、子代理摘要、读模型状态、批量归约结果与完整性原因（`turn_active` / `turn_header_missing` / `baseline_incomplete` / `subagent_summary_truncated`）。
  - `Contracts/LimitContracts.cs`：页/字节/SSE/缓存/回填预算的**唯一常量源**（默认 20/50 条、8 KiB、16 KiB、128 KiB、256 KiB/200 项、2000 条/2 MiB/1s、5 会话/5 MiB、50 条/50ms/200ms 等）。
  - `Contracts/CursorContracts.cs`：`eventHead`/`snapshotCursor`/`lastAppliedSequence` 三游标合同、历史/过程分页游标与冻结失败枚举。
  - `Contracts/PageContracts.cs`：历史页/过程页预算器、SSE 追赶计量器。
  - `Internal/`：ReducerEngine、LimitRules、CursorRules、HistoryPageBounder、ProcessPageBounder、SseCatchUpMeterState；`TextBudget.cs` UTF-8 有界前后缀截断。
- 新增独立测试工程 `Source/PuddingConversationReadModelTests/`（MSTest.Sdk 4.0.1，只引用本组件），**191 个用例**：归约/重放幂等/跳号与倒序分类、终态与迟到事件、父子 run 隔离、子代理摘要限长与完整性截断、页/字节/扫描预算、游标合同每个失败原因、SSE 三预算、UTF-8 截断边界，以及 8 条 S1–S4 边界断言。
- 新增组件 `code_map.md`；根 [code_map.md](../../../../code_map.md) §2/§5 登记组件与测试工程，并刷新 `Source/**`/`Tools/**` 源指纹。
- **S5 未做**：未登记 `PuddingAgentNetwork.slnx`、未改任何宿主 csproj/DI、未改前端；运行时行为零变化。
