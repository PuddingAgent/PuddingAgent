# 会话失败诊断持久化与展示

日期：2026-10-20。

- `Source/PuddingCore/Runtime/ITurnExecutor.cs` 与 `Source/PuddingCore/Platform/ExecutionRunContracts.cs` 增加 Diagnostic；Runtime Adapter 按公开字段白名单传递，Platform Coordinator 与 Journal 保存到 canonical `turn.failed`，不再只剩异常文本。
- `Source/PuddingRuntime/Services/AgentExecutionService.cs` 为页面、日志及复制报告使用同一个 Error ID，并传入冻结路由的 Provider ID。
- `Source/PuddingPlatform/Services/AgentChat/ConversationOpenQueryService.cs` 和对应控制器增加失败回合报告点查，按 conversation/turn 读取单条记录并限长，首屏不读取报告。
- `Source/PuddingPlatformAdmin/src/pages/chat/` 的实时 Store、快照合并、消息块与气泡透传诊断；即使没有模型正文，也显示失败终态。ErrorDiagnosticPanel 支持显式展开、读取重试及复制文本/JSON；复制失败如实反馈。布尔 retryable 的 true/false 均保留。版本升级到 6.9.16。
- 维护代码地图与症状排查手册。

验证：Runtime Adapter/错误导出/摘要调用 16/16；Platform 持久化与历史查询 20/20；前端 6 个测试文件 97/97；`pnpm exec tsc --noEmit` 通过；生产构建及包体积门禁通过（chat 374144 bytes）。Front Matter 检查通过。全 Docs 链接检查仍有原有 25 个失效目标，未新增失效链接。

未完成：本提交验证的是源码与隔离构建，部署、实际加载哈希和在线功能结果另记。旧终态已丢失的诊断不做伪造回填。关联任务：用户要求增强 Responses 调用失败状态与诊断。
