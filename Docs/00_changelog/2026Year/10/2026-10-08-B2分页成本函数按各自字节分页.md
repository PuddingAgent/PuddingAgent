# 2026-10-08 B2 分页成本函数：两种正文表示各按自己的字节分页

## 更正（先说）

上一轮（[B2 format=compact_json](2026-10-08-B2format-compact-json正文第二种表示.md)）我写了「两种表示
**页边界一致**、游标可互换续读」，并把「JSON 与 markdown 同额预算但字节不同」登记为边界。
**那个承诺是错的**：共用"按 markdown 字节"的分页决策，只会让 compact_json **超出**调用方请求的预算——
正好违反 §151 的"合法输出"。本轮把它改成各按自己的字节分页，并更正那条用例与说法。

## 改动

| 层 | 文件 | 改动 |
|---|---|---|
| Automation | `ArticlePaging.cs`（新增） | 块边界分页引擎，接受**成本函数**（块成本、分隔符字节、包装字节）。不变式：① 只落块边界（绝不切块）；② 只要有块被选中就**不超预算**，除非"单块本身超预算"⇒ 整块给出并标注 `OverBudget`；③ 同输入同分页（确定性） |
| Automation | `ArticleMarkdown.cs` | 用引擎分页：块成本 = 渲染后字节数，分隔符 = 空行 2 字节，无包装。**行为与之前一致**（13 条既有用例全部保持绿） |
| Automation | `ArticleCompactJson.cs` | 用引擎分页：块成本 = **同一序列化器**算出的块 JSON 字节（序列化与估算共用 `WriteBlock`，不可能漂移）、分隔符 = 逗号 1 字节、包装 `{"blocks":…,"truncated":…,"nextCursor":…}` **计入预算**；分页后再做一次**精确复核**（游标位数分页后才确定），超出就丢掉最后一块重试，直到装下或只剩一块 |

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingBrowser.AutomationTests` | **235 / 235**（原 234，替换 1 条并新增 1 条） |
| `AgentTools.Tests` · `PuddingDesktop.Tests` · `DesktopSurface.BrowserTests` · `ContractsTests` · `DesktopServiceTests` · `Host` | 60/60 · 320/320 · 64/64 · 152/152 · 229/229 · 258/258 |

新增/改写门禁：

- **各按自己字节分页**：同一预算（96 字节）下 `markdown.Bytes <= 96` **且** `compact_json.Bytes <= 96`
  （改前 compact_json 会超）；
- 各自续读：拼接后每段**恰好出现一次**（不重复、不丢段），段数守恒到 8；
- 单块超预算：整块给出、`Bytes > 预算`、`truncated=true`、`output_budget`，且**仍是合法 JSON**；
- markdown 的 13 条既有用例（结构保真、块边界、覆盖 100%、字节口径…）全部保持通过 ⇒ 重构未改变行为。

**取红实测**：把包装字节估算改成 0 **且**去掉精确复核 ⇒
`EachRepresentationPagesByItsOwnBytes_AndStillCoversEverything` **恰好变红**（JSON 超预算）；复原后 235/235 复绿。

## 已知边界（诚实登记）

- **游标仍是裸整数，因此与表示无关地"可传"**：既然两种表示的页边界不同，把一种表示的游标用到另一种表示上
  会**跳过**若干块（不会重复）。当前没有机制识别游标来自哪种表示 —— 正确用法是"哪个表示给出的游标就用回哪个表示"。
  修法是把游标做成不透明串（例如 `json:3` / `md:3`）并在工具层 fail closed，属**破坏性线格式变更**，
  需要单独一轮（已在本日志登记，不再假装"互换续读"）。
- **`OverBudget` 只覆盖"单块超预算"**：包装本身超预算（预算小到连空壳都放不下）时同样会整块给出并标注；
  预算下限仍是 64 字节（`ArgumentOutOfRangeException` 兜底）。
- **成本按块独立计算**：markdown 的块渲染不依赖前一块（列表缩进是块内信息），因此不存在"上下文相关的成本"；
  若将来引入需要上下文的渲染，成本函数必须改成有状态。
- 真机无关（纯组装层）。

## 影响与回滚

- **行为变化（Agent 可见）**：`mode=text&format=compact_json` 在同一预算下可能返回**更少**的块（此前会超预算），
  因此 `nextCursor` 与页边界会变；`format=markdown` 行为不变。
- 回滚：还原上表 3 个生产文件与 2 个测试文件、frozen 列表与 code_map。
