# 2026-10-08 工具层（一）

| 改动 | 内容 |
|---|---|
| `BrowserAgentToolIds` | `Screenshot = "browser_screenshot"` |
| 测试替身 | `FakeCapabilitySurface.ScreenshotAsync` 抛 `NotSupportedException` |
| **委派清单** | **回退**：工具不存在时不得要求（否则写任务委派全失败） |

## 顺序纪律（再次一致）

**实现 → 声明/要求 → 授予**：截图能力当初也是"执行分支就位后才加进 `DefaultGrantable`"；本轮同样**不**先把 `browser_screenshot` 写进"写任务必需工具"，等工具本体落地再加。
