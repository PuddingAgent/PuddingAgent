# R6 用例：dirty 树不得声明可交付

| 输入 | 期望 |
|---|---|
| `Dirty = true` | ❌ 拒绝，原因含 **`uncommitted`** |
| `Dirty = false` | ✅ 不因该规则被拒 |
| **`null`（未采集）** | ✅ 不因该规则被拒（**`null` ≠ 干净**，但也不等于 dirty） |

**证据**：整链 **12 套件 / 2096 条 / 0 失败** ✓
