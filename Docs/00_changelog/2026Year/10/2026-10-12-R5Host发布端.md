# R5 第三步：Host 发布端

| 项 | 内容 |
|---|---|
| 存储 | `VisionArtifactStorageService.SaveIdempotentAsync`（**与 `ImageReaderTool` 同范式**） |
| 命名 | `vision-<sha256 前 32 位>` ⇒ **内容寻址**，重复发布同一引用 |
| 再校验 | 升序 · 仅末块 `IsLast` · 累计字节 == 元数据 · 非空 · 不超上限 |
| 返回 | 工件 id + 元数据（**无路径/凭据**） |

**证据**：`PuddingHost` 编译通过 ✓

## 未完成
