# 2026-10-18 重启后聊天重试与失败原因修复

## 诊断与改动

用户截图为发送后空白“本轮运行失败”，用户消息仍“发送中”，原文回到输入框。
只读查询当前会话的命令/消息尾部未找到截图中的“重启完成，开始重新测试”，与提交前失败一致；
未取得截图时浏览器的 HTTP 响应，不能证明首次失败的具体网络原因。

- `Source/PuddingPlatformAdmin/src/pages/chat/hooks/useSessionEventConnection.ts`：只保留在途 promise，完成后释放，允许失败后同会话再次准备权威游标。
- `Source/PuddingPlatformAdmin/src/pages/chat/hooks/useMessageSend.ts`：失败更新用户消息 error，并保存助手 executionError；保留草稿恢复。
- `Source/PuddingPlatformAdmin/src/pages/chat/components/MessageRow.tsx`、`AgentMessageBubble.tsx`：透传并优先显示错误原因。
- 对应三个测试文件补充回归；前端 `package.json` 修订号递增至 6.9.6；更新子项目代码地图和诊断手册。

## 验证

- 修复前新增断言复现：5 失败、48 通过。
- 修复后 4 个定向套件（连接、发送反馈、失败卡、MessageRow memo）：61/61 通过；包含并发合并与会话切换隔离。
- 两份改动文档 Front Matter 检查通过。全 Docs 链接检查发现 24 个既存失效目标、0 失效锚点，均位于未改动的架构/任务/QA 文档，本次文档无失效引用。
