# 2026-10-18 前端D3c SSE连接状态驱动轮询开关

## 改动

- `services/platform/api.ts` 的 `subscribeSessionEvents` 新增可选 `onOpen`（响应头通过、流可读）与 `onClose`（流正常结束、非 abort）回调；不改事件分发语义。
- `useSessionEventConnection`：
  - 新增 `connectionState: idle | connecting | connected | reconnecting`；
  - `onOpen` → connected（并刷新 lastEvent 时间）；`onClose` → reconnecting 且有界重连；错误分支 snapshot_required/reconnect → reconnecting，404/410 终态/鉴权失败 → idle；停止流 → idle。
- `useChatState` 透出 `connectionState`；`chat/index.tsx` 后台校正 effect：
  - SSE **connected 且无活动 Turn**：不再启动整页 `/conversation` 轮询；
  - 活动 Turn：保留 5s 有界校正；
  - 终态 Turn：保留 1.2s 档位做一次快照物化，fresh 后 activeRun 清空即停止；
  - 断线/重连：恢复原有 1.2s/5s 档位。
- 前端版本 `6.9.0 → 6.9.1`；frontend code_map 更新连接 hook 边界。

## 验证

- `useSessionEventConnection.test.tsx`：**14/14 通过**（含新增连接状态 connecting→connected→reconnecting 断言）。
- 相关前端套件（connection + store + adapter）：**35/35 通过**。
- `pnpm run build`：成功，`[chat-bundle-budget] ok sync=1383742 chat=363460 common=437435`。
- `pnpm run tsc`：仅基线既有错误（`onEditAndRerun`、`executionFlowProjector`），本次文件无新增类型错误。
- 未部署、未启动 Desktop/WebView2、未重启 Core。

## 未完成与影响

- 健康期不再轮询后，终态消息物化依赖“SSE 终态事件 + 一次 1.2s 快照”；**真实断线重连 replay 与快照游标对齐**尚未做集成测试，也未在真实 WebView2 验证无丢字/重复/终态回退。
- 旧 `/conversation` 仍是活动 Turn 回退与部分场景入口；D2c3/D3c 退役旧入口、活动 Turn SSE 终态直接物化仍未完成。
- 真实库启动 `TaskAutoDispatch` 配置阻塞仍在（验证环境用 env 关闭）；阶段 E/F 未开始。
