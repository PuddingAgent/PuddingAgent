# R6 用例落地：`Dirty` 三态往返

| 输入 | 期望读回 |
|---|---|
| `true` / `false` / 未设置(`null`) | 各自保持 |

**为何单独钉**：守卫只遍历构造参数，`Dirty` 为 **init-only** ⇒ 覆盖不到。

**自记两次失败**：`CS0579`（锚点含 `[Fact]` 归属错）· `CS0117`（读回 API 在 `DeliveryManifestValidator` 而非 `DeliveryManifest`）；均由守卫自动回退。

**验证**：`Pudding.DesktopServiceTests` 全绿（不依赖 WinUI）。
