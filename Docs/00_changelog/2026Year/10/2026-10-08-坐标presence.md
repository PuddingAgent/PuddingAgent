# 2026-10-08 坐标 presence 修正（线缆双向）

## 缺陷

proto3 普通 `double` **没有 presence** ⇒ `(0,0)`（页面左上角，**合法坐标**）与"未设置"不可区分。
既有 `DeltaX/DeltaY` 用 `== 0 ? null` 是安全的（0 位移 = 无位移），但**照抄到 x/y 就错了** ⇒ 会拒绝合法的左上角点击。

## 修正

| 步 | 改动 |
|---|---|
| proto | `optional double x = 10; optional double y = 11;`（生成 `HasX/HasY`，字段号不变 ⇒ 守卫已就位） |
| 编码 | 删掉 `X = interact.X ?? 0`（丢 presence），改为 `if (interact.X is { } pointerX) command.Interact.X = pointerX;`（y 同理） |
| 解码 | `Mapping.cs` L419 起：`x: command.Interact.HasX ? command.Interact.X : null`、y 同理、`observationId:` 空串视作 null |

## 诚实边界

- **尚未补"线缆往返用例"**（编码→解码→字段一致，尤其 **(0,0) 必须通过**）⇒ presence 修正目前只有**编译与既有套件**背书，**缺针对性证据**（下一轮第一件事）；
- **表面 `observationId` 失效判定未做**（安全关键）；**驱动指针路径未做**；**未真机验证**；端到端仍不可用（缺表面与驱动两段）。
