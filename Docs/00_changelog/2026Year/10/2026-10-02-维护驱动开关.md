# 2026-10-02 维护驱动开关（D4 接线）

## 改动

- 新增 `Source/PuddingCodeIndex/Services/CodeIndex/CodeSourceMaintenanceMode.cs`：
  `CodeSourceMaintenanceMode { Legacy, Coordinator }` + `CodeIndexMaintenanceOptions(SourceMaintenance = Legacy)`。
- `Source/PuddingCodeIndex/Services/CodeIndex/CodeIndexMaintenanceService.cs`：新增可选
  `options` / `sourceMaintenance` / `consumerInputs` 三个参数，并在变更施用处按开关分叉：
  - **`Coordinator`**：整批交给 `CodeSourceMaintenanceCoordinator.RunAsync`（完整清单校准 → 真实变更集 →
    更新计划 → 语言批量接缝 → 稳定读指纹 → `ReplaceFilesAsync` 原子提交 → 账本提交）；
  - **`Legacy`**（默认）：既有逐文件路径，一字未改；
  - **打开但零件没装配齐** ⇒ 告警并退回 `Legacy`，绝不假装新链路在跑；
  - 返回值语义**故意不同**：新链路只有在「这一批根本没被处理」（维护能力缺失 / 描述符解析不出 /
    协调器抛错）时才升级为 scope 级运行；单路径失败由协调器记退避、下轮重试。
  - 同时也改了删除的归属：`Coordinator` 模式下 watcher 观察到的消失**不再直接删**（那只是候选），
    作为提示交给协调器，由完整且根可用的扫描确认 —— 这正是「删除只能由完整扫描得出」这条不变量。
- `Source/PuddingCodeIntelligence/DependencyInjection.cs`：默认登记 `CodeIndexMaintenanceOptions()`
  （Legacy），宿主可用自己的注册覆盖以打开新链；协调器改为**显式工厂**并把批量接缝做成**安全探测**
  （`ICodeIndexer as ICodeIndexFileBatchUpdater`），不再抛异常。
  - **原因是一个真实事故形态**：宿主测试会用只做全量索引的替身替换 `ICodeIndexer`，
    原来的抛异常注册会让整条解析链失败（`ValidateOnBuild` 崩掉 Core 的同款故障）。已由宿主组用例复现并守住。

## 验证

- `dotnet test Source\PuddingCodeIndexTests` → **311 通过 0 失败**（本次 +4）。
- `dotnet test Source\PuddingCodeIntelligenceTests` → **132 通过 0 失败**。
- `dotnet test Tests\PuddingHost.Tests --filter CodeIndexMaintenanceHostCompositionTests` → **4 通过 0 失败**
  （含替换索引器的既有用例，证明安全探测生效）。
- 新增 `CodeSourceMaintenanceDriverSwitchTests` 覆盖：`Coordinator` 模式跑通全链并把索引真正写进去、
  **成功时不升级 scope**；语言报待重试 ⇒ 坏路径只影响自己、记入账本退避、**不升级整仓**；
  `Legacy`（默认）仍走逐文件且不写 manifest；开关打开但零件缺失时退回 `Legacy` 而不崩。

## 未完成与影响

- **默认仍是 `Legacy`**：本笔交付的是「可切换」，**运行中实例行为未变**，因此不需要重启；
  但这也意味着**修复尚未生效**（磁盘读取放大的真正收益要打开开关并重启后才可能出现）。
- **打开开关需要对真实仓库的端到端复核**，本 Agent 做不到：按仓库规程先交付
  `ready-for-external-deploy` → 进程外控制器重启到明确的新构建 → 四场景受控性能复核
  （含「无变更时的周期性扫描是否仍读盘」「单文件改动的读盘量」「删除只由完整扫描确认」
  「watcher 溢出后不误删」）。`WatcherHints` 目前来自旧 watcher 的批次路径，
  低延迟优化（事件节流/合并到提示）仍未接。
- 由于本轮改了 `CodeIndexMaintenanceService` 的构造签名（新增可选参数），组合根与测试替身都已同步验证；
  组件边界（`PuddingCodeIndex` 不引用宿主/语言智能）未变。
