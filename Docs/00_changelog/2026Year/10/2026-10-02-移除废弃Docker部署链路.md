# 2026-10-02 移除废弃 Docker 部署链路

## 改了什么

按用户 2026-10-02 裁定「Docker 链路已经废弃，请移除」：

删除：
- `build-and-up.ps1`
- `Source/PuddingAgent/Dockerfile`
- `Source/PuddingPlatformAdmin/Dockerfile`
- `Source/PuddingPlatformAdmin/docker/nginx-spa.conf`（容器内 nginx 静态站配置，目录随之清空）

- `TestScripts/e2e/run-docker-smoke.ps1`

- `Source/PuddingAgent/code_map.md`、`Source/PuddingPlatformAdmin/code_map.md`：移除 `Dockerfile` / `docker/` 索引条目。
- `Docs/07_architecture/41ADR-040开发构建与发布打包链路分离ADR.md`：状态改为 Superseded（Docker 部分），保留其宿主机 `dev-up` 开发链路结论。
