# 2026-10-08 观察登记处（正确形状）

| 成员 | 语义 |
|---|---|
| `Register(metadata)` | 结构校验 + 空 id 拒绝；返回 id |
| `TryResolve(id, BrowserPageGenerations current, out metadata)` | **世代三元组完全一致**才成功；不一致 ⇒ **移除并失败** |
| `InvalidateForPage(pageVersion)` | 换代整体作废 |
| `Count` | 便于断言"过期即移除" |

## 为什么现在才是对的形状

round-366 的结论是"**以 `BrowserScreenshotMetadata` 为中心重建**"：本次即如此 —— 不再有 `BrowserObservation` 这类平行字段集，失效语义也直接用既有的 `BrowserPageGenerations` 与拒绝枚举体系。
