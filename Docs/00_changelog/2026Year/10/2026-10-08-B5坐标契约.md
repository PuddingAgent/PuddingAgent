# 2026-10-08 B5 坐标操作契约落地（§8.2 第一步）

| 改动 | 位置 |
|---|---|
| 动作枚举 + `PointerClick` / `PointerMove` / `PointerDrag` | `InteractionContracts.cs`（`Focus` 之后） |
| 线名 `pointer_click` / `pointer_move` / `pointer_drag` | `DesktopInteractionActionWire.NameOf`（**插入时曾误落到 input-mode 的 switch，已修正**） |
| 请求新增 `double? x` / `double? y`（**CSS viewport 像素**）、`string? observationId` | `DesktopInteractRequest` 主构造末尾（可选，不破坏现有调用） |
| 校验 | 坐标动作**必须成对给 X/Y**；**不得与 locator 混用**（语义只能有一种，fail-closed） |

## 过程记录（一次真实失误）

线名插入时我按"枚举之后第一个 `_ =>` 兜底臂"定位，结果落进了 **`DesktopInputModeWire`** 的 switch（Dom/Native）⇒ 编译报 `CS0266`。
改正方式：锚定 **`NameOf(DesktopInteractionAction action)`** 之后再找兜底臂。**教训**：同一文件里有多个同形 switch 时，锚点必须包含**它所属的方法签名**，不能只找 `_ =>`。

## 诚实边界

- **线缆（proto/WireMapping + 协议冻结守卫 3 处）未做** ⇒ 新动作目前只到契约层；
- **表面校验（observationId 失效判定）与驱动 `InteractScript` 指针路径未做**；
- **`DesktopInteractRequest` 的坐标目前无人使用**（工具层/载荷映射待接）；**未真机验证**。
