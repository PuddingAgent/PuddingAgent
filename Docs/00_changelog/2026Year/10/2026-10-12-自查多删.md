# 自查更正：多删 `temp\dsh-build`

| 项 | 内容 |
|---|---|
| 规程清理范围 | `temp\build\*`、`temp\test-out\*` |
| **我额外删除** | **`temp\dsh-build`（未核验用途）** |
| 随后症状 | `SHELL-BUILD-FAILED`（0 套件）· `Microsoft.NET.Publish.targets(372,5): error MSB3030`（**发布缺文件**） |
| 相关性 | round-715 相同流程下 Shell **构建成功**；本轮唯一新增动作即该删除 |
| 恢复 | `temp/` 不入库 ⇒ **git 无法恢复**；需**重新构建**再生成 |
| 处置 | **如实上报** · **不再越范围删除** · 下一轮先重跑构建确认自愈 |

**只执行规程明示的清理路径；任何额外删除必须先核验用途与影响面。**
