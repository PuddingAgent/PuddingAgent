# 2026-10-08 browser_screenshot 工具本体

| 要点 | 做法 |
|---|---|
| 版本 | **必须钉**（`ExpectedPageVersion` 缺失/非正 ⇒ `browser_invalid_arguments`） |
| scope/detail/format | 线名解析 + 白名单（未登记 ⇒ 明确拒绝） |
| 参数一致性 | 由 `BrowserScreenshotRequest` 构造兜底（`ArgumentException` ⇒ 明确失败） |

| 失败 | 原样上报（`browser_capability_failed` + 原始消息），**不降级** |
