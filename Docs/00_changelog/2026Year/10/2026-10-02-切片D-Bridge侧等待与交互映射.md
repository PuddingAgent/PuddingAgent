## 与 Desktop 侧对齐的语义（逐条有测试）

| 情形 | 行为 |
|---|---|
| 等待**超时** | **成功结果 + `TimedOut=true`**（超时不是失败） |
| 等待**运行时错误** | 失败，且**不透传**错误原文（可能含选择器/URL/查询串） |
| 交互时页面活版本与期望不符 | `page_version_mismatch`，且**在动作之前**拒绝（测试断言"一次都没点"） |
| 交互后版本没有推进 | 响亮 `internal_error`——变更类能力的硬不变量（不诚实的版本会让旧引用重新"有效"） |
| 页面没有活版本 | 响亮 `internal_error`（不做无法安全作用其上的交互） |
| `Focus` 动作 | `unsupported_capability`（运行时没有 focus API，且不拿脚本绕过注入限制——与 Desktop 侧同一口径） |
| `Scroll` | 不需要定位符（与请求形状一致） |

> 版本推进那条检查在 Desktop 侧**才是权威**；Bridge 路径上这一份是纵深防御，
> 两条传输因此对"版本必须前进"给出同一结果。
