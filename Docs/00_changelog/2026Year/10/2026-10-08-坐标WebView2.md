# 2026-10-08 B5 坐标 P4c：WebView2 实现

## 交付

| 改动 | 说明 |
|---|---|
| 类声明 `WebView2BrowserPage : IBrowserPage, IPointerInputPage` | 实现可选能力 |
| `PointerAsync(PointerInput, ct)` | `Policy.PlanPointer*` → 逐条 `SendCdpAsync`；**成对**（planner 保证）；`Policy` 返回 null ⇒ `browser_input_mode_not_supported` |
| **不推进页面版本**（注释写明理由） | 坐标点击是否改页面只有回读才知道；凭猜推进会让旧 Ref 提前作废 |

复用的既有设施：`RequireWebView()`（webView 获取，见 `ScrollAsync` L458）、内部 `Policy` 属性（L51）、`SendCdpAsync`（L406）、`_dispatcher` 的 UI 线程约束（`ScrollAsync` L466 的既有注释"跨线程访问 WebView2 会直接失败"）。

## 验证

| 项 | 结果 |
|---|---|
| `PuddingBrowser.WebView2` 构建 | 通过 ✅ |

## 诚实边界

- **表面尚未接**（`BrowserRuntimeDesktopSurface` 的 `case` 与 L857 抛错未改）⇒ 坐标**仍不可端到端使用**；
- **Bridge 转发（P4b）未做** ⇒ 走浏览器桥的路径（`RemoteBrowserPage`）拿不到坐标；
- `SupportsNativeInput`（第四张表）**尚未**纳入指针动作（应在表面接好**之后**）；
- 本层行为**只有编译背书**（真实点击属真机）；**未真机验证**。
