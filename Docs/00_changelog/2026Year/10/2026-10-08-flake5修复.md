# 2026-10-08 flake #5 修复

| 项 | 内容 |
|---|---|
| 现象 | 修复后 12 连绿的**第 1 次**即红；该套件 42/43 |
| 用例 | `NarrowBrowserPort_RoutesEveryOperationThroughTheRealChannel` |
| 异常 | `InvalidOperationException : Sequence contains no elements`（`Single()` 于空集合） |
| 根因 | 会话**异步注册** ⇒ 立即 `Single()` 偶发落空（**与 flake #2 同类**） |
| 修法 | 4 处（L28/66/111/176）前加 `TestWait.UntilAsync(…, "broker registered the session")`，**仍严格 `Single()`** |
| 验证 | 该套件 **5 次连跑 43/0** |

## 纪律执行情况

上一轮刚立下的"**修一个缺陷类就扫同类全部站点**"**本轮立即生效**：**一次修全 4 处**（而不是只修翻车那一处）⇒ 另外 3 处同类隐患**提前消除**。

## 诚实边界

- 修的是**测试**（夹具时序假设）；**未真机验证**。
