# 2026-10-08 租约生命周期用例（含取红）

## 用例判据（三条）

| # | 判据 |
|---|---|
| ① | 有写授权时 `webview.navigate` 执行成功 |
| ② | 结束后 `Authority.Capture().ActiveLease` **为 null**（本操作的租约已释放） |
| ③ | **第二次写仍成功**，`Surface.NavigateCount == 2`（修复前会被留下的租约挡住） |

## 取红（证明用例有牙齿）

把 `finally` 里的释放条件临时改为恒假（`if (false && lease is not null)`）⇒ 用例**失败**，且失败信息就是缺陷本体：

```
Assert.Null() Failure: Value is not null
Actual: lease ce91d817c5004f919ec4acf63da3f742 ctx-agent/page-1 op=op-write-1 holder=agent-1 @ctl2/grant2
```

随后**完整还原**（残留变异检查 **0**）。
