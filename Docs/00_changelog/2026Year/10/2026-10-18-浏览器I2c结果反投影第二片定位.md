# 2026-10-18 I2-c 结果反投影第二片：page.locate 元素结果

## 改动

- `BrowserBridgeResultAdapter.FromLocate` → `BrowserLocateResultDescriptor`（Elements + Truncated）；
- `FromElement` → `BrowserElementDescriptor`：ref/tag/role/name/text/visible/enabled/checked/pageVersion 逐字段；
- 测试新增：元素字段映射 + truncated + **bbox 缺口**断言（契约 `DesktopElementRef` 没有 bbox ⇒ 线缆保持 null，不伪造坐标）。

## 已知缺口（如实登记）

- `DesktopElementRef` 无 boundingBox ⇒ 线缆 `BoundingBox = null`；工具端定位结果的 bbox 会缺失，接入执行器前需决定补契约或放弃该展示；
- 线缆元素描述符也没有 value/selectedValues（`BrowserElementDescriptor` 无这些字段）——定位面按旧协议本来就不带表单值，保持现状。
