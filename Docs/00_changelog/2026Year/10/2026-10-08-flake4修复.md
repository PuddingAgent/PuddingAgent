# 2026-10-08 flake #4 修复（同类缺陷第二处）

| 项 | 内容 |
|---|---|
| 现象 | 整链第 3 次未产出清单；`PuddingDesktop.Tests` 327/328 |
| 用例 | `DesktopReverseProxyIntegrationTests.…Found_ForwardsStatusAndBody` |
| 异常 | `HttpListenerException : 拒绝访问。`（**与 flake #1 同类**） |
| **根因** | **同一文件里还有第二个监听器**：`FakeUpstream.Start`（**上游**）也"取空闲端口→立即 `Start()`"，**未加守卫**（round-552 只包了 `StartProxy`） |
| 修法 | 同样**换端口重试 ≤5 次** |
| 验证 | `PuddingDesktop.Tests` **6 次连跑 328/0** |

## 教训：**同类缺陷要"扫同类全部站点"**

本会话反复出现的形态：**修了一处，同类另一处还在**（守卫的已实现清单 · 相邻 `case` · **端口竞态的第二处监听器**）。
**⇒ 纪律**：修一个缺陷类时，**立即在同类站点做一次全量扫描**，而不是等下一次翻车。

## 诚实边界

- 修的是**测试夹具**（非产品代码）；**未真机验证**。
