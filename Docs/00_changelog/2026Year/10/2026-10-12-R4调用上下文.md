# R4 ⑥ 最后一块拼图：`DesktopCallContext` 构造范式

| 项 | 内容 |
|---|---|
| `SendAsync` 完整签名 | `SendAsync(DesktopCapability capability, DesktopCapabilityRequest request, DesktopCallContext call, CancellationToken ct = default)`（`DesktopSession.cs:459`） |
| **`call` 构造范式**（照抄 L70–75） | `new DesktopCallContext(_desktopId, operationId, _clock.GetUtcNow() + (deadline ?? TimeSpan.FromSeconds(30)), correlationId: null, browserCaller: binding.Task)` |
| 签发调用形状（L80） | `_send(_capability.Capability, DesktopCapabilityRequest.ForBindingApply(binding), call, ct)` |
| **如实还原三段式**（L83–91） | 异常 ⇒ `(false, null, default, "…threw {Type}")` · `IsFailure` ⇒ `(false, null, default, Error.Message)` · 成功 ⇒ 从 `BindingAck` 取 grant |

## 端口类可一次成型（步骤）

① 契约校验（**在解析会话之前**；scope 线名 `read/write`，未知 ⇒ 拒绝）→ ② 会话解析不到 ⇒ **带理由拒绝**（**显式委派 fail-closed**，与门不同）→ ③ `BrowserCallerIdentity(SubAgent, callerId, childRunId, parentTaskId)`（**双 id 必需**）→ ④ `producer.IssueAsync(BrowserTaskBinding(...), OperationId, null, ct)` → ⑤ `Issued` ⇒ `(GrantId, scope, 到期)`，否则**带理由拒绝** → ⑥ 撤销：照抄 `call` 构造 + `SendAsync(BrowserBindingRevoke, …)`（**唯一落地时确认点**：撤销请求工厂方法名，见 `CapabilityUnions.cs:105/113`）
