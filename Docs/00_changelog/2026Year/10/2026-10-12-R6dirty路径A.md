# R6 收口：`dirty` 读入（路径 A）

| 改动 | 内容 |
|---|---|
| 属性 | `bool? Dirty { get; init; }`（`[JsonPropertyName("dirty")]`） |
| 读入 | 三态解析：`True/False` ⇒ `true/false`；**缺省/不可解析 ⇒ `null`（绝不默认 false）** |
| 构造 | **不进构造参数** ⇒ 用**对象初始化器** `{ Dirty = dirty }` |

**为什么绕开构造参数**：守卫夹具在**可空值类型构造参数**上 NRE（诊断二）；本路径让既有守卫**自然转绿**（**未改、未放宽**）。

**证据**：整链 **12 套件 / 2095 条 / 0 失败** ✓（守卫在套件内通过）
