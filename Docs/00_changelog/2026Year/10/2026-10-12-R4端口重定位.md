# R4 端口重定位到 `PuddingCore`

| 项 | 内容 |
|---|---|
| 为什么 | `PuddingPlatform` **不引用 Contracts** ⇒ 端口留 Contracts 会整链 `CS0246` |
| 新家 | `PuddingCode.Abstractions`（Core）—— Platform/Runtime/Host 都引用 |
| 签名 | **只用标量** ⇒ Core **零新增依赖** |
| 拒绝语义 | `Granted => GrantId 非空` ⇒ **拒绝必须给理由**（fail-closed 可判） |

**证据（按新纪律）**：整链 12 套件 / 2094 条 / **0 失败**、无 `error CS` ✓

## 未完成

删除 Contracts 里的旧接口（重复声明）· `SubAgentManager` 用 Core 类型重新可选注入 · ②-b 申请+四站点撤销 · Host 适配 + 注册 · 装配测试。

## 诚实边界

- 本轮只**重定位端口**（无运行时行为）；R4 端到端仍未成立；**未真机验证**。
