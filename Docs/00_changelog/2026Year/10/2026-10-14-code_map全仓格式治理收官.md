# 2026-10-14 code_map 全仓格式门禁治理收官（error 205 → 0）

## 目标 / 背景

前一日（2026-10-13）的波次只覆盖了 `PuddingCore` / `PuddingPlatform` 两个项目的 `code_map.md`
（见本目录 `2026-10-13-core_code_map波次13–17.md`、`2026-10-13-平台code_map波次6–12收官.md`）。
本轮把**剩余全部** 42 个 `code_map.md`（含仓库根索引）一次治理到通过格式门禁。

- 起点实测：全仓 `files_scanned 45` / **`error 205`** / `gate FAIL`；分类为
  `line-too-long 27` · `field-too-long 51` · `field-too-many-items 1` · `fence-forbidden 6`。
- 终点实测：**`error 0` / `gate PASS`（exit 0）**；`line-too-long 0` · `field-too-long 0` ·
  `field-too-many-items 0` · `fence-forbidden 0` · `fences 0`。

## 改动

**统一修法**（沿用仓内既定样板）：超长单元格缩为语义摘要 + `（见下「关键语义」）` 指针，
被缩掉的**原始文本逐字**下沉为表后普通段落；纯超长行按标点软折行；**只插换行、不删字符**。

- 逐项目波次（每波一个文件、一个 commit）：Core / Contracts / Host / Browser.AgentTools /
  PlatformAdmin / DesktopService / MemoryEngine / Browser.Automation / WpfArchive / Ssh /
  Rpc.Protocol / FullTextIndex / CapabilityBroker.AspNetCore / VectorIndex / IndexChunking /
  DesktopConnection / **仓库根 `code_map.md`** / CodeIntelligence / Runtime / CapabilityBroker /
  Browser.WebView2 / PuddingAgent / Controller / ContextPolicy / TaskRecall.Cli /
  CodeIndexTests / Desktop.CapabilityHost / Browser.WinUI / Browser.Protocol / PuddingDesktop /
  Diagnostics / Browser.Abstractions / PathFiltering / FullTextIndex.Cli / DesktopSurface.Browser。
- 两类形态差异单独处理：
  - **无表格文件**（如 `Source/PuddingDesktop/code_map.md`，`table_lines 0`）：只做拆行/下沉，
    并明确**不得新建表格**（验收须确认 `table_lines`/`entry_rows` 仍为 0）。
  - **含围栏文件**（`fence-forbidden`）：删除围栏标记行、围栏内内容逐字保留为普通行。

## 验证

每波都做以下独立复核（不采信子代理自述）：

1. **格式门禁** `Tools/Docs/code_map_check.py --check --paths <真实仓库路径>`
   ⇒ 每波 `error 0` / `gate PASS`（`exit 0`）。
2. **两个内容守恒门禁都跑**：定向 `verify_codemap_wave.py` + 全局 `verify_codemap_global.py`
   ⇒ 每波 `VERDICT: PASS`（全局门禁逐**单元格**/逐**行**核验原文存活）。
3. **结构守恒**：`table_lines` / `entry_rows` 与波前一致（大文件额外用备份实测对比）。
4. **改动面**：`git status --porcelain` 仅目标文件（共享工作区，只暂存白名单单文件）。
5. **备份真实性**：`git hash-object <备份>` == `git rev-parse HEAD:<文件>`。
6. **变异取红**：对副本删 40 字符 ⇒ 守恒门禁转 FAIL（证明该校验非空转）。

**最终全仓复测（收官后）**：`files_scanned 45` · **`error 0`** · **`gate PASS`（exit 0）** ·
`table_lines 1923` · `entry_rows 1599` · `fences 0` · `warn 125`。
其中 `table_lines/entry_rows` 与治理起点**逐字一致** ⇒ **35 波未增删任何一个表格行**。

## 影响与回滚

- 影响：仅 `code_map.md` 类文档的**版式**（表内长理由改为摘要 + 指针，原文移到表后段落），
  **无代码、配置、运行时不变量改动**；`table_lines`/`entry_rows` 不变，按行解析表格的既有用法不受影响。
- 回滚：逐个文件 `git revert <commit>` 即可（每波一个提交）。
