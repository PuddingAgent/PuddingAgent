# 2026-10-18 I2-c 适配器第四片：page.snapshot → browser.snapshot

## 改动

- `BrowserBridgeCommandAdapter` 扩展 `page.snapshot` → `browser.snapshot`；
- 12 个快照选项**逐字段**搬运：`IncludeDom/IncludeAccessibilityTree/IncludeHidden/IncludeIframes/IncludeShadowDom/IncludeHtml/MaxNodes/MaxTextLength/MaxDepth/ScopeRef/SinceRevision/IncludeContentBlocks`；
- 线缆无 `expectedPageVersion` → 使用 `Unknown`（不猜版本，与导航映射同一取舍）；
- 参数 JSON 非法时 fail-closed 并给出可行动原因；
- 测试新增字段哨兵：一次请求把 12 个选项设为非默认值，逐项断言到达 `DesktopSnapshotOptions`（防 F4 类字段丢失）。

## 验证

- `dotnet test Tests/PuddingDesktop.Tests --filter BrowserBridgeCommandAdapterTests` ⇒ **8/8 通过**；
- 未运行产品/模型；适配器仍未接管执行，无生产行为变化。
