# 2026-10-08 scope 枚举对齐

| 处 | 改前（我造的） | 改后（对齐实现） |
|---|---|---|
| 枚举 | `Element` | `FullPage` |
| 线名 | `"element"` | `"full_page"` |
| 校验 | 元素截图必须给定位 | **全页截图不得带定位/区域**（与视口同规则） |
| 用例 | `AnElementScreenshotRequiresALocator` | `AFullPageScreenshotTakesNoLocatorAndNoRegion` |

## 为什么这是一次必要的自我纠正

架构第一原则要求"**边界显式、单一真源**"；两套各自演化的 scope 枚举会让"契约接受但实现不认"的取值穿过线缆 —— 与 fail-closed 冲突。**新造契约时应先照抄既有实现的枚举**。
