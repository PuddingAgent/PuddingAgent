# 2026-10-08 卫生偏差（诚实记录）

| 项 | 内容 |
|---|---|
| 提交 | **`3059a39`**（flake #3 修复） |
| 文件 | `Tests/PuddingHost.Tests/BrowserBridge/BrowserBridgeTestHost.cs` |
| 我的 hunk | 等待助手默认 **2s→15s**（flake #3 修复）✓ |
| **夹带的他方 hunk** | `-﻿using` → `+using`（**去 BOM**，他方原本的未提交改动） |
| 成因 | 该文件**本已被他方改动**；我为修 flake 编辑它，**写入以 `UTF8Encoding(false)` 重写整文件** ⇒ 他方差异被固化 |
| 影响 | **低**（方向一致、C# 无 BOM 无碍、工作树现已干净），但**属纪律偏差** |
| **新纪律** | ① 编辑工作树中**已被改动的文件**前，先 `git diff` 分辨 hunk 归属；② **保留原编码**（有 BOM 保留 BOM）；③ 或先在临时副本上做最小补丁 |

## 为什么必须写下来

这条**不会让任何测试变红**，也不会影响外部验收 —— 但它**破坏了"不夹带他方改动"的仓库纪律**。**不会被门禁抓到的偏差，只能靠自我记录与纪律补上。**

## 诚实边界

- 已如实记录，**未回退**该 BOM 改动（回退等于替他方决定，且会与其意图相反）；**未真机验证**。
