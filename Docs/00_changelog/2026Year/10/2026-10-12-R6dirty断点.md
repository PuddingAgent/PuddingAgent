# R6 断点：CLI 请求 → 清单之间丢值

| 项 | 结果 |
|---|---|
| 加好入口两环后探针 | `dirty` **仍为 `null`** |
| ⇒ 断点 | **`DeliveryCollectionRequest.WorkingTreeDirty` → `DeliveryBuildFacts`**（或 CLI 未写入请求） |
| 守卫 | 自动回退入口两环；**步骤1 已在位**（事实记录字段 + 采集器投影，`841f409`） |
| 已排除 | CLI 参数解析 · `Dirty` 序列化 · 守卫夹具（`init-only`） |

## 下一轮（先诊断再改）

在 CLI 请求构造处**打印** `WorkingTreeDirty`（或采集器打印 `facts.WorkingTreeDirty`）⇒ 判定是"CLI 未写请求"还是"投影丢值"。

## 诚实边界

- 本轮**无净产出**（入口两环被守卫回退）；清单仍 `dirty=null`（**诚实"未采集"**）；**未真机验证**。
