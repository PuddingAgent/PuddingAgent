# R4 ⑦ 第一批：子委派申请决策四条用例

| 用例 | 断言 |
|---|---|
| `BrowserDelegation_NoPortMeansNoRequest` | 端口为 `null` ⇒ **不申请** |
| `BrowserDelegation_UndeclaredMakesNoRequest` | 父未声明 ⇒ **不申请且零请求** |
| `BrowserDelegation_DeclaredButIncompleteIsRejected` | 声明但不完整 ⇒ **明确拒绝**（`incomplete`）且**零请求**（不降级） |
| `BrowserDelegation_MissingTrustedParentRunIdIsRejected` | 缺可信父 run id ⇒ **拒绝**且**零请求** |

**实现要点**：追加进**既有测试类**（复用其**私有**假件）· 端口走**末位第 9 可选参数**（既有构造调用不变）· **反射直调**私有决策方法（无需 spawn 夹具）。

**验证**：`PuddingPlatformTests` **1442/1442** ✓
