# R1 切片一：许可/租约/选中页

| 缺陷 | 修法 |
|---|---|
| 取消/版本拒绝**泄漏租约** | 准入失败与取消检查移入同一 `try`，`finally` 统一释放 |
| **接管→恢复**后旧排队操作复活 | UI 回调**不再 Admit**；改为比对准入时的 `ControlEpoch/GrantEpoch`，推进即 stale 拒绝 |
| 选页后**无关任务**也能获批 | 同一选中页已被另一任务绑定时明确拒绝（共享需独立显式许可） |

**证据**：反例 **4/4 绿** · 常规 **376/376 绿**。
