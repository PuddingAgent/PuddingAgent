# 2026-10-18 会话读模型阶段C1持久化基础

## 改动

- 新增读模型两张小表实体（Plan §3.2）：
  - `Data/Entities/ConversationTurnSummaryEntity.cs`：`conversation_turn_summaries`，主键 `(conversation_id, turn_id)`，保存终态/计数/有界活动预览/完整性/摘要版本；
  - `Data/Entities/ConversationReadStateEntity.cs`：`conversation_read_state`，保存当前根 Turn、压缩状态、有界子代理摘要 JSON、初始化状态与 revision；事件游标唯一权威仍是现有 `conversation_projection_checkpoints`。
- 新增 `Data/ConversationReadModelSchema.cs`：表名、索引名与 `conversation_events` 两条查询索引命名的**单一定义点**；`PlatformDbContext` 与 bootstrapper 共同引用，避免新库/旧库两套名字。
- `PlatformDbContext`：新增 2 个 DbSet、2 个实体配置；为 `conversation_events` 声明 `(conversation_id, message_id, sequence)` 与 `(conversation_id, turn_id, sequence)` 两条索引（新库由 EF EnsureCreated 创建）。
- 新增 `Services/ConversationReadModelSchemaBootstrapper.cs`：
  - `EnsureCreatedAsync`：存量库幂等创建两张小表与小表索引，启动期成本有界；
  - `EnsureConversationEventIndexesAsync`：为约 300 万行的 `conversation_events` **显式维护**创建两条查询索引，返回 `ConversationEventIndexMaintenanceResult`，不在启动期自动调用。
- `PuddingApplicationInitializer` 仅注册 `EnsureCreatedAsync`（建小表），不注册事件大表索引维护。
- 新增 `Source/PuddingPlatformTests/Services/ConversationReadModelSchemaTests.cs`：EF 模型命名、存量库补齐、幂等、两条索引创建 + `EXPLAIN QUERY PLAN` 按 message/turn 等值收敛断言。
- `Source/PuddingPlatform/code_map.md` 新增「会话首屏读模型」小节；根 `code_map.md` 刷新 `Source/**` 指纹。
- 本提交为阶段 C 的**持久化基础**，尚未接入投影写入与查询 API（阶段 C 继续）。
