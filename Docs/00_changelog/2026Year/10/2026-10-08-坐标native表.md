# 2026-10-08 B5 坐标 P5c：第四张表

## 为什么是"第四张表"

新增一个动作种类要同步**四张表**（我三次栽过）：①`ValidateShape`/`RequiresLocator` ②工具层 `MapAction` ③表面动作→运行时映射 ④**`SupportsNativeInput`**。前三张已在前几轮补齐，本轮补第四张。

## 改动

| 改动 | 位置 |
|---|---|
| `SupportsNativeInput` 纳入 `PointerClick`/`PointerMove`（坐标点击/移动走 CDP 真实鼠标事件 ⇒ 确属 native） | `InteractionContracts.cs`（`Upload` 之后） |
| native 提示文案同步：`native input covers … drag/pointer_click/pointer_move` | `BrowserInteractTool.cs` |
| 覆盖清单用例补两条 `Assert.True` | `InteractContractTests.NativeInputCoverage_IsOneFrozenTruth` |

**拖拽未纳入**：`PointerDrag` 需 `toX/toY`（契约尚未携带）⇒ 纳入即等于宣称支持一个做不到的动作。
