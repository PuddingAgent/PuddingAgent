# 2026-10-08 ② ScreenshotAsync

| 环节 | 失败时 |
|---|---|
| 页面解析 / 版本核对 | 明确失败（版本不符可重试） |
| 几何事实 | `InvalidRequest`（不臆造） |
| 页内计数（安装+读回） | `InvalidRequest`（观察无法建立） |
| `TryPlan` / `CheckBudget` / `TryValidate` | 明确失败（带原因/拒绝枚举） |
| 成功 | **登记观察**并回传结果（含 `ObservationId` 与完整裁剪几何） |

## 两次失败后的正确手法（纪律）

- **写 C# 用单引号 here-string 整块写**（`$"…"` 原样保留），**不要用 PowerShell 拼接**（round-421 因此失败）；
- **禁止全局字符串替换改语法**（round-420 因此误伤 5 处既有代码）；
- 契约与实现**同名不同命名空间**的枚举要分清（`DesktopScreenshotDetail` vs `BrowserScreenshotDetail` —— 本轮最后一处错误即是它）。
