# 2026-10-18 I2-c 适配器第八片：page.create → browser.tabs(New)；activate/close 记录 tabs 版 H3 缺口

## 改动

- `page.create` → `browser.tabs`（`DesktopTabAction.New`）：
  - 唯一"不钉版本"的 tabs 动作（没有已存在页面可钉，`BrowserTabsRequest.New` 语义即如此）；
  - 需要显式 context id；`initialUrl` 必须绝对 http/https（可空）；`activate` 默认 true；
  - 该分支放在"页面命令必须带 page id"校验之前（新建本就没有 page id），避免误拒绝。
- `page.activate` / `page.close`：能力契约要求钉住 `expectedPageVersion`，线缆当前没有该字段（**与 interact 同类的 H3 缺口，tabs 变体**）⇒ fail-closed，原因写明 H3；不猜版本、不回退。
- 通用"未映射"用例改用 `page.list`。

## 验证

- adapter 用例 **13/13 通过**（含 create 成功映射 + activate 拒绝）；
- 未运行产品/模型；适配器仍未接管执行。

## 未完成与影响

- **tabs 版 H3**：补齐 `PageActivateArguments`/`PageCloseArguments` 的 `ExpectedPageVersion` 后可映射 activate/close（下一片，与 interact 同法）；
- `page.list`、`context.getInfo/close/create` 尚未映射（发现/管理面，需区分准入语义后做）；
- 派发器接线、controller 收缩、删除旧路径未做。
- 回滚 = revert 本提交。
