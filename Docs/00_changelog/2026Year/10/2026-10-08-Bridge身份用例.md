# 2026-10-08 Bridge 身份适配用例

| 用例 | 判据 |
|---|---|
| 缺身份 | 拒绝（不补默认身份） |
| kind 未登记 | 拒绝 |
| **子代理缺父任务** | 拒绝（父授权子集的前提） |
| 合法 Agent | 通过 + `TryGetBrowserCaller` 取得到调用者 |

**写法要点**：kind 一律用 `BrowserCallerKindWire.NameOf(BrowserCallerKind.Agent/SubAgent)` **动态取**（不硬编码字符串）；`OperationId` 用 `new OperationId(Guid.NewGuid().ToString("N"))`（记录接受**字符串**）。
