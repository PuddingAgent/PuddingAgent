# Desktop 守护组件独立门禁

- 新增 `Source/PuddingDesktop.Guardian/`：BCL 独立进程、loopback HTTP 命令、健康稳定期、带哈希的持久回滚事务及进程身份校验。编译目标禁止产品项目引用。
- 新增 `Source/PuddingDesktop.GuardianTests/`，只引用守护组件；不加载宿主或 Roslyn/MSBuild。不访问生产数据，不重启当前 Desktop/Core。
- 验证：独立 build 0 警告/0 错误；独立测试 16/16 通过，包含依赖边界、回滚清理、中断恢复、短暂就绪拒绝、主动停止、请求去重和 HTTP 认证。产物在 `temp/build/recovery`，测试证据在 `temp/test-out/guardian`。
- S4 判据：程序集引用只含框架库；项目引用为 0。源码中的产品工程路径仅为进程外构建入口，不构成编译依赖。
- 未完成：S5 Desktop 打包/启动接线、`bootstrap_reboot` 路由、产品集成验证及操作文档；随后独立提交。
