# 2026-10-02 .pudding 纳入版本控制并新增 Markdown Front Matter 技能

## 目标 / 背景

用户要求：① 在 `.pudding/skills` 新建 Front Matter 技能；② 把 `.pudding` 加入 git 追踪并提交。

背景：同日早些时候（他方提交 `ca599e8`/`e1b5868`）曾按当时裁定把根目录 `memory/`、`skills/` 迁入 `.pudding/`
并**移出版本控制**（`.gitignore` 含 `.pudding/`）。本次是用户对该裁定的更新：`.pudding` 纳入追踪。
提交前先核实体量：`.pudding` 仅 **19 个文件 / 0.05 MB**（`skills/` 10 个技能目录；`memory/` 为空目录），
不存在大文件或敏感内容风险。

## 改动（提交 `9fdcfd5`，22 个文件）

1. **新技能 `.pudding/skills/markdown-front-matter/`**
   - `manifest.json`：id/name/version/description/author/created/tags/keywords/source_session
     （字段集与既有 `code_map-incremental-update` 等技能一致）
   - `SKILL.md`（75 行）：12 字段定义与取值来源表；工作流（`--check` → `--fix --dry-run` →
     小范围 `--paths` 试点 → 全量 `--fix` → 回读校验）；命令参考；6 项质量门禁；
     6 条常见坑（只补不覆盖、空列表合法、被移动文件 `--follow` 变慢、skills 不加 Front Matter、
     Front Matter 不写日志、YAML 转义）；关联 `Agents.md` 规则与两个常驻工具。
   - 技能文件本身**不加 Front Matter**（技能格式为 `manifest.json` + `SKILL.md`），
     该例外已写进技能文档，避免与技能加载器冲突。

2. **`.pudding` 纳入追踪**
   - `.gitignore`：移除 `.pudding/` 忽略行；根级 `/agents/`、`/memory/`、`/skills/` 继续忽略，
     注释改写为「仅用于防止旧流程在仓库根原地重建同名目录」。
   - 入库 21 个文件（10 个技能目录 × 2 + `vercel-react-best-practices` 仅 SKILL.md）。
   - `.pudding/memory/` 当前为空，不产生提交；若后续被运行时归档填充，可再评估是否单独忽略。

3. **规范化 11 个技能文件的 UTF-8 BOM**（仓库约定无 BOM）：
   `agent-recent-activity-check`、`agent-status-health-check`、`code_map-incremental-update`、
   `heartbeat-feishu-report`、`session-context-recovery` 的 `SKILL.md`+`manifest.json`，
   以及 `v4-flash-architect-dev/manifest.json`。仅删除前 3 字节，正文与行尾未改。

## 验证

| 检查 | 命令 | 结果 |
|------|------|------|
| 不再被忽略 | `git check-ignore -v .pudding/skills/...` | 无输出 |
| 入库数量 | `git ls-files .pudding` | 21 个文件 |
| manifest 合法性 | 严格 `json.loads(utf-8)` + 校验 id/name/version | 全部通过 |
| 暂存范围 | `git diff --cached --name-status` | 仅 `.gitignore` + `.pudding/**`，未夹带他方改动 |
| Docs 门禁未受影响 | `python Tools/Docs/front_matter.py --check` | Docs 侧不含 skills，规则不变 |

**未验证**：未重启 Core / 未做技能加载 smoke（技能发现属运行时行为；仓库级 `.pudding/skills` 由技能扫描读取，
需在下次 Core 重启或技能重扫后生效）。

## 影响与回滚

- 影响面：`.gitignore`、`.pudding/**`（首次入库）、技能集合新增 1 个。
- 回滚：`git revert 9fdcfd5`（会把 `.pudding` 重新移出版本控制并删除新技能）。
- 后续注意：`.pudding` 已受版本控制，运行时若向其中写入变动内容（缓存/临时文件）会产生 git 噪声，
  必要时按需追加更细的忽略规则。
