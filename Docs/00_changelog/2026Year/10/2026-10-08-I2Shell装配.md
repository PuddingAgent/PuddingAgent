# 2026-10-08 Shell 装配（Bridge + 能力通道同一实例）

## 交付

| 位置 | 改动 |
|---|---|
| `DesktopApplicationCoordinator.Capability.cs`（bridge 构造前） | `var controlPlane = BrowserTaskBindingComposition.Create(lifecycle, new DesktopInstanceId("default"), new DesktopProcessInstanceId($"desktop-{Environment.ProcessId}"));` |
| 同文件 bridge 构造 | `new BrowserWorkspaceTargetBridge(lifecycle, controlPlane.Service)` |
| 同文件 `StartAsync(...)` 调用 | `taskBindings: controlPlane.Service,`（命名实参） |

**为什么必须是同一实例**：bridge 负责"切目标即撤销"，能力通道负责"受理/撤销 ack"；两者若各持一份，撤销就会对不上（审计结论 #1 的同类问题）。

## 诚实边界

- **闸门仍未启用**：生产未给 `DesktopService` 注入连接世代 ⇒ 浏览器能力准入行为不变（无风险）；控制面能力现在走**真实服务**，未握手时明确拒绝。
- 装配路径**没有专属用例**（Shell 组合根难以单测）：本轮的证据是"编译通过 + 两个套件全绿"。
