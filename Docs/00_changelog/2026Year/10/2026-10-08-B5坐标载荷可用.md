# 2026-10-08 B5 坐标载荷可用

## 改动（一处，但关键）

```csharp
- public bool RequiresLocator => Action != DesktopInteractionAction.Scroll;
+ public bool RequiresLocator => Action is not (
+     DesktopInteractionAction.Scroll
+     or DesktopInteractionAction.PointerClick
+     or DesktopInteractionAction.PointerMove
+     or DesktopInteractionAction.PointerDrag);
```

**为什么关键**：round-298 我只加了载荷与校验，但**既有**的 `RequiresLocator` 会让新动作一律抛
`Action 'pointer_click' requires an element locator` ⇒ **载荷实际上用不了**（测试当场抓到）。这正是"只加字段不等于功能可用"的例子。

## 新增用例（`InteractContractTests`，同文件同命名空间——避免我上轮自建文件时的命名空间遮蔽问题）

| 用例 | 判据 |
|---|---|
| `PointerActionsCarryViewportCoordinatesAndObservationId` | X/Y/observationId 如实携带、`Locator` 为 null |
| `PointerActionsRequireBothCoordinates`（Theory × 3 动作） | 缺 X、缺 Y、两者都缺 ⇒ **均拒绝**（不猜默认 (0,0)） |
| `PointerActionsRefuseALocator` | 坐标 + locator 混用 ⇒ 拒绝 |
