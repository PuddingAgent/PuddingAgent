# 2026-10-08 B5 权限/新窗口/下载接管：页面不再停在等人操作的状态

## 目标 / 背景

上一轮（[B5 页面脚本对话框接管](2026-10-08-B5页面脚本对话框接管.md)）结尾登记了同类缺口：
`PermissionRequested`（权限弹窗会阻塞）、`NewWindowRequested`（`window.open` 另开窗口）、
`DownloadStarting`（下载会弹 UI）。它们与脚本对话框是**同一类**问题：不处理 ⇒ 页面停在"等人操作"
的状态，自动化流程没有明确报错却走不下去。

## 改动

| 层 | 文件 | 改动 |
|---|---|---|
| Automation | `PageEventPolicy.cs`（新增） | 三条安全侧确定性默认：<b>权限一律拒绝</b>（自动化不该因为页面想要就悄悄拿到设备权限；要授权必须是显式产品决定，策略里**不留白名单后门**）、<b>弹窗抑制</b>并记录目标地址（**不**偷偷改成"在当前页打开"——那会丢掉当前页面状态，是调用方没要求的语义改变）、<b>下载取消</b>（文件落盘需要授权与明确去向）。摘要只留 `scheme://host`（**不回显路径与查询串**，避免把 token 带进日志），有名/无地址时不留空字段，且长度有界、单行、无控制字符 |
| 驱动 | `WebView2BrowserPage` | 订阅/退订三个事件并确定性作答（权限：`Deny` + `Handled`；新窗口：`Handled`；下载：`Cancel` + `Handled`）；摘要与计数留在页面（`LastPageEvent`/`PageEventCount`，`internal`，供测试与诊断） |

## 验证

| 套件 | 结果 |
|---|---|
| `PuddingBrowser.AutomationTests` | **264 / 264**（原 257 ＋ 7） |
| `PuddingDesktop.Tests` · `Host` · `DesktopSurface.BrowserTests` · `ContractsTests` · `DesktopServiceTests` · `AgentTools.Tests` | 320/320 · 258/258 · 65/65 · 152/152 · 229/229 · 62/62 |

新增门禁：**11 种权限种类（含未知种类与 null）全部拒绝**；弹窗抑制、下载取消；`HostOf` 只保留
`scheme://host`（含非默认端口）并对非法/空地址返回空；权限摘要含种类与 host 且**不含 token/路径**；
弹窗摘要写明"已抑制、如需请显式导航"；下载摘要写明"没有写任何文件"；恶意文件名（换行/制表/控制字符/超长）
不会破坏单行与长度上限；无名/无地址时不产出空字段。

**取红实测**：把权限默认改成放行（新增 `Allow` 并返回它）⇒ `EveryPermissionIsDenied` **恰好变红**；
复原后 264/264 复绿（并确认恢复后枚举里没有留下 `Allow` 这类的死代码）。

## 已知边界（诚实登记）

- **真机未验证**：本环境没有 WebView2。三个策略与摘要有纯函数测试，但"设置了 `Handled`/`State`/`Cancel`
  之后 WebView2 确实不再弹 UI"需要外部进程内 smoke 复核。
- **摘要仍只留在驱动内部**：脚本对话框与这三类事件的摘要都还没经能力通道/工具上报给 Agent
  （"刚才有个权限请求被拒了"目前只有诊断可见）。上报需要一条状态通道（例如让 `PageSnapshot`
  带回 `pageEvents` 事实）——这是下一轮的自然切入点。
- **权限拒绝没有例外**：连剪贴板读取也拒绝。如果将来自动化确实需要某类权限，正确做法是引入**显式授权**
  （调用方声明 + 可见记录），而不是在策略里塞白名单。这一点在原代码注释里写明，避免后人顺手放宽。
- **下载只取消**：没有"下载到某目录并登记为 artifact"的能力；那需要与 artifact 去向/授权一起设计
  （与 B4 的字节归属问题同源）。
- **新窗口只抑制**：没有"把弹窗接管为标签页"的能力（需要标签页模型与调用方语义，未做）。
- `ProcessFailed`、`WebResourceRequested` 等其它事件仍未处理（不在本轮范围）。

## 影响与回滚

- **行为变化（驱动侧）**：权限询问从"弹窗等人点"变成**一律拒绝并记录**；`window.open` 不再另开窗口；
  下载不再弹另存为。没有工具/契约变化，Agent 可见输出不变（摘要尚未上报）。
- 回滚：还原 `PageEventPolicy.cs`、驱动的三个事件订阅/处理器与两个内部属性、其测试与冻结列表、两个 code_map。
