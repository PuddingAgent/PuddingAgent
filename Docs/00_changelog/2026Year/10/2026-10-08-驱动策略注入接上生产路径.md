# 2026-10-08 驱动策略注入接上生产路径：两个浏览器宿主共用同一份策略

## 目标 / 背景

上一轮建好了注入 seam，但**没有生产调用方**：两个宿主都在用 `NullBrowserDriverPolicy`（安全默认生效、
摘要简略）。当时登记的原因是"适配器放的 `Pudding.DesktopSurface.Browser` 不能被 WPF 归档引用，
而 `BrowserWorkspaceController` 刻意不新增引用"。本轮解决它。

## 改动

| 项 | 改动 |
|---|---|
| 适配器位置 | `AutomationDriverPolicy` 从 `Pudding.DesktopSurface.Browser` **移到 `Pudding.DesktopService`**（`Browser/`）——两个浏览器宿主都编译 `BrowserWorkspaceController` 且都引用 `Pudding.DesktopService`，因此**拿到同一份策略** |
| 依赖 | `Pudding.DesktopService` 新增对 `PuddingBrowser.Abstractions`（**叶子**）的引用：注入点类型在那里 |
| 注入 | `BrowserWorkspaceController` 的两处 `CreateContextAsync` 都带 `DriverPolicy = AutomationDriverPolicy.Instance` |
| 边界冻结清单 | `ComponentBoundaryTests.ServiceCsproj_DeclaresExpectedReferencesAndKeepsItsBoundaryTarget` 的期望列表加入 Abstractions，**并写明理由**（按规程"冻结清单与改动一起更新"） |

顺带：把上一轮的适配器注释里"两个宿主"的理由写实（现在是真的了）。

## 验证

| 套件 | 结果 |
|---|---|
| `Pudding.DesktopServiceTests` | **231 / 231**（原 229 ＋ 2：适配器转发用例） |
| `PuddingBrowser.AutomationTests` · `AgentTools` · `PuddingDesktop` · `Host` · `DesktopSurface.Browser` · `Contracts` | 270/270 · 63/63 · 320/320 · 258/258 · 65/65 · 152/152 |
| 构建 | `Pudding.DesktopService` · `PuddingDesktop.WpfArchive` · `PuddingBrowser.WinUI` · `Pudding.DesktopSurface.Browser` 全部**已成功生成** |

新增门禁（DesktopServiceTests）：适配器对 `Alert/Confirm/Prompt` 的答案与 Automation 策略一致；
权限摘要含种类/结论/host 且**不含路径与 token**；弹窗抑制与下载取消的说明照旧。

**边界保护起了作用（值得记录）**：新增 Abstractions 引用**立刻**让 `ComponentBoundaryTests` 变红 ——
这正是"依赖方向由编译期/门禁强制"的设计意图；我按规程更新冻结清单并写明理由，而不是绕过它。

## 已知边界（诚实登记）

- **原生输入 / 原生滚动 / 截图仍在 seam 之外**：WinUI 面依旧显式 unsupported（`#if WINUI_BROWSER`）。
  把它们也搬进注入接口（`DriverCall(Method, ParametersJson)` 列表 + 截图参数 JSON）是下一步。
- **事件事实上报在 WinUI 面仍为空**：`PageEventLog` 在 Automation，WinUI 面拿不到；
  因此 WinUI 面"会接管事件、但不上报事实"。让日志经接口（由策略创建）返回是下一步的可选做法。
- **真机未验证**：两个宿主现在都注入同一策略，但"注入的策略在 WinUI/WPF 真实运行时确实被调用"
  需外部 smoke（本环境无 WebView2）。
- `PuddingDesktop` 整体产物仍未重新生成（本机运行中的 Shell 占用输出文件）——只验证了编译。

## 影响与回滚

- **行为变化（两个宿主）**：页面事件摘要从"安全默认的简略文本"变成 Automation 策略的完整摘要；
  脚本对话框的答案语义不变（alert 接受、其余取消）。
- 回滚：删掉适配器与两处注入、移除 DesktopService 的 Abstractions 引用与冻结清单条目。
