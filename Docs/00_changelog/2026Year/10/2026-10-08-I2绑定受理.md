# 2026-10-08 任务绑定受理与撤销

## 交付

`Source/Pudding.DesktopService/BrowserTaskBindingService.cs`：

| 不变量 | 行为 |
|---|---|
| **绑定不能替代用户选择** | 目标当下不是 `PageTargets.AgentTarget` ⇒ 拒绝，原因 `the binding target is not the page the user currently selected for the agent` |
| 不并存两份授权 | 同一 `(任务, 目标)` 重复受理 ⇒ 先 `RevokeGrant` 旧的，再签新的 |
| `Revoke` 幂等 | 撤销后 `ActiveGrants` 归零；再撤返回 `false`、不抛 |

策略边界照旧：**有效期上限、目标已登记、连接世代存活、子代理子集**都在 `BrowserGrantIssuer`／唯一 authority 判，本类不重写。

## 诚实边界

- **仍无生产调用方**：本类需要一个"收到绑定"的入口 —— 即绑定**传输**（能力通道控制面或 Bridge），
  以及组合根注入（与开闸门**同一次提交**，见 round-197 决策）。
- 撤销目前只覆盖"显式 Revoke"：**切目标/任务结束/父撤销时的自动撤销**尚未编排（方案 §4.1 要求这些路径确定性撤销）。
