# 2026-10-08 B4 专用用例 + 缺陷修复

| 项 | 结果 |
|---|---|
| 截图 ⇒ id 可解析 ⇒ 坐标可用 | ✅ |
| 页面变更 ⇒ id 失效（且不触达驱动） | ✅ |
| **缺陷**：计数初值 0 ⇒ `TryValidate` 拒（要求 > 0）⇒ 首次截图必拒 | **已修**（初值 1） |

## 缺陷是怎么被发现的

`TryValidate` 的拒绝信息 `screenshot was refused (MissingRevisions): screenshot must report PageVersion/domRevision/viewportRevision (> 0)` 直接指向了根因 —— **这也是我坚持"用例断言要先打印错误码"的回报**（前几轮因为没打印错误码白花了两轮）。
