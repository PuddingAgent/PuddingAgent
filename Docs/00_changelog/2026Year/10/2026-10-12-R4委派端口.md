# R4 前置：委派生命周期窄端口（契约层）

| 成员 | 作用 |
|---|---|
| `RequestChildGrantAsync` | 真实子 run 申请子集授权（父身份/子集/到期全都要校验） |
| `RevokeForRunAsync` | 按 run 撤销 |
| `RevokeForTaskAsync` | 按**完整任务运行身份**撤销（不误撤同 Agent 其它 run） |
| `OnConnectionLostAsync` | 本地标记撤销；新世代**不自动恢复** |

**证据**：Contracts 编译通过 · **219/219** ✓

## R4 剩余（待 Runtime 可编译）

`SubAgentInvocationService.BuildSpawnRequest` 两条路径投影可信父身份 + 委派描述；`SubAgentManager` 用**真实子 runId** 申请子集 grant；Host 实现该窄端口（绑定协调器）；**真实 Runtime 装配测试**（父持页 A Read ⇒ 子 snapshot 成功、navigate/页 B 拒绝；父撤销 ⇒ 子再 snapshot 拒绝）。
