# 2026-10-08 接真实通道的缝：`DesktopSession.SendAsync`

## 为什么需要它

定位结果：`DesktopSession` 的发送入口是

```csharp
private async Task<CapabilityResult<TResult>> InvokeAsync<TResult>(
    DesktopCapability capability, DesktopCapabilityRequest request, DesktopCallContext call,
    Func<DesktopCapabilityResponse, CapabilityResult<TResult>> project, CancellationToken cancellationToken)
```

—— **private** 且要求投影函数，因此外部（签发生产者）无法复用它。

## 交付

```csharp
public Task<CapabilityResult<DesktopCapabilityResponse>> SendAsync(
    DesktopCapability capability, DesktopCapabilityRequest request,
    DesktopCallContext call, CancellationToken cancellationToken = default)
    => InvokeAsync(capability, request, call, static response => CapabilityResult<DesktopCapabilityResponse>.Success(response), cancellationToken);
```

| 性质 | 说明 |
|---|---|
| 投影**恒等** | 返回完整响应；**不**代替调用方判断 ack |
| **不改变语义** | 只是把既有 `InvokeAsync` 公开化 + 固定投影；连接/队列/期限/审计逻辑全走原路 |
| 与生产者同形 | `DesktopCapabilitySender` 委托可直接绑 `session.SendAsync` |
