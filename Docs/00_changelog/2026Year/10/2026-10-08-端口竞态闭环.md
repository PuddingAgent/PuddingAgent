# 2026-10-08 端口竞态扫描闭环

| 站点 | 判定 |
|---|---|
| `DesktopReverseProxyIntegrationTests`（代理 + 上游两处） | ✅ **已修**（换端口重试 ≤5 次） |
| **`DesktopBootstrapHttpEndpoint.Start`** | ⛔ **不改** —— 端口由**调用方传入**（对外契约）+ 已**刻意 fail-soft**（记日志并保持 Desktop 运行） |
| `HarnessAgent.Core.Tests`（Feishu） | ⏸ 仅记录（不在链内 + 他方子系统） |

## 判据（为什么"未守卫"≠"遗漏"）

**"没有重试"与"刻意不重试"必须靠读代码区分**：这里注释明确写了 *Port in use / URL ACL missing / http.sys failure: log it and keep Desktop running* ⇒ **产品选择的是 fail-soft，而非抢占另一个端口** —— 换端口反而会**破坏调用方已构造的 URL**。

## 诚实边界

- 结论基于**静态读实**；**未真机验证**该 fail-soft 路径。
