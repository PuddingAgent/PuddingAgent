# R4 ⑥ 完整蓝图（收口版）

| 环节 | 做法 |
|---|---|
| **签发** | `sessionResolver()`（**无会话 ⇒ 拒绝带理由**，fail-closed）⇒ `DesktopBrowserBindingProducer` ⇒ `IssueAsync(BrowserTaskBinding(caller, target, scope, validity, source), OperationId, null, ct)` ⇒ `Issued` ⇒ `(id, scope, expiresAt)`；否则**带理由拒绝（不抛）** |
| **撤销** | Producer **无** `RevokeAsync` ⇒ 走能力：`DesktopCapability.BrowserBindingRevoke`（`Capabilities.cs:58`）+ `BrowserBindingRevokeRequest(Task, Target)`（`BrowserControlPlaneRequests.cs:7`）经 `CapabilityRequest.BindingRevoke`（`CapabilityUnions.cs:29/105/113`）发送 |
| **注册** | 与既有门同形 · **仅启用委派时注册**，否则 `null`（**行为与今天一致**） |
| **验收** | `PuddingHost.Tests`（不需 WinUI）：无会话 / 未知 scope / 未签发 ⇒ **拒绝 + 理由**；成功 ⇒ id + 到期；撤销 ⇒ 发出 `BrowserBindingRevoke` 且**保留父任务与真实子 run**（呼应 `BrowserOperationIdentityTests.ChildBindingMustPreserveParentRunOnApplyAndRevoke`） |

**实现顺序**：端口类 + Host 测试（假 `DesktopSession`）→ 仅启用时注册 → 跑 `PuddingHost.Tests` + `PuddingPlatformTests`（均不需 WinUI）
