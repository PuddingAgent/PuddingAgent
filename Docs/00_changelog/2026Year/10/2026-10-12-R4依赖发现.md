# R4 设计发现：依赖方向约束

| 事实 | 证据 |
|---|---|
| `SubAgentSpawnRequest` 位置 | `Source/PuddingCore/Abstractions/ISubAgentManager.cs:108` |
| Core 的 ProjectReference | **仅** `PuddingDiagnostics`（**不含** `Pudding.Contracts`） |
| 后果 | 直接把 `DesktopPageTarget`/`BrowserPageGrantScope` 放进去 ⇒ **Core → Contracts 反向依赖** |

## 三个方案

| 方案 | 说明 |
|---|---|
| **(a) 标量过桥**（倾向） | Core 只带 `string?`（contextId/pageId/scopeName）；**Runtime** 解析成强类型；未知线名**明确拒绝** |
| (b) 极窄契约程序集 | 只放两个类型，Core/Runtime 都可引用；新增程序集需按组件交付规程登记 |
| (c) 不经 SpawnRequest | 由 Runtime 在自己的执行上下文里挂委派意图 |

## 诚实边界

- 本轮**未改代码**（避免误翻层次）；**未真机验证**；R4 接线未完成。
