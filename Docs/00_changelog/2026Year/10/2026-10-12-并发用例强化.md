# Bridge 并发用例：空验证 → **恰好一次**

## 问题（README L44 的口径未被满足）

| 项 | 内容 |
|---|---|
| README 要求 | "升级为 **A 已授权、B 未授权** 的 fixture，明确断言**首次成功**、**相同 A/operationId 并发执行恰好 1 次**" |
| 原实现 | `ConcurrentDuplicatesMustNotExecuteTwice` 用**无授权**夹具 ⇒ 命令在触碰 handler 前被拒 ⇒ `Count` **恒为 0** |
| 原断言 | `Assert.True(handler.Count <= 1)` ⇒ **空验证**（既非"恰好一次"，也没走到并发路径）✗ |

## 修法（**强化**，非放宽）

1. `GrantAgentPage(lifecycle)` ⇒ **A 已授权**；
2. 并发派发同一 `operationId`；
3. `Assert.All(results, r => r.Success)` ⇒ **首次（及后来者）都必须成功**（防"一律拒绝"）；
4. **`Assert.Equal(1, handler.Count)`** ⇒ **恰好一次**（不是 0，也不是 2）。

用例**通过** ⇒ 产品行为**确实满足** README 要求（授权后并发恰好一次且都成功）✓ · `PuddingDesktop.Tests` **334/334** ✓
