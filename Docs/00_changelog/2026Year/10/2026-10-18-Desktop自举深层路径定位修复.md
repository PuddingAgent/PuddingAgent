# 2026-10-18 Desktop自举深层路径定位修复

## 根因与改动

实际 Desktop 运行在 `temp/build/winui3/bin/PuddingDesktop/Debug/net10.0-windows10.0.19041.0/win-x64`。
旧实现只检查八个目录，漏掉下一个祖先即仓库根，回退为 EXE 目录。控制面最新部署回执显示：
MSB1009、buildExitCode=1、assembliesReloaded=false、coreRestarted=true；这是失败后重启旧 Core。

- `Source/PuddingDesktop.WpfArchive/Bootstrap/DesktopBootstrapSignalParser.cs`：沿父目录探测到卷根，支持 `.git` 文件；显式覆盖和无仓库回退不变。该无 UI 源文件由 WinUI 链接编译。
- `Tests/PuddingDesktop.Tests/Bootstrap/DesktopBootstrapRepositoryRootTests.cs`：覆盖真实深度、工作树标记、显式覆盖和打包回退。
- 更新 Archive 子项目代码地图与桌面启动诊断分册。

## 验证与未完成

使用 `--artifacts-path temp/build/recovery`，仓库根解析与 HTTP 请求解析测试合计 13/13 通过。
本条记录时 WinUI 构建及外部切换尚未执行，不能据此宣称运行进程已加载本修复。
不读取 LLM 凭据、不修改业务数据库。回滚为撤销本次源码提交并重新构建 Shell。
