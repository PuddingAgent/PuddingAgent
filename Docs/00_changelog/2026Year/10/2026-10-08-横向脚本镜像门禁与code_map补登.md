# 2026-10-08 横向：外部脚本↔代码镜像门禁 + 组件 code_map 补登

## 目标 / 背景

第 76 轮我在 changelog 里**登记了一个风险**：外部验收脚本里的观察项编号是 `BrowserSmokePlan` 的**镜像**
（跨语言无法共享常量），**当时没有任何门禁**。横向收尾时应该把登记过的风险变成门禁，而不是让它一直挂着。

另外按 `Agents.md` 的强制要求，本轮补登本会话新增的关键文件到子项目 `code_map.md`。

## 改动

| 改动 | 内容 |
|---|---|
| **镜像门禁**（`BrowserSmokePlanTests`） | 读 `TestScripts/external-acceptance.ps1`，提取 `Id = "S-xx"` 并与 `BrowserSmokePlan.Checks` 的编号**集合相等**断言；同时断言生命周期四步都出现在脚本里（脚本据此写骨架）。脚本与代码任一侧增删观察项都会立即变红 |
| `Source/PuddingBrowser.Automation/code_map.md` | 补登 `ArrivalScroll.cs`、`SubAgentDelegation.cs`、`SubAgentDelegationLeases.cs`、`FileUploadPlan.cs`；并更正 `NativeInputSequence.cs` 的描述（补上 `PlanDrag` 的"分步 + 按下必抬起"要点） |
| `Source/PuddingBrowser.AgentTools/code_map.md` | 补登 `BrowserDelegationTasks.cs`；并更正 `BrowserWaitForTool.cs` 的描述（补上 `content_grows_above_nodes` 这一条件与"超时是正常结果"） |

## 验证

| 项 | 结果 |
|---|---|
| `Pudding.DesktopServiceTests` | **303 / 303**（＋1：镜像门禁） |
| **取红实测** | 把脚本里的 `S-11` 改成 `S-12`（＝脚本漂移）⇒ `TheExternalScriptMirrorsThePlan` **恰好变红**；复原后 303/303 复绿 |
| code_map 覆盖 | 五个新增文件现在都在对应子项目索引里（逐一断言存在） |
| 文档门禁 | `check_md_links --all-repo` 在本次改动的两个 code_map 上**零失效目标**（全仓库剩余 1 条为既有的 `Docs/16_qa/Review.md`，非本次改动） |

## 已知边界（诚实登记）

- **镜像门禁只覆盖编号与生命周期步骤**：脚本里的"区域"文字（`Area = "..."`）与门禁号（`Gate`）没有与代码逐一比对；
  新增观察项时仍需人工对齐这两列（风险从"完全没有门禁"降为"部分门禁"）。
- **没有全仓库 code_map 一键核验**：只核验了本会话涉及的子项目；其它子项目是否漏登不在本轮范围。
- **本轮无功能改动**：门禁与文档，不改变任何运行行为。

## 影响与回滚

- **无行为变化**；新增一条测试与两处文档。
- 回滚：删除镜像门禁用例、还原两处 code_map 描述。
