# 2026-10-22 摘要恢复与诊断现场

## 改动

- `Source/PuddingRuntime/Services/BoundedCompactionSummary.cs`：分离调用结果与摘要验收结果，截断/超额从完整源精简重生成及有界拆分归并；部分输出永不提交。
- `AgentExecutionService.cs`：生成额度与最终容量分离，逐次调用/结果和终态贯通 compactionId；失败报告给出具体原因、用量和现场文件路径。
- 新增 `Services/Diagnostics/CompactionDiagnosticJournal.cs` 及对应测试：有大小/数量/时间上限的本地脱敏记录；保存计划、发送前请求、响应和提交结果，写入失败不影响执行。
- `Source/PuddingCore/Models/TokenUsageDto.cs`、`Core/ResponsesLlmGateway.cs`：保留 provider 推理 token 用量；`DirectLlmClient.cs` 记录真实结束原因和生效配置。
- 更新根/Runtime/Core 代码地图、诊断手册及[生产归因报告](../../../14_reports/2026-10-22-摘要截断归因与压缩现场记录.md)。

## 验证

- 独立摘要/记录器 13/13，通过后接入 Runtime/DI。
- Runtime 定向回归 228/228，通过；包括真实 Responses 请求序列化与截断恢复、百万字节历史落盘诊断、失败回滚和重启水合。
- Core Responses/TokenUsage 定向测试 52/52，通过（相关回归合计 280 项）。
- Front Matter 全量 1725 文件零不合规；链接检查仍有隔离工作树已知的 48 处历史失效目标，本次改动文档无新增失效，锚点零失败。
