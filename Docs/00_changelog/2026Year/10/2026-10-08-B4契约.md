# 2026-10-08 B4 契约

| 类型 | 要点 |
|---|---|
| `DesktopScreenshotScope` + `DesktopScreenshotScopeWire` | `viewport`/`region`/`element`，线名真源 + `TryParse` |
| `DesktopScreenshotDetail` + `DesktopScreenshotDetailWire` | `low`/`high`/`original` |
| `BrowserScreenshotRequest` | 钉版本；scope 与参数**一一对应**（视口不带定位/矩形、元素必须定位、区域必须四值且为正）；格式小写化 |
| `DesktopScreenshotMetadata` | 观察 id + MIME + 字节 + 源/输出尺寸 + 设备缩放 + 视口 + 滚动 + 裁剪 + `PageVersion/DomRevision/ViewportRevision` + 细节档；`Validate()` |
| `DesktopScreenshotChunk` / `BrowserScreenshotResult` | 分块 + 结果（观察 id 随结果回传）；`Validate()` |

## 过程记录

首版我又把校验块写成 `public BrowserScreenshotResult { … }`（位置记录里非法，`CS1001/CS1014`）——与 round-357 的 `BrowserObservation` 同一错误；改为 `Validate()` 方法后通过。**规则**：位置记录**不能**写构造块，校验一律放 `Validate()`/工厂方法。
