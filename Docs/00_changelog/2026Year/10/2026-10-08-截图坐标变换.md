# 2026-10-08 截图坐标变换（纯函数）

| 用例 | 判据 |
|---|---|
| 无缩放/裁剪 | 坐标不变 |
| 2 倍缩放 | 图像 200px ⇒ CSS 100px |
| 裁剪原点 + 缩放 | `(50,30)`、origin `(100,50)`、zoom 2 ⇒ `(125,65)` |
| 越界点 | `ArgumentOutOfRangeException`（不夹取） |
| `zoom = 0` | `ArgumentOutOfRangeException` |

## 为什么放在 `PuddingBrowser.Automation`

它与计划器同处（同为"驱动侧的纯计算"），因此测试可直接放在该组件自己的测试工程 —— 避开 round-358 撞上的 **S2 守卫**（组件测试工程只能引用被测组件）。

|---|---|

| `PuddingBrowser.AutomationTests`（**TRX 判定**） | 见运行输出 |
