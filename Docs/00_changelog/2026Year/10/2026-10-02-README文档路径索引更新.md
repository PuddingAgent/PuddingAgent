# 2026-10-02 更新 README / README_zh-CN 的文档路径索引

## 目标 / 背景

Docs 结构整治（一级目录改 `NN_english_snake`、根文件归位、子仓库迁至 `external/references/`）之后，
两份根 README 的「设计文档 / Design documents」小节只剩 5–6 条十几年前期的选摘链接，
既不指向新的文档地图（`Docs/README.md`），也没有架构总览、调试手册、规程、日志规则与代码地图等入口。
用户要求更新其中的文档路径索引。

## 改动

`README.md`（`## Design documents` → `## Documentation`）与 `README_zh-CN.md`（`## 设计文档` → `## 文档`）：

- 新增**文档地图入口**说明，并把索引改为表格式路径索引，覆盖 9 个权威入口：
  `Docs/README.md`（文档地图）、`Docs/07_architecture/架构.md`（架构总览）、
  `Docs/07_architecture/README.md`（分册与 ADR 全表）、`Docs/08_how_debuge/README.md`（调试诊断手册）、
  `Docs/10_conventions/组件化交付规程.md`（组件化交付门禁）、
  `Docs/10_conventions/Agents-Hygiene.md`（仓库卫生完整规范）、
  `Docs/00_changelog/README.md`（修改日志规则）、`code_map.md`（代码地图）、`Agents.md`（仓库规则）。
- 原「选定设计文档」5 条链接**逐字保留**（仅加小节引导语）；中文版**补齐**此前缺失的「致谢 / Acknowledgments」链接。
- 两份文件互相对称：链接目标集合与顺序完全一致（各 16 条），仅标签语言不同。

## 验证

- `temp/check_readme_docs.py`：两份 README 的全部仓库内引用（18 条/份）**均存在**，无 MISS。
- 对称性检查：`README.md` 与 `README_zh-CN.md` 的链接目标集合相同、顺序一致。
- `git diff --numstat`：`README.md` +17/−1、`README_zh-CN.md` +18/−1，唯一删除行是旧小节标题，
  原有设计文档链接未被删除或重复。
- `python Tools/Docs/check_md_links.py --all-repo` → 743 个 md，失效锚点 0，失效目标 25
  （与改动前一致，均为既有残留：已删除的历史 QA 文件、被移出的 memory/plans、`…` 伪链接）。
- **未验证**：未运行 .NET 构建/测试（纯文档改动）。
