# 2026-10-08 Bridge 截图处理器

| 分支 | 结果 |
|---|---|
| 无执行器 | `BrowserOperationNotSupported`（明确、不静默） |
| 页面不存在 | `BrowserPageNotFound` |
| 未钉版本 | `BrowserInvalidCommand` |
| scope/detail 未登记 | `BrowserInvalidCommand` |
| 身份不合法 | `BrowserUnauthorized`（原因原样上报） |
| 执行失败 | `BrowserOperationFailed` |
| 成功 | `BrowserScreenshotDescriptor`（含 `ObservationId` 与 Base64 分块） |

**关键设计**：走**同一个 `IDesktopCapabilityExecutor`**（`DesktopService`）⇒ 与能力通道**同一准入、同一闸门、同一预算**；桥侧**不自采**（不碰 `Page.captureScreenshot`），观察登记由表面完成。
