# 2026-10-08 ③ 绿路用例

| 环节 | 值 |
|---|---|
| 假页 CDP | `Page.getLayoutMetrics` ⇒ 固定视口/内容尺寸；`Runtime.evaluate` ⇒ 计数 `3` |
| 登记观察 | `PageVersion 7` / `DomRevision 3` / `ViewportRevision` = 布局指标指纹；**裁剪 0/0/1280/720**；输出 512×288（符合 `detail=Low` 最长边 ≤512） |
| 交互 | `PointerClick` + `observationId: "obs-1"` |
| 结果 | **成功**（坐标经 `TryToCssViewport` 变换后送达页面） |

## 契约发现（重要，写给 ②）

**`TryToCssViewport` 要求完整裁剪几何**：`CropX/CropY/CropWidth/CropHeight` 全为 `null` ⇒ 判 `InvalidObservationGeometry` 拒绝（我第一版就是这样，两轮才定位）。⇒ **② 登记观察时必须写入裁剪信息**，视口截图用 `0/0/视口宽/视口高`；**不得**因为"没有裁剪"就留空。
