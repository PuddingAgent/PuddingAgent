# 2026-10-08 带 observationId 的坐标请求明确拒绝

## 为什么

§8.2 要求：**截图来源**的坐标须带 `observationId`，由驱动用**精确变换**转换，且**滚动/缩放/布局/页面世代变化后失效**。
现状（本轮读码）：`ObservationId` 沿途贯通（契约/proto/解码），但**全仓没有观察登记处**、**没有消费者** ⇒ 传进来的 id 会被**静默忽略**并按原始像素硬点。

**静默忽略比拒绝更危险**：调用方以为自己给的是"截图上的坐标、已被正确变换"，实际点在了新视口的同一像素上（滚动后通常完全错位）。

## 改动（`BrowserRuntimeDesktopSurface.InteractAsync`，L704 处）

```csharp
if (request.ObservationId is { Length: > 0 })
{
    return CapabilityResult<DesktopInteractionResult>.Failure(
        DesktopCapabilityError.InvalidRequest(
            "screenshot-derived coordinates require a live observation; none is registered yet"));
}
```

不带 id 的裸坐标**照常允许**（§8.2：坐标统一为 CSS viewport 像素）。
