# 2026-10-08 坐标可选能力接口

## 交付

`Source/PuddingBrowser.Abstractions/IPointerInputPage.cs`（新）

```csharp
public enum PointerInputKind { Click, Move, Drag }
public readonly record struct PointerInput(PointerInputKind Kind, double X, double Y,
    double ToX = 0, double ToY = 0, int ClickCount = 1, int Steps = 8);
public interface IPointerInputPage
{
    Task PointerAsync(PointerInput input, CancellationToken cancellationToken);
}
```

## 设计理由（为什么不是往 `IBrowserPage` 加方法）

加进主接口 ⇒ **全部实现 + ≈7 处假页**都要同步（编译期强制，一轮塞不下）；而坐标输入在**浏览器桥（待接）与假页**上本就**不可用**。
可选接口让"不支持"变成**显式负面路径**（表面 `is IPointerInputPage` 失败 ⇒ 返回 `UnsupportedCapability`，**绝不假装支持**），且替身**零改动**。

## 诚实边界

- **尚无实现方**：`WebView2BrowserPage`（用 `Policy.PlanPointer*` + `SendCdpAsync`）与 `RemoteBrowserPage`（Bridge 转发）都未实现 ⇒ **坐标仍不可端到端使用**；
- 表面分支（`is IPointerInputPage` ⇒ 调用，否则 unsupported）未接；`SupportsNativeInput`（第四张表）仍**最后**加；
- 本轮**无用例**（接口无行为可测）；**未跑全量链**；**未真机验证**。
