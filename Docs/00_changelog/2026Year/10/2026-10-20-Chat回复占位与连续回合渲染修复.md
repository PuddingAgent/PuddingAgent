# 2026-10-20 Chat 回复占位与连续回合渲染修复

## 背景与定位

用户连续截图显示：运行中无助手卡片，刷新不恢复；正文到达后卡片才出现；发送下一条消息时上一条回复又消失。
只读检查当前会话的 conversation、conversation-open 与有界事件尾部：服务端有活动工具过程，
已完成回复也按正确顺序保存在历史中。问题集中在客户端消息投影和快照交接。

## 改动

- `Source/PuddingPlatformAdmin/src/pages/chat/types.ts`、`components/MessageList.tsx`（后者位于同一 `src/pages/chat/` 目录）：
  用 `assistant.isPlaceholder` 区分用户行空占位与真实助手终态；占位接受活动状态，真实终态仍防回退，
  完成快照关闭流式状态。
- `Source/PuddingPlatformAdmin/src/pages/chat/client/chatClientStore.ts`：活动事件绑定 canonical Turn，
  拒绝旧 started 重开；完成事件用 messageId、reply、occurredAt 物化回复，下一轮切换不删除上一轮正文；
  迟到的上一轮完成事件不结束下一轮；后台快照先发布再写 IndexedDB，避免覆盖写缓存期间收到的事件。
- `Source/PuddingPlatformAdmin/src/pages/chat/components/messageTurnMerge.test.ts`、
  `Source/PuddingPlatformAdmin/src/pages/chat/client/chatClientStore.test.ts`：增加刷新、空正文工具过程、
  真实终态、连续回合顺序、重复事件和异步缓存竞争的行为回归。
- `Source/PuddingPlatformAdmin/package.json`：版本 `6.9.14 → 6.9.15`。
- 根及前端 `code_map.md`、[平台与会话诊断手册](../../../08_how_debuge/12-案例-平台与会话.md)：维护当前语义和排查入口。
