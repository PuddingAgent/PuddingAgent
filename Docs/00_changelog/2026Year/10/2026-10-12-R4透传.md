# R4：透传生效 + CS1061 根因

| 项 | 内容 |
|---|---|
| 改动 | 单任务路径透传三个标量委派值到 `SubAgentSpawnRequest` |
| **上次 CS1061 根因** | **不是**类型解析 —— 是 `--no-restore` + **混用 artifacts 路径**导致 Runtime 复用**陈旧 Core 输出** |
| 修法 | 构建**不加** `--no-restore`（或统一 artifacts 路径） |
| 验证 | `PuddingRuntime` **已成功生成** ✓（且用**带守卫**构建：红则自动回退） |

## 流程改进（本轮新增）

**构建守卫**：把"若仍失败则 `git checkout --` 回退并复跑构建"写进同一条命令 ⇒ **结构上不可能留下红构建**。
