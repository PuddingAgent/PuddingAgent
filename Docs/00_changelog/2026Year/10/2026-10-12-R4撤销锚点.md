# R4 ②-b：撤销的统一锚点

| 结束路径 | 锚点 |
|---|---|
| 成功 | `_runIdMap.TryRemove` **L188** |
| 异常 | **L276**（终态 L278） |
| 取消 | **L474**（终态 L476） |
| 启动失败 | `CreateTrackedRunAsync` **L1053** |
| （另）纯移除 | L381 / L444 |

**方案**：`RevokeBrowserDelegationAsync(runId)` 在**上述各处成功分支**各调一次 ⇒ 覆盖**成功/异常/取消/超时/父终止**。

**为什么一次落全**：漏一站 ⇒ **授权泄漏**（子运行结束后仍持页面权限）—— 正是复核拒收的缺陷类别。

## 诚实边界

- 本轮**只定位、未改代码**；R4 端到端仍未成立；**未真机验证**。
