# 2026-10-08 控制面端到端用例

## 覆盖

| 用例 | 判据 |
|---|---|
| 申请（页=用户选定） | ack `Accepted` **且 `GrantId` 非空**；`ActiveGrants` 恰 1 条 |
| 申请（页**未**被用户选定） | ack `Accepted=false`；原因含 `not the page the user currently selected`；无授权 |
| 撤销 | ack `Accepted`；授权清空；**再撤幂等**且原因含 `no binding is active` |

装配是**真实对象**：`BrowserPageLifecycle.Create` → `BrowserGrantIssuer` → `BrowserTaskBindingService` → `DesktopService`（含 `() => Generation` 与 `ExecuteAsync` 的真实分支），不是替身；因此同时验证了"控制面能力在 Desktop 侧被准入"（`AllowedCapabilities` 与 `BrowserContextCallerTrust` 都要对）。

## 验证

| 项 | 结果 |
|---|---|
| 定向（**TRX 判定**） | **3 / 3** ✅ |
| 全量链 | **未跑** |

## 诚实边界

- **仍无生产装配**：组合根尚未构造/注入 `BrowserTaskBindingService`，也未注入连接世代、未开闸门 ⇒ 真实产品路径上控制面**明确拒绝**（fail-closed）。
- **解码 → 服务**这一段仍未在测试里串起来：本用例从 `DesktopCapabilityRequest` 起（即解码之后），`Mapping.Decode` 的控制面分支**尚无用例**。
