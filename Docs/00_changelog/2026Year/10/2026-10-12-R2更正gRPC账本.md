# R2 更正：gRPC 侧已由 `OperationRegistry` 实现

| 位置 | 已有语义 |
|---|---|
| `OperationRegistry.TryBegin(id, fingerprint, …)` L91 | 原子登记 |
| L106 / L110 | 同指纹 ⇒ **InProgress**（等待）；不同 ⇒ **ConflictingPayload** |
| `DesktopConnection` L447/480/510（L462/495/538） | 三处调用 + 冲突分支 |
| 指纹 | `decodedCommand.Fingerprint` ⇒ **R2 修好后含调用者与完整载荷** |

**⇒ 决定：不在 `DesktopService` 重复接线**（那会造出**更弱的第二份判据**：该层拿不到完整 typed payload）。

**剩余可选**：把两种实现统一到同一个账本类型（架构收敛，非缺陷）。

## 诚实边界

- 结论基于**静态读实 + 既有 108 条连接层测试通过**；**未真机验证**。
