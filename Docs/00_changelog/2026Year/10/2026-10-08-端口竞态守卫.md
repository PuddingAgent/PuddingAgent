# 2026-10-08 端口竞态守卫

| 项 | 内容 |
|---|---|
| 现象 | 链第 3 次迭代：1/328 失败，`HttpListenerException: 拒绝访问` |
| 根因 | `GetFreeLoopbackPort()`（取端口即释放）与 `HttpListener.Start()`（真正绑定）之间的**竞态** |
| 修法 | `StartProxy` 内**换端口重试 ≤5 次**（环境错误才重试；**不放宽任何断言**） |
| 证据 | `PuddingDesktop.Tests` **3 次连跑 328/328、0 失败** |

## 为什么值得修

它会让外部 **20× 门禁失败**（正是 20× 的意义）；且这是**环境型**问题，不该由断言让步来"解决"。

## 诚实边界

- **未再跑"整链 ×3"**（本轮只跑了该套件 ×3）；**未真机验证**。
