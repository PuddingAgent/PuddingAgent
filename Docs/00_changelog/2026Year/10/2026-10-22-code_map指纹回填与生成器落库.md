| 指标 | 改造前 | 改造后 |
|---|---|---|
| `error` | 48 | **0** |
| `gate` | FAIL | **PASS** |
| `missing-fingerprint` | 44 | **0** |
| `stale-fingerprint` | 3 | **0** |
| `fingerprint_check` | — | `declared_files=48 globs=148 verified=148 mismatched=0 unverifiable=0` |

改动面（`git diff --numstat -- '*code_map.md'`，共 **46** 份）：`41 × (+1/-0)`、`3 × (+2/-0)`、`2 × (+1/-1)`。
两份 `+1/-1` 是**就地改值**而非丢内容：`Source/PuddingRuntime/code_map.md` 与根 `code_map.md` 的指纹值陈旧，替换为实测值（diff 只有那一行）。

## 做法（为什么不是手写哈希）

- **唯一指纹真源** = `Tools/Docs/code_map_check.py`。生成器 `import code_map_check` 复用 `glob_fingerprint` / `list_scope_files` / `rel_posix`，**不另写算法** —— 手写哈希就是伪造。
- 每个候选 glob 都过一道**文件数守恒校验**：`glob_fingerprint` 把 `bases = [base_dir, root]` 两轮结果并集，组件相对写法会在仓库根二次命中（`**/*.cs` 在每个组件都会算出同一个 3379 文件摘要）⇒ 只接受「实测量 == 组件内应有量」的 glob，被污染者自动升级为根相对写法重试。这道校验同时充当 gitignore 探测器：容器里混进被忽略的构建/运行时产物就会被拒，于是自动退到更细的粒度。
- 取值优先级：**A** 组件相对细分（一级子目录 `<sub>/**` + 顶层未忽略散文件按扩展名）→ **C** 仓库根相对整组件单 glob → **D** 顶层 `*` + 子目录按文件数降序塞进行宽预算，未纳入项用紧随其后的 `> 指纹覆盖:` 行**明示**（不假装全量）。
- 只补 `declared_fingerprint` 为空的文件，已声明的文件不覆盖；写盘保留原 EOL 与 BOM。

## 工具落库

生成器原本写在 `temp/`（该目录被 gitignore，等于**一次性脚本**）。本轮把它落库为 **`Tools/Docs/code_map_fingerprint.py`**，与被复用的 `code_map_check.py` 同目录，`ROOT` 由 `__file__` 推导，`TODAY` 取运行日而非硬编码。

## 顺手修掉的两个真实缺陷（生成器自身）

1. **BOM 下认不出 H1**：原实现用 `line.startswith('# ')` 定位 H1，文件带 UTF-8 BOM 时首行是 `\ufeff# ...`，匹配失败 ⇒ 插入点退回 0，指纹块被插到 BOM **前面**，BOM 被挤到第二行。现在先剥 BOM 再定位，写回时原样补回。
2. **双空行**：原实现判据写反（`if 下一行是空行: 再补一个空行`），H1 后本来就有空行时会叠出两个。现在只在**下一行非空**时补。

验证方式：对 `insert_lines` 做 fixture 断言（临时文件、逐字节比对），5 条用例全 PASS：

| 用例 | 断言 |
|---|---|
| `crlf-plain` | CRLF 输入 CRLF 输出，块紧跟 H1，不产生双空行 |
| `crlf-bom` | BOM 仍在文件头，块在 H1 之后 |
| `front-matter` | 有 YAML front matter 时块插在闭合 `---` 之后（与生成器分支一致），单空行分隔 |
| `no-blank-after-h1` | 仅此时补一个空行 |
| `multi-line-block` | D 阶段「指纹 + 覆盖」两行一起插入，行序正确 |

## 取红证据（能失败的校验才算校验）

新增 `Tools/Docs/code_map_fingerprint.py` 后，根表的 `Tools/**` **立刻**报陈旧：
`declared=ae9f98fc11a7 → computed=7ab6ae6b984b`（文件数 26→27），`stale-fingerprint` 从 0 变 1。
⇒ 指纹机制是**真的会取红**的，不是"永远绿"。随后按实测值更新该 token（等长替换，字节数 42976 不变），复跑转绿。
