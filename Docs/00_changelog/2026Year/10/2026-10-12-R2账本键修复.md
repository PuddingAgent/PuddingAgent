# R2 缺陷修复：账本键的命名空间

## 缺陷

| 位置 | 内容 |
|---|---|
| `BrowserOperationLedger.cs:19–26` | 键 = **进程实例 + 连接世代 + operationId**；"**世代进键 ⇒ 重连后的同 ID 落在新命名空间，不会被旧世代记录误判为重复**" |
| `BrowserBridgeCommandDispatcher.cs:78–79`（注释） | 同样宣称"(进程实例, 连接世代, operationId)" |
| **实现（原 L80）** | **`new BrowserOperationLedgerKey("bridge", 0, …)`** ⇒ **两项都是常量** ✗ |

⇒ **重连后同一 operationId 仍落同一命名空间** ⇒ 被旧世代的已完成记录判为重复并复用（`ReplayCompleted`）⇒ **跨身份/跨世代复用 = 复核 P1 类别** ✗

## 修法（三处，含 Shell 边界）

1. `BrowserAutomationAuthority` 增 **`ProcessInstanceId`**（Contracts 类型）；
2. `BrowserPageLifecycle` 增 **Shell 安全** `LedgerNamespace`（**只返回标量**，不暴露 authority 类型 ⇒ 避免 CS0012）；
3. 派发器改用 **真实** `ns.ProcessInstance` / `ns.Generation`（注释写明"**不得用常量**"）。

## 用例

`BrowserLedgerNamespaceTests`：命名空间携带进程实例 · **随 `NotifyConnectionGeneration(7)` 变化**（`Generation == 7`、与初始不同）· 进程实例**不因重连改变** ✓

## 验证

`DesktopService` 编译 ✓ · **`WpfArchive`（Shell 编译面）编译 ✓ 无 CS0012** · **`DesktopServiceTests` 397/397** · **`Desktop.Tests` 332/332**（均不需 WinUI）

## 诚实边界

- 修的是**键的命名空间来源**；派发器层**跨世代行为**的端到端验证属**集成/真机**阶段。
