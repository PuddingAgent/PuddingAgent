# 2026-11-05 Agent 配置公共 API 核心与施工任务书

## 改动

- 新增 `Source/Pudding.Api.Contracts/`、`PuddingAgentConfiguration.Contracts/`、`PuddingAgentConfiguration/`、`Pudding.Api.Sdk/`：BCL 公共值合同、存储/授权端口、配置更新主流程及 SDK 门面/HTTP 适配。名称与描述支持遗漏/设置/清空，提供 CAS、按调用者幂等、分页变更记录、严格 wire 字段与 unknown 回执。
- 新增两个独立测试项目和 `Tests/PuddingAgentConfiguration.IntegrationTests/`；先完成 S1–S4，再登记 `PuddingAgentNetwork.slnx`、Platform 引用及 Host DI。
- `Source/PuddingPlatform/Services/WorkspaceAgentFileService.Configuration.cs` 实现原子存储端口，复用现有 writer 和锁；配置、回执、变更事实同次原子写入 manifest。`Source/PuddingCore/Configuration/PuddingConfigModels.cs` 新增不透明 `ConfigurationControl`，既有 record-copy writer 保留它。
- 新增 `AgentConfigurationApiFactory` 与 `AgentConfigurationApiController`；管理 JWT 绑定身份和单 Agent 范围。第三方 token/插件委托权限未开放。
- 维护根与相关项目 code_map；新增 [DeepSeek 施工任务书](../../../12_features/Agent配置API-P0P1-DeepSeek施工任务书-2026-11-05.md)、核心指纹清单及校验脚本。DS-01/02/03 分别为只读示例、分页扩展、wire 测试；未替用户派发任务。
- 修正旧文件注释与总规划中的模型配置归属误判：实际模型路由来自实例 manifest，模板只在创建时种子化。

## 边界与未完成

这是 P0/P1 的配置核心切片，不是整套 Agent/Goal/插件基础设施完成。没有创建/执行 Agent API，没有自动 Goal，没有新 Hook 控制面，没有插件跨进程 Agent 授权，没有更换模型或权限的通用 setter。

旧 PUT 保持整份更新语义；新接口与它共享 writer，旧写入会使此前读取的 revision 失效。变更流仅包含新版配置 API 的提交，不假装覆盖所有旧入口。配置源已应用不表示当前 Run 或前端已经刷新。日志满 1024 条时明确拒绝新命令，没有静默删除幂等历史；日志回收留后续设计。

没有部署或重启当前产品，没有读写生产数据、发送消息、commit 或 push。工作树中既有 Slack/工具插件改动保留。
