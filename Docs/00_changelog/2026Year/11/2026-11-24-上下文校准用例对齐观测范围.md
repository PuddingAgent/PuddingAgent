# 2026-11-24 上下文校准用例对齐观测范围

检查重复回复压缩修复时，提交门禁发现两条旧用例仍期待超过 4 倍的实测值能提高校准系数。两条用例均在更新前的 Core 程序集上复现。产品行为来源为 `8dc085a`。

- `Source/PuddingCoreTests/RequestAttributionIdentityTests.cs` 用可接受的 3 倍观测验证模型间的校准隔离。
- `Source/PuddingMemoryEngineTests/ContextCompactionServiceTests.cs` 保留服务商的 150,000 个输入 token 原始报数，验证健康视图如实展示，后续校准系数仍为 1。
- 相关路由归因与校准用例 13 项、压缩服务用例 23 项均通过。
