# 桌面启动探针与 WebView2 故障证据

`TestScripts/test-pudding-desktop-launcher.ps1` 接收绝对包路径和单独的证据根，在独立的生命周期测试数据中关闭 Guardian。Debug 截图经文件流交给 PNG 编码器。工作台初始化保留 WinUI 返回的内层异常，Debug 探针遇到终态失败立即报告。

Desktop 构建通过，真实 WinUI 外壳拉起独立 Core，已观察到 Core Ready 与启动面板 PNG。工作台控制器创建超时，外壳没有达到 WorkbenchReady；本轮未通过可视工作台、托盘和完整重启退出验收。默认渲染和禁用 GPU 的隔离对照均复现超时；仅对测试进程切换 WebView2 用户数据位置的对照返回 COM 初始化错误。现有证据无法确定机器侧根因。日志在 `.work/plugin-product/r1/launcher5.log` 及相应隔离 DesktopHome 的 `logs/desktop.log`。操作入口见[工作台诊断](../../../08_how_debuge/05-常见症状.md)。
