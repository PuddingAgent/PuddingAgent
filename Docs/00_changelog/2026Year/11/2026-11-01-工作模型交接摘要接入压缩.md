# 2026-11-01 工作模型交接摘要接入压缩

关联问题：用户反馈 compaction `warm-prefix:b443a885f1e741df8d454a8aacb01d5a:r1:cc6758395327461980786538cbaf5a44` 后仍占有效窗口 49.3%，希望压缩冗余对话与工具输出，同时让工作模型自己总结下一轮所需信息。本次交付第一阶段的交接摘要机制，不调整压缩目标比例。

## 改动

- 新增 `Source/PuddingContextHandoff/` BCL-only 组件及 `Source/PuddingContextHandoffTests/`：有界笔记、不可变版本、原子 latest、作用域隔离、宿主身份绑定。先独立通过 9 项测试，再加入解决方案、Runtime 引用和 Host 装配。
- `Source/PuddingRuntime/Tools/BuiltIns/Context/ContextHandoffTool.cs` 提供 `context_handoff` 的 save/read；正文上限 6000 UTF-8 字节，完整记录上限 7 KiB；保存只返回索引，读取适配 8 KiB 工具预算。中文不转为长 Unicode 转义序列，失败不改变原历史。
- `Source/PuddingRuntime/Services/AgentLoop/ContextHandoffHook.cs` 用冻结输入容量与已有用量快照建议主动总结；30 分钟冷却、有界提醒缓存，跳过协议/大载荷结果；不增加 LLM 或数据库调用。两处 DI 注册，流式执行补齐既有结果变换 Hook 的调用点。
- `WarmPrefixCompaction.cs`、`BoundedCompactionSummary.cs` 与 `AgentContextCompactionSummaryGenerator.cs` 共用保留规则：优先有效要求、纠正、未完成状态及下一步，已完成且可恢复的细节留下结论和索引。宿主固定注入 handoff 恢复入口，模型笔记不升级为用户授权或已验证证据。
- 更新根、Runtime、Host 与组件 code_map；设计和限制见[上下文交接摘要与压缩保真](../../../12_features/2026-11-01-上下文交接摘要与压缩保真.md)。

## 验证

- 独立组件最终测试：9/9 通过；覆盖并发、版本回读、取消/失败保留、作用域隔离、UTF-8 上限、损坏文件和程序集边界。组件行覆盖率 100%，分支覆盖率 86.84%。
- Runtime 合并定向回归：137/137 通过，包含全部 warm-prefix、分段摘要、应用预算、Agent 摘要、DI、Hook 和流式接线；其中 warm-prefix 单独回归 89/89。各组有重叠，不相加作为独立用例数。
- 最后收紧 JSON/读取预算后，交接摘要与流式定向回归 18/18 通过，包含最大中文笔记经真实 `ToolResultContextPolicy.MaterializeAsync` 后逐字完整的验证。
- `dotnet build Source/PuddingHost/PuddingHost.csproj --artifacts-path temp/build/context-handoff --nologo` 成功：0 错误，74 警告。测试在同一隔离 artifacts 路径 restore/build 后使用 `--no-restore`；输出不进入产品目录。
- 新增两份 Docs 文档按限定路径检查 Front Matter；全库检查扫描 1866 篇，已有 52 篇不合规。全库 Markdown 链接检查有 29 个失效目标、0 个失效锚点，均位于本次未修改文档；本次新增文档无失效链接。未扩大范围修复历史文档。

## 未完成与交付边界

状态：`ready-for-external-deploy`。未重启或部署正在运行的 Desktop/Core，未使用生产会话实测新的压缩后占用率。

模型自主保存是建议机制，不能保证每轮都会调用。实际信息保真率、至少 90% 的有界恢复问答门禁、多次压缩漂移、更大跨度的分层压缩及已外存正文的确定性降级尚未实现/验证；当前测试不构成这些结论。

临时产物清理受环境限制：已核实 `temp/build/context-handoff`、`temp/test-out/context-handoff`、`temp/test-out/context-handoff-leaf` 和 `Source/PuddingContextHandoffTests/TestResults` 均为仓库内普通目录，但自动审批仍拦截了删除操作，仅返回 `blocked by policy`。产物保留在 Git 忽略范围，未暂存或提交。
