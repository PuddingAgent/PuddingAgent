# PA-03 S5 完成事件 Outbox 分发器

- 新增 `ReviewEventDispatcher` + `IReviewCompletionSink`：按 occurred 顺序取未发布 `review_events`，交给产品 sink；**仅 sink 成功后标记 published**，失败保留给下一轮（至少一次，消费方按 EventId 去重）；批大小有界；不丢弃、不静默确认。
- 完善 outbox schema/实体：`review_events` 持久完整逻辑键（epoch/iteration/objective/acceptance/artifact/policy）与 `occurred_at_ms`（SQLite 可排序），保证 sink 拿到不丢版本的完成事实。
- 测试：`ReviewEventDispatcherTests` 4/4（真实 SQLite：发布并标记一次、失败重试、批量排序、已发布不再投递）。
- 未完成：产品 `IReviewCompletionSink` 实现（映射到 canonical/Goal 事件）、调度宿主注册、07A 07B 扩展点注册、PA-04 Goal 接入。
