# PA-04 Goal 完成评审门禁接入

把评审完成事实接入 Goal 完成裁决；未 commit、未部署、未调用真实模型。

## 1 门禁

- 新增 `GoalReviewCompletionGate`（`IGoalReviewCompletionGate`）：
  - 读取该 Goal 最新评审 Job；无 Job → `NotRequired`（未尝试评审的 Goal 保持原有证据规则）；
  - Job 的 `ObjectiveVersion` 与当前 capsule 不一致 → `Stale`；
  - Pending/Waiting/Running → `Pending`；Failed/Cancelled → `Unknown`；
  - Completed：`Satisfied + CheckVerified` → `Satisfied`；`NeedsWork` → `NeedsWork`；其余 → `NeedsUser`。
- `ConservativeGoalIterationVerifier` 注入可选门禁：在“全部必需条件通过”分支中，仅当评审为 `NotRequired/Satisfied` 才允许 Complete；否则降级为 `review_pending/review_needs_work/review_stale/review_not_satisfied` 的不可完成裁决（repair/等待，不关闭 Goal）。

## 2 测试与验证

- `ConservativeGoalIterationVerifierTests` 新增 4 条：评审 NeedsWork → 不完成；Satisfied → 完成；Pending → 不完成；无评审 Job → 保持原行为。
- 该测试类 **29/29**；Platform S5 切片 **144/144**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r24 exit 0（组件 274 + Platform 144 + 前端 47 + tsc）。
- 冻结基线：Host DI 文件属 P0/P1 清单，注册门禁属有意变更，已审阅重签指纹（配置 18/18 PASS）。
- 证据：`.work/pa04/goal-review-gate/`、`.work/verification/goal-gate-solution/`、`.work/pa08/components-20261106-r24/`。

## 3 未完成

- Goal **自动续跑**闭环仍取决于评审 Job 的自动提交与结算后 continuation 调度（现有 GoalContinuationWorker/GoalSettlementWorker 尚未显式消费评审事实）；本轮只锁定“不得凭证据跳过未满足评审而完成”。
- 插件/后台 Job 授权、流式/子代理预算、08B/08C（NotRun）保持原状。
