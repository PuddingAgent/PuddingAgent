# 2026-11-18 定时扫描串接时钟与原子写入

## 改动

- `Source/PuddingScheduling/ScheduleTickService.cs` 使用同一时点读取到期计划、计算补跑及提交事务，逐项返回计划、提交结果或异常。
- `Source/PuddingSchedulingTests/ScheduleTickServiceTests.cs` 用假时钟与真实 SQLite 验证到点触发、换连接后同一时点重扫、单项出错后的继续扫描及 RunOnce 重试。

## 验证

- 独立构建 0 警告、0 错误，MTP 真实执行 54/54。
- 在隔离副本分别偏移调度时钟和取消普通写入失败的隔离，两条对应行为用例各自取红。
