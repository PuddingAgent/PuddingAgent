# 插件工作区事件订阅与宿主激活身份

## 改了什么

- `Source/Pudding.ToolPlugins.Contracts/PluginContracts.cs`：新增 `PluginSubscriptionDefinition`、`PluginEvents` 白名单、`PluginWorkspaceEvent`、`PluginEventDelivery`；`PluginManifest.Subscriptions`；`PluginScope.ActivationKey`；`IToolPlugin.SubscriptionIds`/`OnWorkspaceEventAsync`。
- `Source/Pudding.ToolPlugins.Runtime/PluginValidation.cs`：贡献计数纳入订阅；订阅 Id 唯一、事件必须在白名单。
- `Source/Pudding.ToolPlugins.Runtime/PluginManager.cs`：`PluginAuthorization.SubscriptionsApproved`；零工具插件不再要求 ExecuteApproved；宿主作用域（ActivationKey）校验；初始化比对 `subscriptionIds`；新增 `PublishWorkspaceEventAsync`（按 Workspace/Agent/Session 过滤、逐激活投递、失败隔离、5 秒上限）。
- `Source/Pudding.ToolPlugins.Worker/Program.cs`：`initialize` 上报 `subscriptionIds`；新增 `event` 请求 kind。
- `Source/Pudding.ToolPlugins.Sdk/ToolPlugin.cs`：`SubscriptionIds` 与 `OnWorkspaceEventAsync` 默认实现。
- `Source/Pudding.ToolPlugins.RuntimeTests/PluginRuntimeTests.cs`、`AgentCallbackLifecycleTests.cs`：fake worker 上报订阅；新增合同/宿主作用域/事件投递用例。

## 验证

- `Pudding.ToolPlugins.RuntimeTests` 定向 `PluginRuntimeTests|AgentCallbackLifecycleTests`：**30/30**，0 跳过。
- 插件验收脚本 `TestScripts/test-pudding-tool-plugins.ps1`（TEMP/TMP 指向仓库内目录）：**全绿**（Runtime/真实 Worker/Host/SDK 样例），证据 `.work/plugins/20261108-205559`。
- 证据目录：`.work/plugin-events/20261108-freeze/`。
