# PA-03 S5 持久验收任务存储接入

- 新增 `Source/PuddingPlatform/Services/Reviews/`：
  - `ReviewJobStore`（`IReviewJobStore`）：逻辑键 + OperationId 幂等提交（同键复用、Operation 换内容冲突）；owner-epoch 租约认领 + expected revision（旧 worker 认领被拒）；完成/失败要求 Running 且同 owner/revision；取消仅限非终态；结论为评审任务结果，不写 Goal 终态。
  - `ReviewJobSchemaBootstrapper`：`review_jobs`/`review_job_operations` 幂等建表与索引；`Data/Entities/ReviewJobEntities.cs` + `PlatformDbContext` 两个 DbSet。
- Host 接入：DI 注册 `ReviewJobStore` 与 `IReviewJobStore`（同一 singleton），启动 schema 阶段调用 bootstrap；Host 构建 exit 0。
- 测试：`ReviewJobStoreTests` 8/8 通过（真实 SQLite：幂等提交、Operation 冲突、收件/查询、租约与 revision 围栏、完成结果持久化、失败目标校验、非终态取消、跨 DbContext 持久化）。
- 取红：忽略 Operation 冲突、允许旧 owner 认领、任意状态可完成 —— 均使对应测试变红（还原哈希已核对）。
- 冻结清单：Host DI/启动文件属配置 API P0/P1 清单，本次新增评审任务注册与 bootstrap（diff 已核对），按任务书 01 §5 由主代理审阅更新基线；三条冻结检查 3/3 PASS。
- 未完成：`IReviewEvidenceReader`/`IReviewExecutor` 适配、ReviewJob Worker、completed 事件 outbox（07A S5）、Goal 续跑接入、08A 面板挂载。
