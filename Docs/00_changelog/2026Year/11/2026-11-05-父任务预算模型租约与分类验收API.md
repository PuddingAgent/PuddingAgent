# 2026-11-05 父任务预算、模型租约与分类验收 API

## 改动

- 独立交付 `Source/PuddingExecutionResources.Contracts/`、`Source/PuddingExecutionResources/`、`Source/PuddingExecutionResourcesTests/`。祖先共享原子预留；实际、预留、未知用量分离；取消后不提前释放仍在运行的 provider。预留调用前返还与派发后未知、超量真实记账均有红灯判据。
- 独立交付 `Source/PuddingModelEvaluation/`、`Source/PuddingModelEvaluationTests/`。分类只返回已声明标签或弃权；证据评审逐项验证 ID 与 verdict 一致性；截断/非法回答降级，缺证据不能变成“通过”。两个组件先完成独立构建、测试与反向引用负向门禁，再修改宿主接入。
- `Source/Pudding.Api.Contracts/ModelEvaluation.cs`、`Source/Pudding.Api.Sdk/ModelEvaluationsClient.cs`、`Source/Pudding.ToolPlugins.AgentSdk/PluginModelEvaluations.cs` 提供类型化模型 API；调用方无需凭据、模型池或 HTTP 细节。Core API 1.3 仅允许三个具名模型能力，不开放任意模型或 work.submit。
- `Source/PuddingRuntime/Operators/PublicApi/` 新增冻结模型绑定与父资源租约工厂。复用主调用的 `ProviderRateLimiter`、现有网关与必须落账的 usage recorder，单次派发，无隐式重试。分时价格、全零价格、无明确路由均拒绝，不伪造免费调用。
- `ExecutionUsageBudgetTracker.cs` 持有 dispatch 父账；新模型调用预留额度与旧主调用/委派事后记账共用父账。`AgentExecutionService.Buffered.cs` / `Streaming.cs` → `ToolInvocationService.cs` → 插件传递 `[JsonIgnore]` 资源对象；补齐 Buffered CONTINUE 路径遗漏的模型快照。取消已发生时，账本初始化不抢在原主循环清理分支之前抛异常。
- 普通聊天也限制辅助模型为每 dispatch 8 次、8192 输出、并发 2；重建或重载插件不重置这份父账。输入仍为单请求容量，不累计消耗窗口。流式终态用量包含模型算子用量，保留上下文窗口元数据。
- 新增 `Tests/PuddingModelEvaluation.IntegrationTests/`、真实 Worker fixture、SDK 拒绝错误回执测试、父预算与工具调用边界测试。Host 组合根校验实际插件消费者拿到了模型工厂及共享资源池。解决方案和相关 code_map 已维护；接口与限制见[接入合同](../../../12_features/父任务预算与模型算子API-契约与接入-2026-11-05.md)。
