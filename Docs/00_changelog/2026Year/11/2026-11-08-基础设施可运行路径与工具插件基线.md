# 基础设施可运行路径与工具插件基线

[两阶段目标 §9](../../../12_features/基础设施服务生命周期与最小原型两阶段目标-2026-11-07.md) 增加当前运行命令、I1-06 与 A5/A6 并行施工范围、首个工作区插件演示和 B 放行后的组合验收。[T 矩阵](../../../14_reports/2026-11-08-CORE-I1-06-当前证据与T矩阵.md) 更正了 slice 9 之后的租约接入状态、可复用的文件过期测试和预留/派发间的持久化窗口。

工具插件脚本第一次使用默认 TEMP，Runtime 测试 25/29，4 项在测试包导入时报 I/O 错误，脚本按设计停止。仅将该次子进程的 TEMP/TMP 指向独立目录，再用新 RunId 从头运行，Runtime 29/29、真实 Worker 6/6、Host 循环等 6/6，SDK 样例构建通过。两次日志分别在 `.work/plugins/road-to-run-1794141286858/` 和 `.work/plugins/road-to-run-1794141286858-isolated/`。默认临时目录 I/O 错误的底层原因未定位。

预算部分核对 slice 9 的既有日志（Runtime 57/57、Platform 75/75）和发送、持久化源码。本轮验收范围为已有工具插件；工作区产物事件、I1-06 独立复核及 B 原型仍待实施或放行。
