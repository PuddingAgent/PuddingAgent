# PA-06 配置权威模型策略适配（manifest 读写）

把 06A/06B 的 purpose 策略落到既有 Agent manifest 权威上；未 commit、未部署、未调用真实模型。

## 1 适配

- `WorkspaceAgentFileService` 新增 partial 实现 `IAgentModelPolicyStore`：
  - 复用同一 `_writeLock` 与 `AtomicFileWriter`，只修改 manifest 的 `ModelPolicy` 子树；显示名/描述/配置 journal 等其他字段保持不变；
  - 读：加载 manifest → 校验 workspace 归属 → `AgentModelPolicyMapper.ToSnapshot`；
  - 写：经宿主授权实现校验 → CAS patch（`ModelPolicyPatchApplier`）→ 原子写；IO 失败返回 `model.unavailable`（未确认写入，需以相同操作/版本重试）。
- 新增 `IAgentModelPolicyAuthorization`（Host 提供 principal 映射）：**未注册或拒绝即 fail-closed**（`model.scope_forbidden`），不接受裸 ActorId，也不以 AgentId 冒充调用方。

## 2 测试与验证

- `WorkspaceAgentModelPolicyStoreTests` 3/3（真实临时 DataRoot + manifest 文件）：
  - 无授权实现：读/写均 `scope_forbidden`；
  - 授权：set/inherit/clear 往返、revision 递增、manifest 其他字段保留；
  - 过期 revision → `config_revision_conflict`。
- Platform S5 切片 **133/133**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r20 exit 0（组件 274 + Platform 133 + 前端 47 + tsc）。
- 证据：`.work/pa06/policy-store/`、`.work/verification/policy-store-solution/`、`.work/pa08/components-20261106-r20/`。

## 3 未完成

- Host 尚未注册 `IAgentModelPolicyAuthorization` 的 principal 实现（HTTP/插件/后台三类入口）；因此产品侧策略读写当前会 fail-closed。
- 真实 `IReviewModelLeaseSource`、Review Worker 注册；流式/子代理预算、Goal 自动续跑、08B/08C（NotRun）保持原状。
