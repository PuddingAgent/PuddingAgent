# PA-07A S5 事件投递租约与死信存储

- 新增 `EventDeliveryStore`（`IEventDeliveryStore`）：按 (订阅, eventId) 去重入队并租约至多 MaxCount；失败可选择重试（attempt+1）或死信；死信不参与 pending/claim，仅显式 `RequeueDeadLetter` 才回到投递；外来 delivery id 拒绝。
- schema：`event_deliveries` 增加 `dead_lettered` 列（幂等建表语句同步）；Host DI 注册 `EventDeliveryStore`/`IEventDeliveryStore`。
- 测试：`EventDeliveryStoreTests` 4/4（去重/批量租约、重试/死信、死信重排、外来 id）。
- 未完成：outbox 事务写入、订阅分发 Worker、真实 PluginManager/Worker fixture。
- 三条冻结检查 3/3 PASS。未 commit；证据 `.work/pa-07/s5-deliveries/`。
