# 2026-11-16 按住说话松开发送与快捷键

- 用户选择主流程为按住说话、松开发送。麦克风按钮和聊天页 Ctrl+Shift+Space 支持该流程；输入区鼠标中键提供同等操作。短按不发送，Esc/右键/失焦取消；未注册全局系统热键。
- `cloudVoiceInput.ts` 在麦克风授权与 AudioWorklet 就绪后立即采集，不等待 ASR 建连；开头 PCM 有界暂存并分批排空。松开会立即收尾录音，等待最终识别，再通过原发送/排队入口提交一次。
- `IntentConsole.tsx` 保留「转写到草稿」选项；取消、空转写和识别失败不自动发送；发送失败保留完整文字。切会话与迟到回调保持围栏，保留执行偏好与附件提交路径。前端版本为 6.19.0。
- 先独立验证录音暂存/手势（7/7），再接入 composer。最终前端 11 套 77/77、TypeScript 检查通过；包含初始化中松开、取消最终排空、重复回调不重复发送、鼠标两种入口和空转写不误发旧稿。
- 更新前端代码地图。证据在 `.work/voice-hold/20261116/`。
- 当前为 `ready-for-external-deploy`；构建、部署和真实语音验收另记最终结果。本次仅改前端，不改服务商协议、Core 代码或运行时凭据。
