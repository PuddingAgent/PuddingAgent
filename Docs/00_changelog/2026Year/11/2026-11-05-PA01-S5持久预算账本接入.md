# PA-01 S5 持久预算账本接入

- 新增 PA-01 S5 持久层（`Source/PuddingPlatform/Services/ExecutionBudgets/`）：
  - `ExecutionBudgetStore`：实现 `IExecutionBudgetRecoveryLedger`，SQLite 事务内祖先原子预留、Operation/Attempt 幂等与冲突、取消 revision 线性化、owner fencing、结算仅一次且回执幂等、Unknown 保留不退款、释放仅限未派发、子树取消、恢复候选列表。
  - `ExecutionBudgetSchemaBootstrapper`：`execution_budget_accounts`/`execution_budget_reservations` 幂等建表与唯一索引。
  - `Data/Entities/ExecutionBudgetEntities.cs` + `PlatformDbContext` 两个 DbSet。
- S5 接入：`PuddingHost` DI 注册唯一产品账本（`IExecutionBudgetLedger`/`IExecutionBudgetRecoveryLedger` 均指向同一 singleton，**不再注册内存实现**）；启动 schema 阶段调用 `ExecutionBudgetSchemaBootstrapper`。
- 契约修正：`BudgetIdentity.IsValid` 原先用 `RootKind != default`，把 `GoalRun`（枚举值 0）判为非法、与任务书“根为 GoalRun”矛盾；改为显式枚举成员校验。PA-01 领域测试回归 35/35 通过。
- 测试：`Source/PuddingPlatformTests/Services/ExecutionBudgets/ExecutionBudgetStoreTests.cs` 10/10 通过（真实 SQLite `:memory:`，含跨 DbContext 持久化）；Platform、Host、PlatformTests 构建均 exit 0。
- 取红（临时改真实 store 后逐次构建运行并还原，恢复哈希已核对）：祖先不更新、owner fencing 移除、结算非仅一次、Unknown 归零 —— 均使对应测试变红。
- 冻结清单（主代理审阅后有意变更）：`Source/PuddingHost/Extensions/PuddingServiceCollectionExtensions.Platform.cs` 属配置 API P0/P1 冻结清单；本次仅新增 2 条 using + 3 条账本 DI 注册（diff 已核对），按任务书 01 §5“原三个冻结清单的有意变动由主代理审阅”更新 `Docs/12_features/Agent配置API-P0P1-核心文件指纹.json` 中该文件基线；三条冻结检查恢复 3/3 PASS。
- 未完成：`ExecutionBudgetReconciler` 启动调和、`ExecutionRunCoordinator`/`ExecutionUsageBudgetTracker` 迁移到异步预留/派发确认；PA-03/04/07 的 S5。
