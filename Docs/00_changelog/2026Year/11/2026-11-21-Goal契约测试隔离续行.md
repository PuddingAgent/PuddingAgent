# 2026-11-21 Goal 契约测试隔离续行

`Source/PuddingWebApiTests/GoalApiContractTests.cs` 的测试宿主移除 `GoalContinuationWorker`。后台执行器可能在 HTTP 命令返回后抢先领取续行意图并受理一个轮次，使检查命令副作用的断言收到 1 条轮次。

定向运行整个 `GoalApiContractTests`，7 条通过。生产续行由自己的执行器与测试覆盖。关联 [Goal 持久目标 ADR](../../../07_architecture/89ADR-074Goal持久目标自主续行与自动压缩ADR.md)。
