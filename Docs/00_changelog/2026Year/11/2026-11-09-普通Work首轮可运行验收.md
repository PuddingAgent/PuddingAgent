# 普通 Work 首轮可运行验收

原型按 Work 回执选择插件会话，把插件权限所有者加入测试策略。记录 Completed 前校验真实 dispatcher 的终态、工具失败数及模型收到的 echo。取消测试等到模型已进入等待，经过控制注册表取消后检查终态和产物。权限曝光测试覆盖显式允许、默认及显式排除。

组合测试与曝光测试各通过 1 项。把 Worker 的 echo 改为其他字符串，组合测试退出 2，未生成成功回执。增加 `-VerifyCore` 以独立空目录启动真实 Console Core，健康证据与 Work 回执分别落盘。Work 测试使用进程内 SDK 和脚本模型。产品 HTTP 派发与外部模型联调留待下一阶段。
