# 2026-11-19 面板图表生成器（无脚本 + 截图验收）

## 改动

- 新增 `Tools/Charts/render-series-chart.ps1`：日线 + 事件标记面板图生成器。数据源支持必盈基金/ETF 代码（`-Code`）或自备 CSV（`-Csv date,close,volume`）；可配 `-EventsPath`、`-Ranges`、`-RightAxisFactor`、`-MaFast/-MaSlow`、关键位。
- 新增 `Tools/Charts/events.example.json`：事件文件 schema 示例（`date/label/category/source`），category 决定标记颜色。
- 生成器末尾自检：输出若含 `<script>` 直接抛出，避免再次产出面板里必然空白的图。

## 为什么固化

同一张图在一小时内改了 6 个版本，起因不是数据，而是面板的三条约束只有实测才知道：

1. 面板内出现 `<script>` ⇒ 同面板所有 `<svg>` 退化成 300×150 空壳（框架、按钮、图例都正常，只有图空白）。
2. `html_path` 必须位于工作区目录内，仓库 `temp\` 会被拒。
3. SVG 属性必须带引号，否则清洗器丢弃属性、图形消失。

交互因此改为纯 CSS：区间切换用 `radio + :checked` 兄弟选择器；逐日读数用透明 `<rect>` 内嵌原生 `<title>`。

## 验证

- 518880（211 点 / 9 事件 / 双轴 / 4 档区间）与 510300（211 点 / 无事件 / 单轴）两条序列均生成成功，`script_tags=0`。
- 渲染验收用 `screen_capture` 抓 Desktop 窗口肉眼确认，不再以「文件里存在某段字符串」作为证据；此前 4 个 revision 都「渲染成功」而实际空白。

## 未完成

- 事件在高度密集（相隔数日）时仍会重叠，双行错位只能缓解；需聚簇 + 展开方案。
- 不支持多标的同图叠加（例如与美元指数双轴对比）。
