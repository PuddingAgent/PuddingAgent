# 2026-11-21 Chat HTTP 隔离测试端口

Windows 的动态端口分配在隔离验收时返回 6665 和 6669，Node Fetch 拒绝连接。测试共享回环端口分配器，从高端口随机选择并在端口冲突时重试。重定向测试同时证明首个请求确实到达服务。

使用提交版插件、实际 app-server、独立 Core 和本地模型测试服务连续两次运行，均通过 11/11。关联 [外部 Agent 接入与集中消息总线](../../../12_features/外部Agent接入与集中消息总线-2026-11-21.md)。
