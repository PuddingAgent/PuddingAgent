# PA-03 评审预算预留顺序器

- 新增 `ReviewBudgetSequencer`（依赖 `IExecutionBudgetLedger`）：`BeginAsync` = Reserve → MarkDispatched（**派发失败才 Release 退款**）；`SettleAsync` 用真实 usage/cost 结算；`AbandonAsync` = MarkUnknown（**金额不可用、不退款**）；旧 owner 结算被拒。
- 测试：`ReviewBudgetSequencerTests` 5/5（真实内存账本 + 故意失败的 dispatch 包装）：预留/派发/结算、取消后不可预留、派发后失败才退款、未知保留、旧 owner/非法理由 typed。
- 取红 2/2：派发失败不退款、Abandon 改成退款 —— 对应测试变红。
- 未完成：Host `IReviewEvaluationBinder`（选模型/冻结价格/真实租约）与 Worker 注册，仍未接真实 Runtime binder。
- 未 commit；证据 `.work/pa-03/s5-budget-sequencer/`。
