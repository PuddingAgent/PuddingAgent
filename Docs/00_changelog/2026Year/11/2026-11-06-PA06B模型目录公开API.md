# PA-06B 模型目录公开 API（actor 绑定）

补齐 06B 公共读取面：`Resolve` 不再返回“缺 actor”的 typed 拒绝；未 commit、未部署、未调用真实模型。

## 1 API

- `PlatformModelCatalogApi`（`IModelCatalogApi`）：
  - `ListAsync` 复用 `ModelCatalogAdapter`（受权能力/价格来源字段投影）；
  - `ResolveAsync` 以 host 绑定的 actor 经 `ModelPolicyResolver` 解析 Purpose；未配置 → `model.policy_missing`；仅显式 `InheritPrimary` 才借用 Primary；用 `IModelCatalogSource` 冻结 catalog revision。
- `ModelCatalogApiFactory.ForManagementUser(principal)`：仅认证管理主体可绑定；外部 token/未认证 → `model.scope_forbidden`。
- `ModelCatalogController`：`GET /api/models`、`POST /api/models/resolve`，typed 错误 403/404/400/503。
- Host 注册 `ModelCatalogAdapter`、`ModelCatalogApiFactory`。

## 2 测试与验证

- `PlatformModelCatalogApiTests` 3/3：Purpose 解析/显式继承、缺失 purpose typed、factory 拒绝非管理主体。

- 冻结基线：Host DI 文件属 P0/P1 清单，注册属有意变更，已审阅重签指纹（配置 18/18 PASS）。
