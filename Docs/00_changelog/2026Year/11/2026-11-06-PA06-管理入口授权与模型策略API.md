# PA-06 管理入口授权与模型策略 API

按裁定“配置写入检查调用方权限、actor 由宿主绑定”接通管理入口；未 commit、未部署、未调用真实模型。

## 1 授权

- 新增 `ManagementModelPolicyAuthorization`：
  - 只接受**已认证管理登录**（NameIdentifier/sub）；
  - 拒绝外部访问 token（`ExternalAccessTokenClaimNames.TokenId` / `ext:` actor 前缀）与未认证请求；
  - 绑定的 actor 必须等于 principal subject —— 不接受请求体 ActorId，也不以 AgentId 冒充。

## 2 API

- `AgentModelPolicyApiFactory.ForManagementUser(principal)` → `PlatformAgentModelPolicyApi`：
  - GET 有效策略：`ModelPolicyResolver` 经既有 `IAgentModelPolicyStore` 解析（instance/继承/缺失原因）；
  - PATCH：DTO patches → `UpdateModelPolicyCommand` → manifest CAS 写入 → receipt。
- 新增端点 `GET/PATCH /api/workspaces/{workspaceId}/agents/{agentId}/model-policy`（JWT 管理域），typed 错误映射 403/404/409/400/503。
- Host DI：注册 `IAgentModelPolicyStore`（复用 `WorkspaceAgentFileService`）、`IAgentModelPolicyAuthorization`、`AgentModelPolicyApiFactory`、`AddHttpContextAccessor`。

## 3 测试与验证

- `AgentModelPolicyApiTests` 3/3：管理主体只绑定自身 actor、外部 token/未认证拒绝、factory 拒绝非管理调用、GET/PATCH 使用 subject 且传递 CAS revision。
- Platform S5 切片 **136/136**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r21 exit 0（组件 274 + Platform 136 + 前端 47 + tsc）。
- 冻结基线：Host DI 文件属 P0/P1 清单，本次注册属有意变更，主代理审阅后已更新指纹（配置 18/18 PASS）。
- 证据：`.work/pa06/host-authorizer/`、`.work/verification/policy-api-solution/`、`.work/pa08/components-20261106-r21/`。
