# 预算结算重放与多 attempt 独立记账测试

补 P2 的“响应丢失/重试”记账语义；未 commit、未部署、未调用真实模型。

## 1 新增测试（真实 SQLite）

`ModelAttemptBudgetGateTests` +2、合计 **8/8**：
- **结算重放幂等**：同一 permit 同 usage/receipt 二次结算返回同一 receipt revision，`Cost` 不重复累计；改 usage/receipt → `budget.settlement_conflict`，账本不变。
- **两个 attempt 独立记账**：同一 Enforced 根下两个已派发 attempt（各自预留）分别结算；`ActiveAttempts=0`、`ReservedCost=0`、`Calls=2`、`Cost>0`，不共享一次预留。
