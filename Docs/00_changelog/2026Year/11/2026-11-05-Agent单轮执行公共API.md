# Agent 单轮执行公共 API

## 改动

- 新增 `Source/Pudding.Api.Contracts/AgentWork.cs`：请求、受理回执、状态、终态证据与绑定调用者的 `IAgentWorkApi`。
- 新增 `Source/PuddingAgentWork.Contracts/`、`Source/PuddingAgentWork/` 及独立测试：校验、授权、调用者作用域、稳定操作身份、请求哈希和未知提交结果；csproj 强制依赖方向。
- 新增 `Source/PuddingPlatform/Services/AgentWork/` 及 `Controllers/Api/AgentWorkApiController.cs`：复用 `SubmitTurnHandler` 的原子受理与既有 worker/journal，不新增数据库表或执行器；准确读取 batch/input/command/Turn/event，损坏或串身份不报完成。已有主会话做 owner/Agent/角色/状态检查。
- 新增 `Source/Pudding.Api.Sdk/AgentWorkClient.cs`、`HttpAgentWorkApi.cs`：可绑定已有 Agent、提交和查询同一操作；HTTP 丢回执标 unknown，不自动重试；拒绝会被 URI 归一化的非法路径段。
- Host 组合根只新增 `AddAgentWorkApi` 调用；Platform 增加组件引用；解决方案登记新组件与测试；更新受影响 code_map。
- 补充契约说明、DS-W01 离线示例施工任务书、16 个核心文件的冻结指纹和检查脚本。既有配置 API 的 18 个冻结文件保持不变，未改 DS-01/02/03 施工范围。
