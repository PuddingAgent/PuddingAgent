# 2026-11-15 语音基础链路与聊天体验接入

## 改动

- `PuddingAgentNetwork.slnx`、Runtime/Platform 工程：S1–S4 独立测试和编译边界通过后，登记并引用 `PuddingSpeech`；更新根与相关子项目代码地图。
- `Source/PuddingRuntime/Services/QwenMessageAsrProvider.cs`：指定 Qwen Message 模型的 WebSocket 适配；普通业务仍调用统一转录服务。默认配置改用该 ASR 和现有 Qwen3 TTS。
- `VoiceController.cs`、`VoiceFailureAttribute.cs`：统一转录服务、真实 WAV 校验、合成 SSE、能力查询、额度与凭据等脱敏错误；上层请求不选择供应商。
- `DashScopeTtsProvider.cs`：逐帧读取服务端 SSE，显式区分 Qwen3 请求，传播取消与结构化错误。
- 前端 `cloudVoiceInput.ts`、AudioWorklet 与 `voiceAudio.ts`：16 kHz 单声道 WAV、120 秒上限、音量/计时、完成/取消分离、草稿保留、迟到回调围栏；移除固定 200ms 等待。
- 前端 `ttsPlaybackController.ts`、`useTtsPlayer.ts`、`cloudVoiceOutput.ts`：全局单一播放任务、PCM SSE、取消网络/播放、切会话清理、可见错误；统一消息/面板朗读。版本递增到 6.17.0。
- 历史核查报告更新录音文件引用并标注实施前基线；测试夹具同步新取消合同。

## 验证

- 独立组件 12/12；Runtime 定向 11/11；Platform 控制器及统一 ASR/TTS 服务 5/5。
- 前端语音定向测试 42/42；`pnpm exec tsc --noEmit` 通过；`pnpm run build` 与包体积门禁通过。
- Host 构建 0 错误。VSTest 的父进程权限问题令宿主测试运行器中止；使用隔离进程调用真实 `PuddingApplicationHostCompositionTests.DesktopChild_CompositionRoot_ResolvesSingletonRuntimeToolsAndServices` 方法，实际组合根及新增语音服务解析断言通过。未将中止结果算通过。
- 所有构建/测试日志在 `.work/asr-tts/20261115/`，隔离临时 DataRoot 未使用运行中用户数据库。

## 未完成与部署边界

本提交状态为 `ready-for-external-deploy`。部署、运行时默认模型切换、真实 Qwen 调用与产品 UI 验收另记实际结论；尚未宣称 `in-product-functional-complete`。

当前 ASR 是完整录音结束后转写到草稿，底层用 Qwen WebSocket 正确完成任务；持续边录边转写的浏览器实时通道、火山第二适配器及全双工语音属于后续切片。当前版本不冒充这些能力已完成。

付费/仅免费额度策略不改动。代码回滚可 revert 本提交；运行时配置若另行调整须单独恢复对应备份，Guardian 回滚不回滚用户配置。
