# 2026-11-21 内置 Agent 接入消息和委派总线

- `Source/PuddingPlatform/Services/MessageFabric/ExternalAgentDirectory.cs` 让内置 Agent 的消息路由与 Agent 目录发现同工作区的外部适配器，保留目标的持久投递类型。
- `Source/PuddingPlatform/Controllers/External/V1/ExternalAgentAdaptersController.cs` 接受发给内置 Agent 的通知和任务。通知查询投递确认，任务查询 canonical Turn 终态。内置 Agent 发给外部工具的任务结果经 Message Fabric 被动投回主会话。
- `Tools/CodexPlugins/plugins/chat-http/pudding-bus.mjs` 增加 `delivery` 子命令查询文本确认。

定向路由与目录 13/13。Core 构建通过。隔离 Core、真实 Codex app-server 与本地模拟模型的测试通过 11/11，覆盖内置与外部 Agent 的双向文本、双向委派和回信入会话。当前实例部署与真实模型验收另记。
