# 2026-11-04 Slack 渠道首版

## 改动

- `Source/PuddingSlack/`：零工程/包引用的协议组件；Socket Mode 重连、持久化后 ACK、DM/@提及准入、字符串 ts、收件箱去重、发送前账本和 Unknown 防重发。
- `Source/PuddingHost/Connectors/SlackConnector.cs`、`Services/SlackConnectorFactory.cs`：接入独立组件；仓库外凭据文件、唯一 Agent/App 绑定、身份校验、后台收件箱交接；注册到 slnx、Host 引用与 DI。
- `Source/PuddingHost/Services/MessageGatewayIngress.cs`：飞书继续主会话；Slack 按 DM/频道线程隔离，保留渠道身份及回复路由，不映射为桌面管理员。
- `Source/PuddingPlatform/Services/MessageGateway/ConversationReplyProjectionWorker.cs`、`Source/PuddingHost/Services/ConnectorDeliveryDispatcher.cs`：Slack 文本终态投影；429 按 Retry-After 重试，Rejected/Unknown 死信，不重跑 Agent。
- `Source/PuddingHost/Controllers/SlackChannelDiagnosticsController.cs`：认证诊断和发送回执查询；通过 ConnectorHost 查询动态注册的实例。
- `Source/PuddingCore/Configuration/ChannelConfigModels.cs`、`SlackChannelValidation.cs` 和 `Source/PuddingPlatform/Services/ChannelConfigurationFileService.cs`：Slack provider/配置与白名单；凭据仅保存外部路径。
- `Source/PuddingPlatformAdmin/src/pages/workspace/[id]/index.tsx`、`src/services/platform/api.ts`：Slack 配置表单；前端版本 `6.10.5 → 6.11.0`。
- 提供 [接入说明](../../../01_message_channels/Slack接入.md)、可导入 manifest 和 `TestScripts/test-pudding-slack-credentials.ps1` 脱敏身份探针；维护相关代码地图与故障分诊入口。
