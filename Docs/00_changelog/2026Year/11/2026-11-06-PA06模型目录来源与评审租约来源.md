# PA-06/PA-03 模型目录来源与评审租约来源

把目录/报价/门禁/评审路由接到真实配置权威；未 commit、未部署、未调用真实模型。

## 1 目录来源

- 新增 `ILlmModelCatalogView` + `LlmConfigModelCatalogSource`：
  - 视图由 Host 的 `ILlmConfigService.GetAllModels()` 提供（llm.providers.json 唯一权威），不暴露 endpoint/密钥；
  - 映射 max context/input/output、prices、price-window profile version、deprecated 状态；
  - **零/负价格映射为 null（未知）**，不伪造 ExplicitFree；embedding 模型不进入目录；列表有界/排序/游标。
- 新增 `ReviewModelLeaseSource`：把 `ReviewModelBinding` 的冻结 catalog 限额/价格变成 `ILeasedModel.Descriptor`；`InvokeAsync` 只调用一次 `IReviewModelProvider`（真实产品 gateway 适配点）。

## 2 Host 注册

- `ILlmModelCatalogView` / `IModelCatalogSource` / `IModelQuoteSource`（`CatalogModelQuoteSource`）/ `ModelAttemptBudgetGate` / `ReviewModelRouter` 已注册到 Host DI（真实配置权威 + 持久账本）。
- Review Worker/executor 仍未注册：缺 Host `IReviewModelProvider`（产品 gateway 适配）实现。

## 3 测试与验证

- `LlmConfigModelCatalogSourceTests` 2/2（配置模型映射/零价未知；列表有界/排序/隐藏 embedding）。
- `ReviewModelLeaseSourceTests` 2/2（冻结描述符/一次 provider 调用；非法 binding 在 provider 前 typed 失败）。
- Platform S5 切片 **140/140**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r22 exit 0（组件 274 + Platform 140 + 前端 47 + tsc）。
- 冻结基线：Host DI 文件属 P0/P1 清单，本次注册属有意变更，主代理审阅后已更新指纹（配置 18/18 PASS）。
- 证据：`.work/pa06/llm-catalog/`、`.work/pa06/llm-catalog-host/`、`.work/pa03/lease-source/`、`.work/verification/llm-catalog-solution/`、`.work/pa08/components-20261106-r22/`。
