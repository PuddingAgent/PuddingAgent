# Slack 频道可见性与提及

## 改动

- `Source/PuddingSlack/`：区分真人和 bot 授权，允许授权 bot 的频道显式提及；拒绝自身及 bot 私聊。持久化线程额度和频道分钟额度，抑制也写去重墓碑。出站保留显式成员提及、转义广播等特殊文本。
- `Source/PuddingCore/Configuration/` 与 `Source/PuddingHost/`：配置 `allowedBotUserIds`，入口二次校验，诊断暴露 `messagesSuppressed`；渠道会话保留绑定 Agent 和独立线程身份。
- `Source/PuddingPlatform/Controllers/Api/SessionApiController.cs`：提供最多 100 条的渠道目录查询，跳过全文历史回填。
- `Source/PuddingPlatformAdmin/`：版本 6.12.0；常驻渠道会话入口、10 秒/窗口聚焦刷新，复用历史和 canonical 过程。修正把渠道 principalId 当 Agent ID 的错误；主会话投影只用于主会话。渠道输入框禁用并提示到原渠道回复。
- 生产配置已备份后通过配置服务更新：允许既定测试频道和 dot bot，保留鲸鲸绑定和既有真人授权；凭据仍在仓库外。
