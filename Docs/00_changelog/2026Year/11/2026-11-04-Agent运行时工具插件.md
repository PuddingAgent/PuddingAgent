# Agent 运行时工具插件

## 改动

- 新增 `Source/Pudding.ToolPlugins.Contracts`、`Sdk`、`Protocol`、`Runtime`、`Windows`、`Worker` 独立项目；编译期引用白名单限制依赖方向，Core 不加载插件 DLL。
- `Source/PuddingRuntime/Services/Plugins/` 与 `Tools/BuiltIns/Plugins/PluginTools.cs`：导入、加载、卸载、诊断，工具按执行身份和会话绑定，支持建议 Hook。
- `Source/PuddingRuntime/Services/AgentExecutionService.cs` 及 Buffered/Streaming：目录代际变化后下一轮刷新模型工具清单；旧代工具不重定向至新版本。
- `Source/PuddingCore/Tools/PuddingToolContracts.cs`、注册与权限/Firewall 适配：上下文工具源、模板权限归属、实际函数审批及资源权限检查。
- 移除 `PluginManifestCatalog.cs` 中不可执行的假工具与相应测试；旧 v1 清单保留元数据读取。
- `Source/PuddingHost/Build/PuddingHostContent.props`：随 Core 构建/发布 Worker、SDK、示例和指南；通用助手预设包含管理入口，未修改现有 Agent 配置。
- 新增管理 API、前端“可运行插件”页；前端版本 6.13.0。新增 SDK 示例、独立/集成测试和 `TestScripts/test-pudding-tool-plugins.ps1`；维护相关 code_map。

## 验证与限制

独立 Runtime 22 项、真实 Windows Worker 6 项、宿主闭环 6 项、既有回归 207 项、前端 5 项通过；Core Release 发布、SDK 示例构建、前端类型检查及生产构建通过。详细判据、证据路径和环境问题见[验收报告](../../../14_reports/2026-11-04-运行时插件验收.md)。

未部署产品；实时 HTTP/UI 和真实模型验收未完成，隔离 Core 重启命令被自动审批拒绝。产品原有停止状态保持不变。全 Docs 链接检查仍有 29 个既有失效目标。当前只交付工具与建议 Hook，Worker 以当前用户权限运行，不是恶意代码沙箱。

首次使用需部署新版 Core；以后插件增删改通过加载/卸载完成。包导入不执行代码，实例卸载保留包，不自动恢复。现有 Agent 授权需显式启用相关管理工具。使用说明见[运行时工具插件](../../../04_tools_and_skills/运行时工具插件.md)。未执行 git commit / push。
