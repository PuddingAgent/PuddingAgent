# PA-07 07B 插件任务与扩展点 SDK 契约

- `PluginJobs.cs`（冻结）：`PluginJobEnvelope`（JobId/PluginId/Generation/Kind/Payload/幂等键/截止/尝试上限）+ 显式 `PluginJobState` 结果（`Unknown` 是第三态，既非成功也非失败；`Running` 不可作为最终结果）+ `IPluginJobHandler`；不暴露 Host 服务。
- `PluginExtensions.cs`（冻结）：Observer/Advice/Transform/Guard 声明与处理形状；声明有界；Transform/Guard 结果必须显式成功/失败（失败需 FailureCode）；grant/generation/protected-field 校验仍由宿主 `PuddingInvocationPipeline` 负责。
- 测试：`Pudding.ToolPlugins.AgentSdkTests` 增至 **19/19**（新增 Job 2 + Extension 2）；插件 Agent API 冻结检查 18/18 PASS。
- 未完成：真实 PluginManager/Worker fixture 生命周期、07A S5 outbox/checkpoint、宿主扩展 registry 接入。
