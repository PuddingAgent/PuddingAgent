# PA-01 P2 流式模型调用预算门禁

流式路径不再 fail-closed 绕过持久预算；未 commit、未部署、未调用真实模型。

## 1 实现

- `LlmInvocationService.InvokeStreamAsync`：
  - 有预算身份时先 `BeginAsync`；**门禁拒绝在流启动前抛出**，provider 不会被枚举；
  - 正常完成：取流中最后一个 `TokenUsageDto` 作为实际 usage → 结算；无 usage → `MarkUnknown("llm.usage_unknown")`；
  - provider 失败 / 调用方取消 / 消费者提前 break：`finally` 中仅标记一次 Unknown（`llm.provider_failed`/`llm.cancelled`/`llm.stream_abandoned`），不退款；
  - 手工枚举 + `try/finally` 保证提前放弃也能核账。

## 2 测试与验证

- `LlmInvocationServiceBudgetTests` 新增 4 条：流式结算上报 usage（含 cache tokens）、门禁拒绝不启动流、provider 失败标记 Unknown、消费者提前放弃标记 Unknown。
- Runtime 预算/取消测试合计 **12/12**。
- Platform S5 切片保持 **151/151**；全解决方案构建以当轮 restore + `--no-restore` 验证；一键脚本 RunId 20261106-r26 exit 0（组件 274 + Platform 151 + 前端 47 + tsc）。
- 证据：`.work/pa01/stream-budget/`、`.work/pa08/components-script-r26.log`。
