# PA-01 P2 接入 LLM 调用边界

把 P2 门禁接到共享 LLM 调用门面（`LlmInvocationService`），未 commit、未部署、未调用真实模型。

## 1 契约与适配

- `PuddingExecutionResources.Contracts` 新增 `IModelAttemptBudgetPort`：
  - `BeginAsync(claim)` → Legacy 返回 null（不门禁）；Enforced/Shadow 返回含冻结价格的 grant，或抛 typed 错误；
  - `SettleAsync(grant, usage, receipt)` / `MarkUnknownAsync(grant, reason)`；
  - `ModelAttemptBudgetGrant.CostOf(usage)` 按 BaseUnit/cache 价计算实际成本。
- `LlmInvocationRequest` 增加可选 `LlmAttemptBudget BudgetAttempt`（account/ancestors/identity/attempt/model revision/价格版本/token 上界/币种）。
- Platform 新增 `PlatformModelAttemptBudgetPort`：把 claim 映射到 `ModelAttemptBudgetGate`，把 `ExecutionResourceException`/`ModelException` 包装成 `ModelAttemptBudgetException`；Legacy 返回 null。

## 2 调用边界行为

- `LlmInvocationService` 注入可选 `IModelAttemptBudgetPort`：
  - 有预算身份：先 `BeginAsync`（被拒绝时**不调用 provider**，返回带 `ErrorCode` 的失败结果）；
  - provider 成功后按实际 usage 结算；provider 未报告 usage → `MarkUnknown("llm.usage_unknown")`，不按 0 结算；
  - provider 异常 / 调用方取消 → `MarkUnknown` 后返回失败/抛出；
  - 无预算身份：保持原行为。
- 流式路径：携带预算身份时**fail-closed**（`budget.dispatch_invalid`），不静默绕过持久预算；等待后续轮次接入流式结算。

## 3 测试

- Runtime `LlmInvocationServiceBudgetTests` 6/6：门禁成功结算（含 cache 命中）、拒绝不调用 provider、provider 失败标记 Unknown、缺 usage 标记 Unknown、无预算身份不触门禁、流式有预算 fail-closed；既有 cancellation 测试 3/3 仍绿。
- Platform `PlatformModelAttemptBudgetPortTests` 2/2：Legacy 无 grant、Enforced 返回冻结价格并按实际 usage 结算（1.0 usd）。
- 结果：Platform S5 切片 **107/107**；全解决方案构建 exit 0；一键脚本 RunId 20261106-r10 exit 0（组件 274 + Platform 107 + 前端 47 + tsc）。
- 证据：`.work/pa01/p2-boundary/`、`.work/verification/p2-boundary-solution/`、`.work/pa08/components-20261106-r10/`。
