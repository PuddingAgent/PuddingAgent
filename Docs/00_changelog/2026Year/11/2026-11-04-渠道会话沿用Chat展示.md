# 渠道会话沿用 Chat 展示

用户截图中的渠道视图沿用消息气泡，但执行过程还是裸按钮，底部保留不可用的编辑器。按主聊天的展示方式整理，同时保留渠道来源和可核对的原始记录。

## 改动

- `Source/PuddingPlatformAdmin/src/pages/chat/components/ConversationProcessDetails.tsx`：复用主聊天过程样式与 Ant Design 控件；按工具调用 ID 配对参数和返回结果，展示完成/失败/等待状态；详情折叠；可切换原始记录。分页、失败重试、截断标记和旧请求取消继续保留。
- `Source/PuddingPlatformAdmin/src/pages/chat/components/ChatMain.tsx`：渠道线程标题移至消息区顶部；渠道会话底部显示原渠道回复说明，不再显示不可用的 Web 编辑器。普通 Chat 保留原输入入口。
- `Source/PuddingPlatformAdmin/package.json`：版本递增至 6.12.4；对应 code_map 和 Slack 接入手册就地更新。
- `ConversationProcessDetails.test.tsx`、`ChatMain.test.tsx`：覆盖按需加载、配对展开、原始记录、错误重试、切换会话取消及渠道输入边界。
