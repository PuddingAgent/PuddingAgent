# PA-05 能力目录宿主绑定工作区修正

- 问题：全量核验发现 `PuddingCapabilityCatalog` 构建失败 —— `CapabilityCatalogService` 读取公开 `CapabilityQuery.WorkspaceId`，但冻结的公开契约已按“宿主绑定工作区”设计（`CapabilityQuery(Kind, Cursor, MaxCount)` 无 workspace），服务与契约不一致（此前只跑过叶任务构建，未回归组件工程）。
- 修正：`CapabilityCatalogService` 构造时接收宿主绑定 workspace（不合法即 `capability.request_invalid`），调用源时使用该绑定值；公开查询契约保持无 workspace，调用方不能扩大范围。
- 测试：`PuddingCapabilityCatalogTests` 更新为宿主绑定构造（10/10 通过）；DS-PA05-A 示例回归 18/18 通过。
- 未完成：该组件仍待 S5 接入既有工具/MCP/上下文来源；05B~05F 其余抽取与 05E 未开始。
