# 2026-11-21 Chat HTTP 状态目录启动修复

验证提交版插件时，旧 `private-directory.ps1` 被 Windows 的 RemoteSigned 执行策略拒绝。把工作区已有的 ACL 初始化移入 `bridge.mjs` 的内联调用，继续拒绝重解析点并将目录访问权限定给当前用户。

隔离仪器使用提交版插件加这项启动修复重新验证，11 项通过，包含真实 app-server 与独立 Core 的注册、订阅、双向文本及委派终态。关联 [外部 Agent 接入与集中消息总线](../../../12_features/外部Agent接入与集中消息总线-2026-11-21.md)。
