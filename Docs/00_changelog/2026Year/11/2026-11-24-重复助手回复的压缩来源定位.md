# 2026-11-24 重复助手回复的压缩来源定位

鲸鲸主会话在模型窗口占用 74.13% 时触发保护。摘要完成后，提交阶段对 26 条相同回复各找到了 26 个候选。原始错误 ID 为 `llm-226fd234847843a09767f9704accdc27`。

- `Source/PuddingCore/Models/ChatMessage.cs` 与 Runtime 的流式、非流式执行路径记录助手回复的执行 Turn。水合时从规范转录恢复消息及 Turn 身份，暖历史核对遇到冲突时保留原对象。
- `Source/PuddingRuntime/Services/ContextCompactionService.cs` 按持久身份匹配。缺少 Turn 的旧回复只有在两侧用户身份及转录顺序都吻合时才消解同文歧义。真正的歧义会在写入前拒绝整批，未投影的工具原文仍与摘要原子归档。
- 错误证据增加 `compaction_source_problem_count`。诊断手册说明了它与初始内存 ID 缺失数的区别。[常见症状](../../../08_how_debuge/05-常见症状.md)
- 由本轮诊断及只读转录提取 424 条候选的脱敏结构，分别用旧、新程序集执行同一个 SQLite 内存回放。旧版返回 26 个歧义且代次维持 0。修复版提交成功，26 条均覆盖，代次变为 1，覆盖清单遗漏数为 0。回放采用替代文本，验证范围为来源解析和持久事务。
- Runtime 定向回归 170 项全部通过，覆盖流式与非流式压缩、同文回复、旧历史、来源冲突、事务回滚和重启水合。Docs 的 Front Matter 与 Markdown 链接检查均通过。
- Guardian 构建当前实例的候选包后，候选程序集通过同一份现场回放。确认无运行中回合后部署，命令 `0affb365-7d45-4206-9502-478b9600962a` 达到 `healthy`，新 Core 的 `/health/ready` 返回 200。已核对部署目录的 PuddingCore、PuddingRuntime 与回放程序集的 SHA-256。原失败回合保留其终态。
