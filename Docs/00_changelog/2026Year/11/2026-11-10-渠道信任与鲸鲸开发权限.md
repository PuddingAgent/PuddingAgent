# 渠道信任与鲸鲸开发权限

工作区后台的「渠道管理 → 渠道信任」可分别设置每个 Agent 的 Chat 和外部渠道。默认受限。Chat 可信模式要求已登录且有当前工作区写权限。外部渠道要求管理员将应用、组织、外部成员 ID 绑定到有相应权限的本地账号。飞书开发权限仅支持真人私聊。绑定后的外部开发会话按成员隔离，群内只发状态提示。鲸鲸原有工具选择和自动审批继续生效。

Core 在受理时封装本轮身份，在执行时复核绑定和工作区权限。入口见 `Source/PuddingPlatform/Controllers/Api/ChannelDevelopmentTrustController.cs`，执行边界见 `Source/PuddingPlatform/Services/AgentChat/ExecutionRunCoordinator.cs`。

- 候选包的身份与钉钉受理定向用例 8/8，渠道网关定向测试 33/33。宿主用例使用直接执行测试方法的 runner，网关用例使用自运行 MSTest。
- 单独导出暂存的渠道信任改动及固定版本的 GM 子模块，Host 构建 0 错误，飞书命令定向测试 8/8。新增日志的 front matter 合规。全库文档链接检查报告 134 个失效目标、0 个失效锚点，均未指向本日志的链接。
- 隔离 Core 使用本地模型替身和真实 Chat、自动审批、Shell，按“受限 → 可信 → 受限”执行三轮。只有中间一轮可见 Shell，实际运行 `git status --short`，读到隔离工作区的标记文件。
- 正式环境使用 `D:\Data`。Guardian 的 Desktop 整包请求 `1f6fd093cc4943dab65cef76bf0faaab` 到达 `healthy`。Desktop PID 41332，直接子进程 Core PID 50304。ready/live 均为 HTTP 200，安装的五个程序集、Desktop 可执行文件和前端入口均与候选哈希相符。浏览器读回鲸鲸 Chat 可信、钉钉受限，前端版本为 `6.16.0+dirty`。
