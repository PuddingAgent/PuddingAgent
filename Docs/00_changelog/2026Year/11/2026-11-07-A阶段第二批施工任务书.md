# A 阶段第二批施工任务书

在 `Docs/12_features/` 增加[批次索引](../../../12_features/A阶段第二批施工任务书-2026-11-07.md)与四张代码级施工单。前两张允许 DeepSeek 按独立白名单施工，后两张由主代理维护身份/报价合同、执行接线与每次推理发送的计费流程。根 `code_map.md` 在基础设施导航处登记入口。

本次裁定 DS-I1-04 的 O1。请求改变已存在健康账户的冻结币种返回 Conflict，创建新子账户时币种与父不一致返回 CurrencyMismatch。主执行范围优先覆盖 canonical 单轮 Work，两个 Runtime 请求入口和 Responses 文件引用重建重发均列入验收。
