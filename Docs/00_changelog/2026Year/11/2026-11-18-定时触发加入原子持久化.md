# 2026-11-18 定时触发加入原子持久化

## 改动

- `Source/PuddingScheduling/SqliteScheduleStore.cs` 在同一个 SQLite 事务提交触发键、任务写入和调度游标。仅触发唯一键冲突按幂等处理，其余写入失败回滚。
- `Source/PuddingScheduling/IScheduleStore.cs`、`AutomationScheduleRecord.cs` 和 `ScheduleStoreSchema.cs` 定义 tick 提交契约、版本比较和到期扫描索引。
- `Source/PuddingScheduling/PuddingScheduling.csproj` 在编译时拒绝其他项目引用。独立测试通过真实 SQLite 验证事务边界。

## 验证

- 独立工程构建 0 警告、0 错误，MTP 真实执行 52/52。
- 在隔离源码副本移除唯一键冲突处理、放宽版本比较并强制提交失败事务，3 条对应行为用例取红。
- 在隔离副本加入 ProjectReference，MSBuild 按边界断言拒绝构建。
