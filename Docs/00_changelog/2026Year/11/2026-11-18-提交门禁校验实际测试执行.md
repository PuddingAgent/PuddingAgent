# 2026-11-18 提交门禁校验实际测试执行

## 改动

- `TestScripts/check-staged-tests.ps1` 为每个选中项目隔离结果目录，交叉校验 TRX 实际执行数、逐项结果、运行状态与进程退出码。缺失报告、零执行和中止均阻断；完整运行的失败仍按原有基线核对。
- `TestScripts/README.md` 和 `code_map.md` 记录门禁入口与证据规则。

## 验证

- 用独立 Git 夹具运行真实门禁脚本，模拟 VSTest 和 MTP 报告。14 个对照全部符合预期，旧版在其中 9 个场景错误放行。场景覆盖正常通过、基线失败、新失败、零执行、缺报告、意外退出码、结果缺失和部分执行后中止。
- Foundation VSTest 实际运行 513/513，Scheduling MTP 实际运行 37/37。两份真实 TRX 均通过门禁解析规则。另用独立 MTP 工程验证完整运行下的失败结果仍可归到具体用例，历史中止报告被拒绝。
- 新日志 Front Matter 校验通过，全 Docs 断链扫描报告 134 个存量失效目标和 0 个失效锚点。
