# PA-04 评审事实映射接入

- 新增 `GoalReviewFactMapper`：最新评审投影 → `ReviewFact`。规则：`Satisfied` 仅当证据级别 `CheckVerified`；`Satisfied` 但证据不足 → `NeedsUser`；`NeedsWork`/`NeedsUser`/`Inconclusive`/未知 finding 各自映射；artifactSetHash 或 acceptanceContractVersion 与 Goal 事实不匹配 → `Stale`；无评审按 required 返回 `Missing`/`NotRequired`。
- 测试：`GoalReviewFactMapperTests` 5/5（含“模型建议不足以让 Goal 完成”的纯策略联动断言）。
- 取红：把 Satisfied 门改为任意级别、忽略版本不匹配 —— 均使对应测试变红。
- 未完成：把该映射接入既有 Goal continuation/calculator（需修改现有 Goal 状态机与 outbox 消费路径）、PA-08 面板读取同一投影、PA-03 runtime binder/worker 注册。
