# 2026-11-18 定时触发保留准点并截断积压

## 改动

- `Source/PuddingScheduling/ScheduleTickPlanner.cs` 保留 Skip 策略在当前调度分钟内的触发。达到积压扫描上限时，游标推进到当前时间之后的首次触发，并标记跳过数下限。
- `Source/PuddingScheduling/CronExpression.cs` 根据当地日历和标准偏移判定当前分钟是否匹配，供有界扫描略过长积压时判定准点触发。
- `Source/PuddingSchedulingTests/ScheduleTickPlannerTests.cs` 覆盖准点、长积压和补跑上限边界。

## 验证

- 独立调度测试工程构建 0 警告、0 错误，MTP 实际执行 46/46。
- 在隔离副本去掉准点触发与未来游标推进，4 条行为用例取红。
