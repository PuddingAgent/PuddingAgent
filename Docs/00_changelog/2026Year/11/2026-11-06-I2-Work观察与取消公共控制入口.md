# I2 Work Observe/Cancel 公共控制入口

补齐公共闭环的观察/取消入口；未 commit、未部署、未调用真实模型。

## 1 控制入口

- `PlatformAgentWorkControlApi` + `AgentWorkControlApiFactory`：
  - 只接受管理 principal，actor 与 addressed Agent 由宿主绑定；
  - Observe/Cancel 校验请求边界与 Agent 归属；跨 Agent/外部 token → typed `permission.denied`。
- `CanonicalAgentWorkControlBackend`：
  - Observe 复用 `IAgentWorkBackend` 精确回执，再分页读取 canonical conversation events；保留窗口外返回 `SnapshotRequired`；终态时 `Complete=true`；
  - Cancel 通过既有 `IExecutionControlService` 提交 `CancelRequested`（与聊天取消同一权威），返回 `Requested` 而**不宣称 provider 已停止**；终态返回 `AlreadyTerminal`；revision 不匹配 typed。
  - WorkId 使用与 `AgentWorkService` 相同的确定性哈希，不引入第二套状态。
- `AgentWorkControlController`：`GET .../work-control/{operationId}`、`POST .../work-control/{operationId}/cancel`。
- Host DI 注册 `IAgentWorkControlBackend` 与 `AgentWorkControlApiFactory`（未改动受保护的工作 API 契约文件）。

## 2 测试与验证

- `PlatformAgentWorkControlApiTests` 3/3：Observe/Cancel 绑定 addressed Agent；跨 Agent/外部 token 拒绝；终态返回 AlreadyTerminal。
- Platform S5 切片 **164/164**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r31 exit 0（组件 276 + Platform 164 + 前端 47 + tsc）。
- 证据：`.work/i2/work-control/`、`.work/verification/i2-work-control-solution/`、`.work/pa08/components-20261106-r31/`。

## 3 未完成

- **首个公共闭环的端到端测试尚未完成**：还没有“Get Agent → Submit → Observe → Cancel（隔离 SQLite + fake provider，验证预算/取消/并发到达边界）”的整体运行证据；本轮的 canonical backend 只有编译与 API 层假后端测试。
- 真实 canonical backend 需要真实 acceptance/control 数据，未在测试中构造；Submit 路径已有 Host 接线但同样缺端到端。
- 子代理池/提交端口、工具/授权/MCP/上下文/工作区/插件消费者迁移、Goal 自动评审接线、08B/08C（NotRun）保持原状。
