# PA-05C MCP 生命周期与事件游标组件

- 新增 `Source/PuddingMcp.Contracts/McpPorts.cs`（BCL-only MCP 端口）与 `Source/PuddingMcp/McpConnectionCoordinator.cs`；未改 Host/DI/既有 MCP 服务。
- 语义：启动有界超时，失败/超时 → `start_timeout`/`start_failed` 且永不 Ready；同 generation 连接幂等；请求要求 Ready + generation 匹配；截止时间已过 → Unknown 且不触达传输；传输超时/不确定失败 → Unknown 且**不自动重试**；Drain 释放传输并停止受理；事件按 sequence 有序受理、重复/乱序丢弃、缺口报告、游标持久化并在重连后保留。
- 测试：`Source/PuddingMcpTests` 10/10 通过（构建 exit 0、0 警告）。
- 取红（隔离副本 `.work/pa-05/mutation-mcp-runs/`）：超时上报 Ready、未就绪允许请求、移除 generation 围栏、Unknown 自动重试、忽略游标去重 —— 均使对应测试变红。
- 未完成：S5 适配（接既有 `McpService`/stdio/http 传输、进程回收、OAuth/token 存储）、05B/05E 抽取。
- 未 commit；证据 `.work/pa-05/run-05c/`、`.work/pa-05/mutation-mcp-runs/`。
