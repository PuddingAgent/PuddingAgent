# DS-I1-04 预算账户绑定与幂等创建

- 重写 `Source/PuddingPlatform/Services/ExecutionBudgets/ExecutionBudgetAccountMapper.cs`：删除语义错误的 `ParentWorkId`，改为显式 `BudgetAccountId? ParentAccountId`；`ResolveAsync` 只调用 Store 的新原子绑定入口，删除 `TryGetModeAsync` 与自动创建 Goal 父账户；成功 Scope 从持久记录构造，Ancestors 为 root→immediate parent（不含自身）。
- 新增 `Source/PuddingPlatform/Services/ExecutionBudgets/ExecutionBudgetStore.AccountBinding.cs`：Platform 内部 `BudgetAccountDefinition`/`BudgetAccountBindingResult` 与 `EnsureAccountBindingAsync`——单事务读取既有账户与父链、逐字段比较（AccountId/Parent/Identity 五项/Limits 五项/CostUnit/Mode）、创建或复用；父缺失 `budget.account_missing`，环/自引用/断链/>64 层 `budget.path_invalid`，Workspace/Mode 不一致 `budget.conflict`，币种不一致 `budget.currency_mismatch`，取消 `budget.cancelled`；唯一键竞争与 BUSY/LOCKED 有界重试 ≤3，耗尽保留异常。
- `Source/PuddingPlatform/Services/ExecutionBudgets/ExecutionBudgetStore.cs` 仅把类声明改为 `partial`，既有 Create/Reserve/Dispatch/Settle/Cancel/Reconcile 方法零改动。
- 更新 `Source/PuddingPlatformTests/Services/ExecutionBudgetAccountMapperTests.cs`（旧 parent 字段迁移、静默冲突改为明确 Conflict、保留合法重复解析不变），新增 `ExecutionBudgetAccountBindingTests.cs`（A01～A14，真实 SQLite，含两个独立 Store/独立连接的文件库并发）与 `RuntimeBudgetAccountBindingTests.cs`（B01～B04，真实 mapper → port/gate/store → `LlmInvocationService` → fake provider）。
- 更新 `Source/PuddingPlatform/code_map.md` 的预算绑定条目与测试入口；新增本报告与日志。
