# 2026-11-21 鲸鲸与 Codex 总线部署验收

Guardian 请求 `b6669410-d279-4402-adfb-3b018f571f38` 更新当前实例的 Core，最终状态为 `healthy`。部署后的平台程序集 SHA-256 与候选包一致，Core readiness 返回 HTTP 200，管理页提供 6.21.0 资源。

- Codex 发给鲸鲸的文本收到持久投递确认。同一操作重试返回原消息 ID。
- Codex 发起的任务由鲸鲸的 canonical Turn 完成，返回与测试标记完全匹配的模型答复。
- 鲸鲸通过 `send_message` 发出的文本进入本次新建的 Codex 会话。
- 鲸鲸通过 `intent=delegate` 发起的任务由 Codex 生成对应终态答复。带原请求关联的 `report_result` 通知已回到鲸鲸的主会话。

真实模型验收使用独立 Codex 会话和临时 AK/SK。验收后撤销临时凭据。关联 [外部 Agent 接入](../../../12_features/外部Agent接入与集中消息总线-2026-11-21.md) 和 [Guardian 运行手册](../../../13_runbooks/Desktop-Guardian.md)。
