# Agent 组件化任务书 1~8 领域层与 SDK 门面交付

- 按[总则与依赖](Docs/12_features/Agent组件化任务书-总则与依赖-2026-11-05.md)完成八份任务书的**独立领域层/契约层**与全部 **8 个可委派叶任务**；宿主 S5 接入、进程外部署与真实模型验收**未开始**。
- PA-01：`PuddingExecutionResources.Contracts` 持久预算端口/快照/Release/恢复候选；`InMemoryExecutionBudgetLedger`（祖先原子、取消线性化、owner fencing、幂等结算、未知保留）；`DurableBudgetCoordinator`（先预留后派发、恢复计划）；公共 `ExecutionBudget.cs` + `ExecutionBudgetClient`；测试 35 + SDK 3。
- PA-02：`PuddingAgents.Contracts` 绑定端口与目录/工作控制/委派租约；`PuddingAgents` 目录/工作控制/委派服务与所有权策略；公共目录/工作控制/委派 DTO；测试 16 + 目录示例叶任务。
- PA-03：`ReviewJobs` 公共 DTO、`PuddingReviews.Contracts` Job/证据/执行/outbox 端口、`PuddingReviews` 输入/结果校验与协调器（建议级结论、证据级别、owner/revision 围栏）；测试 23 + 评审示例叶任务 + `ReviewJobsClient`。
- PA-04：`PuddingGoalPolicy.Contracts` 冻结事实/策略快照；`GoalContinuationPolicy` 纯决策（取消优先、Chat 单轮、旧版本不完成、未知不默认、预算/轮次停止、修复/停滞边界、稳定 next-round key）；测试 22 + 决策展示叶任务 + `GoalDecision` 公共 DTO。
- PA-05：能力目录公共 DTO + `PuddingCapabilityCatalog` 只读目录服务（kind/界限校验、Revision/Generation/Complete/Partial、Forbidden 不折叠为空）；测试 10 + 能力目录示例叶任务。
- PA-06：`PuddingModels.Contracts` 配置/目录/报价端口；`ModelPolicyResolver`（分层/CAS/显式继承）、`ModelQuoteService`（派发时冻结、未知不为零、缓存计价、窗口/币种）、`ModelLeaseRegistry`（代际围栏、降配不抢占）；测试 24 + 模型策略示例叶任务。
- PA-07：`PuddingEventing` 订阅/投递/事务 outbox/原子 checkpoint/死信/代际围栏与 Job 票据；`Pudding.ToolPlugins.AgentSdk/PluginEvents.cs` 插件事件/审计冻结契约；测试 20 + AgentSdk 3 + 审计插件叶任务。
- PA-08A：冻结 `ExecutionReviewPanel.types.ts`/`fixtures.ts`（6 组状态）与精确渲染契约；交付纯展示组件 + 测试（主代理补全状态表后 18/18 Jest、tsc exit 0）；前端版本 6.13.0→6.14.0；未挂载。
- 8 张叶任务均走 ContractRelease→施工→独立复核→主代理终验→索引/日志集成（未 commit）；证据在 `.work/ds-pa0*/`、`.work/pa-0*/`。
- 未完成：各任务书 S5（Platform 持久存储/Worker/DI、SDK 适配、Goal/模型/插件适配、05A~05F 组件抽取、08A 挂载、08B 部署、08C 真实 smoke、08D 报告）。
