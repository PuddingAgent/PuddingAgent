# SDK Work Observe/Cancel 控制客户端

补齐上层消费者可直接使用的观察/取消入口；未 commit、未部署、未调用真实模型。

## 1 SDK

- `HttpAgentWorkControlApi`（`IAgentWorkControlApi`）：
  - Observe：`GET api/workspaces/{w}/agents/{a}/work-control/{op}?afterSequence=&maxCount=`；
  - Cancel：`POST .../work-control/{op}/cancel`，校验回执 OperationId/TargetOperationId；
  - 不安全 workspace/agent/operation id 在 HttpClient 之前拒绝（防止 dot-segment 归一化）；
  - 取消响应丢失 → `cancel.unknown`（**不声称已停止**）。
- `AgentWorkControlClient`/`AgentWorkControl` 便捷句柄：绑定不创建 Agent、不启动工作。

## 2 测试与验证

- `WorkControlSdkTests` 3/3：路由与请求体、危险 id 零传输、丢失响应 unknown。
- SDK 测试 **25/25**（原 22 + 3）；Platform S5 切片 170/170；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r35 exit 0（组件 276 + Platform 170 + 前端 47 + tsc）。
- 证据：`.work/i2/work-control-sdk/`、`.work/verification/work-control-sdk-solution/`、`.work/pa08/components-20261106-r35/`。
