# PA-05B 工具门面只读组件

- 新增 `Source/PuddingTools.Contracts/ToolFacadePorts.cs`（BCL-only 工具门面端口）与 `Source/PuddingTools/ToolFacade.cs`；未改 Host/DI/既有工具系统。
- 语义：**无执行入口**，仅搜索/检查/状态；不可见工具在搜索/检查/状态中均返回 NotFound、不泄露存在性；结果按工具 id 确定排序、页大小有界且截断时 `Complete=false`；状态字符串原样保留 `unknown`；源失败 typed，不返回"空成功"；非法 tool id 在触达源前拒绝。
- 测试：`Source/PuddingToolsTests` 7/7 通过（构建 exit 0、0 警告）。
- 取红（隔离副本 `.work/pa-05/mutation-tools-runs/`）：搜索泄露不可见工具、移除可见性过滤（hidden schema 不再隐藏）、忽略 maxCount、源失败吞成空页、放宽边界校验 —— 均使对应测试变红。
