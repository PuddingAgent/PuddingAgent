# I0 查询/执行作用域拆分与公共 Agent 目录

按收敛计划 I0/I2 先交付“无 Work/预算的受权目录读取”；未 commit、未部署、未调用真实模型。

## 1 作用域拆分

- 新增 `AgentReadBinding(WorkspaceId, ActorId, AllowedCapabilities)`：**不需要 OwnerWorkId/RootBudgetId**；`AgentOwnershipPolicy.EnsureWorkspace` 为读取 binding 增加独立校验。
- `AgentDirectoryService.ListAsync/GetAsync` 增加 `AgentReadBinding` 重载；原 `AgentBinding` 重载委托给读取作用域（保持既有调用者行为）。

## 2 公共目录

- `WorkspaceAgentDirectoryStore`（Platform）：复用 `WorkspaceAgentFileService` 的 manifest/ref 权威，只读、游标=上一页最后 AgentId、空截断页不报告 not-found。
- `PlatformAgentDirectoryApi` + `AgentDirectoryApiFactory`：管理 principal 绑定 actor；外部 token/未登录拒绝。
- `AgentDirectoryController`：`GET /api/workspaces/{workspaceId}/agents`（List）、`GET .../agents/{agentId}`（Get），只借用、不创建/不推理/不计费。
- Host 注册 `IAgentDirectoryStore` 与 `AgentDirectoryApiFactory`。

## 3 测试与验证

- 组件 `AgentReadScopeTests` 2/2：读取不需要 Work/预算；跨工作区/非法 binding 在 store 之前拒绝。
- Platform `AgentDirectoryPublicApiTests` 2/2：manifest 目录可分页读取（无执行身份）；管理 actor 可用，外部/匿名拒绝。
- `PuddingAgentsTests` 18/18；Platform S5 切片 **157/157**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r28 exit 0（组件 **276** + Platform 157 + 前端 47 + tsc）。
- 冻结基线：Host DI 文件属 P0/P1 清单，注册属有意变更，已审阅重签指纹（配置 18/18 PASS）。
- 证据：`.work/i0/directory/`、`.work/verification/i0-directory-solution/`、`.work/pa08/components-20261106-r28/`。
