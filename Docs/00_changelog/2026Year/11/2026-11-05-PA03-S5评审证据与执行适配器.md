# PA-03 S5 评审证据/执行适配器

- `GoalReviewObjectiveSource`（`IReviewObjectiveSource`）：目标文本取 `goal_runs.objective`，条件取版本化 `goal_acceptance_contracts.criteria_json`；缺失合同、ObjectiveVersion 非整数、空条件或空目标 → not-ready（不读聊天文本）。
- `ReviewEvidenceReader`（`IReviewEvidenceReader`）：只把 `finished` 且报告非空的受控检查记录转成 `EvidenceKind.CheckReport`（hash 为 report JSON 的 SHA-256，exitCode 尽力解析）；pending/leased 永不计数；某条件缺报告 → `MissingReasons` + `EvidenceComplete=false`；缺合同/目标 → `review.snapshot_required`。
- `ReviewExecutor`（`IReviewExecutor` + `IReviewEvaluationBinder` 绑定 seam）：快照 → 公共 `AcceptanceRequest` → 结果映射（Accept→Satisfied、Reject→NeedsWork、Abstain→Inconclusive），Degraded/Unknown → `review.executor_unknown`；版本/provenance 保留；不接触模型密钥/gateway。
- Host：DI 注册 objective source 与 evidence reader（executor 需真实 runtime binder，worker 仍未注册）。
- 测试：新增 11 条（executor 4、evidence 4、objective 3）全部通过（真实 SQLite + fake 绑定）；PA-03 S5 现有 24 条测试。
- 未完成：runtime `IReviewEvaluationBinder` 实现（模型评估绑定 + Job 预算）、Worker HostedService 注册、outbox 分发器、Goal 续跑接入。
- 冻结清单：Host DI 文件属 P0/P1 清单，本次新增 objective/evidence 注册（diff 已核对），主代理审阅后更新基线；三条冻结检查 3/3 PASS。
