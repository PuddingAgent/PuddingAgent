# S5 适配器安全属性变异取红

在隔离构建目录下对被适配器源码做临时变异、构建并跑对应测试，随后逐字节还原（4 文件哈希均核对一致；工作树无残留改动）：

| 变异 | 预期安全属性 | 结果 |
|---|---|---|
| A 报价未知价格映射为 0 | 未知价格不出报价 | 红：`MissingPriceOrRevisionOrCurrencyProducesNoQuote` |
| B 预算 API 把 UnknownCost 置 0 | Unknown 不显示为 0 | 红：`MapsKnownAndUnknownAmounts_AndMissingAccountIsNull` |
| C 查询服务把缺失 Job 当“无数据”静默返回 | 缺 Job 必须明确 missing reason | 红：`MissingOrInvalidInputs_AreExplicitMissingReasons` |
| D 目录源失败返回空目录 | 源失败 typed，不伪装空成功 | 红：`List_SourceFailureIsTyped_NotAnEmptyCatalog` |

- 证据：`.work/pa-adapters/mutations/`（每个变异的 build/test 日志）。
- 未 commit；未改测试或产品行为。
