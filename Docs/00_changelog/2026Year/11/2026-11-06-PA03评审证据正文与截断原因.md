# PA-03 评审证据正文与截断原因

落实裁定 §5.2“hash 不能让模型知道交付内容”：证据项增加有界正文视图；未 commit、未部署、未调用真实模型。

## 1 变更

- `ReviewEvidenceItem` 增加可选 `ContentExcerpt`、`ContentTruncated`、`ContentUnavailableReason`（默认 null/false，向后兼容）。
- `ReviewEvidenceReader`：
  - 优先取报告 JSON 的 `summary`/`output`/`body`/`text`/`message` 字符串作为摘要；否则取原始 JSON；
  - **上限 4096 字符**，超出截断并标记 `ContentTruncated=true`；
  - 报告 JSON 不可解析时 `ContentUnavailableReason="report-unreadable"`，不伪造正文；
  - 原有 ContentHash 仍按完整报告计算，摘要不改变证据身份。
- `ReviewExecutor` 的 acceptance evidence 文本追加 `excerpt=…`（仅在存在时），使模型能看到受权有界正文而不是只有 hash/exit。

## 2 测试与验证

- `ReviewEvidenceReaderTests` +2：摘要提取/不截断标记；大正文截断到 4096 且标记、不可读报告显式原因。
- `ReviewEvidenceReaderTests`（6）+ `ReviewExecutorTests`（4）**10/10**。
- Platform S5 切片 **112/112**；全解决方案构建 exit 0；一键脚本 RunId 20261106-r12 exit 0（组件 274 + Platform 112 + 前端 47 + tsc）。
- 证据：`.work/pa03/evidence-body/`、`.work/verification/evidence-body-solution/`、`.work/pa08/components-20261106-r12/`。
