# 2026-11-21 外部 Agent 注册与在线租约

## 改动

- `Source/PuddingAgents.Contracts/AgentAdapterPorts.cs` 定义宿主解析的工作区、Agent 和插件安装绑定，以及用于隔离连接的在线租约。
- `Source/PuddingAgents/AgentAdapterRegistry.cs` 按工作区和 Agent 路由，同一 Agent 保留一个有效连接。替换、续租和释放核对安装身份与租约。
- `Docs/12_features/外部Agent接入与集中消息总线-2026-11-21.md` 描述 Pudding Core 集中路由、Chat HTTP 适配和消息与任务回执的接法。

## 验证

独立 Agent 构建 0 错误，MTP 实际执行 24/24，含新增注册用例 6 条。在隔离副本删除安装身份比对，两个跨安装和租约替换用例取红。

## 未完成

Core 鉴权入口、持久收件箱和委派回执接线，以及真实 Chat HTTP 适配器待实施。关联 [外部 Agent 接入与集中消息总线](../../../12_features/外部Agent接入与集中消息总线-2026-11-21.md)。
