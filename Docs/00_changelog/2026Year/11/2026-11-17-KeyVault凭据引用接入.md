# 2026-11-17 KeyVault 凭据引用接入

## 改动

- `Source/PuddingSecretReferences/`：独立解析环境变量与 vault 引用，未解析/解密失败明确失败；启动缓存只保存 DPAPI 密文，不反向引用宿主。
- Platform 语音服务分开原始配置和执行副本；Runtime 的 LLM、Embedding、搜索、余额、CalDAV 及 Host 的飞书、Home Assistant 接执行解析。Desktop/Guardian 通过源文件链接处理启动凭据，保留程序集边界。
- 保留主密钥取值顺序与加密实现，损坏的持久主密钥不被覆盖；持久化失败及启动解密失败拒绝就绪。
- `Tools/Secrets/`：分阶段、可重复迁移，原子替换前保管箱往返验证，DPAPI 恢复副本、显式历史备份删除及无值审计输出。新增组件及相关代码地图已登记。

## 验证

- 独立组件 10/10，Platform 定向 18/18，Runtime 定向 78/78，迁移工具独立假 HTTP/真实 DPAPI 测试 4/4。
- 引用守卫变异：10 项中 1 项失败；逐字节复原及 SHA-256 一致，复跑 10/10。
- 宿主 DPAPI 独立探针 5 项检查通过，包括跨实例持久读取与坏文件保留。
- Guardian 既有 23 个 Fact 方法通过同进程反射入口调用全部通过；未把两组 Theory 算入此数字。新增文档 Front Matter 与链接定向检查通过。全 Docs 链接扫描有 134 个既存坏目标，均不在本次修改文档中，未扩展修复范围。
- Core 构建、WinUI Desktop 构建、独立 Guardian 构建/发布通过。旧 VSTest testhost 在本环境父进程监视处访问被拒；MSTest 改用独立 MTP 可执行测试入口运行，未把进程中止计为通过。
