# PA-03 快照携带可信 actor 与路由适配

为 live binder 做接口准备：冻结快照携带可信 actor，router 可直接从快照解析路由；未 commit、未部署、未调用真实模型。

## 1 变更

- `ReviewInputSnapshot` 增加可选 `ActorId`；`ReviewEvidenceReader` 从 Job 复制该字段（受理记录中的原始委托者）。
- `ReviewModelRouter.ResolveAsync(ReviewInputSnapshot)` 重载：复用同一 `ResolveCoreAsync`（预算账户身份 + actor → Review purpose + 目录冻结 revision/pricing）；`ReviewModelRouter.ResolveAsync(ReviewJobView)` 保留。

## 2 测试与验证

- 新增 2 条：快照重载使用冻结 actor/budget account 解析；无 actor 快照返回 typed `review.actor_unavailable`；并断言证据读取后的快照携带 actor。
- `ReviewModelRouterTests`（6）+ `ReviewEvidenceReaderTests`（8）**14/14**。
- Platform S5 切片 **123/123**；全解决方案构建：首次 restore 出现 Guardian/ExitObserver 的 RID 资产竞态（NETSDK1047），`dotnet restore` 后 `--no-restore` 构建 **exit 0**；一键脚本 RunId 20261106-r17 exit 0（组件 274 + Platform 123 + 前端 47 + tsc）。
- 证据：`.work/pa03/binder-actor/`、`.work/verification/binder-actor-solution/`、`.work/pa08/components-20261106-r17/`。

## 3 未完成

- live `IReviewEvaluationBinder`（`ModelEvaluationService` + `IModelResourcePool` + 唯一持久预留）仍未实现；真实 `IAgentModelPolicyStore` 适配仍缺；Review Worker 不注册。
- 流式/子代理预算、Goal 自动续跑、08B/08C（NotRun）保持原状。
