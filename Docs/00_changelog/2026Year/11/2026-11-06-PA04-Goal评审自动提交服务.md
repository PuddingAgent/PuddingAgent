# PA-04 Goal 评审自动提交服务

为“半交付 A → 评审缺 B → 自动补 B”补上提交入口（服务层，尚未接入结算事务）；未 commit、未部署、未调用真实模型。

## 1 服务

- 新增 `GoalReviewSubmissionService`（`PA-04 → PA-03` seam）：
  - 输入冻结的 Goal 迭代身份（GoalRun/Workspace/Task、ActivationEpoch/IterationNo/ObjectiveVersion、验收合同/artifact/policy 版本、actor、Goal 根预算、deadline）；
  - 生成确定性 `JobId/ReviewId/OperationId`（基于上述版本字段的 SHA-256），调用 `ReviewJobStore.CreateOrGetAsync`；
  - 同内容重复提交 → 同一 Job（幂等）；artifact/版本变化 → 新逻辑键 → 新 Job；
  - actor/BudgetAccountId 必填且来自请求（由调用方从 Goal 记录/宿主绑定传入），服务不臆造 actor 或预算。

## 2 测试与验证

- `GoalReviewSubmissionServiceTests` 4/4（真实 SQLite）：创建单个 Required Job（actor=`actor-1`、budget=`goal:goal-1`、key=Goal 版本）、重复提交幂等、缺 actor/过期 deadline 拒绝、artifact 变化产生新 Job。
- Platform S5 切片 **151/151**；全解决方案构建 exit 0（restore + --no-restore）；一键脚本 RunId 20261106-r26 exit 0（组件 274 + Platform 151 + 前端 47 + tsc）。
- 证据：`.work/pa04/goal-review-submission/`、`.work/verification/review-submission-solution/`、`.work/pa08/components-20261106-r26/`。
