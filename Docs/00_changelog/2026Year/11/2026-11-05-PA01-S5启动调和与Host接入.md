# PA-01 S5 启动调和与 Host 接入

- 新增 `ExecutionBudgetReconciler`：启动扫描全部账本账户，仅处理 unsettled 预留 —— 未派发（Pending）安全释放并退款；已派发（Dispatched）记为 Unknown（预算保持不可用、**绝不退款**）；已有 Unknown 保留为恢复候选；并发结算/冲突只计入保留，不伪造成功。整轮幂等。
- `ExecutionBudgetStore` 增加 `ListAccountIdsAsync` 供调和器枚举账户。
- Host 接入：DI 注册 `ExecutionBudgetReconciler`，并在 schema bootstrap 之后（`PuddingApplicationInitializer`）执行调和；Host 构建 exit 0。
- 测试：`ExecutionBudgetReconcilerTests` 3 条（真实 SQLite）：Pending 释放 + Dispatched/Unknown 保留 800 Unknown 且不退款、二次运行 no-op、已结算不被触碰；与 Store 测试合计 `--filter ExecutionBudget` **15/15 通过**。
- 取红：把已派发分支改成 `ReleaseAsync`（退款）后测试变红；还原后哈希一致。
- 冻结清单：Host DI/启动文件属配置 API P0/P1 清单；本次新增 reconciler 注册与启动调用（diff 已核对），按任务书 01 §5 由主代理审阅更新基线指纹，三条冻结检查 3/3 PASS。
- 未完成：`ExecutionRunCoordinator`/`ExecutionUsageBudgetTracker` 迁移到异步预留/派发确认（禁止 `.Result/.Wait()`）、PA-03/04/07 S5。
