# PA-08A 执行评审只读 API 端点

- 新增 `ExecutionReviewController`：`[Authorize] GET /api/v1/execution-reviews/{reviewId}?stale=` → `{ review: ExecutionReviewSnapshot }`；非法 id → 400，缺失 review → 404 `review_not_found`，快照不可用 → 503 `review_unavailable`；不暴露任何控制变更。
- 测试：`ExecutionReviewControllerTests` 2/2（200 快照字段与金额；404/400 错误映射）。Host 构建 exit 0，控制器按程序集扫描自动注册。
- 未完成：前端 hook/聊天挂载（08A 集成）、08B/08C/08D。
