# PA-07 07B 扩展注册与管道组件

- 新增 `PuddingInvocationPipeline.Contracts/ExtensionPorts.cs`（BCL-only 扩展端口）与 `PuddingInvocationPipeline`：
  - `ExtensionRegistry`：按 point 生成不可变快照；重复/非法描述符拒绝；observed generation 围栏；源失败 typed（不静默变空插件集）；副作用前二次 `EnsureGeneration`。
  - `ExtensionPipeline`：Guard → Transform → Advice → Observer 排序（同类按优先级降序、id 稳定）；未授权扩展只进 `Skipped`、不静默改写；`ValidateTransform` 禁止修改 toolCallId/授权/真实退出码/预算归属/failureCode，禁止把失败改成成功。
- 测试：`PuddingInvocationPipelineTests` 9/9 通过。
- 取红（隔离副本 `.work/pa-07/mutation-07b-runs/`）：Guard 排到最后、忽略 grant、允许改保护字段、接受过期 generation —— 均使对应测试变红。
- 未完成：真实 `PluginManager` 集成、generation/卸载生命周期 S5、AgentSdk `PluginEvents/PluginJobs/PluginExtensions` 契约扩展、Worker fixture 验收；07A S5 outbox 分发插件事件仍待接入。
