# PA-03 S5 完成事件产品 Sink 与分发接入

- 新增 `ConversationReviewCompletionSink`（`IReviewCompletionSink`）：把完成事实写成 Goal 当前会话的 canonical `review.completed` 事件（稳定 EventId + finding/level/revision/完整逻辑键 payload，`SourceKind=Goal`）；Goal/会话不可解析 → typed 失败，outbox 保持未发布并重试，绝不静默丢弃。
- Host：DI 注册 sink 与 `ReviewEventDispatcher`（分发仍由宿主调度器驱动，本轮未加 HostedService）。
- 测试：`ConversationReviewCompletionSinkTests` 2/2（真实 SQLite conversation event store：事件类型/payload 字段/EventId；无 Goal、空会话、无 GoalRunId 均为 typed 失败）。
- PA-03 S5 累计测试：30 条（store 8 + worker/outbox 5 + executor 4 + evidence 4 + objective 3 + dispatcher 4 + sink 2）。
