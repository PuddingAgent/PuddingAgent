# PA-05A 授权判定与审批生命周期组件

- 新增 `Source/PuddingAuthorization.Contracts/AuthorizationPorts.cs`（BCL-only 授权/审批端口）与 `Source/PuddingAuthorization`（`AuthorizationEvaluator`、`ApprovalCoordinator`），未改 Host/DI/既有授权实现。
- 语义：系统 Deny 不可被插件 Allow 或已批准审批覆盖；插件/工作区规则只能收紧；无规则默认拒绝；策略版本过期/源失败为 `Unavailable` 且不 fail-open；规则过期忽略；批准绑定动作/资源/参数 hash/策略版本/有效期，未决/过期/不匹配不授权；审批请求按 OperationId 幂等，仅宿主/系统身份可决定，决定按 revision CAS。
- 测试：`Source/PuddingAuthorizationTests` 15/15 通过（构建 exit 0、0 警告）。
- 取红（隔离副本 `.work/pa-05/mutation-auth-runs/`）：允许 Allow 覆盖 Deny、忽略插件 Deny、批准不绑定参数 hash、忽略过期、源失败 fail-open、插件可自行审批 —— 均使对应测试变红。
- 未完成：S5 适配（接既有 `ToolPermissionPolicyService`/`AgentFirewall`/审批服务、UI 身份与存储）、05B~05F 抽取。
- 未 commit；证据 `.work/pa-05/run-05a-auth/`、`.work/pa-05/mutation-auth-runs/`。
