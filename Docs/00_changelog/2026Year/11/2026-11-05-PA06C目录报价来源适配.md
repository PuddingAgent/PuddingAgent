# PA-06C 目录报价来源适配

- 新增 `CatalogModelQuoteSource`（`IModelQuoteSource`）：从受权能力目录按 `ModelQuoteRequest` 冻结报价；只有 **精确 revision、币种一致、派发时刻在有效窗口内、价格已知** 才返回报价；缺失/不匹配/窗口外返回 `null`（无报价），**不把未知价格映射为零**；只有 `ExplicitFree` 才允许零单价；`CacheHitPerMillion` 缺省回落到输入价；报价含 QuoteId/BaseUnit/窗口/时区/来源/PricingRuleVersion/FrozenAt。
- 测试：`CatalogModelQuoteSourceTests` 5/5（有效窗口、缺价/revision/币种/目录缺失、窗口外、ExplicitFree 零价、非法请求 typed）。
- 未开始：真实目录来源接入、报价与 PA-01 预留的跨窗口原子调整、Host DI 注册。
- 未 commit；证据 `.work/pa-06/s5-quote-source/`。
