# PA-01 预算只读 API 适配与 PA-08 查询服务

- `ExecutionBudgetApiAdapter`（`IExecutionBudgetApi`）：持久账本 → 公共只读预算快照；Unknown 保持 Unknown（不置零）、缺账户 null、取消标记与 revision 原样。
- `ExecutionReviewQueryService`：按 reviewId 解析 Job → 预算 → 最新 `review.completed` 投影 → `ExecutionReviewAssembler` 快照；缺 Job/预算返回明确 missing reason，不伪造空快照；`IReviewGoalConversationResolver` 负责 goal→conversation，映射缺失为 null。
- Host：DI 注册预算 API 适配器、conversation resolver 与查询服务（HTTP 端点待接，前端 hook 待接）。
- 测试：`ExecutionBudgetApiAdapterTests` 2/2（真实 SQLite）、`ExecutionReviewQueryServiceTests` 3/3（fake ports，含 stale 标记与 missing reason）。
- 未完成：HTTP 控制器/前端 hook/聊天挂载、PA-03 runtime binder/worker 注册、PA-04 接入 Goal 状态机、08B/08C。
