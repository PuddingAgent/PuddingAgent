# PA-06C 报价跨窗口派发调整

- 新增 `QuoteWindowAdjuster`：派发时冻结报价仍 `IsUsableAt` → **Keep**；过期则用刷新报价计算成本与预留差额 → **Requote**（差额可正可负，原子调整 PA-01 预留）；刷新报价缺失/价格未知/币种空 → **Block(PriceUnknown)**；差额超出剩余预算 → **Block(QuoteCapExceeded)**，**绝不复用旧低价**；提供按 BaseUnit 与 cache-hit 单价的成本计算。
- 测试：`QuoteWindowAdjusterTests` 6/6（保留、窗口过期重报价、缺价/未知区块、预算不足、降价释放、cache-hit 计价）。
- 未开始：真实目录来源接入、与 PA-01 账本的实际预留调整调用、Host DI。
