# 2026-11-20 提交门禁区分环境门控与零执行

## 目标 / 背景

`Tests/PuddingPluginAgentApi.IntegrationTests` 声明 `<UseVSTest>false</UseVSTest>`（MTP），
而 .NET 10 SDK 的 `dotnet test` 在 MSBuild 目标层直接拒绝 VSTest 目标（exit 8，无 TRX）。
门禁对此有 MTP 回退，回退确实被走到了——阻塞信息来自 `Read-TestRun`，只有 MTP 路径能产生它。

真正的原因在被解析的 TRX 里：

```
<ResultSummary outcome="Failed">
<Counters total="4" executed="0" passed="0" failed="0" notExecuted="4" ... />
<RunInfo outcome="Error"><Text>Exit code indicates failure: '8'. ...</Text></RunInfo>
```

该工程 4 个用例全部依赖 `PUDDING_PLUGIN_WORKER`，未设置时走 `Assert.Inconclusive`。
MSTest 4 把 Inconclusive 记成 `notExecuted`，于是整跑呈现「total>0 / executed=0」，
`ResultSummary` 的 `outcome` 是 `Failed`，MTP 又以 exit 8 登记一条 run-level Error。

旧逻辑只有一个条件同时承担两件事：

```powershell
($executed -le 0 -and -not $AllowZero)
```

它把「什么都没发现」和「发现了但一条都没跑」折叠成同一种阻塞，于是这个工程**永远提交不了**
（`outcome` 期望 `Completed` 实得 `Failed`、runErrors=1），任何触及它的提交只能 `--no-verify`。

## 改动

只改 `TestScripts/check-staged-tests.ps1`，三处：

- `Read-TestRun` — 把计数合法性校验与零执行判定拆开。新增环境门控判据
  `total > 0 且 executed = 0 且 notExecuted = total`，命中则 `Write-Warning` 明示
  「N/N test(s) not executed」并返回 `Gated = $true`，不再要求 `outcome`/退出码匹配。
- 零执行判定保留为独立分支：`total = 0` 或 `notExecuted < total` 时仍然抛
  「zero tests executed」。**静默零执行这个洞没有被放松**，那正是门禁存在的理由。
- `Invoke-TestProject` — 若过滤跑已判定为环境门控，直接返回，不再徒劳跑一遍无过滤的同工程。
- 汇总行 — 门控工程打印 `environment-gated: N test(s) not executed` 而不是 `executed 0 test(s)`。

## 验证

用真实产物取证，不是构造的夹具：

- MTP 实跑该工程（无过滤）→ TRX `total=4 / executed=0 / notExecuted=4`；
  MTP 实跑 `--filter` 匹配不到任何用例 → TRX `total=0`。
- 探针通过 PowerShell AST 从**仓库里的脚本原文**提取 `Read-TestRun` 再执行（不复制函数体，
  避免探针与被测代码漂移）：
  - 门控 TRX：`VERDICT=RETURNED` / `GATED=True` / `TOTAL=4`，并打印 environment-gated 告警。
  - 零执行 TRX：`VERDICT=THREW`，消息含 `zero tests executed` ⇒ 洞仍然关着。
- 变异取红：把 `$total -gt 0` 改成 `$total -gt 1000000` → 门控 TRX 立刻 `VERDICT=THREW`，
  抛出的正是改动前那条阻塞消息；还原后 SHA-256 与变异前**比特一致**
  （`b1654175…208d06`），再次 `VERDICT=RETURNED`。
- 解析校验：`[Parser]::ParseFile` 结果 `SYNTAX_OK`。

## 影响与回滚

- 只影响提交门禁本身，不改变任何产品代码或被测用例的判定。
- 放行的只是「一个都没跑」且「确实发现了用例且全部被跳过」的情形，并把这件事打到输出里；
  真正的零发现依旧阻塞。
- 回滚：`git revert` 本提交。
