# PA-06B 模型能力目录只读适配

- 新增 `ModelCatalogAdapter`（`IModelCatalogApi`）：`ListAsync` 只映射受权能力字段（id/revision/上限/模态/工具/结构化/可用性/价格来源/ExplicitFree/币种/单价），不返回 endpoint/API token；查询边界校验在源之前；源失败 typed，不返回空目录冒充成功。
- `ResolveAsync` 明确**不伪造**：按 Purpose 选择模型需要宿主绑定调用方 actor，本适配器拿不到该身份，返回 typed `model.scope_forbidden`，不用 agent id 冒充 actor（决策项）。
- 测试：`ModelCatalogAdapterTests` 4/4（字段映射/排序、边界前置校验、源失败 typed、Resolve typed scope_forbidden）。
- 未开始：`IAgentModelPolicyStore` 真实适配与 actor 绑定、Host DI 注册、06C 报价/预留跨窗口。
- 未 commit；证据 `.work/pa-06/s5-catalog-adapter/`。
