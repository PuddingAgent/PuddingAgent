# 最小工具内核与产品插件验收

`PuddingHost/ToolPackages`（位于 `Source/`）将本次清点的 142 个业务工具分为 19 个随包插件。产品注册八个发现、审批和生命周期工具。`HostToolContributions` 按作用域提供第一方导出，`HostToolMounts` 在卸载时撤销新调用并等待在途调用。现有宿主服务继续承载第一方工具实现，SDK DLL 在随包独立 Worker 中执行。

配置端可选择已安装工具。模型可见清单依据当前激活、工具选择与执行能力生成，执行时再次校验。`AgentRuntimeProfileResolver` 从 Agent 明确保存的 Shell 配置生成权限。原有 Task 角色兜底与 Shell 权限推导已移除。代理加载 DLL 仍要求进程执行权限和已批准的加载操作。

Windows 实测使用隔离的数据根、真实产品 Core、SQLite、Worker 和本地 HTTP 模型替身。22 项断言覆盖安装清单、匿名与未批准拒绝、配置及默认选择、跨会话隔离、Shell 不可见且直接调用被拒、文件内容回读、Worker 计算回执、Agent 卸载及卸载后的模型请求。插件运行时 35 项、模型配置解析 4 项、子代理与防火墙定向 33 项通过。DesktopChild 组合根测试体实跑通过。证据在 `.work/plugin-product/r1/`，一键复跑见[运行手册](../../../04_tools_and_skills/运行时工具插件.md)。

本次没有运行外部付费模型或部署到用户日常实例。服务型插件的业务程序集仍跟随宿主发布，声明式挂载可热切换导出。验证范围不含每个外部业务系统的实机操作。
