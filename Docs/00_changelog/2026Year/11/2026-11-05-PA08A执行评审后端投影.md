# PA-08A 执行评审后端投影

- 新增 `Pudding.Api.Contracts/ExecutionReview.cs`：冻结面板只读 DTO（run/review 状态、预算 Limits/Actual/Reserved/Unknown、模型策略、取消、新鲜度、模型建议、失败检查）。
- 新增 `ExecutionReviewAssembler`：权威预算/评审/取消/新鲜度 → `ExecutionReviewSnapshot`。规则：未知成本桶非零时 `Unknown` 为 `known=false/amount=null`；只有 `Satisfied+CheckVerified` 才映射为 satisfied，建议级 Satisfied → needs-user；缺评审/Job → unknown（不伪造）；stale/gap 明确标注；取消请求不清理占用。
- 测试：`ExecutionReviewAssemblerTests` 6/6；取红 2/2（禁用 CheckVerified 门；未知成本按 0 渲染）。
- 未完成：把该投影接到真实 API/前端 hook 与聊天挂载（08A 集成）、08B/08C/08D。
- 未 commit；证据 `.work/pa-08/s5-assembler/`。
