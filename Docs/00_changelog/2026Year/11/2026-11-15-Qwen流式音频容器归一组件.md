# 2026-11-15 Qwen 流式音频容器归一组件

真实调用补查发现 Qwen3 TTS 的 SSE 首块为 `RIFF/WAVE`，数据长度使用流式占位值。若将容器头当作采样播放，会产生开头噪声。

- `PcmStreamDecoder.cs`、`QwenTts.ReadPcmAudioAsync`：跨 SSE 帧累积并剥离 WAV 头，验证 PCM16、单声道与期望采样率；兼容裸 PCM，保留增量输出和取消。
- 更新组件与测试代码地图；组件仍为 BCL-only，无宿主引用。
- 独立测试 15/15 通过，新增占位长度/跨帧头、错误采样/截断、正常音频无需等待流结束三项用例。日志在 `.work/asr-tts/20261115/component-pcm.log`。
- 本提交只完成独立组件验证；Runtime 调用切换与真实部署复验在后续接入提交中完成。
