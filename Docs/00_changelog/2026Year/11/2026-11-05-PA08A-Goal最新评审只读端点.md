# PA-08A Goal 最新评审只读端点

- `ReviewJobStore.GetLatestByGoalAsync`：按 accepted_sequence 取某 Goal 的最新评审 Job（`IReviewJobByGoalReader`）；缺失返回 null。
- `ExecutionReviewQueryService.GetLatestForGoalAsync`：复用同一投影/装配路径；无效 id → RequestInvalid，缺失 → NotFound，不伪造快照。
- `GET /api/v1/goals/{goalId}/execution-review?stale=` → 200 快照或 404 `execution_review_not_found`；Host DI 注册 `IReviewJobByGoalReader`。
- 测试：`ExecutionReviewGoalLookupTests` 3/3（store 排序/缺省、query service、controller 200/404）。
