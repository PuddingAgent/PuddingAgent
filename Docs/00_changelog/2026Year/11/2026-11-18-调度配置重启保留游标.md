# 2026-11-18 调度配置重启保留游标

## 改动

`Source/PuddingScheduling/SqliteScheduleStore.cs` 用单条 SQLite upsert 同步调度定义。相同定义保留游标，时间或任务定义变更重算游标并递增版本，旧快照提交会被拒绝。

## 验证

独立调度测试 55/55 通过。新增真实 SQLite 用例覆盖重启复用原游标及定义变更后的旧计划拒绝。
