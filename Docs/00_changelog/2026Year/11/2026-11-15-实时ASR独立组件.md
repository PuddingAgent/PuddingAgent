# 2026-11-15 实时 ASR 独立组件

- `QwenAsr.cs` 新增持续 PCM 流入口，复用既有 run/finish 协议；输入流尚未关闭时即可产出中间文字，输入关闭才发送 finish-task，取消则释放连接。
- `RealtimeAsrSession.cs` 定义服务商无关端口与单次录音状态机：按句 ID 替换、确认句去重、有界队列/时长、停止最终排空、取消丢弃与失败终态。
- 更新组件与测试代码地图；本切片只修改独立组件及其测试，未接入宿主。
- 独立测试 23/23 通过，包含 8 项实时链路用例；边界仍为 BCL-only、零 ProjectReference/PackageReference。日志在 `.work/asr-realtime/20261115/component.log`。
- 后续接入浏览器 WebSocket、统一服务、实时草稿和部署验收；本提交不声称产品已具备实时录音。
