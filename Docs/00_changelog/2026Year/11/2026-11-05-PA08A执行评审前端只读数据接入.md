# PA-08A 执行评审前端只读数据接入

- `src/services/platform/api.ts`：新增 `ExecutionReviewSnapshotDto` 等 DTO 与 `getExecutionReview(reviewId, {stale, signal})`，调用受权只读端点。
- `src/pages/chat/utils/executionReviewView.ts`：纯映射 `ExecutionReviewSnapshotDto → ExecutionReviewView`；未知状态收敛为 `unknown`；**未识别金额不置零**（known=false → amount=null）；stale/gap 原样传递；不推导控制结论。
- `src/pages/chat/hooks/useExecutionReview.ts`：单次读取、不轮询、不重试；过期响应按请求序号丢弃，卸载/切 review 时 abort；缺失返回 `review_not_found` 错误而不伪造快照。
- 测试：`executionReviewView.test.ts` 5 条 + `useExecutionReview.test.ts` 3 条，Jest **8/8**；`pnpm exec tsc --noEmit` exit 0。
- 前端版本 `6.14.0 → 6.15.0`（新增功能文件）。
- 未完成：聊天挂载（`ChatMain`/`ConversationProcessDetails` 集成与前端 build）、08B/08C/08D；后端控制器已就绪。
- 未 commit；证据 `.work/pa-08/s5-frontend/`。
