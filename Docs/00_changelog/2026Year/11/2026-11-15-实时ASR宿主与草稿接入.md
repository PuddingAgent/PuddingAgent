# 2026-11-15 实时 ASR 宿主与草稿接入

## 改动

- Runtime 的 Qwen Message 适配器实现独立组件定义的实时 PCM 端口，统一服务按默认路由解析能力。业务、UI 不选择供应商；原完整录音入口继续使用同一协议实现。
- Platform 新增授权 POST `/api/voice/asr/ticket` 与 WebSocket `/api/voice/asr/stream`。30 秒、单次使用凭证在首帧提交，同源检查，凭证不入 URL；PCM、控制消息和错误均为供应商中立协议。
- AudioWorklet 每块音频立即上传，不保存完整录音；停止 flush 后等待 completed，取消可中止权限/连接启动、录音或最终排空。客户端、服务端均限制积压并释放麦克风与连接。
- 主输入框实时替换语音区间、显示确认字数；停止保留最终文字，取消移除本次语音插入并保留原稿与区域外编辑，失败只保留确认文字。编辑语音区域或启动 IME 时保留编辑并结束录音；切会话隔离迟到回调。
- 修正 Ant Design TextArea ref 为真实 DOM，使用实际光标位置；命令式草稿写入同步更新读引用，防止连续转写事件重复或冲突。转写期间阻止发送未确认草稿。
- 语音面板同步启动取消和停止/取消语义，不再标记错误的 browser/web-speech 供应商元数据。前端版本递增到 **6.18.0**。
- 更新相关代码地图与语音诊断手册。

## 验证与交付状态

- 组件 25/25，先独立测试再接入；编译边界反向引用探针实际报 `PUDDING001`。

- TypeScript、pnpm 构建与包体积门禁通过。宿主组合根通过隔离控制台调用现有真实 xUnit 方法，新增实时服务/凭证单例解析断言通过；不将该定向探针算作完整宿主套件。
