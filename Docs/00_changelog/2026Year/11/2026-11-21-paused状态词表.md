# paused 运行状态（P0-b1）

## 为什么

检测器（P0-a，已交付）判定「原地打转」后要能**暂停**子代理并通知父代理裁决。
但「暂停」必须先有地方可写：状态词表里原来只有 running + 6 个终态，没有暂停这一档。

设计裁定（`子代理生命周期护栏-2026-11-21.md` §五）：`paused` 与 `budget_exhausted` **并列** ——
两者停止原因不同（预算用尽 / 重复输出被叫停），但对调度与使用方一样：**执行已停、上下文仍热、靠 resume 恢复**。
所以它是**终态 + 可续跑**，不是"运行中的一种"。

## 改了什么

**单一真源（`SubAgentRunEntity`）**

| 成员 | 内容 |
|---|---|
| `TerminalStatuses` | 加入 `"paused"`（现 7 项） |
| `NonTerminalStatuses` | 仍只有 `running` —— paused **不在**其中 |
| `ResumableStatuses`（新增） | `["budget_exhausted", "paused"]` |
| `IsTerminalStatus` / `IsResumableStatus`（新增） | Ordinal 精确比较，null → false |

**替换散落字面量**（这些位置原先各写一份，新增一个可续态就会漏掉某一处）

- `SessionStateManager`：重复终态守卫、`resumable` 判定、状态投影 switch（新增 `"paused" => "paused"`）
- `SubAgentManager`：终态事件 switch、`resumable` 判定
- `FileSubAgentRunStore.IsTerminalStatus` 改为委托实体方法

**活动状态投影**（新增 `ToActivityStatus` / `ToActivitySummary`）

- `completed` → `Succeeded`；`IsResumableStatus` → `Deferred`；其余 → `Failed`
- 两种可续态的摘要**分开写**：预算耗尽要「补预算后 resume」，异常暂停要「裁决 resume / sleep / destroy」。
  合并成一句，裁决者就不知道自己该做什么。

**事件类型**：`ConversationEventTypes.SubAgentRunPaused` + `EventSchemaRegistry` 注册（版本 1）。
实测：未注册时 `GetSchemaVersion` 返回默认 1、**不抛异常**，但 `IsValidEventType=false`（也就是"发得出去但没人认识"），故按相邻格式注册。

**刻意不改**：`SubAgentTransientDirectoryGcService` 不把 `paused` 纳入回收集 —— 热暂停的现场（临时目录、事件流）要留着供 resume。只加注释说明口径更窄。

## 三处值得记住的判断

**一、`ToTerminalEventType` 对未知状态保持 fail-fast**

默认分支抛 `ArgumentOutOfRangeException` 是故意的。返回默认事件类型会把「上游自己造了个新词」写成一条看起来正常的终态事件，之后再也查不出哪一步走偏。

**二、`NormalizeSubAgentTerminalStatus` 排除 `interrupted`**

子代理原本把它改成「凡终态即放行」——那样 `interrupted` 也放给了 Runtime 上报，等于允许调用方伪造「上次进程崩了」。
已收窄为 `IsTerminalStatus(x) && x != "interrupted"`，保留 2026-11-21 之前的既有行为。

**三、`paused` 退出 `NonTerminalStatuses` 正是为了恢复安全**

`FileSubAgentRunStore.RecoverInterruptedRunsAsync` 的跳过判据是「终态即跳过」。
paused 一旦进终态，重启就**自动**不会把它翻成 `interrupted`；另一条恢复路径（`SessionStateManager.RecoverInterruptedSubAgentsAsync`）只取 `status=="running"`，同样不碰它。两处都有测试锁住。

## 验证

```
dotnet build Source/PuddingPlatform/PuddingPlatform.csproj -t:Rebuild      → 0 错误
dotnet build Source/PuddingPlatformTests/PuddingPlatformTests.csproj -t:Rebuild → 0 错误

```

三处变异取红（子代理两处 + 父代理独立一处）：

| 变异 | 结果 |
|---|---|
| 从 `TerminalStatuses` 移除 `paused` | 至少 3 条红（终态判定 / 恢复跳过 / 投影） |
| 从 `ResumableStatuses` 移除 `paused` | 至少 3 条红（可续跑 / Deferred / 摘要区分） |
| **父代理独立**：`ToActivityStatus` 的 `Deferred` 改成 `Failed` | **失败 3 / 通过 19**，命中的正是「paused 必须投影为 Deferred 而不是 Failed」两组用例（paused 与 budget_exhausted 各一条）+ 摘要区分用例 |

复原后 `SubAgentManager.cs` SHA `C7A2AADA…` 逐位一致，`-t:Rebuild` 后 22/22 复绿。

## 遗留（P0-b2 / P0-b3）

1. **检测器仍未接线**：`paused` 目前没有生产者，行为变化为零。
2. **读模型投影未接**：`ConversationEventContracts` 是数字枚举（`SubAgentRunBudgetExhausted = 37`），
   加一种事件要连带改 `ConversationReadModelEventMapper` / `AgentConversationProjectionService`(x4) /
   `ConversationOpenQueryService` / `ConversationDiagnosticEventProjector`(x2) + 前端 —— 留 P0-b3。
3. **前端无暂停徽标与 resume 入口**：同 P0-b3。
4. `AgentExecutionService` 有 Buffered / Streaming 两条并行路径，P0-b2 接线必须双路径覆盖。
