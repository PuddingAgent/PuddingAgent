# PA-08A 执行评审面板聊天挂载

- 新增 `ExecutionReviewSection`：Goal 详情 Popover 内只读小节，用 `useGoalExecutionReview(goalId)` 单次读取 `GET /api/v1/goals/{goalId}/execution-review`；映射到冻结 panel；**无投影/错误时不渲染伪造视图**；证据点击只展示已获引用（不 fetch/不执行工具）。
- `GoalBanner` 在 `GoalStepsPanel` 之后挂载小节；Popover 内容首开才渲染 ⇒ 请求仅在用户展开详情时发生（不进入聊天首屏链路）。
- `src/services/platform/api.ts` 增加 `getExecutionReviewByGoal`；新增 `useGoalExecutionReview`（不轮询/不重试、过期响应丢弃、卸载 abort）。
- 测试：`ExecutionReviewSection.test.tsx` 3 条 + 既有 `GoalBanner.test.tsx` 全量 → Jest **21/21**；`pnpm exec tsc --noEmit` exit 0。
- 未完成：前端 build/产物部署与版本徽标核对（08B/08C/08D 需用户授权与测试配置）。
