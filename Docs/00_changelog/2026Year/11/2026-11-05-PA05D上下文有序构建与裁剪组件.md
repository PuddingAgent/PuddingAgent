# PA-05D 上下文有序构建与裁剪组件

- 新增 `Source/PuddingContext.Contracts/ContextPorts.cs`（BCL-only 上下文端口）与 `Source/PuddingContext`（`ContextContributionValidator`、`ContextAssembler`）；未改 Host/DI/既有上下文管线。
- 语义：canonical 历史必须按严格递增顺序且以当前用户围栏结束、围栏 hash 必须匹配；外部/记忆/工具/调用方内容只能以 Tool 身份出现，不得冒充 user/system；贡献 id 唯一、字段有界、内容 hash 必须匹配；贡献按优先级降序 + id 稳定排序、只裁剪最低优先级；canonical 历史单独超预算或贡献超自身上限 → typed 失败，绝不静默截断；Tokenizer 失败/取消不吞。
- 测试：`Source/PuddingContextTests` 10/10 通过（构建 exit 0、0 警告）。
- 取红（隔离副本 `.work/pa-05/mutation-context-runs/`）：允许外部数据冒充 user/system、围栏不校验、忽略预算、忽略贡献上限、不校验内容 hash —— 均使对应测试变红。
- 未完成：S5 适配（接既有 `ContextAssemblyService`/压缩/记忆/Tool data 来源）、05B/05C/05E 抽取。
