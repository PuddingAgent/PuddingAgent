# PA-06 06A 模型策略补丁 CAS 应用

- 新增 `ModelPolicyPatchApplier`：`UpdateModelPolicyCommand` 校验（operation id/apply policy/revision 有界；1~32 条 patch；purpose 必填且不重复；Clear 不得与 ModelId/InheritPrimary 组合；非 Clear 必须 set 或 inherit），并以 `InstanceRevision` 做 CAS 应用；只修改 instance 层，workspace/system 层保持原样；返回 `PersistedRevision/AppliedRevision/AppliesFromNextRun/PolicyGeneration`。
- 测试：`ModelPolicyPatchApplierTests` 3/3（Set/Clear/Inherit、矛盾/重复/空 patch、revision 冲突与非法 apply policy）。
- 未完成：真实配置文件的 `IAgentModelPolicyStore` 适配（需与既有配置权威的集成决策）、06B/06C Host 适配。
