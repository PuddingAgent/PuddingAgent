# PA-07A S5 插件后台任务持久协议接入

- 新增 `Source/PuddingPlatform/Services/Plugins/`：
  - `PluginJobStore`（`IPluginJobStore`）：Submit 只持久受理并立即返回票据（不等完成）、按 (workspace, operation) 幂等且同键换内容冲突；取消为非阻塞独立路径；取消/状态迁移都按 plugin generation 围栏；终态不可回退；过期任务不能被标记成功。
  - `PluginJobSchemaBootstrapper`：`plugin_jobs`/`plugin_job_operations` 幂等建表与索引；`Data/Entities/PluginJobEntities.cs` + `PlatformDbContext` 两个 DbSet。
- Host：DI 注册 `PluginJobStore`/`IPluginJobStore`；启动 schema 阶段调用 bootstrap；Host 构建 exit 0。
- 测试：`PluginJobStoreTests` 5/5（真实 SQLite：幂等/冲突、查询与 workspace 排序、generation/状态机围栏、取消、过期不可成功）。
- 未完成：插件任务 Worker/租约执行、事件订阅 outbox/checkpoint（07A 剩余）、真实 PluginManager 生命周期。
- 冻结清单：Host DI 文件属 P0/P1 清单，主代理审阅后更新基线；三条冻结检查 3/3 PASS。
- 未 commit；证据 `.work/pa-07/s5-jobs/`。
