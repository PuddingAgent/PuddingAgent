# 2026-11-15 独立语音协议组件 S1–S4

新增 `Source/PuddingSpeech/` 与 `Source/PuddingSpeechTests/`：零项目/包依赖的语音叶子组件，以及只引用该组件的测试工程。包含实际 WAV/PCM 校验、服务商无关的错误、Qwen Message ASR 的 run/finish 排空与取消、显式 Qwen TTS 请求和增量 SSE 解码。两个工程各有 code_map。

## 验证

- 独立构建成功；MTP 独立运行 12 项测试，12 通过、0 失败、0 跳过。
- 默认 VSTest 在当前 Windows 环境因监视父进程权限而中止；改用 `dotnet run --project Source/PuddingSpeechTests/PuddingSpeechTests.csproj --artifacts-path .work/asr-tts/20261115/build -p:UseVSTest=false -p:CollectCoverage=false -- --report-trx --results-directory .work/asr-tts/20261115/results` 实际执行测试，没有将测试中止算通过。
- 引用门禁正向断言通过；向组件临时注入 Runtime 引用后，`EnforceReferenceDirection` 应报 PUDDING001，取红结果在接线前确认。临时引用随后恢复。
- 日志与 TRX 留在 `.work/asr-tts/20261115/`。
