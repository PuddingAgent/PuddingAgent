# 新增桌面能力一致性清单（强制）

**结论先行**：新增一个能力**不是"加个枚举"**，而是**九处同步**；且守卫常**成组出现**（元组 + 名字 + 计数）。**每加一个能力，必须跑一次全量链** —— 逐套件验证会漏（实测漏掉了 `Pudding.DesktopServiceTests` 的 2 条）。

## 一、九处同步

| # | 处 | 内容 | 遗漏会红在 |
|---|---|---|---|
| 1 | `Contracts/Capabilities.cs` 枚举 | `X = 1 << N`（取**当前最高位 +1**） | 编译（`CS0117`） |
| 2 | 同文件 `Catalog` | 描述符 `new(X, "线名", InitialVersion, Kind, Traits)`；**按线名的序数序插入** | `Catalog_IsFrozenSnapshot`、`PolicyTable_IsFrozenSnapshot` |
| 3 | `CapabilityCatalogTests` 冻结快照 | 期望串（**序数序**；`BrowserScreenshot` **在** `BrowserSnapshot` **之前**：`c` < `n`） | `Catalog_IsFrozenSnapshot` |
| 4 | 同测试 `RequiresPageTarget_MarksExactlyTheWebViewCapabilities` | 期望数组（若该能力要页目标） | 同名守卫 |
| 5 | 同测试 `RequiresTrustedContext_IsNeverGrantedToUntrustedTargets` | 期望名单（若标记可信上下文） | 同名守卫 |
| 6 | `Contracts/Desktop/BrowserOperationMapping.cs` | `case X: operation = …; return true;`（**注意：该 switch 无 `break`，落穿会静默映射到上一个 case 的操作**） | `EveryWebViewCapabilityInTheCatalogHasAMapping`（**只查非空 ⇒ 查不出错映射！**） |
| 7 | `DesktopService/DesktopCapabilityChannelSettings.cs` | 授予清单 `| X` | `DeclaredCapabilities_AllHaveAnAdmissionRule` |
| 8 | `DesktopService/DesktopCapabilityPolicy.cs` | 策略表项 `[X] = [信任级别]` | `PolicyTable_CoversEveryRegisteredCapability` |
| 9 | `DesktopService/DesktopService.cs` | 准入规则 `case X:`（可与同类能力**共用**） | 同上 |
| 附加 | `CapabilityBroker.AspNetCore/CapabilityChannelConfiguration.cs` | 握手默认授予（**仅当执行分支已存在**） | 运行时"能力未声明" |
| 附加 | `Pudding.Rpc.Protocol` proto + 三项守卫 | 字段号元组 / oneof 名字 / **oneof 计数** | `WireContractSnapshotTests` 三条 |

## 二、线缆改动的守卫（成组）

| 守卫 | 内容 |
|---|---|
| 字段号元组 | 命令与结果的 `("线名", N)` 列表 |
| oneof 名字列表 | 由生成枚举比对 |
| **oneof 计数** | 显式数字（**只改名字会漏它** —— 实测报 `Expected: 18, Actual: 19`） |

## 三、顺序与语义规则（血泪）

1. **目录按序数序**（`Screenshot` 在 `Snapshot` 前，因 `c` < `n`）；违反⇒冻结快照红；
2. **无 `break` 的 `case` switch：新增 case 的位置决定语义** —— 插在别的 case 之上会**落穿**，静默映射到错误操作；
3. **可选 double 一律 presence**（0 是合法坐标，不能与"未设置"混同）；
4. **失败信息要打印**（`Assert(ok, Describe(result))`）—— 实测两次靠它一行定位根因；
5. **枚举先照抄既有实现**（我曾自造 `Element`，实现是 `FullPage`，等于造平行模型）；
6. **契约与实现同名不同命名空间**要分清（`DesktopScreenshotDetail` vs `BrowserScreenshotDetail`）；
7. **位置记录不能写构造块**，校验一律 `Validate()`，用例**显式调用**；
8. **函数式接线（工厂→不变式）必须有直接断言** —— 编译通过 ≠ 装配正确。

## 四、验证顺序（推荐）

1. 单测目标组件；2. **跑全量链**（`TestScripts/delivery-manifest.ps1`）—— **清单不绿即未完成**；3. 更新 `code_map.md`（就地）；4. changelog 与代码**同 commit**。
