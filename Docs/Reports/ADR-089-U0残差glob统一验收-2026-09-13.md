## 3. canonical 合同（G1 裁决要点）

1. null / 空 / 全空白 → 匹配一切。
2. `**/`、`**\`、前导 `**` 单次剥离（由 matcher 内建，调用方不得再自行剥离）。
3. 通配符仅 `*`（可 0 个字符）与 `?`（恰好一个）；`[ ] { }` 为字面字符。
3a. **整串 `*.*` ≡ `*`**（兼容既有 `filePattern` 默认值，避免静默丢失 `Makefile` 等无扩展名文件；范围严格限于整串）。
4. 不含分隔符 → 按文件名匹配；含分隔符 → 按相对路径匹配（分隔符归一为 `/`）。
5. 无通配符 → 精确匹配。
6. `ignoreCase: true`（Windows First）。
7. 不含通配符时**不**走 glob 语义（见 §4 的 not-glob 契约）。
8. `*` 与 `?` **不跨** `/`（与 gitignore / bash / MSBuild 同构）。
9. 可见性 `public`（供 `PuddingRuntime` 跨程序集消费），**不**为此开 `InternalsVisibleTo`。

## 4. 显式保留项（父级决策，非缺陷）

- **不含通配符的 `pattern` = 大小写不敏感子串包含，不是 glob 合同。**
  依据：`FileSearchTool` 的 `pattern` 语义为「文件名文本」过滤（工具描述与默认值 `*` 佐证），改为精确匹配属未授权行为回归。已在类型级 XML doc 与行内注释写明「not-glob 契约」，并标注 **U1 拆参迁移点**（把「pattern 文本」与「glob 过滤器」拆为两个参数后收口）。

## 6. 登记残差

- **R-G2-1**：`MaxEnumeratedFiles` 只统计命中文件 → glob 命中稀少时失去早期退出（需遍历更多目录）；仍受同一 10s 调用预算约束，超时显式表达为 `timeout`，不静默。缓解留待 U3 索引化。
- **R-G3-1**：`MatchesFileOrPath` 把绝对路径分隔符归一为 `/` 后作 relativePath 传入（含盘符 `c:/...`）；若调用方 glob 亦带盘符需同样归一才能命中。当前仓库无此类调用方（零回归佐证），U1 拆参时需显式复查该约定。
- **R-G3-2**：legacy `SearchAsync` 改全量枚举后过滤，大目录下比 Win32 前置过滤多枚举条目（性能略降），换取正确性；异常处理面与改动前一致（legacy 路径本无 try/catch）。
- **工具观察**：Windows CMD 下 `dotnet test > log 2>&1` 会丢失 stdout 测试摘要（仅 stderr 入日志）；验证时应直接读终端输出或改用 `--logger trx`。
