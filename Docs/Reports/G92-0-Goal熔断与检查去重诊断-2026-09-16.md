- 实测 `dedup_key` = `7ef90f2c…|1|work_unit|1|sha256:4357c6fa09c…|epoch:1:objective:1`

`input_fingerprint` 的生成（`GoalAcceptanceContractPlanner.cs:150-156`）：

```csharp
=> string.IsNullOrWhiteSpace(planFingerprint)
    ? $"epoch:{activationEpoch}:objective:{objectiveVersion}"   // 无绑定 Plan 时的退化值
```

**本项目该 Goal 的 `task` 为 null（缺陷 2b60040d）⇒ 无绑定 Plan ⇒ 退化为 `epoch:N:objective:N`**，实测正是 `epoch:1:objective:1`。
