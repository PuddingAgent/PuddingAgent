**可复用要点（本轮新增的平台知识）**：
1. 平台验证器解析的是**命令输出中的标准化英文摘要**；本地化（zh-CN）或编码错乱的输出会导致 `test_count_unknown` 并判证据不可信。
2. `terminal_start` 有**命令白名单**：`dotnet, git, python, python3, node, npm, npx, pnpm, yarn, bun...`。`.cmd`/`.bat` 被白名单直接拒绝；`powershell` 走审批依赖通道（当前不可达）。
3. **设置环境变量驱动白名单命令的可行姿势**：`file_write` 一个纯 ASCII 的 Python 脚本到 `temp/`，脚本内 `subprocess.run(cmd, env=dict(os.environ, DOTNET_CLI_UI_LANGUAGE='en-US', ...))` 原样透传 stdout 与退出码，再由 `terminal_start(command="python temp/xxx.py")` 执行 —— 全程不依赖 shell / cmd / PowerShell。
4. 同时产出 TRX（`--logger "trx;LogFileName=...trx" --results-directory .tmp-test-out`；`.tmp-test-out/` 已在 `.gitignore`），作为语言无关的第二证据形态。
