## 6. 关键发现 & 优化目标

### 🔴 P0: L6-AGENT-LOG-RECALL 无上限 (max 55,905 tokens)
- **问题**: 日志召回层没有硬上限，极端情况占系统提示词 97%
- **影响**: 单次组装从 ~5K 膨胀到 57K tokens
- **建议**: 设置 5,000 token 硬上限 + Flash 裁剪强制截断
- **预期收益**: 消除 ~50K token 的尾部膨胀

### 🔴 P0: 工具定义不可见且不可控 (~22K tokens, 73%)
- **问题**: 73 个工具的 JSON Schema 占每次调用 73%，但不在层监控中
- **影响**: 心跳/简单对话场景浪费 ~20K tokens
- **建议**: 
  1. 将工具定义纳入 `context_layer_metric_events` 追踪
  2. 按 Agent 角色/任务类型动态加载工具子集
  3. 心跳场景仅加载 ~10 个核心工具
- **预期收益**: 心跳场景 **-15K tokens (-50%)**

### 🟡 P1: subconscious-memory 缓存命中率 0.3%
- **问题**: 873 次调用，几乎每次都是全新 prompt，无 KV-cache 复用
- **影响**: $1.95 费用，1.49M tokens 完全浪费
- **建议**: 统一 subconscious prompt 前缀，或批量处理
- **预期收益**: 缓存命中率 0.3% → 80%+

### 🟡 P1: L2-INHERITED 子代理继承上下文 (avg 10K, max 36K)
- **问题**: 父代理上下文快照过大
- **建议**: 压缩继承上下文，仅传递任务相关摘要
- **预期收益**: 子代理 prompt -50%

### 🟢 P2: L8-RUNTIME 偶发膨胀 (avg 728, max 15,085)
- **问题**: 运行时指令层偶尔膨胀 20x
- **建议**: 排查膨胀原因（可能是 goal.md 历史累积）
